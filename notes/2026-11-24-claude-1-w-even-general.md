# 予想 K46：偶数 w ≤ v−1 のすべての類で型は無限に多い

## 考え方

定理 K44 の証明（Issue #278）の鎖の記述を一般化した。

- q·a + r = s·X（X = 2^N）、m = 3a − 2、M = 3a とする。
- d = (αa − c)/2^K と書き、β = rα + qc とおくと、q·2^K·d = sαX − β が成り立つ。
- 一本道の奇数の段 d → (M+d)/2 では、α → α + 3·2^K なので、β → β + 3r·2^K となる。
- よって、奇数の点での b = β/2^K は b ↦ (b + 3r)/2^{v2(b+3r)} で動く。
- h = (3a − 1)/2 は c = 1、α = 3 で、β = 3r + q。

この形の族に、次の 2 つの条件を課す。

- **(i)** v2(m+1) = v、つまり β = 2^v：q + 3r = 2^v。
- **(ii)** h の鎖が b = 1 にとどまる：1 + 3r = 2^ρ（ρ は偶数）。このとき鎖は 1 段で ρ ずつ進むので、m+2 の連の長さはおよそ N/ρ になる。

この 2 つから q = 2^v − 2^ρ + 1、r = (2^ρ − 1)/3 が決まる。

- ρ = 2 は定理 K36 の族（q = 2^v − 3、r = 1、X = 4^N）。
- v = 5、ρ = 4 は定理 K44 の族（q = 17、r = 5、s = 3）。

## やったこと

- **w = ρ の証明**（手で）：
  - 3a − 1 = (3sX − 3r − q)/q = (3sX − 2^v)/q なので、u = (3a − 1)/2^v = (3sX/2^v − 1)/q。
  - よって u + 1 = (3sX/2^v + 2^v − 2^ρ)/q。
  - 2^v − 2^ρ の付値は ρ（ρ < v）で、3sX/2^v の付値は N − v + v2(s) > ρ（N ≥ v + ρ + 1 のとき）。q は奇数。
  - したがって v2(u+1) = ρ。あわせて v2(m+1) = v2(3a − 1) = v（N > v のとき）。
- **数値**：`code/w_even_family.js` で、v = 5..11 のすべての偶数 ρ < v について調べた（`data/w_even_family.txt`）。
  - q | s·2^N − r かつ a が奇数となる最小の奇数 s を探した。
  - N ∈ [40, 400] の解のうち最初の 6 個（3 個以上あるとき）について、v2(m+1)、w と m+2 の連の最大を求めた。

## 結果

### 予想 K46 `[予想]`

v ≥ 5 が奇数、ρ が偶数で 2 ≤ ρ ≤ v − 1、q = 2^v − 2^ρ + 1、r = (2^ρ − 1)/3 とする。q | s·2^N − r で a = (s·2^N − r)/q が奇数のとき、m = 3a − 2 とする。

- このとき v2(m+1) = v、w = ρ である。これは上で示した（`[非形式証明]`、N ≥ v + ρ + 1）。
- 予想：m+2 の間隔の連の最大は、N とともに限りなく大きくなる（およそ N/ρ）。
- 正しければ、偶数 w ≤ v − 1 のすべての類で型は無限に多い。
- 数値（v ≤ 11）：解が 3 個以上あった 10 組のすべてで、w = ρ で、連の最大が N とともに真に増えた。
  - 連の最大はほぼ (N − c)/ρ。例：v = 7、ρ = 6、s = 11 で、N = 44, 56, …, 104 に対し 7, 9, …, 17。
  - 解がなかった組：(v, ρ) = (9, 2)、(9, 6)、(11, 2)、(11, 4)、(11, 8)。2 の q を法とする位数が大きく、N ≤ 400 に解が 3 個ない。
  - このうち ρ = 2 の組は定理 K36 で済んでいる（X = 4^N の形で解がある）。
