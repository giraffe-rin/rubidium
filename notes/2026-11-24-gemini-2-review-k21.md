### 主張ごとの査読結果

#### 1. 定理 K21（22〜91 行）：**正しい（最後まで確認した）**
- **`v = 1` の場合**：`u = h = (m+1)/2 ≥ 3`（奇数）、`E = m + 2 − 3h = −(h − 1) ≠ 0` ゆえ `ℓ = v2(E) = v2(h − 1) = 2j + 1`（奇数）。査読済み定理 K19 より型は `1^{j+1}0` で始まる（`j + 1 = (ℓ+1)/2`）。密度も `h − 1` が偶数上を一様に動くため `2/3`。正確。
- **`v ≥ 3` の場合**：
  - `h = 2^{v−1}u ≥ 4`（偶数）、`v − 1` 偶数、`E = (2^v − 3)u + 1 ≥ 5u + 1 > 0`、`K = (ℓ − 1)/2 ≥ 0`。
  - 境界 `ℓ = 1`（`K = 0`）：`c_k` の集合は空、`d_1 = (m+2+u)/2` は奇数（`v2(4(m+2)−E) = v2(E) = 1`）。ブロック 0 で `u, h, d_1 ∈ S_0` より `g_0 = m+2`、ブロック 1（O 型）で `d_1 ∈ S_0 ⇒ u ∉ S_1 ⇒ h ∉ S_1 ⇒ g_1 = m+1`。境界ケースも完全に成立。
  - 整数性・偶奇・範囲：`0 < c_k < (m+2)/3 = (2h+1)/3 ≤ h − 1`（`h ≥ 4`）、`d_k < 2(m+2)/3 ≤ m`（`m ≥ 7`）、`u < 4u − 1 ≤ h − 1`。`(iii)` は奇数の距離 `u, c_k` には一切当たらない（`d_{K+1}` はブロック 0 でのみ参照）。
  - O 型での `2^a u` 連鎖：`m + 2 + 2^a u` は奇数なので (ii) は効かず、`h − 1` は奇数なので (iii) も効かない。よって `2^a u ∈ S_n ⇔ 2^{a−1}u ∉ S_n`、`v − 1` が偶数より `h ∈ S_n ⇔ u ∈ S_n`。
  - 帰納法 `Q(n)`（`0 ≤ n ≤ K`）およびブロック `K + 1`（`d_1 ∈ S_K ⇒ u ∉ S_{K+1} ⇒ h ∉ S_{K+1} ⇒ g_{K+1} = m+1`）は誤り・穴なし。
  - 密度：`2^v − 3` は奇数ゆえ `u` が奇数上を一様に動くとき `E` は偶数上を一様に動き、`ℓ` 奇数の密度は `2/3`。正確。
- **軽微な記法注記（誤りではない）**：`1 ≤ k ≤ K+1` で `d_k := 2c_k` と書かれているが、`c_{K+1}` は整数ではないため `d_{K+1}` は `(4^{K+1}(m+2)−E)/(3·2^{2K+1})` の式で直接定義される。
