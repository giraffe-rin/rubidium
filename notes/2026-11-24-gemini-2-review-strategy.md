#### 1. 系 W（一般の局面 `(r, p)` の必勝手の明示）：**正しい（最後まで確認した）**
- **勝ち手の一般形（24〜30 行）**：合法手集合は `M = {1, …, min(m, r)} \ {p}` であり、行き先 `(r − k, k)` が P となる合法手の集合は `M ∩ T(r) = T(r) \ {p} = W(r, p)`。`(r, p)` が N ⇔ `W(r, p) ≠ ∅`。正確。
- **`m = 1`（32〜33 行）**：`r = 0` では `T(0) = ∅` で P。`r ≥ 1` では K7′（`m = 1`）より `T(r) = {1}` なので `W(r, p) = {1} \ {p}`。よって N ⇔ `p ≠ 1`（すなわち `p = 0`）で、必勝手は `k = 1`。正確。
- **`m ≥ 2`（35〜58 行、`r = a_j + d`, `0 ≤ d < g_j`）**：
  - **ケース 1（`d = 0`, A 行）**：`T(r) = ∅` より `W(r, p) = ∅`、全 `p` で P。正確。
  - **ケース 2（`1 ≤ d ≤ m`, `p ≠ d`）**：`H(j)` ステップ 2 より `d ≤ min(m, r)` かつ `r − d = a_j` が A 行なので `d ∈ T(r)`。`p ≠ d` より `d ∈ W(r, p)`、行き先 `(a_j, d)` は P。正確。
  - **ケース 3（`1 ≤ d ≤ m`, `p = d`）**：`H(j)` ステップ 2 より `T(r) = {d} ∪ X`（`X` は (i) `d/2`、(ii) `e = (g_{j−1}+d)/2`、(iii) `h` のうち成立するもの）。いずれの要素も `d` と異なり `1 ≤ k ≤ min(m, r)` を満たすため `W(r, d) = X`。各ケースの行き先も (i) `(a_j + d/2, d/2)`（`d/2 ∈ S_j` で P）、(ii) `(a_{j−1} + e, e)`（`e ∈ S_{j−1}` で P）、(iii) `(a_{j−1} + m + 1, h)`（`H(j−1)(c)` より `S(h)` 行で P）と一致する。よって `(r, d)` が N ⇔ `X ≠ ∅` ⇔ `d ∉ S_j`。正確。
  - **ケース 4（`d = m + 1`, `g_j = m + 2` のときのみ）**：`H(j)` ステップ 3 (β) より `m` は奇数（`m ≥ 3`）、`h ∈ S_j`、`T(r) = {h}`（`1 ≤ h ≤ m = min(m, r)`）。`W(r, p) = {h} \ {p}` より N ⇔ `p ≠ h`。`k = h` の行き先は `(a_j + m + 1 − h, h) = (a_j + h, h)` であり `h ∈ S_j` より P。正確。
