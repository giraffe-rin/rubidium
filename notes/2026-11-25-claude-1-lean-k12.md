# 定理 K12 (a)（110 型）の Lean 4 での形式化

## やったこと

`lean/Rubidium/K12.lean` に、定理 K12 (a) を sorry なしで証明した（公理は `[propext, Quot.sound]`）。

```lean
theorem K12a (m : Nat) (hm4 : m % 4 = 1) (hm5 : 5 ≤ m) (hv : v2 (3h+1) = 2)
    (hQ : (11h+5)/8 % 2 = 1) (n : Nat) :   -- h = (m+1)/2
    IsP m n 0 ↔ (n % (3m+5) = 0 ∨ n % (3m+5) = m+2 ∨ n % (3m+5) = 2m+4)
```

## 証明の組み立て

記号：w = (3h+1)/4（奇数）、e* = 2w、Q = (11h+5)/8（m + 2 + w = 2Q）。
L = 3m+5、a = iL、b = a + (m+2)、c = b + (m+2) とする。
もとの証明（ノート 2026-11-23-claude-1-proof-k12.md）の主張 Θ(j) を、ブロックの理論 H(j) を使わずに局面の言葉で示した。

**`k12_step`**（1 周期分）は、次の順で示す。
1. (a + h, h) は P（h は奇数）。`row_long` より、行 b はすべての p で P。
2. (a + 2w, 2w) は N（手 w）。(b + w, w) は N（手 Q。行き先 (a + Q, Q) は、Q が奇数なので P）。
3. (b + 2w, 2w) は P（`p_two`、z = w）。
4. (b + h, h) は P。どの手の行き先も N であることを示す。
   - 手 k < h：h が奇数なので N。
   - 手 h + 1：`not_isP_near` より N。
   - 手 e*：行き先 (a + 2w, 2w) は N。
   - ほかの手：`not_isP_of_row` より N。
5. `row_long` をもう一度使って、行 c はすべての p で P。
6. (c + h, h) は N。手 2w で (b + 2w, 2w) に移れる。
7. `row_next` より行 a + L はすべての p で P。奇数 d は P（`odd_of_rows`）。

**最後の場合分け**は n mod L で行う。2m + 3 = b + (m+1) では、(b + h, h) が P なので `not_isP_near` を使う。

**技術的なこと**：(m+1)/2 などの割り算が入れ子になると omega が時間切れになった。そこで h、w、Q を変数にして、m + 1 = 2h、3h + 1 = 4w、11h + 5 = 8Q の 1 次の関係で扱った。それでも k12_step は重いので、`set_option maxHeartbeats 2000000` を付けた（ビルド約 30 秒）。

## 意味

- 定理 K12 (a) が [Lean検証済み] の候補になった（査読待ち）。
- これで Lean にあるのは K3・K4・K5・K6・K9・K10 (a)・K12 (a)・K13 の 8 つ。どれも H(j) を使わない。
