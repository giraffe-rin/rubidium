# 定理 K7′（すべての m で勝敗表は周期的）の Lean 4 での形式化

## やったこと

`lean/Rubidium/K7.lean` に、定理 K7′ を sorry なしで証明した。

```lean
theorem K7' (m : Nat) : ∃ N₀ T, 0 < T ∧ ∀ r, N₀ ≤ r → ∀ p, (IsP m (r + T) p ↔ IsP m r p)
```

公理は `[propext, Classical.choice, Quot.sound]`（`by_cases` と `simp` から）。m = 0 も含む。

## 証明の組み立て（H(j) を使わない）

もとの証明（ノート 2026-11-23-claude-1-proof-periodicity.md）は、ブロックの漸化式 R（K8）の状態が有限個であることを使っていた。ここでは、局面の勝敗の規則だけから直接示した。

1. **`isP_big`**：p > m の局面 (r, p) は (r, 0) と同じ。どの手 k（1 ≤ k ≤ m）も、p にも 0 にも等しくないから。
2. **`window_step`**：「行 r の窓」を、i < m、p ≤ m の局面 (r + i, p) の P/N の組とする。行 r の窓と行 s の窓が同じなら、(r + m, p) と (s + m, p) の P/N も同じ。
   (r + m, p) からの手 k（1 ≤ k ≤ m）の行き先は (r + (m − k), k) で、これは窓の中にあるから。
3. **`window_all`**：窓が同じなら、それ以降のすべての行（すべての p）が同じ。t についての帰納法で、窓 (r + t) と窓 (s + t) が同じことを示す。p > m の局面は 1 で扱う。
4. 窓を長さ m(m+1) の Bool の列 `win m r`（`List.ofFn`）で表す。2 進の符号 `enc` で 2^{m(m+1)} 未満の自然数にする。`enc` は、同じ長さの列の上で単射（`enc_inj`）。
5. **`pigeon`**（鳩の巣原理）：i ≤ B で f i < B なら、i < j ≤ B で f i = f j となるものがある。
   B についての帰納法で示す。f(B+1) の値が前に現れなければ、値 B を f(B+1) に付け替えた関数に帰納法の仮定を使う。
6. f(r) = enc(win m r) に鳩の巣原理を使うと、窓が同じ i < j が見つかる。3 より、N₀ = i、T = j − i で周期的になる。

## 意味

- 定理 K7′ が [Lean検証済み] の候補になった（査読待ち）。もとの証明の前提だった K8（H(j)）を使わない。
- 系として、開始局面の列 (n, 0) も、すべての m で周期的（前周期を許す）。
- 得られる周期の上界は 2^{m(m+1)} で、実際の周期よりずっと大きい。周期の具体的な値は、これまでどおり計算（漸化式 R）で求める。
