## 記号

- v ≥ 3 は奇数、ρ = v + 1、z = ρ/2 = (v+1)/2、L = lcm(1, …, z) とする。
- Q = 2^v − 1、r = (2^{v+1} − 1)/3、q = −Q とする（q + 3r = 2^v、1 + 3r = 2^ρ）。
- N は偶数で N ≥ 2v + 2 とし、σ は奇数で Q | σ·2^N + r、s = −σ とする。a = (σ·2^N + r)/Q、m = 3a − 2 とおく。
- R = ⌈(N − v)/ρ⌉ とする。

## 定理 K55 `[非形式証明]`

R ≡ 1 (mod 2L) かつ R − 1 ≥ ρ + 4 + 2v/ρ なら、次が成り立つ。

- 間隔の列のすべての m+2 の極大な連の長さは R。
- すべての m+1 の極大な連の長さはちょうど z = (v+1)/2。

系：各奇数 v ≥ 3 で、v2(m+1) = v、w = v の類の型は、周期部分だけで数えても無限に多い。予想 K51 のうち R ≡ 1 (mod 2L) の場合が示されたことになる。

定理 K54（偶数 w ≤ v − 1）、定理 K36（w = 2）と合わせると、次がいえる。予想 K38 で型が決まらなかったすべての類（w 偶数 ≤ v − 1、w = v）で、型は周期部分だけで数えても無限に多い。

### 証明

定理 K54 と同じ (A)(B)(C) を示す。

**(A) 連の長さ**（補題 K48 の代わり）：

- ブロック 0 からの連は定理 K47b による。
- 直前に m+1 が z 個以上続く位置 B から始まる連を考える。定理 K47 と同じ h の鎖で、終点の v2 は次のとおり。
  - i ≤ k のとき、v2 は ρ − 1 = v。補題 Q_z が直接分かるのは v2 ≤ min(2z − 1, v − 1) = v − 1 の範囲なので、この値は直接は分からない。
  - そこで E 型の規則を使う。d_end は偶数で、d_end/2 の v2 は v − 1。v − 1 は偶数で範囲内なので、d_end/2 ∈ S_B。よって d_end ∉ S_B となり、v2 が奇数のときと同じ値（入らない）になる。
  - i = k + 1 のとき、v2 は e − 1 ≤ ρ − 2 = v − 1 で、範囲内（偶数、入る）。
- したがって、定理 K47 と同じく、連の長さはちょうど R。

**(B) 連の後の m+1 が z 個以上**：定理 K54 の証明（補題 K52 の再帰と補題 K54.1）をそのまま使う。

- 補題 K52 の (a)(b)（距離の形、e ≤ m）は q の符号によらない。
- 補題 K53 は 3r = 2^ρ − 1 にだけよるので、そのまま使える。
- 補題 K54.1 の入口は c < 2^{ρ−1} = 2^v で、終点の v2 は t(c) − 1 ≤ ρ − 2 = v − 1。よって補題 Q_z の範囲に入る。
- 残るのは、鎖の条件 (M+d)/2 ≤ m（下の (b′)）だけである。

**(b′) q < 0 での (M+d)/2 ≤ m**：鎖の奇数の点で d = (ab + cσ·2^{N−K})/r（K = v + S、S はそれまでの t の和）。σ·2^N = Qa + r なので、d ≤ 3a − 4 は次と同値になる。

> a(3r − b − cQ/2^K) ≥ 4r + cr/2^K

- **S = 0（最初の奇数の点）**：d = c(3a − 1)/2^v で、c < 2^v なので d < 3a − 4。
- **S ≥ 1**：補題 K53 により、b は c を右に S 桁（ρ を法として）回転したものである。c < 2^{ρ−1} とする。
  - b + c/2^S ≤ 2⌊c/2^S⌋ + (c mod 2^S)·2^{ρ−S} + (c mod 2^S)/2^S。
  - 右辺は < (2^{ρ−S} − 2) + (2^ρ − 2^{ρ−S}) + 1 = 2^ρ − 1 = 3r（S ≤ ρ − 1 のとき。S ≥ ρ では b は回転を繰り返し、c/2^S はもっと小さい）。
  - Q < 2^v ≤ 2^K なので、cQ/2^K < c/2^S。よって D = 3r·2^K − b·2^K − cQ は正の整数。
- **a が十分大きいこと**：左辺 ≥ a/2^K、右辺 ≤ 5r なので、a ≥ 5r·2^K なら成り立つ。
  - a > 2^{N−v} なので、N − v − K ≥ ρ + 1 で十分。
  - K ≤ v + (R − 1)ρ/2 + zρ（r の平均 ≤ ρ/2、定理 K54 と同じ）と N ≥ v + ρ(R − 1) + 1 から、R − 1 ≥ ρ + 4 + 2v/ρ で成り立つ。
- **d ≠ h − 1 と v2(β) < N**：定理 K54 と同じ評価で、この下限で成り立つ。

**(C) m+1 の連の長さ**：補題 Q_n により z = ⌈v/2⌉ 個以下。(B) とあわせて、ちょうど z。

∎
