### 主張ごとの査読結果

#### 1. 定理 K6（`m ≡ 5 (mod 8)` の開始局面の特徴づけ、28〜76 行）：**正しい（最後まで確認した）**
- **準備（32〜37 行）**：
  - `m = 8t + 5`（`t ≥ 0`）とすると `h = (m+1)/2 = 4t + 3`（奇数、`h ≡ 3 (mod 4)`、`3 ≤ h < m`）。
  - `e* = (m + 2 + h)/2 = (2h + 1 + h)/2 = (3h + 1)/2 = 6t + 5` は奇数の整数で `e* ≥ 5 ≥ 1`。
  - `e* ≤ m ⇔ 6t + 5 ≤ 8t + 5 ⇔ 0 ≤ 2t`（すべての `t ≥ 0` で成立。最小例 `m = 5, t = 0` では `e* = 5 = m`）。
- **主張 `P(j)` の帰納法（39〜63 行）**：
  - `j = 0`（偶数）：K3 と `H(0)(b)` より全奇数 `d`（`1 ≤ d ≤ m`）で `v2(d) = 0` 偶数ゆえ `d ∈ S₀`。特に奇数 `h ∈ S₀`、よって `H(0)(c)` より `g₀ = m + 2`。
  - `j ≥ 2` が偶数：`P(j−1)` より `g_{j−1} = m + 1`。奇数 `d`（`1 ≤ d ≤ m`）に対し、(i) は `d` 奇数で偽、(ii) は `(m+1) + d = 偶数 + 奇数 = 奇数` で偽、(iii) は `g_{j−1} = m + 1 ≠ m + 2` で偽。よって `H(j)(d)` より `d ∈ S_j`。特に `h ∈ S_j` より `H(j)(c)` から `g_j = m + 2`。
  - `j ≥ 1` が奇数：`P(j−1)` より `g_{j−1} = m + 2` かつ全奇数 `d ∈ S_{j−1}`。`d = h` に対して `H(j)(d)` の (ii) を調べると、`j ≥ 1`、`(m+2) + h = 2e*` は偶数、`e = e*` は `1 ≤ e* ≤ m` かつ奇数なので `e* ∈ S_{j−1}`。よって (ii) が成立し `h ∉ S_j`、`H(j)(c)` より `g_j = m + 1`。
- **A 行の位置と結論（65〜76 行）**：
  - `a₀ = 0`、`a_{2i+1} = a_{2i} + (m+2)`、`a_{2i+2} = a_{2i+1} + (m+1)` より帰納法で `a_{2i} = i(2m+3)`、`a_{2i+1} = i(2m+3) + (m+2)`。
  - `0 < m + 2 < 2m + 3` より剰余類 `{0, m+2} (mod 2m+3)` が A 行全体と一致し、系 1.1 より定理 K6 が成立する。

#### 2. 補足「先手の必勝手」（82〜85 行、ラベル `[非形式証明]`）：**誤りあり**
- **誤りのある箇所**：`notes/2026-11-23-claude-1-proof-k6.md` 83 行および 85 行
  > - `0 < c < m+2` なら `k = c` を取ると A 行 `n − c` に移る。
  > - `c` が `0` でも `m+2` でもないとき、先手は上のどちらかで必ず勝てる（ラベルは K6 と同じ `[非形式証明]`）。
- **誤りの内容**：`c = m + 1` のとき `0 < m + 1 < m + 2` を満たすため、上記の規則は `k = c = m + 1` を取るよう指示している。しかし `PROBLEM.md` の合法手の条件は `1 ≤ k ≤ min(m, r)` であり、`k = m + 1 > m` は **非合法手** である。
- **最小反例**：`m = 5`（`5 ≡ 5 (mod 8)`）、`n = 6`（`c = 6 mod 13 = 6 = m + 1`）。
  - 補足の規則は `k = 6` を指示するが、一度に取れる石は最大 `m = 5` 個のため指せない。
  - 一般に任意の `m ≡ 5 (mod 8)` と `i ≥ 0` に対し `n = i(2m+3) + (m+1)` がすべて反例となる（検証範囲 `5 ≤ m ≤ 101, n ≤ 3000` で 661 件）。
- **正しい必勝手（参考・検証済み）**：
  - `0 < c ≤ m` のとき：`k = c`（`1 ≤ k ≤ m`、A 行 `a_{2i} = n − c` へ遷移）。
  - `c = m + 1` のとき：行 `n = a_{2i} + m + 1` は K2(c) より `S(h)` 行なので `T(n) = {h}`。先手は `k = h = (m+1)/2`（`1 ≤ h ≤ m`）を取ると、`(n − h, h) = (a_{2i} + h, h)` に移る。主張 `P(2i)` より `h ∈ S_{2i}` なので `(a_{2i} + h, h)` は P 局面である。
  - `m + 2 < c < 2m + 3` のとき：`k = c − (m+2)`（`1 ≤ k ≤ m`、A 行 `a_{2i+1}` へ遷移）。
  - この修正版戦略は `code/gemini2_verify_k6.py` で全 13 個の `m`、`n ≤ 3000` の全 N 開始局面において反例 0 件であることを確認した。
