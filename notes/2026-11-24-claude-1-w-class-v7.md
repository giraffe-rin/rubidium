  - 条件：型が N で 1 つでも変わる族をすべて出す。
  - 結果：`data/w_class_family_v7_w{4,6,7}_{a,m}.txt`。

- そこで c = 1 について、N = 56, 84, …, 616 の 21 個で、型と周期の中の m+2 の連の最大を求めた（`code/w_class_v7_family.js`、`data/w_class_v7_family.txt`）。
  - 型は 3200 ブロックまでの計算からの推測で、周期が 4 回以上見えるものに限った。

## 結果

### 予想 K45 `[予想]`

N ≡ 0 (mod 28)、N ≥ 56、a = (2^N − 4641)/29、m = 3a − 2 とする。

- m は v2(m+1) = 7、w = 4 を満たす。a は 2 進で −4641/29 に近いので、m+1 の下位の桁は N によらない。数値でも 21 個すべてで確認した。
- 型の周期の中の m+2 の間隔の連の最大は、N とともに限りなく大きくなる。
- 数値：N = 56 で 9、84 で 14、…、420 で 70、616 で 103。おおよそ N/6 で、N = 336（43）の 1 個だけが単調でない。
- 型そのものは不規則：前周期 0〜114、周期 12〜361。K36 や K44 のような単純な形はない。
- 正しければ、v = 7 の w = 4 の類の型は無限に多い。
