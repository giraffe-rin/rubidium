# 定理 K15（1(10)^k 型、一般の k ≥ 2）の Lean 4 での形式化

## やったこと

`lean/Rubidium/K15gen.lean` に、定理 K15 を一般の k ≥ 2 で、sorry なしで証明した。

```lean
theorem K15_gen (m h k w : Nat) (hmh : m + 1 = 2 * h) (hW : 3 * h + 1 = 4 ^ k * w) (hw : w % 4 = 3) (hk : 2 ≤ k)
    (n : Nat) :
    IsP m n 0 ↔ (r = 0 ∨ (m + 2 ≤ r ∧ ((r - (m+2)) % (2m+3) = 0 ∨ (r - (m+2)) % (2m+3) = m + 2)))
    -- r = n mod L、L = (m+2) + k(2m+3)
```

条件の意味：w ≡ 3 (mod 4) は、Q = (m+2+w)/2 が奇数であることと同じ。型は 1(10)^k で、周期の間隔は m+2、そのあと (m+2, m+1) が k 回。
公理は `[propext, Classical.choice, Quot.sound]`。k = 1 は K12 (a)（PR #404）。

もとの K15 は、k ≤ 16 の計算機による証明書だった。PR #441 の分析で見つけた 3 つの難点を、次のように解決した。

## 証明の組み立て

ブロックの並び：R₀（始まり）、R₁ = R₀ + (m+2)（O）、R₂ = R₁ + (m+2)（O）、E_i = R₀ + (m+2) + i(2m+3)（E、E₀ = R₁）、O_i = E_i + (m+2)（O、O₀ = R₂）。E_k が次の始まり。
e* = (3h+1)/2 = 2^{2k−1}·w。

1. **(iii) の例外**：k ≥ 2 では h ≡ 5 (mod 16)（`k15_h16`）。q ≡ 3 (mod 4) なら、2·2^j q + 1 は 7、13 (mod 16) か 1 (mod 8) で、h にならない。
   そこで、h が奇数のときの半分にする規則 `o_half'`・`o_iter3` を作った。
2. **値の上界**：Inh の型 `K15I r i` に、仮定 3·2^b q + 5·4^i ≤ 2·4^k·w を入れた（q ≡ 3 (mod 4)、2i ≤ b ≤ 2k−1 なら、(r + 2^b q) が P ⇔ b が奇数）。
   1 段で (E_i, q, b) から (E_{i−1}, q′, b−2) に移る。2^{b−2}q′ = e* + 2^{b−2}q で、上界は保たれる（`k15_istep`）。
3. **最初の O 型の連続**：E₀ = R₁ の値（`K15I r 0`）を、`o_iter3` から直接出した。そのため、E₁ の Inh の (ii) の相手が R₁ でも、同じ `k15_istep` が使える。

**ほかの部品**
- `o_odd_iff`：O 型の行の奇数 x について、(o + x) が P ⇔ 相手 (e + (m+2+x)/2) が N。
- `blk_EO`：Blk m s e から Blk m (s+2) c（c = e + (m+2) + (m+1)）。間の O 型の奇数 h + d/2 の相手は e* + d/4 で、v2 は v2(d) − 2。
  d = m − 1 は v2 が奇数（`k15_vm1`）なので、相手が m を超える場合は起きない。
- **h の所属**（`k15_step`）：
  - R₁ で P（R₀ の (e*) が N）。
  - R₂ で N（R₁ の e* が P）。
  - O_i（i ≥ 1）で N（E_i の e* が P。Inh と `k15_bound`：5·4^i ≤ 2^{2k−1} w）。
  - E 型では P（h は奇数）。
- 周期の始まりの行で使うのは、Blk m (2k−1) だけ（E_k で `blk_EO` から得る）。

## 意味

- **定理 K15 が、すべての k ≥ 2 で [Lean検証済み] の候補になった**（査読待ち）。K12 (a)（k = 1）と合わせると、v2(m+1) = 1 で Q が奇数のすべての k が確かめられた。
- Lean で型が決まる m の割合（`data/lean_coverage.txt`、m ≤ 10^6）：
  - v2(m+1) = 1 で 79.17% → **83.33%**
  - 全体で 90.95% → **92.00%**
