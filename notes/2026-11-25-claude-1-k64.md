# 予想 K64：v2(m+1) = 1、v2(3h+1) = 2 で Q が偶数のときの型 1^{j+2} 0

## 背景

Lean で型が決まらない部分のうち、v2(m+1) = 1 で v2(3h+1) が偶数、Q が偶数の場合を調べた（まとめは PR #444）。
k = 1（v2(3h+1) = 2）で Q が奇数なら 110 型（K12 (a)）。K12 (b) によると、v2(Q) が奇数なら g₂ = m + 2 になる。

## やったこと

1. k = 1 で Q が偶数の m（m ≤ 6000）の型を、v2(Q) ごとに数えた。v2(Q) = 1 では、1110 型が多く、11110 型などが混ざる。
2. K12 の証明の規則を 1 段先までたどった。
   h ∈ S₃ ⇔ e* ∉ S₂ ⇔ w ∈ S₂ ⇔ Q ∉ S₁ ⇔ Q/2 ∈ S₁ ⇔ R := (m+2+Q/2)/2 ∉ S₀ ⇔ v2(R) が奇数。
   よって g₃ は R の v2 の偶奇で決まる。R が奇数なら g₃ = m+1 で、型の先頭は 1110。
3. この規則をくり返す量の列を作った：X₀ = Q、X_{i+1} = (m+2+X_i/2)/2。
4. `code/k64_chain.js`：v2(X₀) = … = v2(X_{j−1}) = 1 で X_j が奇数の m について、型が 1^{j+2} 0 になるかを確かめた。

### 予想 K64 `[予想]`

v2(m+1) = 1、3h+1 = 4w（w は奇数）とし、X₀ = Q = (m+2+w)/2、X_{i+1} = (m+2+X_i/2)/2 とおく。
v2(X₀) = … = v2(X_{j−1}) = 1 で X_j が奇数なら、型は前周期なしで 1^{j+2} 0（周期 L = (j+2)(m+2) + (m+1)）。

- j = 0 は K12 (a)（110 型、Lean検証済み）。
- 確かめた範囲：m ≤ 40000 の 416 個（漸化式 R）と、m ≤ 4000 の 41 個（直接の DP、n ≤ 3L）。

## 残り（この予想に入らない k = 1、Q 偶数の m）

- ある i で v2(X_i) ≥ 2 になるもの。例：v2(Q) = 2 では 110 型と 1101110 型などが混在する（手順 1 の表）。
  K12 の補足にある「v2(Q) が 2 以上の偶数なら混在」と同じ現象。

## 次にやるべきこと

  O 型の連続では、半分にする規則と奇数の規則が交互に効く。X_i の連鎖は、その規則をたどったもの。
- v2(X_i) ≥ 2 の場合の分類。
