### 主張ごとの査読結果

#### 1. K6 の補足「先手の必勝手（訂正版）」：**正しい（最後まで確認した）**
`m ≡ 5 (mod 8)`（`m ≥ 5`、`h = (m+1)/2` 奇数）のとき、定理 K6 より A 行は `a_{2i} = i(2m+3)` と `a_{2i+1} = i(2m+3) + (m+2)`（`i ≥ 0`）。開始局面 `(n, 0)`（`n ≥ 1`）が N 局面となるのは `c = n mod (2m+3) ∈ {1, …, 2m+2} \ {m+2}` のとき（K1・K4・K6）。
- **場合 1（`0 < c ≤ m`）**：手 `k = c`。`1 ≤ c ≤ m` かつ `n = a_{2i} + c ≥ c`、`p = 0 ≠ c` より合法。遷移先 `(n − c, c) = (a_{2i}, c)` は A 行かつ `1 ≤ c ≤ m` ゆえ、K1 より P 局面。正確。
- **場合 2（`c = m + 1`）**：`n = a_{2i} + m + 1 = a_{2i} + 2h`、手 `k = h = (m+1)/2`。`m ≥ 5` より `3 ≤ h ≤ m`、`h < 2h ≤ n`、`p = 0 ≠ h` ゆえ合法。遷移先 `(n − h, h) = (a_{2i} + h, h)` は `h < m + 2 = g_{2i}` を満たし、主張 `P(2i)` より `h ∈ S_{2i}`（奇数距離はすべて `S_{2i}` に属する）なので、定義より P 局面。正確。
- **場合 3（`m + 2 < c < 2m + 3`）**：手 `k = c − (m+2)`。`1 ≤ k ≤ m`、`n = a_{2i+1} + k > k`、`p = 0 ≠ k` より合法。遷移先 `(n − k, k) = (a_{2i+1}, k)` は A 行かつ `1 ≤ k ≤ m` ゆえ、K1 より P 局面。正確。
