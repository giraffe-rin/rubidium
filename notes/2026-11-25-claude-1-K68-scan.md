# 予想 K68：v2(m+1) = 3 の未証明の類を u mod 512 で分ける（claude-1, SG-005）

## やったこと

`code/lean_coverage.js` で、v2(m+1) = 3（m+1 = 8u）のうち Lean の定理がない u の類を調べた。
- 該当する類は u mod 64 ∈ {3, 7, 13, 23, 29, 35, 39, 45, 51, 55}。
- u ≡ 13 は K67-13 として別に登録した。残りの 9 類を u mod 512 で 72 の部分類に分けた。
- 各部分類で、u ≤ 12000（23〜24 個）の型を漸化式 R で求めた（`code/k68_scan.js`、結果は `data/k68_scan.txt`）。

## 結果

型が一定（前周期なし）の部分類が 24 個あった。予想 K68（`claims/conjectures/K68.json`）として登録した。

| 型 | u mod 512 |
|---|---|
| 10 | 45, 365 |
| 100 | 103, 221, 359, 477 |
| 110 | 227, 343, 483 |
| 10100 | 157, 173, 413, 429 |
| 11100 | 195, 243, 247, 451, 499, 503 |
| 11110 | 179, 435 |
| 1001100 | 39, 295 |
| 1101100 | 407 |

- 残りの 48 部分類は型が混ざっていて、もっと細かい類で分ける必要がある。
- 24 類が全部証明されると、m ≤ 10⁶ の被覆率はおよそ +0.6%（m+1 mod 4096 の 24 類）。

## 次

11100 型と 100 型は、K67b・K67c と同じ鎖の方法で Lean 化できる見込みがある。ただし鎖の偶奇は類ごとに違うので、類ごとに確かめる必要がある。

## Lean：K68 の u ≡ 221 (mod 256)（u ≡ 221, 477 (mod 512)、100 型）

`lean/Rubidium/K68a.lean`、`theorem K68_221`：(m+1) % 2048 = 1768 なら (n,0) が P ⇔ n mod (3m+4) ∈ {0, m+2, 2m+3}。
- K67c（u ≡ 61 (mod 64)）と同じ証明で通った。
- 違うのは X₃ = (11u+1)/2 の v2 が 4 でなく 6 であることだけ。どちらも偶数で、Blk m 7 の範囲に入る。
- 依存する公理は propext / Classical.choice / Quot.sound だけ。被覆率は m ≤ 10⁶ で 94.21% → 94.26%。
- 11100 型の類（195, 243, 247 等）は K67b の鎖の偶奇条件が合わない（例：u = 243 では (169u+21)/32 が偶数）。これらには別の鎖が要る。
