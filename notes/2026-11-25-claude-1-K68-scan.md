# 予想 K68：v2(m+1) = 3 の未証明の類を u mod 512 で分ける（claude-1, SG-005）

## やったこと

`code/lean_coverage.js` で、v2(m+1) = 3（m+1 = 8u）のうち Lean の定理がない u の類を調べた。
- 該当する類は u mod 64 ∈ {3, 7, 13, 23, 29, 35, 39, 45, 51, 55}。
- u ≡ 13 は K67-13 として別に登録した。残りの 9 類を u mod 512 で 72 の部分類に分けた。
- 各部分類で、u ≤ 12000（23〜24 個）の型を漸化式 R で求めた（`code/k68_scan.js`、結果は `data/k68_scan.txt`）。

## 結果

型が一定（前周期なし）の部分類が 24 個あった。予想 K68（`claims/conjectures/K68.json`）として登録した。

| 型 | u mod 512 |
|---|---|
| 10 | 45, 365 |
| 100 | 103, 221, 359, 477 |
| 110 | 227, 343, 483 |
| 10100 | 157, 173, 413, 429 |
| 11100 | 195, 243, 247, 451, 499, 503 |
| 11110 | 179, 435 |
| 1001100 | 39, 295 |
| 1101100 | 407 |

- 残りの 48 部分類は型が混ざっていて、もっと細かい類で分ける必要がある。
- 24 類が全部証明されると、m ≤ 10⁶ の被覆率はおよそ +0.6%（m+1 mod 4096 の 24 類）。

## 次

11100 型と 100 型は、K67b・K67c と同じ鎖の方法で Lean 化できる見込みがある。ただし鎖の偶奇は類ごとに違うので、類ごとに確かめる必要がある。

## Lean：K68 の u ≡ 221 (mod 256)（u ≡ 221, 477 (mod 512)、100 型）

`lean/Rubidium/K68a.lean`、`theorem K68_221`：(m+1) % 2048 = 1768 なら (n,0) が P ⇔ n mod (3m+4) ∈ {0, m+2, 2m+3}。
- K67c（u ≡ 61 (mod 64)）と同じ証明で通った。
- 違うのは X₃ = (11u+1)/2 の v2 が 4 でなく 6 であることだけ。どちらも偶数で、Blk m 7 の範囲に入る。
- 依存する公理は propext / Classical.choice / Quot.sound だけ。被覆率は m ≤ 10⁶ で 94.21% → 94.26%。
- 11100 型の類（195, 243, 247 等）は K67b の鎖の偶奇条件が合わない（例：u = 243 では (169u+21)/32 が偶数）。これらには別の鎖が要る。

## Lean：K68 の u ≡ 103 (mod 256)（u ≡ 103, 359 (mod 512)、100 型）

`lean/Rubidium/K68b.lean`、`theorem K68_103`：(m+1) % 2048 = 824 なら (n,0) が P ⇔ n mod (3m+4) ∈ {0, m+2, 2m+3}。
- X₁ = (9u+1)/2 の v2 が 4 で、Blk m 3 の範囲に入らない。そこで始まりの行の不変量を「Blk m 3 かつ (a + X₁) が P」にした。
- 次の始まりの行 a' で (a' + X₁) が P であることは、e_iff を 2 回使って示した。
  (a' + X₁/2) は v2 = 3 で N。(c + 4u + X₁/2) は (b + 2z)（z = 3u + X₁/8）を経て (a + Y) に帰着し、v2(Y) = 2 で P。
- DP の観察：u = 103, 359, 615 で、始まりの行のずれは v2 ≥ 4 だけ（直接の DP で確認）。
- 依存する公理は propext / Classical.choice / Quot.sound だけ。被覆率は m ≤ 10⁶ で 94.26% → 94.31%。

## Lean：K68 の 11100 型 u ≡ 195, 243, 247 (mod 256)（u mod 512 で 6 類）

`lean/Rubidium/K68c.lean`：`theorem K68_195`、`K68_243`、`K68_247`。それぞれ (m+1) % 2048 = 1560, 1944, 1976 なら、(n,0) が P ⇔ n mod (5m+8) ∈ {0, m+2, 2m+4, 3m+6, 4m+7}。
- 始まりの行の不変量は K67b と同じ Blk m 3。
- 変わるのは、(b_k + X₁)（k = 0, 1, 2）と (b₃ + 6u) を始まりの行に落とす鎖の形だけ。
  鎖は O 型の行の 2 つの規則（o_half'：偶数を半分に、o_odd_iff：奇数を前の行へ）の繰り返し。
- 鎖は `code/k68_gen11100.js` が u = r + 256t（t = 0..7）で形が一定なことを確かめてから生成する。Lean ファイルは `code/k68_asm11100.js` で組み立てる。
  最後に行き着く距離の v2 はどれも 3 以下（Blk m 3 で決まる）。
- 依存する公理は propext / Classical.choice / Quot.sound だけ。被覆率は m ≤ 10⁶ で 94.31% → 94.45%。

## 証明の生成器 `code/k68_gen.js` と K68_407（1101100 型）

型の語 w と類 u ≡ r (mod M) を与えると、始まりの行の不変量 Blk m 3 で閉じる場合の Lean の証明を生成する。
- 各行の (行 + 4u) の P/N を規則で始まりの行の距離に落とす。
  - O 型の行：o_half'（偶数）、o_odd_iff（奇数）。
  - E 型の行：blk1_direct（v2 ≤ 1）、e_iff（v2 ≥ 2、2 つに分かれる。N を示すときは P になる片方だけを使う）。
- 生成の前に、u = r + Mt（t = 0..7）で証明の形が同じことを確かめる。
- `lean/Rubidium/K68d.lean`、`theorem K68_407`：(m+1) % 4096 = 3256（u ≡ 407 (mod 512)）なら、(n,0) が P ⇔ n mod (7m+11) ∈ {0, m+2, 2m+4, 3m+5, 4m+7, 5m+9, 6m+10}。
  依存する公理は標準のものだけ。u = 407, 919 で直接の DP とも一致した。
- 1001100 型（u ≡ 39, 295）は (b₁ + 4u) が Blk m 3 だけでは決まらない（v2 = 4 の距離が要る）ので、この方法では閉じない。

## K68e：生成器で 38 類（u mod 2048）をまとめて証明

`code/k68_search.js` で、v2(m+1) = 3 の未被覆の u mod 2048 の各類を調べた。
- 手順：u = r の型の語を漸化式 R で求め、前周期 0 で語が 00 で終わる類について `k68_gen.js` が通るかを試す。
- 38 類が通った（10100 型 14、110100 型 9、1101100 型 6、11100 型 5、1111100 型 2、110111100 型 2）。
- 全部を `lean/Rubidium/K68e.lean`（10433 行）に生成した。コンパイルは約 18 分。
- 定理名は K68_r（r = 55, 87, 119, …, 1975）。前提は (m+1) % 16384 = 8r。
- 被覆率は m ≤ 10⁶ で 94.48% → 94.71%。v2(m+1) = 3 の中では 68.75% → 76.75%。
