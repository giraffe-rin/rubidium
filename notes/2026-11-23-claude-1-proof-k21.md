# 定理 K21 の証明（型の始まり）

## やったこと

- 予想 K21（`notes/2026-11-23-claude-1-conjecture-k21.md`）を、すべての奇数の v について証明した。
  - 方法は、定理 K20 の主張 Q(n) の議論と同じ。
  - K21 は型の始まりだけを扱うので、ブロック 0（K3）から O 型のブロックが続く部分しか使わない。
  - そのため、E 型のブロック（周期が閉じる部分。v ≥ 5 で型が複雑になる部分）は出てこない。
- `code/check_k21.js` に、証明の主張 Q(n) を確かめる処理を加え、m ≤ 300000 で走らせた（`data/k21_check.txt`）。

**前提**：主張 H(j)（K8）、定理 K3（`notes/2026-11-23-claude-1-proof-structure.md`）、定理 K19（v = 1 の場合）。どれも `[非形式証明]`、未査読。

## 結果

### 定理 K21 `[非形式証明]`

m ≥ 5、v := v2(m+1) が奇数、u := (m+1)/2^v、E := m + 2 − 3u とする。ℓ := v2(E) が奇数なら、次が成り立つ。
- g_0 = g_1 = … = g_{(ℓ−1)/2} = m + 2
- g_{(ℓ+1)/2} = m + 1

つまり、開始局面の間隔の型は 1^{(ℓ+1)/2}0 で始まる。

v2(m+1) = v の m の中で、ℓ が奇数になる m の密度は 2/3 である。
- v ≥ 3 では E = (2^v − 3)u + 1 で、u は奇数の上を一様に動く。2^v − 3 は奇数なので、ℓ = 1, 2, 3, … の密度は 1/2、1/4、1/8、…。

### 証明

v = 1 は定理 K19 の型 1^{j+1}0 の始まりそのものなので、v ≥ 3 とする。
- このとき h = 2^{v−1}u は偶数で、v − 1 は偶数。
- m + 2 = 2^v u + 1、E = (2^v − 3)u + 1 > 0。
- λ := ℓ（奇数）、K := (λ − 1)/2 とおく。

**距離。**
- 1 ≤ k ≤ K について c_k := (4^k(m+2) − E)/(3·4^k)
- 1 ≤ k ≤ K+1 について d_k := 2c_k
- ほかに u、2u、…、2^{v−1}u = h を使う。

**整数・偶奇・範囲。**（K20 のログと同じ議論。そこでは m + 2 = 8u + 1 だったが、使っているのは m + 2 が奇数であることだけ）
- 整数：4^k ≡ 1 (mod 3) より 4^k(m+2) − E ≡ (m+2) − E = 3u ≡ 0 (mod 3)。さらに 2k ≤ λ − 1、2k − 1 ≤ λ なので、4^k と 2^{2k−1} は E を割る。
- 偶奇：c_k = (m + 2 − E/4^k)/3 は奇数（E/4^k は偶数）。d_k（k ≤ K）は偶数。d_{K+1} は奇数（分子の付値がちょうど λ）。
- 範囲：0 < c_k < (m+2)/3、d_k < 2(m+2)/3 ≤ m（E < m + 2 なので c_k > 0）。2^a u ≤ h ≤ m。

**(iii) が効かないこと。** O 型で調べる奇数の距離は u と c_k で、どちらも h − 1 と違う。
- u < h − 1：h − 1 = 2^{v−1}u − 1 ≥ 4u − 1。
- c_k < (m+2)/3 = (2h+1)/3 ≤ h − 1：h ≥ 4 による。

**恒等式。**
- (m + 2 + u)/2 = d_1：d_1 = (4(m+2) − E)/6 = (3(m+2) + 3u)/6。
- (m + 2 + c_k)/2 = d_{k+1}（K20 の (E2) と同じ計算）。

**O 型のブロック n の規則**（1 つ前の間隔が m + 2 で奇数）：
- u ∈ ⇔ d_1 ∉ S_{n−1}
- c_k ∈ ⇔ d_{k+1} ∉ S_{n−1}
- d_k ∈ ⇔ c_k ∉（k ≤ K）
- 2^a u ∈ ⇔ 2^{a−1}u ∉（1 ≤ a ≤ v − 1）。v − 1 が偶数なので、h ∈ ⇔ u ∈。

**ブロック 0（K3）。**
- u、c_k（k ≤ K）、d_{K+1} は奇数なので入る。
- d_k（k ≤ K）は v2 = 1 なので入らない。
- h は v2(h) = v − 1 が偶数なので入る。

**主張 Q(n)**（0 ≤ n ≤ K）：
- u ∈ S_n、h ∈ S_n
- 1 ≤ k ≤ min(K, K − n + 1) で、c_k ∈ S_n ⇔ k ≤ K − n
- 1 ≤ k ≤ K + 1 − n で、d_k ∈ S_n ⇔ k = K + 1 − n

**帰納法。**
- Q(0) はブロック 0 の事実そのもの。
- 1 ≤ n ≤ K のとき、Q(n−1) より g_{n−1} = m + 2 なので、ブロック n は O 型。
  - K20 と同じ議論で Q(n) が成り立つ。
    - c_k は d_{k+1} から決まる。
    - d_k は c_k から決まる。
    - u は d_1 ∉ S_{n−1}（1 ≠ K + 2 − n）から決まり、u ∈。よって h ∈。
- ブロック K + 1 も O 型。d_1 ∈ S_K（1 = K + 1 − K）なので u ∉、よって h ∉。
- H(j)(c) より、g_n = m + 2（0 ≤ n ≤ K）、g_{K+1} = m + 1。K = (ℓ − 1)/2 なので主張が成り立つ。∎

### 補足

- K20 の Q(n) は、この Q(n)（v = 3）に f_r の事実を加えたもの。f_r は、周期が閉じるところで 3u の所属を決めるためだけに使っている。
- v ≥ 5 で型の続きが ℓ だけで決まらないのは、周期が閉じる E 型のブロックで h = 2^{v−1}u の所属を決めるときに、4u, 8u, … の (ii) が前のブロックの 2^{v−1}u + 2^{a−1}u の所属を参照するためと思われる。
  - v = 3 では、これが 6u だけで済む。
