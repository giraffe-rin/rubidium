## 補題 K53 `[非形式証明]`

ρ ≥ 2 を偶数、M = 2^ρ − 1 とし、0 < b < M を奇数とする。b を ρ 桁の 2 進の語 b_{ρ−1} … b_1 b_0（b_0 = 1）とみる。

**(1)** t = v2(b + M) は、b の最下位の 1 から次の 1 までの距離である（b = 1 なら ρ）。T(b) = (b + M)/2^t は、b を ρ 桁で右に t 桁回転したものに等しい。とくに T(b) は奇数で、0 < T(b) < M。

- 証明：b + M = (b − 1) + 2^ρ。b > 1 なら 0 < b − 1 < 2^ρ なので、t = v2(b − 1) は b_0 の次の 1 の位置。
- (b − 1)/2^t + 2^{ρ−t} は、最下位の 1 を除いた語を t 桁右にずらし、除いた 1 を上から t 番目の位置に置いたもので、これは右に t 桁の回転である。
- b = 1 なら t = ρ で、T(1) = 1。∎

**(2)** b の軌道は純周期的である。

- T は語の回転なので、軌道は b の回転の集合（有限）の中にある。
- 回転は可逆なので、T は b の奇数の回転の集合の上の全単射である。よって前周期はない。

**(3)** b の語の基本周期を d（d | ρ で、右に d 桁回転すると b に戻る最小の数）とし、1 周期の中の 1 の個数を p とする。このとき、閉路の長さは ℓ = p、閉路 1 周での t の和は d。

- T は、1 の位置を 1 つずつたどって回転する。p 回で d 桁回転して b に戻り、それより前には戻らない。

**(4)** t の平均 d/ℓ が ρ になるのは b = 1 だけである。

- d ≤ ρ、ℓ ≥ 1 なので、d/ℓ = ρ ⇔ d = ρ かつ ℓ = 1 ⇔ 1 の個数がちょうど 1 個 ⇔ b = 1（b は奇数）。

### 帰結（定理 K50 の評価について）

**(i) 入口の 1 の個数は z 以下**：E 型ブロック B+R+j0 から始めると、評価木の中で O 型ブロックへの入口 c(3a−1)/2^k に着くまでに、e の段（c ↦ 2^k + c）をちょうど j0 回通る。

- 補題 K52 の不変条件 c < 2^k から、2^k + c は c に新しい最上位の 1 を加えたものになる。
- h は c = 1 から始まるので、入口の c の 1 の個数は j0 + 1 ≤ z（j0 ≤ z − 1）。

**(ii) 閉路の長さと P**：c < M なら、(3) により c の閉路の長さは ℓ = p ≤ z = ρ/2。

- よって ℓ | L = lcm(1, …, ρ/2) で、P = 2L の倍数の R − 1 では、どの入口の鎖も軌道をちょうど偶数周する。
- これが定理 K50 の P = 2·lcm(1..ρ/2) と、剰余類 {1, L + 1} の理由になる。

**(iii) 鎖の条件**：c < M なら、(1) により軌道の b はいつも < M = 3r。(4) により、c ≠ 1 なら r の平均は < ρ。

- よって定理 K50 の形式的な評価の 3 条件（純周期的で ℓ | L、b < 3r、平均 < ρ）は、c < M のすべての入口で成り立つ。
- c ≥ M（ρ 桁を超える c）だけが「不明」になる。

**(iv) 値の閉じた式**：c < M、c ≠ 1、R ≡ 1 (mod 2L) なら、F(c, k) = [t(c) − 1 が偶数] XOR [k が奇数]。

- 終点の b は c で、終点の v2 は t(c) − 1。
- 段数の偶奇は v − k + 1 ≡ k (mod 2)（v は奇数）。
- R ≡ L + 1 のときは、段数の偶奇が L + (L/ℓ)(d − ℓ) だけずれる。

- 閉路の長さの集合は {1, …, ρ − 1}。評価木の入口に現れるのは、(i) によりそのうち z 以下のものだけ。
