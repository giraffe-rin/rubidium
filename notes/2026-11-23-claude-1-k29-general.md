# 予想 K29 の 5 ≤ v ≤ 27 での証明（定理 K29.3）

## やったこと

- 定理 K29.2（`notes/2026-11-23-claude-1-k29-v5-full.md`、v = 5）の議論を一般の v に広げた。
  - 数値で、各ブロックの 2^a u と h + 2^{a−1}u の所属を見た。どちらも u によらない形をしていた（v = 5〜11）。
  - そこで、距離を c·u（1 ≤ c ≤ 2^v − 1）に限って R を計算した。所属は「入る／入らない／不明」の 3 値で扱った。
- u ≡ 1 (mod 4) の m を、u ≡ 1 と u ≡ 5 (mod 8) の 2 通りに分けた。2 通りとも、h = 2^{v−1}u の所属がブロック 1〜L で決まった（L = (v+1)/2）。
  - 5 ≤ v ≤ 27 のすべての奇数 v で決まった（`code/k29_symbolic.js`、`data/k29_symbolic.txt`）。
  - u mod 8 で分けずに計算すると、ブロック L の h だけが「不明」になった。分けることで、K29.2 の (★) にあたる相関が入る。

**前提**：主張 H(j)（K8）と定理 K3（`[非形式証明]`、未査読）。

## 結果

### 定理 K29.3 `[非形式証明]`（計算機による証明書つき）

5 ≤ v ≤ 27 の奇数 v で、v2(m+1) = v、u := (m+1)/2^v ≡ 1 (mod 4) なら、m は前周期なし・周期「1 0^{(v−1)/2}」の型である（予想 K29）。
- v = 5 は K29.2 の別証明になる。
- これで予想 K29 は v ≤ 27 で定理になった。残るのは v ≥ 29。

### 証明

m = 2^v u − 1、h = 2^{v−1}u、m + 1 = 2^v u、m + 2 = 2^v u + 1、L := (v+1)/2 とする。距離 c·u（1 ≤ c ≤ 2^v − 1）だけを考える。これは 1 以上 m 以下である。

**O 型のブロック n**（1 つ前の間隔 m + 2。ブロック 1 と、帰納法で示すブロック qL + 1）：
- **偶数の c**：m + 2 + cu は奇数なので (ii) は効かない。(iii) の h − 1 は奇数なので効かない。よって cu ∈ ⇔ (c/2)u ∉。
- **奇数の c**：(ii) の e_c := ((2^v + c)u + 1)/2 を見る。
  - e_c ≤ m は c ≤ 2^v − 3 なら成り立つ。c = 2^v − 1 なら、u ≥ 3 で成り立つ。u = 1 では e = 2^v > m となる。この c は 3 (mod 4) なので、下の「不明」に入る。
  - **c ≡ 1 (mod 4)**：(2^v + c)u + 1 ≡ c + 1 ≡ 2 (mod 4)（u ≡ 1 (mod 4)、v ≥ 2）なので、e_c は奇数。
    - 1 つ前のブロックは K3（ブロック 0）か E 型（ブロック qL）で、どちらでも奇数は入る。よって e_c ∈ で、cu ∉。
  - **c ≡ 3 (mod 4)**：e_c は偶数。u を mod 8 で u₀ ∈ {1, 5} に固める。
    - c·u₀ + 1 ≡ 4 (mod 8) なら、(2^v + c)u + 1 ≡ cu + 1 ≡ 4 (mod 8)（v ≥ 3）なので、e_c/2 は奇数。
      - ブロック 0 では v2(e_c) = 1 で、K3 により e_c ∉。
      - E 型のブロックでは e_c/2（奇数）∈ なので、(i) により e_c ∉。
      - どちらでも e_c ∉ なので cu ∈。ただし (iii)（cu = h − 1）でないとき。
      - h − 1 = 2^{v−1}u − 1 が u の倍数になるのは u = 1 のときだけ。そのときの c = 2^{v−1} − 1 は「不明」にしておく。
    - それ以外は「不明」。

**E 型のブロック n**（1 つ前の間隔 m + 1 = 2^v u）：
- 奇数の c：2^v u + cu は奇数なので (ii) は効かず、(iii) は O 型だけ。よって入る。
- 偶数の c：cu ∈ ⇔ (c/2)u ∉ S_n かつ (2^v u + cu)/2 = (2^{v−1} + c/2)u ∉ S_{n−1}。
  - 2^{v−1} + c/2 ≤ 2^v − 1 で、e ≤ m も成り立つ。

**3 値の計算。** 上の規則を「不明」を含めて伝える。
- 否定：不明は不明のまま。
- かつ：どちらかが「入らない」なら「入らない」、両方「入る」なら「入る」、ほかは不明。

この計算は、各ブロックの本当の所属と矛盾しない（「入る／入らない」と出た距離は、本当にそうである）。
- これは c についての帰納法で示せる。各規則が R の (i)(ii)(iii) を正しく写しているためである。

**周期性。** O 型のブロックの計算が 1 つ前のブロックについて使うのは、次の 2 つだけである。
- 「奇数の e は入る」
- 「e/2 が奇数なら e は入らない」

どちらも、ブロック 0（K3）とブロック qL（E 型）の両方で成り立つ。したがって、ブロック qL + 1〜(q+1)L の 3 値の計算は、ブロック 1〜L と同じになる。ただし g_{qL} = m + 2 が前提である（帰納法で示す）。

**計算の結果**（`data/k29_symbolic.txt`）：5 ≤ v ≤ 27 のすべての奇数 v と、u₀ = 1, 5 の両方で、h の所属は次のとおりに決まった。
- ブロック 1〜L−1 で「入らない」
- ブロック L で「入る」

ブロック 0 では h ∈（v2(h) = v − 1 は偶数）。よって H(j)(c) と q についての帰納法により、g_{qL} = m + 2、g_{qL+i} = m + 1（1 ≤ i ≤ L − 1）。型は 1 0^{L−1}。∎

### 補足

- 「不明」の個数は、ブロック 1〜L で、u₀ = 1 のとき 2^{v−2} − 1、2^{v−4} − 1、…、7、1、0、u₀ = 5 のとき 2^{v−2}、2^{v−4} − 1、…、7、1、0 となった。どの v でも同じ形をしているので、一般の v でも成り立つと予想される。手での一般の証明はまだ。
- `code/check_k29.js`（分割つきの K16 の証明書）では、ℓ = 1 の類の一部が証明できずに残っていた。この 3 値の方法は u の深い桁によらないので、その残りも含めて示している。
