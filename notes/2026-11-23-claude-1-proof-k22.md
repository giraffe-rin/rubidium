## 結果

### 定理 K22 `[非形式証明]`

m ≥ 5、v := v2(m+1) が奇数、u := (m+1)/2^v、E := m + 2 − 3u、ℓ := v2(E) とする。n₁ を、g_0 から数えて最初に m+1 になるまでの m+2 の個数とする（型が 1^{n₁}0 で始まる）。このとき次が成り立つ。
- (a) ℓ が奇数なら n₁ = (ℓ+1)/2（定理 K21）。
- (b) ℓ が偶数で、μ := v2(m + 2 − E/2^ℓ) が奇数なら n₁ = ℓ/2。
- (c) ℓ が偶数で μ が偶数なら n₁ ≥ ℓ/2 + 1。

密度（v2(m+1) = v の m の中）は、(a) が 2/3、(b) が 2/9、(c) が 1/9。

### 証明

**記号。**
- c_k := (4^k(m+2) − E)/(3·4^k)、d_k := 2c_k とおく。
- 定理 K21 の証明と同じく、c_k は 2k ≤ ℓ で整数、d_k は 2k − 1 ≤ ℓ で整数である（3 で割り切れることも同じ）。
- 2k < ℓ なら c_k は奇数で、v2(d_k) = 1。

**補題（連鎖）。** j ≥ 0 とし、次を仮定する。
- g_0 = … = g_{j−1} = m + 2
- c_1, …, c_j が奇数の整数
- d_{j+1} が整数

このとき 1 ≤ k ≤ j+1、0 ≤ i ≤ j + 1 − k について、d_k ∈ S_i ⇔ d_{k+i} ∈ S_0。特に d_1 ∈ S_j ⇔ d_{j+1} ∈ S_0。

証明：i についての帰納法で示す。
- i = 0 は自明。
- i ≥ 1 のとき、ブロック i は O 型である（g_{i−1} = m + 2）。
  - d_k は偶数なので、d_k ∈ S_i ⇔ c_k ∉ S_i。
  - c_k は奇数なので、c_k ∈ S_i ⇔ d_{k+1} ∉ S_{i−1}。(m+2+c_k)/2 = d_{k+1} による。
  - よって d_k ∈ S_i ⇔ d_{k+1} ∈ S_{i−1}。
  - (iii) と範囲の確認は K21 のログと同じ。v = 1 では c_k = h − 1 は 2k = ℓ のときしか起きない。偶数の d_k が h − 1 に等しくなることもない。∎

**u と h。** ブロック j + 1 が O 型なら、u ∈ S_{j+1} ⇔ d_1 ∉ S_j（(m+2+u)/2 = d_1）。
- v ≥ 3 なら h = 2^{v−1}u ∈ ⇔ u ∈（K21 のログ）。v = 1 なら h = u。
- よって g_{j+1} = m + 2 ⇔ d_1 ∉ S_j ⇔ d_{j+1} ∉ S_0。
- K3 より、d_{j+1} ∉ S_0 ⇔ v2(d_{j+1}) が奇数。
- ブロック 0 では u ∈ S_0（奇数）、v2(h) = v − 1 は偶数なので、g_0 = m + 2。

**場合分け。** j = 0, 1, … の順に、v2(d_{j+1}) が奇数である限り m + 2 が続く。
- 2(j+1) < ℓ の間は v2(d_{j+1}) = 1 なので続く。
- (a) ℓ が奇数：j + 1 = (ℓ+1)/2 で d_{j+1} が奇数（v2 = 0）になり、止まる。よって n₁ = (ℓ+1)/2。
- ℓ が偶数：j + 1 = ℓ/2 で c_{ℓ/2} = (m + 2 − E/2^ℓ)/3 は整数で、v2(c_{ℓ/2}) = μ。v2(d_{ℓ/2}) = 1 + μ である。
  - (b) μ が奇数なら 1 + μ は偶数で止まる。n₁ = ℓ/2。
  - (c) μ が偶数なら続く。n₁ ≥ ℓ/2 + 1。

補題の仮定（c_1, …, c_j が奇数）は、どの場合も j + 1 ≤ ⌈ℓ/2⌉ で使い、2j < ℓ なので満たされる。∎

**密度。**
- ℓ の分布は、K21 のログのとおり ℓ = 1, 2, … の密度が 1/2、1/4、…。
- ℓ を決めると、E/2^ℓ は奇数で、m + 2 − E/2^ℓ は偶数。その付値 μ ≥ 1 は、さらに下の桁で一様に分布し、μ が奇数の確率は 2/3。
- よって (b) は (1/3)·(2/3) = 2/9、(c) は 1/9。数値の個数（下）もこれに合う。

### 補足

- (c) のとき、さらに d_{ℓ/2+1} は整数でなくなる（分子の付値が ℓ になる）。そのため、この連鎖では先へ進めない。
  - n₁ − ℓ/2 の分布（下）は、1, 2, 3, … がおよそ 2/3, 2/9, 2/27, … の割合で、同じ形の連鎖がもう一段ある可能性を示している。
- 定理 K19、K20 の型の始まりは (a) の特別な場合である。
