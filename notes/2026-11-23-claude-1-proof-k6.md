### 定理 K6 `[非形式証明]`

m ≡ 5 (mod 8)（m ≥ 5）のとき、すべての n ≥ 1 で：(n, 0) が P ⇔ n ≡ 0 または n ≡ m+2 (mod 2m+3)。

**準備**：
- m = 8t + 5（t ≥ 0）と書くと、h = 4t + 3。よって h は奇数で、h ≡ 3 (mod 4)、h ≥ 3。
- m は奇数なので、m+1 は偶数、m+2 は奇数。
- e* := (m + 2 + h)/2 とおく。m + 2 = 2h + 1 なので e* = (3h + 1)/2 = 6t + 5。
  よって e* は奇数の整数で、e* ≤ m ⇔ 3h + 1 ≤ 4h − 2 ⇔ h ≥ 3 から e* ≤ m。

**主張 P(j)**：
- j が偶数なら、1 ≤ d ≤ m のすべての奇数 d で d ∈ S_j、かつ g_j = m+2。
- j が奇数なら、g_j = m+1。

P(j) を j についての強い帰納法で示す。帰納法の仮定は「P(0), …, P(j−1) が成り立つ」こと。

**j = 0**：
- 定理 K3 より、奇数 d は v2(d) = 0 が偶数なので d ∈ S₀。
- h は奇数なので h ∈ S₀。m は奇数なので、H(0)(c) より g₀ = m+2。

**j ≥ 2 が偶数**：仮定 P(j−1) より g_{j−1} = m+1（j−1 は奇数）。
- 1 ≤ d ≤ m の奇数 d について、H(j)(d) の (i)〜(iii) を調べる。
  - (i)：d が奇数なので成り立たない。
  - (ii)：g_{j−1} + d = (m+1) + d は「偶数 + 奇数」で奇数なので、成り立たない。
  - (iii)：g_{j−1} = m+1 ≠ m+2 なので、成り立たない。
- よって d ∈ S_j。特に h ∈ S_j（h は奇数で 1 ≤ h ≤ m）。
- H(j)(c) より g_j = m+2。

**j ≥ 1 が奇数**：仮定 P(j−1) より g_{j−1} = m+2 で、j−1 は偶数なので、奇数 d はすべて S_{j−1} に入る。
d = h について、H(j)(d) の (i)〜(iii) を調べる。
- (i)：h は奇数なので成り立たない。
- (iii)：d = h − 1 が条件だが、d = h ≠ h − 1 なので成り立たない。
- (ii)：j ≥ 1 で、g_{j−1} + h = (m+2) + h は「奇数 + 奇数」で偶数。
  e = (g_{j−1} + h)/2 = e* は、準備より e* ≤ m。
  e* は奇数なので、仮定より e* ∈ S_{j−1}。よって (ii) が成り立つ。
- したがって h ∉ S_j。H(j)(c) より g_j = m+1。

これで P(j) がすべての j で成り立つ。

**A 行の位置**：g_j = m+2（j が偶数）、m+1（j が奇数）なので、i ≥ 0 について次が成り立つ（i についての帰納法で確かめられる）。
- a_{2i} = i(2m + 3)
- a_{2i+1} = i(2m + 3) + (m + 2)

確認：
- a₀ = 0。
- a_{2i+1} = a_{2i} + g_{2i} = i(2m+3) + (m+2)。
- a_{2i+2} = a_{2i+1} + g_{2i+1} = i(2m+3) + (m+2) + (m+1) = (i+1)(2m+3)。

A 行の集合は {n ≥ 0 : n ≡ 0 または m+2 (mod 2m+3)}。
（0 ≤ m+2 < 2m+3 なので、これは剰余で正しく表せている。）
系 1.1 より、n ≥ 1 で (n, 0) が P ⇔ n が A 行 ⇔ n ≡ 0 または m+2 (mod 2m+3)。∎

### 補足

- **どこで m ≡ 5 (mod 8) を使ったか**：e* = (3h+1)/2 が奇数であることだけ（h ≡ 3 (mod 4) が必要）。
  これが「奇数 d はすべて 1 つ前の偶数番目のブロックに入っている」ことと組み合わさって、h ∉ S_j を出す。
- **先手の必勝手**：n mod (2m+3) = c とする。
  - 0 < c < m+2 なら k = c を取ると A 行 n − c に移る。
  - m+2 < c < 2m+3 なら k = c − (m+2) を取ると A 行に移る。このとき 1 ≤ k ≤ m。
  - c が 0 でも m+2 でもないとき、先手は上のどちらかで必ず勝てる（ラベルは K6 と同じ `[非形式証明]`）。
- **数値による裏付け**：m ≡ 5 (mod 8)、m ≤ 100, n ≤ 10000 で反例なし（全探索）。m ≤ 200 で R 経由でも反例なし（`data/conjecture_checks.txt`）。

## うまくいかなかったこと（m ≡ 1 (mod 8) への拡張の試み）

同じ議論を m ≡ 1 (mod 8)（h ≡ 1 (mod 4)）に当てはめようとしたが、完全にはいかなかった。

- **うまくいく部分**：
  - h ≡ 1 (mod 4) では e* = (3h+1)/2 が偶数になり、「e* ∈ S₀ ⇔ v2(e*) が偶数」（K3）でブロック 1 の挙動が分かれる。
  - h = 4t + 1 とすると e* = 2(3t + 1) なので、v2(e*) = 1 + v2(3t+1)。
  - v2(3t+1) が奇数なら e* ∈ S₀ となって h ∉ S₁、g₁ = m+1。例：m = 25（t = 3）は「10」型。
  - v2(3t+1) が偶数なら e* ∉ S₀ となって h ∈ S₁、g₁ = m+2。例：m = 9（t = 2）は「110」型。
  - ここまでは H(1)(d) の (ii) を直接計算しただけ。g₁ の予測は m ≡ 1 (mod 8), 9 ≤ m ≤ 200 の 24 個すべてで R の計算と一致した。
- **うまくいかない部分**：
  - ブロック 2 以降では、g が m+2 のブロックが続くと、偶数番目のブロックで「奇数 d がすべて S_j に入る」が崩れる。
    (ii) が g + d 偶数の奇数 d にも効くようになるから。
  - そのため、P(j) のような単純な不変量が作れなかった。
  - 実際、m ≡ 1 (mod 8) の周期型は「10」「110」「1110110」「111010」などばらばら（`data/block_periods_m2-200.txt`）。
    単純な閉じた式があるかどうかも分からない。
