### 補題 4.0（言い換え）

m ≥ 2 のとき、次の 3 つは同値。
- (1) すべての n ≥ 1 で「(n, 0) が P ⇔ (m+1) | n」。
- (2) A 行の集合が {0, m+1, 2(m+1), …}。
- (3) すべての j で g_j = m+1。

証明：
- (1) ⇔ (2)：系 1.1 より、n ≥ 1 では「(n, 0) が P ⇔ n が A 行」。r = 0 は常に A 行。
- (2) ⇔ (3)：a₀ = 0 で、a_j は A 行を小さい順に並べたもの。
  - (3) ⇒ (2)：a_j = j(m+1) なので、A 行の集合は m+1 の倍数全体。
  - (2) ⇒ (3)：A 行の集合が m+1 の倍数全体なら、小さい順の j 番目は j(m+1) なので、g_j = m+1。∎

### 定理 K4 `[非形式証明]`

m ≥ 2 のとき：すべての n ≥ 1 で「(n, 0) が P ⇔ (m+1) | n」が成り立つ ⇔ v2(m+1) が偶数。

#### 証明（⇐、場合 1：m が偶数）

- H(j)(c) より、g_j = m+2 になるのは m が奇数のときだけ。
- m は偶数なので、H(j)(a) と合わせて、すべての j で g_j = m+1。
- 補題 4.0 より (1) が成り立つ。

（m が偶数なら m+1 は奇数で v2(m+1) = 0 は偶数なので、これは「v2(m+1) が偶数」の場合に含まれる。）

#### 証明（⇐、場合 2：m が奇数で v2(m+1) が偶数）

- **準備**：m+1 は偶数なので v2(m+1) ≥ 1。偶数なので v2(m+1) ≥ 2。
  s* := v2(h) = v2(m+1) − 1 とおくと、s* は奇数で s* ≥ 1。特に h は偶数。
  m ≥ 2 で m は奇数なので m ≥ 3 で、1 ≤ h ≤ m。

**主張 Q(j)**：次の 2 つが成り立つ。
- (Q1) g₀ = g₁ = … = g_j = m+1。
- (Q2) 1 ≤ d ≤ m かつ v2(d) ≤ s* を満たすすべての d について、d ∈ S_j ⇔ v2(d) が偶数。

Q(j) をすべての j ≥ 0 で、j についての帰納法で示す。Q1 がすべての j で成り立てば、補題 4.0 より (1) が成り立つ。

**j = 0**：
- 定理 K3 より、1 ≤ d ≤ m のすべての d で d ∈ S₀ ⇔ v2(d) が偶数。特に (Q2) が成り立つ。
- h は v2(h) = s* が奇数なので h ∉ S₀。
- H(0)(c) より g₀ = m+1。よって (Q1) が成り立つ。

**j ≥ 1**：帰納法の仮定は Q(j−1)。つまり g₀ = … = g_{j−1} = m+1 で、(Q2) が j−1 で成り立つ。

まず H(j)(d) の (ii)(iii) を簡単にする。
- **(iii)**：g_{j−1} = m+1 ≠ m+2 なので、成り立たない。
- **(ii)**：g_{j−1} + d = m + 1 + d。m+1 は偶数なので、これが偶数 ⇔ d が偶数。
  d が偶数のとき e = (m+1+d)/2 = h + d/2。

次に (Q2) を、s := v2(d) についての帰納法（s = 0, 1, …, s*）で示す。
内側の帰納法の仮定は「v2(d') < s かつ 1 ≤ d' ≤ m のすべての d' で、d' ∈ S_j ⇔ v2(d') が偶数」。

- **s = 0（d が奇数）**：
  - (i)：d が奇数なので成り立たない。
  - (ii)：g_{j−1} + d が奇数なので成り立たない。
  - (iii)：上で示したとおり成り立たない。
  - H(j)(d) より d ∈ S_j。v2(d) = 0 は偶数なので、主張と一致する。

- **1 ≤ s ≤ s*（d が偶数）**：d = 2x とおくと v2(x) = s − 1、1 ≤ x < d ≤ m。
  - **(i)**：「x ∈ S_j」かどうか。v2(x) = s − 1 < s なので、内側の帰納法の仮定より x ∈ S_j ⇔ s − 1 が偶数。
  - **(ii)**：e = h + x。
    - **e ≤ m の確認**：d は偶数、m は奇数、d ≤ m なので d ≤ m − 1。よって x ≤ (m−1)/2 = h − 1 で、e = h + x ≤ 2h − 1 = m。e ≥ 1 も明白（h ≥ 1）。
    - **v2(e) の計算**：h = 2^{s*}·u、x = 2^{s−1}·w（u, w は奇数）と書く。s − 1 < s* なので
      e = 2^{s−1}·(w + 2^{s* − s + 1}·u)。s* − s + 1 ≥ 1 なので括弧の中は「奇数 + 偶数」で奇数。
      よって v2(e) = s − 1 ≤ s*。
    - 帰納法の仮定 Q(j−1) の (Q2) を e に使うと、e ∈ S_{j−1} ⇔ s − 1 が偶数。
    - よって (ii) が成り立つ ⇔ s − 1 が偶数。
  - **場合分け**：
    - s が奇数（s − 1 が偶数）：(i) が成り立つので d ∉ S_j。v2(d) = s は奇数なので、主張と一致する。
    - s が偶数（s − 1 が奇数）：(i) も (ii) も成り立たず、(iii) も成り立たない。よって d ∈ S_j。v2(d) = s は偶数なので、主張と一致する。

これで Q(j) の (Q2) が示せた。
- h は 1 ≤ h ≤ m、v2(h) = s* ≤ s* なので (Q2) が使える。v2(h) = s* は奇数なので h ∉ S_j。
- H(j)(c) より g_j = m+1。g₀〜g_{j−1} = m+1（帰納法の仮定）と合わせて (Q1) が成り立つ。

帰納法により、すべての j で Q(j) が成り立つ。よって、すべての j で g_j = m+1。
補題 4.0 より (1) が成り立つ。∎（⇐）

#### 証明（⇒）

対偶を示す。v2(m+1) が奇数なら (1) は成り立たない。

- v2(m+1) が奇数なら v2(m+1) ≥ 1 なので、m+1 は偶数で m は奇数。m ≥ 2 なので m ≥ 3 で、1 ≤ h ≤ m。
- v2(h) = v2(m+1) − 1 は偶数。定理 K3 より h ∈ S₀。
- H(0)(c) より g₀ = m+2。よって a₁ = m+2。
  行 m+1 は a₀ = 0 と a₁ の間にあるので A 行ではない。
- 系 1.1 より (m+1, 0) は N。一方 (m+1) | (m+1) なので、(1) は n = m+1 で成り立たない。∎（⇒）

### 定理 K5 `[非形式証明]`

m ≥ 2 で v2(m+1) が奇数なら、(n, 0) が P となる最小の n ≥ 1 は n = m+2。

証明：
- K4（⇒）の証明より a₁ = g₀ = m+2。
- a₁ は 0 の次の A 行なので、1 ≤ n ≤ m+1 の行はどれも A 行ではない。
- 系 1.1 より、(n, 0) が P となる最小の n ≥ 1 は a₁ = m+2。∎

### 補足

- **主目標との関係**：K4 により、v2(m+1) が偶数の m ≥ 2 では、主目標 1 の答えが出る。
  - 開始局面 (n, 0) が先手必勝 ⇔ n が m+1 の倍数でない。
  - これは m が偶数のときと、m ≡ 3 (mod 8)、m ≡ 15 (mod 32) などのとき。

  ただし前提が未査読なので、ラベルは `[非形式証明]`。v2(m+1) が奇数の m では、まだ特徴づけができていない。
- **先手の必勝手**：K4 の条件の下で、n が m+1 の倍数でないなら、先手は k = n mod (m+1) を取れば A 行 (n − k, k) に移れる。
  (n − k) は m+1 の倍数で、A 行なのですべての p で P。最初の手には制限がない（p = 0）。
  これは K4 の証明から直接読み取れる戦略（ラベルは K4 と同じ `[非形式証明]`）。
- **数値による裏付け**：K4 は 2 ≤ m ≤ 100, n ≤ 10000 で反例なし（全探索）。K5 も 2 ≤ m ≤ 100 で反例なし（`data/conjecture_checks.txt`）。
