# 定理 K29（すべての奇数 v ≥ 5）の Lean 4 での形式化

## やったこと

`lean/Rubidium/K29gen.lean` に、定理 K29 を一般の奇数 v ≥ 5 で、sorry なしで証明した。

```lean
theorem K29_gen (m v u : Nat) (hv5 : 5 ≤ v) (hvo : v % 2 = 1) (hmu : m + 1 = 2 ^ v * u) (hu : u % 4 = 1)
    (hu5 : 5 ≤ u) (n : Nat) :
    IsP m n 0 ↔ (n % L = 0 ∨ (m + 2 ≤ n % L ∧ (n % L - (m + 2)) % (m + 1) = 0))   -- L = (m+2) + ((v−1)/2)(m+1)
```

主張の意味：型は前周期なしで、周期は 1 0^{(v−1)/2}。v2(m+1) = v の m の半分にあたる。
公理は `[propext, Classical.choice, Quot.sound]`。

主張は、直接の DP と照らし合わせて確かめた：(v, u) = (5, 5)、(5, 9)、(7, 5)、(7, 9)、(7, 13)、(9, 5) で、n ≤ 2L まで一致。

**u ≥ 5 の仮定について**：u = 1（m = 2^v − 1）では、c = H − 1 の距離が「(iii) の対象」になる。もとの証明の 3 値の計算でも、ここは U（不明）として扱っている。
Lean の証明では、補題 `p_oddb` の条件 qu + 1 ≠ h のために u ≥ 5 を使った。u = 1 で v = 5（m = 31）は、K29.2（PR #420）に含まれる。

## 証明の組み立て

もとの証明（ノート 2026-11-23-claude-1-k29-proof.md）は、補題 P_n・Inh_n と 3 値の計算を使っていた。Lean では 3 値を使わず、値が T か F に決まる q だけを追った。H(j) は使わない。

**追う q**（「よい q」）は次の 2 種類。T(q) := (qu ≡ 3 (mod 8)) とおく。
- q ≡ 1 (mod 4)：S₁[q] = F。e_q = (m+2+qu)/2 は奇数なので、行 a で P。
- qu ≡ 3 (mod 8)：S₁[q] = T。e_q の v2 は 1 なので、行 a で N（Blk m 1）。よって `p_oddb` で P。

この性質は、q′ = q + 2^{v−b}（v − b ≥ 3）にしても保たれる（mod 8 で同じだから）。

**部品**
- `k29_S0`：行 b で、(b + 2^b·qu) が P ⇔ (T(q) ⇔ b が偶数)。`o_iter` を使う。
- `k29_istep`：E 型のブロック c_j で、2j ≤ b ≤ v − 3 なら、同じ値 V(q, b) = (T(q) ⇔ b が偶数)。K38 の `k38_istep` の値を V に変えたもの。
- `k29_eD`：2^{v−2}·ku（k = 1, 3）について `e_iff` を書き直したもの。

**h の所属**（`k29g_step`）
- 行 b：S₁[H] = V(1, v−1) = F。よって (b + h) は N。
- c_j（1 ≤ j ≤ (v−3)/2）：H/2 = 2^{v−2}u は P。`k29_eD` で、半分 2^{v−3}u（q = 1）と 1 つ前のブロックの 2^{v−3}·5u（q = 5）がどちらも N（V = F）だから。よって手 H/2 で (c_j + h) は N。
- 最後の c_{(v−1)/2}：
  - H/2 は Blk m (v−2) より N（v2 = v − 2 は奇数）。
  - 3H/2 は 1 つ前のブロックで N。u ≡ 1 (mod 8) なら T(3) で (c + 2^{v−3}·3u) が P。u ≡ 5 (mod 8) なら T(7) で (p + 2^{v−3}·7u) が P。どちらでも `k29_eD` の右辺が崩れる。
  - よって `e_iff` で (c + h) は P。この行が次の周期の始まりになる。
- 周期の始まりの行で使うのは、Blk m 1（`blk_mono`）と (a + h) が P であることだけ。

## 意味

- **定理 K29 が、すべての奇数 v ≥ 5（u ≥ 5）で [Lean検証済み] の候補になった**（査読待ち）。もとの証明は計算機による証明書（v ≤ 27）と、手での証明（H(j) を前提）だった。
- K38（PR #429・#431）と合わせると、v2(m+1) = v ≥ 5 の奇数の m のうち、次の部分の型が Lean で確かめられた。
  - u ≡ 1 (mod 4)（K29）：全体の 1/2
  - u ≡ 3 (mod 4) で w の条件を満たすもの（K38）：全体の約 1/6

## 追記（2026-11-25）：仮定 u ≥ 5 を外した（Issue #436、ブランチ claude-1/lean-k29u1）

u ≥ 5 を使っていたのは、`k29_S0` の qu + 1 ≠ h（`p_oddb` の条件）だけだった。
これは T の種類の q（qu ≡ 3 (mod 8)）にしか使わない。そのとき qu + 1 ≡ 4 (mod 8) で、h = 2^{v−1}·u ≡ 0 (mod 8)（v − 1 ≥ 4）なので、u によらず qu + 1 ≠ h となる。
そこで仮定を外した。これで `K29_gen` は、m + 1 = 2^v·u、u ≡ 1 (mod 4) のすべて（u = 1、つまり m = 2^v − 1 を含む）を扱う。
u = 1 の場合、m = 2^v − 1（v = 5, 7, 9, 11, 13）が型 1 0^{(v−1)/2} であることを、直接の DP で n ≤ 3L まで確かめた。

もとの証明で u = 1 のときの c = H − 1 を「不明」としていたのは、3 値の計算がこの距離を扱えなかったためで、型の結論には影響しない（H − 1 ≡ 7 (mod 8) は u = 1 では「よい q」に入らず、証明で使わない）。

`code/lean_coverage.js` と `data/lean_coverage.txt` も、この変更に合わせて更新した。
