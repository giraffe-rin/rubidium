# 予想 K40：周期の始まりの状態の比較

## やったこと

- 予想 K40（q = 23、N 偶数）の証明を閉じるには、「周期の始まりのブロックで使う事実が、ブロック 0（K3）と E 型の始まりで同じ値になる」ことが要る（`notes/2026-11-24-claude-1-k40-chains.md`）。
- `code/k40_start_state.js` で、N = 22, 44, 66, 88, 110, 132, 220 について、ブロック 0〜3P の間隔を遅延評価で求めた（`data/k40_start_state.txt`）。
  - 各周期の始まり B = 0, P, 2P（P = N/2）で参照された距離と値を集めて比べた。

**前提**：ブロック漸化式 R。

## 結果 `[予想]`（観察）

| N | 参照された距離（B = 0 / P / 2P） | B = 0 と P の両方で参照 | 値が違うもの |
|---|---|---|---|
| 22 | 12 / 23 / 22 | 12 | 0 |
| 44 | 27 / 50 / 44 | 24 | 0 |
| 88 | 49 / 94 / 88 | 46 | 0 |
| 220 | 115 / 226 / 220 | 112 | 0 |

- どの N でも、間隔の列は (1^{N/2−1} 0)^3 で、両方で参照された距離の値はすべて一致した。
- 参照される距離の個数は N に比例して増える（N = 220 で 115 個）。
  - 中身は、鎖 2a − 4^i、2a − 5·2^t、M − 9·2^t の各要素と、入り口の距離。
- ブロック 0 だけで参照された距離（N = 44 で 3 個）がある。遅延評価の順序の違いで、周期 1 の計算では使われなかったもの。

これは、帰納法による証明の形（周期 q の計算が、始まりのブロックの事実だけに依存し、それが周期ごとに同じ値になる）と矛盾しない。

## うまくいかなかったこと

- 最初の比較では、距離を「a の 1 次式」の文字列にそろえるときに、表せない距離をまとめて「?」にしていた。そのため「値が違う」と誤って判定した。距離そのもので比べ直した上の結果が正しい。
- 証明はまだ閉じていない。参照される距離が N とともに増えるので、「有限個の距離」ではなく、鎖ごとに始まりの値が一致することを示す必要がある。
  - 鎖 2a − 4^i（v2 = 1）、M − 9·2^t（奇数）は、K3 と E 型ブロックの規則で値が一致することがすぐわかる。
  - 鎖 2a − 5·2^t の終わりの部分などは、まだ。
