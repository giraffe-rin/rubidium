# 定理 K66：m + 1 = 8u、u ≡ 11 (mod 16) なら 110 型

## 見つけた経緯

v2(m+1) = 3 で、Lean で型が決まっていない m（K10 (a)・K13 以外）の型を、u mod 16 と v2(9u+1)、v2(11u+1) ごとに数えた（u ≤ 1500、漸化式 R）。
u ≡ 11 (mod 16)（v2(9u+1) = 2、v2(11u+1) = 1）の 94 個は、すべて 110 型だった。ほかの類は混在していた（u ≡ 3 では 11100、110、11110 など）。

## 定理と Lean での証明

`lean/Rubidium/K66.lean`（sorry なし、公理 `[propext, Classical.choice, Quot.sound]`）：

```lean
theorem K66 (m : Nat) (hm : (m + 1) % 128 = 88) (n : Nat) :
    IsP m n 0 ↔ (n % (3m+5) = 0 ∨ n % (3m+5) = m + 2 ∨ n % (3m+5) = 2m + 4)
```

(m+1) % 128 = 88 は、m + 1 = 8u、u ≡ 11 (mod 16) と同じ。
直接の DP でも、u = 11, 27, 43, 59, 75 で n ≤ 3L まで一致した。

**証明**（局面の言葉、H(j) を使わない）：h = 4u。行は a（始まり）、b = a + (m+2)（O）、c = b + (m+2)（O）、a' = c + (m+1)。
始まりの行で使うのは、Blk m 1（奇数は P、v2 = 1 は N）と、(a + 4u) が P であることだけ。

- **(b + 4u) は P**。(b + u) は P で、半分の規則を 2 回使うと (b + 4u) が P になる。
  (b + u) が P なのは、相手 X₁ = (9u+1)/2 の v2 が 1 で、行 a で N だから。
- **(c + 4u) は N**。
  - (b + o₁)（o₁ = X₁/2）は N。相手 Y = (41u+5)/8 が奇数で、行 a で P だから。
  - よって (b + X₁) は P、(c + u) は N、(c + 2u) は P、(c + 4u) は N。
- **(a' + 4u) は P**（`e_iff`）。
  - (a' + 2u) は N（v2 = 1）。
  - (c + 6u) は N。順に、(b + X₃) が N（X₃ = (11u+1)/2、相手 Z = (27u+3)/4 は奇数）、(c + 3u) が P、(c + 6u) が N。
- 行 b、c、a' がすべての p で P になることは、`row_long`・`row_next` で示す。a' の Blk m 1 は `blk1_direct` による。

Y・Z・X₁ の偶奇は、u ≡ 11 (mod 16) から出る（41u + 5 ≡ 8 (mod 16)、27u + 3 ≡ 4 (mod 8)、9u + 1 ≡ 4 (mod 8)）。
