## 結果

### 系 W（必勝手の明示）`[非形式証明]`

**勝ち手の一般形**：局面 (r, p) で、行き先が P 局面になる合法手は W(r, p) := T(r) \ {p} の要素だけ。
(r, p) が N ⇔ W(r, p) ≠ ∅。

- 証明：合法手は {1, …, min(m, r)} \ {p}。
  そのうち行き先 (r − k, k) が P になる k の集合は、T(r) の定義から T(r) \ {p}。
  N の定義（P へ移る合法手がある）と合わせて成り立つ。∎

**m = 1 の場合**：r ≥ 1 では T(r) = {1}（K7′ の証明の m = 1 の部分）。
よって (r, p) が N ⇔ p ≠ 1 で、必勝手は k = 1。r = 0 では手がない（P）。

**m ≥ 2 の場合**：r がブロック j の距離 d の行（r = a_j + d、0 ≤ d < g_j）とする。必勝手は次のとおり。

1. **d = 0（A 行）**：T(r) = ∅ なので、すべての p で P。必勝手はない。
2. **1 ≤ d ≤ m で p ≠ d**：k = d を取る。行き先 (a_j, d) は A 行なので P。
3. **1 ≤ d ≤ m で p = d**：
   - (r, d) が N ⇔ d ∉ S_j。
   - そのとき、次のうち成り立つものを 1 つ取る（少なくとも 1 つは成り立つ）。
     - (i) d が偶数で d/2 ∈ S_j なら、k = d/2。行き先は同じブロックの距離 d/2 の行で、局面は (a_j + d/2, d/2)。これは S(d/2) 行の P 局面。
     - (ii) j ≥ 1、g_{j−1} + d が偶数、e = (g_{j−1} + d)/2 ≤ m、e ∈ S_{j−1} なら、k = e。行き先は 1 つ前のブロックの距離 e の行で、局面は (a_{j−1} + e, e)。これは P。
     - (iii) j ≥ 1、g_{j−1} = m+2、d = h − 1 なら、k = h。行き先は 1 つ前のブロックの距離 m+1 の行で、局面は (a_{j−1} + m + 1, h)。これは P。
4. **d = m+1**（g_j = m+2 のときだけ現れる）：
   - (r, p) が N ⇔ p ≠ h。
   - そのとき k = h を取る。行き先は (a_j + h, h) で、h ∈ S_j（H(j)(c)）なので P。

**証明**：
- **ケース 1, 2, 3**：H(j) の証明のステップ 2 の「まとめ」より、1 ≤ d ≤ m では T(r) = {d} ∪ X。
  X は (i)〜(iii) のそれぞれが成り立つときに生じる手 d/2、e、h からなる集合で、どれも d と異なる。
  - p ≠ d なら d ∈ W(r, p)。
  - p = d なら W(r, d) = X。X ≠ ∅ ⇔ (i)〜(iii) のどれかが成り立つ ⇔ d ∉ S_j（H(j)(d)）。
  - 各手の行き先が P であることは、ステップ 2 でそれぞれの手を T(r) に入れたときの理由そのもの。
- **ケース 4**：ステップ 3 の (β) より T(r) = {h} なので、W(r, p) = {h} \ {p}。
- **d = 0**：ステップ 3 (α) とステップ 4 で、A 行では T(r) = ∅ と示してある（a₀ = 0 も T(0) = ∅）。
- 以上と「勝ち手の一般形」から、主張が成り立つ。∎

### 補足

- **戦略の性質**：多くの N 局面では「直前の A 行まで戻す」（k = d）だけで勝てる。
  それが禁じられているとき（p = d）だけ、同じブロックの半分の距離か、1 つ前のブロックへ移る別の手が要る。
- **数値による確認**：`node code/strategy.js check 2 100 10000` で、2 ≤ m ≤ 100, 0 ≤ r ≤ 10000、全 p の 51,485,148 局面すべてについて次を確かめた。
  - 戦略が「手なし」と判定する ⇔ P 局面。
  - 戦略が返す手は合法で、行き先が P 局面。

  反例はなかった（`data/strategy_check.txt`）。
- **開始局面との関係**：p = 0 は d と一致しないので、開始局面 (n, 0) ではケース 2（n が A 行でなく、距離 d ≤ m のとき）かケース 4 になる。
  A 行でない開始局面では、先手は「直前の A 行まで戻す」か「k = h」で勝てる。
  K4・K6 の補足に書いた戦略は、この特別な場合にあたる。
