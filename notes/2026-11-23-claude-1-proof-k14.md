### 定理 K14 `[非形式証明]`

m ≥ 5 で v2(m+1) = 1、v2(3h+1) = 2k（k ≥ 2）とし、q := v2(Q_k) が偶数とする。このとき次が成り立つ。
- g₀ = g₁ = g₃ = m+2、g₂ = m+1
- g₄ = m+2 ⇔ q ≥ 2

### 系 K14.1 `[非形式証明]`

v2(m+1) = 1、v2(3h+1) = 2k（k ≥ 2）とする。
- (1) m が 1(10)^k 型なら v2(Q_k) = 0。
- (2) k = 2 なら、「m が 11010 型 ⇔ v2(Q₂) = 0」。

**証明。**
- (1) 1(10)^k 型では g₂ = g₄ = m+1（k ≥ 2 なので、4 は周期 2k+1 の中の偶数番目）。
  - m ≠ 9 なら、K12″ (b) より q は偶数。すると K14 より q < 2、つまり q = 0。
  - m = 9（k = 2、q = 1）は、計算で確かめた。

    - 手での証明はしていない。
- (2) (1) と K12″ (a) から従う。∎

### 証明（定理 K14）

**準備。**
- **w ≠ 1 であること**：w = 1 なら Q_k = h + 1 = (4^k + 2)/3。4^k + 2 ≡ 2 (mod 4) なので v2(Q_k) = 1 となり、q は奇数。
  よって q が偶数なら w ≥ 3 で、4^k w = 3h + 1 ≥ 48 より h ≥ 16。
- **(iii) の対象**：h − 1 = 2^i w N（N は奇数、i ≥ 1）とすると、3·2^i w N = 4^k w − 4 となり、w は 4 を割る。よって w = 1 となり、上に矛盾する。
  したがって、下で O 型のブロックで調べる偶数の距離（e_i、2^i w_t）は (iii) の対象にならない。
- **記号**：1 ≤ t ≤ 2k−2 について、次のようにおく。
  - f_t := h + e_t（奇数）
  - c_t := e* + e_{t−1} = 2^{t−1} w_t。ここで w_t := w(2^{2k−t} + 1)（奇数）。
  - Y_t := (m+2+w_t)/2 = Q_k + 2^{2k−t−1} w
  - 最後の等式は、Q_k = (m+2+w)/2 と w_t − w = 2^{2k−t} w から従う。
- **値の範囲**（h ≥ 16 で、どれも 1 以上 m = 2h−1 以下）：
  - f_t ≤ h + e_{2k−2} = h + (3h+1)/4 ≤ 2h−1 ⇔ h ≥ 5。
  - c_t ≤ e* + e_{2k−3} = 5(3h+1)/8 ≤ 2h−1 ⇔ h ≥ 13。
  - 2^i w_t（0 ≤ i ≤ t−1）は c_t 以下。
  - Y_t ≤ m ⇔ w_t ≤ 2h−3。w_t ≤ w(2^{2k−1}+1) = e* + w ≤ 9(3h+1)/16 で、これは h ≥ 12 なら 2h−3 以下。
  - e*、Q_k ≤ m は K12″ のログで示した。
- **(ii) で使う e の値**：
  - O 型で f_t を調べるとき、e = (m+2+f_t)/2 = (3h+1+e_t)/2 = e* + e_{t−1} = c_t。
  - O 型で w_t を調べるとき、e = Y_t。
  - E 型で e_i（i ≥ 1）を調べるとき、e = h + e_{i−1} = f_{i−1}。

**ブロック 0〜2。**
- K12″ (b) より g₀ = g₁ = m+2。q は偶数なので g₂ = m+1。
- その証明から、O 型のブロック 1 では e_i ∈ S₁ ⇔ i が奇数（0 ≤ i ≤ 2k−1）。

**ブロック 3。**
- g₂ = m+1 なので E 型。h（奇数）∈ S₃ より g₃ = m+2。

**ブロック 4。**
- g₃ = m+2 なので O 型。h ∈ S₄ ⇔ e* ∉ S₃。以下で e* ∈ S₃ ⇔ q = 0 を示す。

**f_t ∈ S₂ の判定（1 ≤ t ≤ 2k−2）。**
- ブロック 1（O 型、1 つ前は K3）で：
  - w_t ∈ S₁ ⇔ Y_t ∉ S₀ ⇔ v2(Y_t) が奇数。
  - O 型の偶数の規則で 2 倍ずつたどると、c_t = 2^{t−1} w_t ∈ S₁ ⇔ v2(Y_t) + (t−1) が奇数 ⇔ v2(Y_t) + t が偶数。
- ブロック 2（O 型）で：f_t ∈ S₂ ⇔ c_t ∉ S₁ ⇔ **v2(Y_t) + t が奇数**。
- Y_t = Q_k + 2^{2k−t−1} w で、2k−t−1 ≥ 1 である。
  - q = 0 なら Y_t は奇数で v2(Y_t) = 0。よって f_t ∈ S₂ ⇔ t が奇数。
  - q ≥ 2 で t = 2k−2 なら Y_t = Q_k + 2w で v2(Y_t) = 1。1 + (2k−2) は奇数なので f_{2k−2} ∈ S₂。

**ブロック 3（E 型）での e_i。**
- e₀ = w（奇数）∈ S₃。e₁ は (i) で入らない。
- 2 ≤ i ≤ 2k−1 では、e_i ∈ S₃ ⇔ e_{i−1} ∉ S₃ かつ f_{i−1} ∉ S₂。
- **q ≥ 2 の場合**：f_{2k−2} ∈ S₂ なので e* = e_{2k−1} ∉ S₃。よって h ∈ S₄、g₄ = m+2。
- **q = 0 の場合**：i についての帰納法で、2 ≤ i ≤ 2k−1 では「e_i ∈ S₃ ⇔ i が奇数」を示す。
  - i が偶数：f_{i−1} ∈ S₂（i−1 は奇数）なので e_i ∉ S₃。
  - i が奇数（≥ 3）：e_{i−1} ∉ S₃（帰納法の仮定、i−1 は 2 以上の偶数）、f_{i−1} ∉ S₂（i−1 は偶数）。よって e_i ∈ S₃。
  - 2k−1 ≥ 3 は奇数なので e* ∈ S₃。よって h ∉ S₄、g₄ = m+1。
- H(4)(c) より主張が成り立つ。∎
