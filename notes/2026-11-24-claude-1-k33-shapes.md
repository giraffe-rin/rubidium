## 追記：記号的な証明（定理 K58 への査読（PR #354）と同じ基準に合わせる）

定理 K58 の査読で、「形の比較だけでは定理 K36d″ の基準に届かない」と指摘された。この定理も同じ方法で示していたので、鎖を記号的に記述し直した。

### 記号と恒等式

- q = 1、r = −1、s = 3、X = 2^e、a = 3X + 1（qa + r = sX）とする。e は奇数で、R = (e − 1)/2。
- 周期は w = 1^{e−1} 0 1^R 0、L = 3R + 2。E 型ブロックは B と E1（= ブロック 2R + 1）。
- v2(m+1) = 1 なので、h = (3a − 1)/2 は奇数である。

鎖の距離 d = (αa − c)/2^K、β = rα + qc = c − α について、恒等式 r(αa − c) = βa − csX が成り立つ。

- 奇数の点で β = 2^K b なら、d = 3c·2^{e−K} − ba。
- 写像は T(b) = (b − 3)/2^{t(b)}、t(b) = v2(b − 3)。

**越える場面（補題 K59.1 の一般の r 版）**：奇数の点（β = 2^K b、K < N）での奇数の段の後に、2^K(b + 3r) = 2^E b′ となったとする。

- **E = N**：u = v2(b′a − cs) とおく。半分にする段は (N − K − 1) + u 回で、新しい鎖は α′ = r b′、c′ = r c s、K′ = u、β′ = b′ + q r c s。
- **E > N**：半分にする段は N − K − 1 回で、新しい鎖は α′ = r·2^{E−N} b′、c′ = r c s、K′ = 0、β′ = 2^{E−N} b′ + q r c s。

証明は、d = 2^{N−K−1}(2^{E−N} b′a − cs)/r に v2 を当てるだけである（r = ±1）。r = 1 のときは補題 K59.1 と同じ。

### 鎖 A：入口 2a + 1（= 6X + 3、α = 2、c = −1、K = 0）

- β = −3 は奇数なので、b = −3 の奇数の点。T(−3) = (−6)/2 = −3（t = 1）で、b = −3 の不動点にとどまる。
- j 番目の奇数の点は K = j − 1、d = 3a − 3·2^{e−K}。
- 長さ n ≤ e − 1 の鎖で、最後の段の後の E = n ≤ e − 1 < N なので、越えない。終点の v2 は t − 1 = 0（奇数、入る）。
- 段数は n なので、値は「n が偶数なら入る」。
  - E1 からの鎖（n = 2R）では「入る」。
  - B からの鎖（n = R）では、e ≡ 1 (mod 4) なら「入る」、e ≡ 3 なら「入らない」。
- 条件：0 < d < 3a − 4（K ≤ e − 2 で 3·2^{e−K} ≥ 12）。d = h − 1 ⇔ 3X + 2 = 2^{e−K+1} で、e ≥ 2 では解がない。

### 鎖 B：入口 5(a + 1)/2（= (15X + 10)/2、α = 5、c = −5、K = 1）

- β = −10 = 2·(−5) なので、K = 1、b = −5 の奇数の点（半分にする段なしで始まる）。
- T(−5) = (−8)/8 = −1（t = 3）、T(−1) = (−4)/4 = −1（t = 2）。奇数の点の K は 1, 4, 6, …（j ≥ 2 で K_j = 2j）、段の後の E は 4, 6, 8, …（j ≥ 2 で 2j + 2）。
- **B からの鎖（n = R）**：最後の段（j = R、K = e − 1）で E = e + 1 > N。
  - 半分にする段は N − K − 1 = 0 回で、終点 d = (2b′a − cs)/r = 2a − 15（b′ = −1）。これは奇数なので入る。
  - 段数は R + (2 + (R − 2)) = 2R（偶数）なので、値は「入る」。
- **E1 からの鎖（n = 2R）**：j = R で E = e + 1 > N となり越える。
  - 半分にする段は 0 回。新しい鎖は α′ = 2、c′ = 15、K′ = 0、β′ = −2 + 15 = 13。
  - 越えた後の軌道は 13 →（t = 1）5 →（t = 1）1 →（t = 1）−1 →（t = 2）−1 → …。最後の奇数の点（越えた後の R 番目）で K′ = 2R − 5 で、E = 2R − 3 < N なので、2 回目は越えない。
  - 終点の v2 は t(−1) − 1 = 1（入らない）。
  - 段数は 2R + (2 + (R − 2) + 0 + 0 + 0 + (R − 4)) = 4R − 4（偶数）なので、値は「入らない」（e = 21 で段数 36、数値と一致）。
- 条件：越える前の d は 5(a + 1)/2、a − 15·2^{e−K}（K ≥ 4）。越えた後の d は 45·2^{e−K′} − ba で、2a − 15、(5a − 15)/2、(11a − 15)/4、a + 15(a − 1)/2^{K′}（K′ ≥ 3）。どれも (0, 3a − 4) にあり、h − 1 と等しくない（a = 3·2^e + 1 が十分大きいとき）。

### 1 段の全体

周期の始まり B の仮定は、奇数は入る、v2 = 1 は入らない（補題 K33d）、6X + 8 ∉ S_B。

- **最初の連（ブロック 1..2R）**：h の鎖は c = 1、α = 3、K = 1、β = −2 で、b = −1、t = 2。
  - **i ≤ R − 1**：E = 2i + 1 < N なので、終点の v2 は 1（入らない）。段数は 2i − 1（奇数）なので h ∈ S_i。
  - **i = R**：E = N。u = v2(−a − 3) = v2(3X + 4) = 2。終点 d = 2^{N−K−1}(b′a − cs)/r = 2(a + 3) = 6X + 8（K = e − 2）。仮定により入らないので、h ∈ S_R。
  - **R < i ≤ 2R**：R 段目で越えて、新しい鎖 α′ = 1、c′ = −3、K′ = 2、β′ = −4（b = −1、t = 2）に移る。
    - 残りの n′ = i − R ≤ R − 1 段では、E′ = 2n′ + 2 < N なので、終点の v2 は 1。段数は 2R + 2n′ + 1（奇数）なので h ∈ S_i。
    - n′ = R（i = 2R）では、最後の段で E′ = e + 1 > N となる。終点 2a − 9 は奇数で入り、段数は 4R + 1（奇数）なので、h ∉ S_{2R}。
- **E1（ブロック 2R + 1）**：h は奇数なので入る。
- **2 本目の連（ブロック 2R + 2..3R + 1）**：h の鎖は E1 で終わる。
  - i ≤ R − 1 では、終点の v2 は 1（入らない）なので h ∈ S。
  - i = R では、終点 6X + 8 が下の評価木により E1 で入るので、h ∉ S_{3R+1}。
- **ブロック L**：h は奇数なので入る。
- **自明でない E 型の事実**：
  - E1 で 3X + 4 = a + 3：(a + 3)/2 は v2 = 1 で入らない。h + (a + 3)/2 = 2a + 1 は鎖 A（長さ 2R）で入る。よって a + 3 ∉ S_{E1}。
  - E1 で 6X + 8：a + 3 ∉ S_{E1}。h + (a + 3) = 5(a + 1)/2 は鎖 B（長さ 2R）で入らない。よって 6X + 8 ∈ S_{E1}。
  - L で 3X + 4：2a + 1 は鎖 A（長さ R）。e ≡ 1 (mod 4) なら入る（3X + 4 ∉ S_L）、e ≡ 3 なら入らない（3X + 4 ∈ S_L）。
  - L で 6X + 8：
    - e ≡ 3 では、a + 3 ∈ S_L なので、6X + 8 ∉ S_L。
    - e ≡ 1 では、a + 3 ∉ S_L で、5(a + 1)/2 は鎖 B（長さ R）で入るので、6X + 8 ∉ S_L。
    - どちらでも、仮定が次の周期で再現される。

以上は、奇数 e ≥ 21 のすべてで記号的に成り立つ（必要な小さい条件は R ≥ 4 など）。e ≤ 19 は prove による確定。値は `data/k33_shapes.txt` の自明でない事実と一致する。∎
