# 交互型の必要条件：v2(m+1) = 3 の場合（K10c）と v2(m+1) ≥ 5 の場合（K11）

## やったこと

- v2(m+1) が 3 以上の奇数の m で、交互型がどのブロックで崩れるかを R で調べた。
  - v2(m+1) ≥ 5 では、m ≤ 20000 で、必ずブロック 1 か 2 で崩れた。
  - v2(m+1) = 3 では、ブロック 2 までで決まる必要条件があることが分かった。
- ブロック 1（O 型）とブロック 2（E 型）での所属を、少数の距離について計算して証明した。
- 数値でも確かめた：v2(m+1) ≥ 3 の奇数の m ≤ 20000（1667 個）で、ブロック 0〜2 を R で計算し、下の定理と矛盾しないこと。
  その場のコマンドで確かめたので、データファイルは残していない。

**前提**：`notes/2026-11-23-claude-1-proof-structure.md` の主張 H(j) と定理 K3（`[非形式証明]`、未査読）。

「交互型」の意味は `notes/2026-11-23-claude-1-conjecture-k9.md` と同じ。

## 結果

### 記号と準備

- v := v2(m+1) は 3 以上の奇数。m + 1 = 2^v·u（u は奇数）と書く。
  - h = 2^{v−1}·u（偶数、v2(h) = v − 1 は偶数）
  - m + 2 = 2^v·u + 1（奇数）
- 奇数 c について X_c := ((2^v + c)·u + 1)/2 とおく。(2^v + c)u は奇数なので、X_c は整数。

**ブロック 0**：定理 K3 より h ∈ S₀（v2(h) は偶数）。H(0)(c) より g₀ = m+2。

**補題 O（ブロック 1 の所属）**：g₀ = m+2（奇数）なので、H(1)(d) は次のようになる。

- (O-偶) 偶数 d ≤ m について：(ii) は g₀ + d が奇数なので不成立。(iii) は対象 h − 1 が奇数なので不成立。
  よって d ∈ S₁ ⇔ d/2 ∉ S₁。
  これを i 回くり返すと、奇数 c について 2^i·c·u ∈ S₁ ⇔ 「i が偶数なら cu ∈ S₁、i が奇数なら cu ∉ S₁」。
  （2^i·c·u ≤ m の範囲で。途中の 2^{i'}·c·u も m 以下。）
- (O-奇) 奇数 d = cu（c は奇数）で、cu ≠ h − 1、かつ e = (m + 2 + cu)/2 = X_c ≤ m のとき：
  (i) は不成立、(iii) も不成立。よって cu ∈ S₁ ⇔ X_c ∉ S₀ ⇔ v2(X_c) が奇数（定理 K3）。

**値の範囲**：
- X_c ≤ m ⇔ (2^v + c)u + 1 ≤ 2^{v+1}·u − 2 ⇔ cu + 3 ≤ 2^v·u。
  v = 3 で c ≤ 3、v ≥ 5 で c ≤ 9 の範囲で使うので、いずれも成り立つ（8u ≥ 3u + 3、32u ≥ 9u + 3）。
- cu ≠ h − 1 の確認：cu = 2^{v−1}u − 1 なら u(2^{v−1} − c) = 1 なので u = 1 かつ c = 2^{v−1} − 1。
  - v = 3：c = 3 のとき u = 1（m = 7）だけが例外。
  - v ≥ 5：2^{v−1} − 1 ≥ 15 > 9 なので、使う c ∈ {1, 3, 5, 9} では起きない。

**補題 1′（g₁ の式）**：h = 2^{v−1}·u（v − 1 は偶数）なので、(O-偶) より h ∈ S₁ ⇔ u ∈ S₁ ⇔ v2(X₁) が奇数（(O-奇)）。
したがって g₁ = m+2 ⇔ v2(X₁) が奇数（H(1)(c)）。

**補題 E2（ブロック 2 の所属、g₁ = m+1 のとき）**：1 つ前の間隔 m+1 は偶数なので、次が成り立つ。
- 奇数 d は S₂ に入る。
- 偶数 d ≤ m − 1 は、d ∈ S₂ ⇔ d/2 ∉ S₂ かつ h + d/2 ∉ S₁（(ii) の e = (m+1+d)/2 = h + d/2 ≤ m）。
- (iii) は効かない。

### 定理 K10c `[非形式証明]`

v2(m+1) = 3（m + 1 = 8u）とする。m が交互型なら、v2(9u+1) = 1 かつ v2(11u+1) は偶数。

より詳しく、次が成り立つ。
- (a) g₁ = m+2 ⇔ v2(9u+1) が偶数。これは K10a と同じ。
- (b) g₁ = m+1 のとき（u ≥ 3）：g₂ = m+2 ⇔ v2(11u+1) が偶数。
- (c) u = 1（m = 7）は交互型でない。

証明：v = 3 なので X₁ = (9u+1)/2、X₃ = (11u+1)/2。
- **(a)**：補題 1′ より、g₁ = m+2 ⇔ v2(X₁) = v2(9u+1) − 1 が奇数 ⇔ v2(9u+1) が偶数。
- **(b)**：g₁ = m+1 なので補題 E2 が使える。h = 4u について調べる。
  - (i)：2u ∈ S₂ か。u は奇数なので u ∈ S₂、よって (i) により 2u ∉ S₂。したがって h の (i) は成り立たない。
  - (ii)：e = h + 2u = 6u ∈ S₁ かどうか。
    (O-偶) より 6u ∈ S₁ ⇔ 3u ∉ S₁。u ≥ 3 なら 3u ≠ h − 1 なので (O-奇) より、3u ∈ S₁ ⇔ v2(X₃) が奇数。
    よって 6u ∈ S₁ ⇔ v2(X₃) が偶数。
  - したがって h ∈ S₂ ⇔ 6u ∉ S₁ ⇔ v2(X₃) が奇数 ⇔ v2(11u+1) が偶数。
  - H(2)(c) より主張が成り立つ。
- **(c)**：u = 1 なら 3u = 3 = h − 1 で、(iii) により 3 ∉ S₁。
  - (O-偶) より 6 ∈ S₁。
  - g₁：v2(9u+1) = v2(10) = 1 は奇数なので、(a) より g₁ = m+1 で、補題 E2 が使える。
  - h = 4 の (ii)：e = 6 ∈ S₁ なので成り立ち、h ∉ S₂。
  - g₂ = m+1 となり、交互型でない。
- **まとめ**：交互型なら g₁ = m+1、g₂ = m+2 なので、(a)(b)(c) より次が必要。
  - u ≥ 3
  - v2(9u+1) が奇数
  - v2(11u+1) が偶数

  (11u + 1) − (9u + 1) = 2u は v2 = 1 なので、v2(9u+1) と v2(11u+1) の一方は 1 で、他方は 2 以上。
  v2(11u+1) が偶数（≥ 2）なら v2(9u+1) = 1。∎

**系（予想 K10 (b) の証明）** `[非形式証明]`：u ≡ 7 (mod 8) なら交互型でない。
- 11u + 1 ≡ 78 ≡ 6 (mod 8) なので v2(11u+1) = 1 は奇数。K10c より交互型でない。
- u ≡ 3 (mod 8) では 9u + 1 ≡ 4 (mod 8) で v2(9u+1) = 2。これは系 K10b（既出）。

### 定理 K11 `[非形式証明]`

v2(m+1) が 5 以上の奇数なら、m は交互型でない。

証明：v ≥ 5 とする。g₀ = m+2 は上で示した。
- **v2(X₁) が奇数の場合**：補題 1′ より g₁ = m+2。交互型でない。
- **v2(X₁) が偶数の場合**：g₁ = m+1 で、補題 E2 が使える。h ∉ S₂ を示す。
  u の 4 で割った余りで場合分けする。X₁ = ((2^v + 1)u + 1)/2 の偶奇は、(2^v+1)u + 1 ≡ u + 1 (mod 4) で決まる。
  - **u ≡ 3 (mod 4)（X₁ は偶数）**：
    - X₃ = X₁ + u は奇数なので v2(X₃) = 0。(O-奇) より 3u ∉ S₁。
    - (O-偶) で i = v − 2（奇数）とすると、3·2^{v−2}·u ∈ S₁ ⇔ 3u ∉ S₁ なので、3·2^{v−2}·u ∈ S₁。
    - これは h の (ii) の e = h + h/2 = 3·2^{v−2}·u にあたる。よって (ii) が成り立ち、h ∉ S₂。
  - **u ≡ 1 (mod 4)（X₁ は奇数）**：
    - X₅ = X₁ + 2u と X₉ = X₁ + 4u は奇数で、v2 = 0。(O-奇) より 5u ∉ S₁、9u ∉ S₁。
    - (O-偶) で i = v − 3（偶数）とすると、5·2^{v−3}·u ∈ S₁ ⇔ 5u ∈ S₁ なので、5·2^{v−3}·u ∉ S₁。
    - (O-偶) で i = v − 4（奇数）とすると、9·2^{v−4}·u ∈ S₁ ⇔ 9u ∉ S₁ なので、9·2^{v−4}·u ∈ S₁。
    - 補題 E2 で、d = 2^{v−3}·u（偶数、v − 3 ≥ 2）を見る。(ii) の e = h + 2^{v−4}·u = 9·2^{v−4}·u ∈ S₁ なので、2^{v−3}·u ∉ S₂。
    - 補題 E2 で、d = h/2 = 2^{v−2}·u を見る。
      - d/2 = 2^{v−3}·u ∉ S₂。
      - (ii) の e = h + 2^{v−3}·u = 5·2^{v−3}·u ∉ S₁。
      - よって h/2 ∈ S₂。
    - 補題 E2 で、d = h を見る。d/2 = h/2 ∈ S₂ なので (i) が成り立ち、h ∉ S₂。
- どちらの場合も、H(2)(c) より g₂ = m+1。交互型でない。∎
