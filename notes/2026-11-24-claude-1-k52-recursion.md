## 補題 K52 `[非形式証明]`

定理 K47 の族（v 奇数、偶数 ρ ≤ v − 1、N 偶数）で、連 g_B..g_{B+R−1} = m+2、g_{B+R} = m+1 の直後の E 型ブロック B+R+j（j ≥ 1）を考える。

**(a) 距離の形**：h の評価で現れる距離は、すべて x = c·(3a − 1)/2^k の形をしている（c は奇数、1 ≤ k ≤ v、c < 2^k）。

- 偶奇：k < v なら x は偶数、k = v なら x は奇数（u = (3a−1)/2^v は奇数）。
- 半分にする：x/2 は (c, k+1)。
- E 型の規則の第 2 項：e = h + x/2 = (2^k + c)(3a − 1)/2^{k+1} は (2^k + c, k + 1)。
- c < 2^k なら 2^k + c < 2^{k+1} なので、不変条件 c < 2^k は保たれる。h は (1, 1) で、1 < 2 から始まる。

**(b) e ≤ m はいつも成り立つ**：c' < 2^{k'}、k' ≤ v から、e ≤ (2^{k'} − 1)(3a − 1)/2^{k'} = 3a − 1 − (3a−1)/2^{k'} ≤ 3a − 2 = m。

**(c) 再帰**：E_j(c, k) を「(c, k) の距離がブロック B+R+j で入るか」とする（3 値：入る・入らない・不明）。

- k = v なら「入る」（奇数）。
- k < v なら、A = E_j(c, k+1) と、次の B を使う。
  - j = 1 のとき B = F(2^k + c, k + 1)。
  - j ≥ 2 のとき B = E_{j−1}(2^k + c, k + 1)。
- E_j(c, k) = (A = 入らない かつ B = 入らない)。どちらかが「入る」なら「入らない」。それ以外は「不明」。

**(d) O 型ブロック B+R での値 F(c, k)**（R ≡ 1 または L + 1 (mod 2L)、R が十分大）：

- c = 1：入口は h の偶数の段の途中なので、h ∉ S_{B+R} から、F(1, k) = [k が偶数]。
- c ≥ 3：
  - 定理 K50 の形式的な評価と同じ条件（軌道が純周期的で周期が L を割る、軌道の各 b < 3r、r の平均 < ρ）のもとで、段数の偶奇と終点の v2 = r(c) − 1 から決まる。
  - 条件を満たさなければ「不明」。

**結論**：E_j(1, 1)（j = 1..z−1）は、(v, ρ) だけで決まる有限の計算である。N にも s にもよらない。定理 K50 の形式的な評価（`code/k50_general.js` の v:ρ:formal）は、この再帰を計算している。

- プログラムは偶奇を a ≡ −r/q (mod 2^256) で決めている。
- (a) から、偶奇は「k = v か」だけで決まるので、同じことになる。
- e ≤ m の判定（leM）も、(b) により常に「はい」になっている。

## うまくいかなかったこと

- F(c, k) を、すべての c について式で与えようとした。
  - c > 3r なら「最初の奇数の点で (M+d)/2 > m なので入る」と考え、F = [v − k が偶数] とした。
  - これで計算すると、(v, ρ) = (5, 4)、R ≡ 1 (mod 4) で m+1 が 3 個続くと予想された。実際のデータ（`data/k50_check.txt`、R = 17 で 2 個）と食い違った。
  - **原因**：最初の奇数の点の距離は c(3a − 1)/2^v = c·u で、c < 2^v なので 3a − 4 を超えない。この前提が誤りだった。(M+d)/2 > m が起こりうるのは、その後の奇数の点で b ≥ 3r となったときだけで、そこでの d の大きさは b と c·q/2^K の差で決まる。
  - `code/k50_general.js` はこの場合を「不明」として扱っていて、正しい。
- 一般の ρ を示すには、E_j(1, 1)（j ≤ ρ/2 − 1）がいつも「入らない」になることを、再帰の構造から示す必要がある。
  - 評価木の大きさは 2^v 程度まで増えうる（c < 2^k）。
  - 不明を正しく扱った再帰でも、v = 41 ではメモリが尽きた。ただし定理 K50 の形式的な評価は、3 値の短絡のおかげで v = 61 まで計算できている。
