# 定理 K29 の証明（すべての奇数 v ≥ 5）

## やったこと

- 定理 K29.3（`notes/2026-11-23-claude-1-k29-general.md`）の 3 値の計算（v ≤ 27）の中身を、v = 9 で 2 進付値 b = v2(c) ごとに集計した。
  - E 型のブロック n では、b が小さい距離は q（c の奇数部分）によらず決まっていた。
  - b が大きい距離は、ブロック 1 の値をそのまま引き継いでいた。
- これを 2 つの補題（P_n、Inh_n）にまとめ、手で証明した。そこから、すべての奇数 v ≥ 5 で K29 が従う。
- `code/check_k29_lemmas.js` で、補題を v ≤ 21 の 3 値の計算と照合した（`data/k29_lemmas.txt`）。

**前提**：主張 H(j)（K8）、定理 K3（`notes/2026-11-23-claude-1-proof-structure.md`、`[非形式証明]`、未査読）。3 値の計算の規則と健全性は K29.3 のログのとおり。

## 結果

### 定理 K29 `[非形式証明]`

v := v2(m+1) が 5 以上の奇数で、u := (m+1)/2^v ≡ 1 (mod 4) なら、m は前周期なし・周期「1 0^{(v−1)/2}」の型である。
- 例：v = 5 で 100、v = 7 で 1000、v = 9 で 10000。
- v2(m+1) = v の m の中で、この条件の密度は 1/2。
- 定理 K29.2（v = 5）と K29.3（5 ≤ v ≤ 27、計算機による）を含む。

### 証明

**記号と 3 値の計算。**
- m = 2^v u − 1、N := 2^v、H := 2^{v−1}（h = Hu）、L := (v+1)/2 とする。
- u₀ := u mod 8 ∈ {1, 5} を固める。
- 距離 c·u（1 ≤ c ≤ N − 1）の所属を、K29.3 のログと同じ 3 値（T = 入る、F = 入らない、U = 不明）で表す。ブロック n の値を S_n[c] と書く。

規則（K29.3 のログで R から導いたもの。この計算は本当の所属と矛盾しない）：
- **ブロック 1（O 型）**
  - 奇数の c：c ≡ 1 (mod 4) なら F。c ≡ 3 (mod 4) なら、c·u₀ + 1 ≡ 4 (mod 8) のとき T、そうでなければ U。ただし u = 1 のときの c = H − 1 は U。
    - 特に、奇数の c の値は c mod 8 だけで決まる（H − 1 ≡ 7 (mod 8) の例外も、u₀ = 1 では 7·1 + 1 ≡ 0 (mod 8) なので、もともと U）。
  - 偶数の c：S_1[c] = ¬S_1[c/2]。よって S_1[2^b q] = S_1[q]（b 偶数）、¬S_1[q]（b 奇数）（q は奇数）。
- **ブロック n ≥ 2（E 型。1 つ前の間隔が m + 1 のとき）**
  - 奇数の c は T。
  - 偶数の c は S_n[c] = ¬S_n[c/2] ∧ ¬S_{n−1}[H + c/2]。

**事実 A（付値）。** 偶数 c = 2^b q（q 奇数、c ≠ H）では b ≤ v − 2 で、H + c/2 = 2^{b−1}(2^{v−b} + q)。
- v − b ≥ 1 なので q′ := 2^{v−b} + q は奇数で、v2(H + c/2) = b − 1。
- さらに v − b ≥ 3 なら q′ ≡ q (mod 8) なので、S_1[q′] = S_1[q]（ブロック 1 の奇数の値は mod 8 だけで決まる）。

以下、ブロック 2〜L が E 型であること（g_1 = … = g_{L−1} = m + 1）は、n についての帰納法の中で同時に示す（下の「h の所属」）。

**補題 P_n**（2 ≤ n ≤ L）：偶数 c で b = v2(c) ≤ 2n − 3 なら、S_n[c] = T ⇔ b が偶数（値は T か F で、U にならない）。

証明：n についての帰納法、各 n では b についての帰納法で示す。b ≤ 2n − 3 ≤ v − 2 なので、事実 A が使える。
- b = 1：c/2 は奇数なので S_n[c/2] = T。よって S_n[c] = F。
- b ≥ 2 が偶数：
  - c/2 の付値 b − 1 は奇数で、2n − 3 以下。帰納法により S_n[c/2] = F。
  - H + c/2 の付値も b − 1（奇数）。b は偶数で 2n − 3 以下なので b − 1 ≤ 2n − 5 = 2(n−1) − 3。
  - n − 1 ≥ 2 なら P_{n−1} により S_{n−1}[H + c/2] = F。n = 2 では b ≤ 1 なので、この場合は起きない。
  - よって S_n[c] = ¬F ∧ ¬F = T。
- b ≥ 3 が奇数：c/2 の付値 b − 1 は偶数で、2n − 3 以下。帰納法により S_n[c/2] = T、よって S_n[c] = F。∎

**補題 Inh_n**（2 ≤ n ≤ L）：偶数 c で 2n − 2 ≤ b ≤ v − 3 なら、S_n[c] = S_1[c]。

証明：n についての帰納法、各 n では b（2n − 2 から上）についての帰納法で示す。b ≤ v − 3 なので、事実 A の q′ ≡ q (mod 8) が使える。

まず、S_{n−1}[H + c/2] = ¬S_1[c] を示す。
- H + c/2 = 2^{b−1}q′ の付値は b − 1。2(n−1) − 2 = 2n − 4 ≤ b − 1 ≤ v − 3。
- n − 1 = 1 なら、そのまま S_1[2^{b−1}q′]。n − 1 ≥ 2 なら、Inh_{n−1} により S_{n−1}[H + c/2] = S_1[2^{b−1}q′]。
- ブロック 1 の偶数の規則と S_1[q′] = S_1[q] より、S_1[2^{b−1}q′] = ¬S_1[2^b q] = ¬S_1[c]。
- よって ¬S_{n−1}[H + c/2] = S_1[c]。

次に ¬S_n[c/2] を求める。
- b = 2n − 2 のとき：c/2 の付値は 2n − 3（奇数）。P_n により S_n[c/2] = F、¬S_n[c/2] = T。
  - よって S_n[c] = T ∧ S_1[c] = S_1[c]。
- b > 2n − 2 のとき：c/2 の付値 b − 1 は 2n − 2 以上 v − 3 以下。b についての帰納法により S_n[c/2] = S_1[c/2] = ¬S_1[c]。
  - よって ¬S_n[c/2] = S_1[c]、S_n[c] = S_1[c] ∧ S_1[c] = S_1[c]。

3 値の ∧ では x ∧ x = x、T ∧ x = x が成り立つ。∎

**h の所属。** n についての帰納法で、h が S_1, …, S_{L−1} に入らず、S_L に入ることを示す。H(j)(c) により、g_1 = … = g_{L−1} = m + 1、g_L = m + 2 となる。これでブロック 2〜L が E 型であることも、順に保証される。
- **n = 1**：S_1[H] = S_1[1]（v − 1 は偶数）= F（1 ≡ 1 (mod 4)）。
- **2 ≤ n ≤ L − 1**：S_n[H] = ¬S_n[H/2] ∧ ¬S_{n−1}[3H/2]。ここでは S_n[H/2] = T を示す（すると S_n[H] = F）。
  - S_n[H/2] = ¬S_n[H/4] ∧ ¬S_{n−1}[H + H/4]。H/4 = 2^{v−3}、H + H/4 = 5·2^{v−3}。
  - 付値 v − 3 = 2L − 4 は 2n − 2 以上 v − 3 以下なので、Inh が使える（ブロック n − 1 でも同じ。n − 1 = 1 ならそのまま）。
  - S_n[2^{v−3}] = S_1[2^{v−3}] = S_1[1] = F（v − 3 は偶数）。
  - S_{n−1}[5·2^{v−3}] = S_1[5·2^{v−3}] = S_1[5] = F（5 ≡ 1 (mod 4)）。
  - よって S_n[H/2] = T ∧ T = T。
- **n = L**：S_L[H] = ¬S_L[H/2] ∧ ¬S_{L−1}[3H/2]。
  - H/2 = 2^{v−2} の付値 v − 2 = 2L − 3 は P_L の範囲で、奇数なので S_L[H/2] = F。
  - S_{L−1}[3H/2] = S_{L−1}[3·2^{v−2}] = ¬S_{L−1}[3·2^{v−3}] ∧ ¬S_{L−2}[H + 3·2^{v−3}]。
    - S_{L−1}[3·2^{v−3}]：付値 v − 3 = 2(L−1) − 2 なので Inh_{L−1} より S_1[3·2^{v−3}] = S_1[3]。
    - S_{L−2}[H + 3·2^{v−3}] = S_{L−2}[7·2^{v−3}]：付値 v − 3 ≥ 2(L−2) − 2 なので、Inh_{L−2}（L − 2 = 1 ならそのまま）より S_1[7·2^{v−3}] = S_1[7]。
    - よって S_{L−1}[3H/2] = ¬S_1[3] ∧ ¬S_1[7]。
  - ブロック 1 の規則で S_1[3]、S_1[7] を求める。
    - u₀ = 1：3·1 + 1 = 4 なので S_1[3] = T。よって S_{L−1}[3H/2] = F。
    - u₀ = 5：7·5 + 1 = 36 ≡ 4 (mod 8) なので S_1[7] = T。よって S_{L−1}[3H/2] = F。
  - したがって S_L[H] = T ∧ T = T。
- v ≥ 5 なので L ≥ 3 で、L − 2 ≥ 1。上で使ったブロックはどれも存在する。

**周期性。** K29.3 のログのとおり、ブロック 1 の計算が 1 つ前のブロックについて使う事実は、ブロック 0（K3）でもブロック qL（E 型）でも成り立つ。よって、ブロック qL+1〜(q+1)L でも同じ計算になり、q についての帰納法で型は 1 0^{L−1} になる。

**ブロック 0。** S_0 ∋ h（v2(h) = v − 1 が偶数）なので g_0 = m + 2。∎

### 補足

- 証明に必要な具体的な値は、ブロック 1 の S_1[1] = S_1[5] = F と、S_1[3]、S_1[7] の少なくとも一方が T であることだけ。後者は u ≡ 1 (mod 4) の 2 つの場合（u mod 8）で確かめた。
- 補題 P_n、Inh_n は、K29.3 の 3 値の計算の、2 進付値ごとの構造を表している。観察 K30（`notes/2026-11-23-claude-1-k29-cone.md`）の依存の範囲は、この構造から生じる。
