## 結果

### 定理 K9 `[非形式証明]`

m ≥ 3 で v2(m+1) = 1 とする（h = (m+1)/2 は奇数で、h ≥ 3）。このとき次の 3 つは同値。
- (1) すべての n ≥ 1 で、(n, 0) が P ⇔ n ≡ 0 または m+2 (mod 2m+3)。
- (2) m は交互型。すべての j で、g_j = m+2（j が偶数）、g_j = m+1（j が奇数）。
- (3) v2(3h+1) が奇数。

(1) ⇔ (2) は K9 のログで述べた（A 行の集合と間隔の列が互いに決まる）。
(2) ⇒ (3) は定理 K9（⇒）の対偶。以下で (3) ⇒ (2) を示す。

#### 準備

- N := 3h + 1 とおく。仮定より v2(N) = 2k + 1（k ≥ 0）。N = 2^{2k+1}·q（q は奇数）と書く。
- e* := N/2 = 2^{2k}·q。
- m = 2h − 1 は奇数。m + 1 = 2h（v2 = 1）、m + 2 = 2h + 1（奇数）、m + 2 + h = 3h + 1 = N。
- **q ≥ 5**：N = 3h + 1 ≡ 1 (mod 3)。2^{2k+1} ≡ 2 (mod 3) なので 2q ≡ 1 (mod 3)、q ≡ 2 (mod 3)。q は奇数なので q ≡ 5 (mod 6) で、q ≥ 5。

**交互型の下での R の形**（H(j)(d) の (i)〜(iii) を、1 つ前の間隔ごとに書き直したもの）：

- **(E 型) 1 つ前の間隔が m+1（偶数）のブロック（j ≥ 2 の偶数番目を想定）**：
  - 奇数 d：(i) は d が奇数なので不成立。(ii) は m + 1 + d が奇数なので不成立。(iii) は 1 つ前の間隔が m+2 でないので不成立。よって d は入る。
  - 偶数 d = 2x（d ≤ m − 1）：(ii) の e = (m+1+d)/2 = h + x ≤ m。(iii) は不成立。
    よって「d が入る ⇔ x が入らない、かつ h + x が 1 つ前のブロックに入らない」。
- **(O 型) 1 つ前の間隔が m+2（奇数）のブロック（奇数番目を想定）**：
  - 奇数 d：(i) は不成立。(iii) は対象 d = h − 1 が偶数なので不成立。
    (ii) は、m + 2 + d が偶数なので e = (m+2+d)/2 として、e ≤ m なら「e が 1 つ前のブロックに入る ⇔ (ii) が成り立つ」。
    よって e ≤ m のとき、「d が入る ⇔ e が 1 つ前のブロックに入らない」。
  - d = h + y（y は偶数で y ≥ 0）とすると、e = (N + y)/2 = e* + y/2。

#### 木 T の定義

偶数 c（0 ≤ c ≤ 2k）と奇数 r の組 (c, r) を節点とする木 T を、次のように再帰的に定める。
- 根は (2k, q)。
- c ≥ 2 の節点 (c, r) は、2 つの子 (c−2, r) と (c−2, r + 2^{2k+2−c}·q) を持つ。
- c = 0 の節点は葉。

性質：
- **r はいつも奇数**：子の r + 2^{2k+2−c}·q は、2k+2−c ≥ 2 なので「奇数 + 偶数」で奇数。
- **節点の値**：節点 (c, r) の値を val(c, r) := 2^c·r とする。根の値は e*。
- **子の値**：val(c−2, r) = val(c, r)/4。val(c−2, r + 2^{2k+2−c}·q) = 2^{c−2}·r + 2^{2k}·q = e* + val(c, r)/4。

**値の上界**：T の節点の値はすべて m 以下。
- 子の値はどちらも e* + val/4 以下。根の値は e*。
- よって深さ i の節点の値 v_i は v_i ≤ e*(1 + 1/4 + … + 1/4^i)。
- 最大の深さは k なので、
  v ≤ e*·(1 − 4^{−(k+1)})·(4/3) = (2^{2k}·q)·(4^{k+1} − 1)/(3·4^k) = q·(4^{k+1} − 1)/3。
- 一方 m = 2h − 1 = (2N − 5)/3 = (4^{k+1}·q − 5)/3。
- v ≤ m ⇔ 4^{k+1}·q − q ≤ 4^{k+1}·q − 5 ⇔ q ≥ 5。準備より成り立つ。

#### 事実の集合

T から次の事実の集合を作る。
- **E 型のブロックで成り立つべき事実**：
  - (Ea) すべての奇数 d が入る。
  - (Eb) 各節点 (c, r) について、val(c, r) = 2^c·r が入る。
  - (Ec) c ≥ 2 の各節点 (c, r) について、2^{c−1}·r が入らない。
- **O 型のブロックで成り立つべき事実**：
  - (Oa) h が入らない。
  - (Ob) c ≥ 2 の各節点 (c, r) について、h + 2^{c−1}·r が入らない。

**値の範囲**：(Ec)(Ob) の値も m 以下。
- 2^{c−1}·r < 2^c·r ≤ m。
- h + 2^{c−1}·r は奇数で、下の O 型の計算で e = e* + 2^{c−2}·r（= T の子の値、m 以下）。
  よって m + 2 + (h + 2^{c−1}·r) = 2e ≤ 2m から h + 2^{c−1}·r ≤ m − 2。

#### 主張 Ψ(j)

- j が偶数なら、(Ea)(Eb)(Ec) が S_j で成り立ち、g_j = m+2。
- j が奇数なら、(Oa)(Ob) が S_j で成り立ち、g_j = m+1。

Ψ(j) を j についての強い帰納法で示す。帰納法の仮定は「Ψ(0), …, Ψ(j−1) が成り立つ」こと。

**j = 0**：定理 K3（d ∈ S₀ ⇔ v2(d) が偶数）による。
- 奇数は v2 = 0 なので入る。
- 2^c·r（c は偶数）は v2 = c が偶数なので入る。
- 2^{c−1}·r は v2 = c − 1 が奇数なので入らない。
- h は奇数なので h ∈ S₀。H(0)(c) より g₀ = m+2。

**j ≥ 2 が偶数**：仮定 Ψ(j−1) より g_{j−1} = m+1。E 型の規則が使える。
- (Ea)：奇数 d は入る。
- (Eb)(Ec)：c についての帰納法で示す（c = 0, 2, …, 2k）。
  - c = 0：2^0·r = r は奇数なので入る（(Ea)）。
  - c ≥ 2：子 (c−2, r) について 2^{c−2}·r が入る（c−2 での主張）。
    - (i) により 2^{c−1}·r は入らない。これが (Ec)。
    - 次に d = 2^c·r = 2x（x = 2^{c−1}·r）とする。
      x は入らない（いま示した）。h + x = h + 2^{c−1}·r は 1 つ前のブロックに入らない（Ψ(j−1) の (Ob)）。
      E 型の規則より d は入る。これが (Eb)。
- h は奇数なので入る（(Ea)）。H(j)(c) より g_j = m+2。

**j ≥ 1 が奇数**：仮定 Ψ(j−1) より g_{j−1} = m+2 で、S_{j−1} で (Ea)(Eb)(Ec) が成り立つ。O 型の規則が使える。
- (Oa)：d = h のとき e = e* = val(2k, q) ≤ m で、(Eb) より e* ∈ S_{j−1}。よって h は入らない。
- (Ob)：節点 (c, r)（c ≥ 2）について、d = h + 2^{c−1}·r（y = 2^{c−1}·r は偶数）とする。
  e = e* + 2^{c−2}·r = val(c−2, r + 2^{2k+2−c}·q)（T の子の値）≤ m。
  (Eb) より e ∈ S_{j−1}。よって d は入らない。
- h ∉ S_j なので、H(j)(c) より g_j = m+1。

帰納法により、すべての j で Ψ(j) が成り立つ。よって (2) が成り立つ。∎

### 補足

- **事実の数**：T は深さ k の完全二分木で、節点数は 2^{k+1} − 1、内部節点数は 2^k − 1。
  事実の数は、(Eb) 2^{k+1} − 1 個、(Ec) 2^k − 1 個、(Ob) 2^k − 1 個、(Oa) 1 個、それに「h ∈ E」の 1 個で、合計 2^{k+2} − 1。
  これは予想 K9-S の大きさの式と一致する。
  ただし、値が重なる場合は集合としての大きさが小さくなりうる。m ≤ 3000 の 498 個では重なりはなかった（数値検査で、集合の大きさが 2^{k+2} − 1 と一致した）。
- **K9-S について**：上で作った事実の集合が、K9-S の「証明書」の一般形にあたる。
  K9-S の「証明書が存在する」部分は、この証明で示されたことになる。
  「大きさがちょうど 2^{k+2} − 1」の部分は、`code/k9_certificate.js` が最小の証明書を選んでいるかどうかにも依存するので、`[予想]` のままにする。
- **既存の証明との関係**：K6（k = 0）、K9-25・K9-v3（k = 1, 2 の場合）は、この証明の特別な場合。
- **主目標との関係**：
  - v2(m+1) = 1 の m のうち、v2(3h+1) が奇数のものは、開始局面の特徴づけが完成した：後手必勝 ⇔ n ≡ 0, m+2 (mod 2m+3)。
  - v2(3h+1) が偶数の m では「交互型でない」ことしか分かっていない。開始局面の P の集合そのものは、まだ特徴づけていない。
  - したがって、問題全体の完全な証明ではない（AGENTS.md 第 9 節の「完全な証明」には当たらない）。
