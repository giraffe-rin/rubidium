# 「100」型の条件（定理 K13）

## やったこと

- 間隔の型の集計（`data/gap_types_m2000.txt`）で 3 番目に多かった「100」型について調べた。
  - 間隔の始まりが 1, 0, 0 の m は、多くが「100」型だった。始まりが 1, 0, 0 になるのは、K10c・K11 で g₁ = g₂ = m+1 となる場合。
  - ただし例外もあった（m ≤ 3000 で、v2(m+1) = 3 では 5 個、5 では 7 個、7 では 8 個など）。
- v2(m+1) = 3 の場合に、「100」型になる十分条件を証明した（定理 K13）。
- `code/check_k13.js` で確かめた（`data/k13_check.txt`、m ≤ 8000）。

**前提**：`notes/2026-11-23-claude-1-proof-structure.md` の系 1.1、主張 H(j)、定理 K3（`[非形式証明]`、未査読）。
記号は `notes/2026-11-23-claude-1-proof-k10c-k11.md` と同じ。

## 結果

### 型の定義

「m が **100 型**」とは、すべての i ≥ 0 で g_{3i} = m+2、g_{3i+1} = g_{3i+2} = m+1 となることとする。
このとき A 行は次のとおり（i についての帰納法）。
- a_{3i} = i(3m+4)
- a_{3i+1} = i(3m+4) + m + 2
- a_{3i+2} = i(3m+4) + 2m + 3

系 1.1 より、100 型 ⇔ すべての n ≥ 1 で「(n, 0) が P ⇔ n mod (3m+4) ∈ {0, m+2, 2m+3}」。

### 定理 K13 `[非形式証明]`

m + 1 = 8u（u は奇数）とし、{v2(9u+1), v2(11u+1)} = {1, 3} とする。このとき m は 100 型。

#### 準備

- h = 4u、m + 2 = 8u + 1。
- X₁ := (9u+1)/2、X₃ := (11u+1)/2 とおく。
- 仮定より、X₁, X₃ の一方は奇数（v2 = 0）。他方を Y とすると v2(Y) = 2 で、Y = 4y（y は奇数）と書ける。
- **値の範囲**：どれも 1 以上 m = 8u − 1 以下。
  - X₁, X₃ ≤ m は K10c のログで示した。
  - 6u ≤ 8u − 1。
  - h + Y/2 = 4u + 2y ≤ 4u + (11u+1)/4 ≤ 8u − 1（u ≥ 1 で 11u + 1 ≤ 16u − 4 ⇔ u ≥ 1）。
- **(iii) の対象**：(iii) は d = h − 1 = 4u − 1（奇数）にだけ効く。
  - 下で O 型のブロックで使う奇数の距離は u と 3u。u = 4u − 1 は起きない。
  - 3u = 4u − 1 は u = 1 のときだけ。
    u = 1 なら v2(9u+1) = 1、v2(11u+1) = v2(12) = 2 なので、仮定 {1, 3} を満たさない。
    よってこの定理では起きない。

#### ブロックの種類

100 型を仮定すると、1 つ前の間隔で規則が決まる。
- j ≡ 0 (mod 3) で j ≥ 3：1 つ前の間隔は m+1（E 型）。
- j ≡ 1 (mod 3)：1 つ前の間隔は m+2（O 型）。
- j ≡ 2 (mod 3)：1 つ前の間隔は m+1（E 型）。

E 型と O 型の規則は K10c のログの補題 O・補題 E2 と同じ形。
- **E 型**：奇数はすべて入る。偶数 d は「d/2 が入らず、h + d/2 が 1 つ前のブロックに入らない」とき入る。
- **O 型**：偶数 d は「d/2 が入らない」とき入る。奇数 d（≠ h−1）は、e = (m+2+d)/2 ≤ m について「e が 1 つ前のブロックに入らない」とき入る。

#### 主張 Λ(j)

- **j ≡ 0 (mod 3)**：
  - (A1) すべての奇数 d が S_j に入る
  - (A2) Y ∈ S_j
  - g_j = m+2
- **j ≡ 1 (mod 3)**：
  - (B1) u ∉ S_j
  - (B2) 3u ∉ S_j
  - (B3) 6u ∈ S_j
  - g_j = m+1
- **j ≡ 2 (mod 3)**：
  - (C1) 6u ∉ S_j
  - (C2) h + Y/2 ∉ S_j
  - g_j = m+1

Λ(j) を j についての強い帰納法で示す。帰納法の仮定は「Λ(0), …, Λ(j−1) が成り立つ」こと。

- **j = 0**：定理 K3 より、奇数は入り、Y（v2 = 2）も入る。h（v2 = 2）も入るので g₀ = m+2。
- **j ≡ 1 (mod 3)**（O 型、1 つ前は (A1)(A2) を満たす）：
  - (B1)：u の (ii) は e = X₁ ≤ m。X₁ は奇数か Y なので、(A1)(A2) より 1 つ前のブロックに入る。よって u ∉ S_j。
  - (B2)：3u の (ii) は e = X₃ で、同様に 1 つ前のブロックに入る。よって 3u ∉ S_j。
  - 2u ∈ S_j（O 型の偶数：u ∉ S_j だから）。h = 4u ∉ S_j（2u ∈ S_j だから）。
  - (B3)：6u ∈ S_j（3u ∉ S_j だから）。
  - H(j)(c) より g_j = m+1。
- **j ≡ 2 (mod 3)**（E 型、1 つ前は (B1)〜(B3) を満たす）：
  - (C1)：3u は奇数なので入る。よって (i) により 6u ∉ S_j。
  - (C2)：h + Y/2 = 4u + 2y = 2(2u + y)。2u + y は奇数なので入る。よって (i) により h + Y/2 ∉ S_j。
  - h = 4u について：
    - (i)：2u ∈ S_j か。u（奇数）∈ S_j なので 2u ∉ S_j、よって (i) は成り立たない。
    - (ii)：e = h + 2u = 6u ∈ S_{j−1}（(B3)）。よって (ii) が成り立つ。
    - したがって h ∉ S_j で、H(j)(c) より g_j = m+1。
- **j ≡ 0 (mod 3) で j ≥ 3**（E 型、1 つ前は (C1)(C2) を満たす）：
  - (A1)：奇数は入る。
  - (A2)：Y = 4y について調べる。
    - (i)：Y/2 = 2y は入らない（y は奇数で入るので、2y の (i) が成り立つ）。よって Y の (i) は成り立たない。
    - (ii)：e = h + Y/2 ∉ S_{j−1}（(C2)）。よって成り立たない。
    - したがって Y ∈ S_j。
  - h = 4u について調べる。
    - (i)：2u ∉ S_j なので成り立たない。
    - (ii)：e = 6u ∉ S_{j−1}（(C1)）。よって成り立たない。
    - したがって h ∈ S_j で、g_j = m+2。

帰納法により、すべての j で Λ(j) が成り立つ。よって m は 100 型。∎

### 補足

- **m = 7（u = 1）**：仮定を満たさない（v2(11u+1) = 2）が、100 型である（`data/gap_types_m2000.txt`）。
  これは (iii) により 3u = h − 1 = 3 が O 型のブロックで必ず入らないためで、(B2) が X₃ に頼らずに成り立つ。
  上の証明で (B2) をこの理由に置き換え、Y = X₁ = 5（奇数）の場合として読むと、同じ議論が通るように見える。
  ただし、ラベルを付けるほどには確かめていない。
- **K13 の条件を満たさない場合**：始まりが 1, 0, 0 でも、max(v2(9u+1), v2(11u+1)) が 5 以上だと 100 型かどうかは混在する（`data/k13_check.txt`）。
  例：5 では 19 個が 100 型、12 個が 100 型でない。K9 と同じく、より深い量で決まると思われる。
- **v2(m+1) ≥ 5 の 100 型**（m = 31, 159, 287, …）は、この定理の対象外。
