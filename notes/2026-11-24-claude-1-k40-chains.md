# 予想 K40（q = 23）の証明の途中経過

## やったこと

- 予想 K40（`notes/2026-11-24-claude-1-class9-clean.md`）の q = 23、N 偶数の場合で、残っていた「周期の始まり（E 型ブロック P = N/2）で d₁ = (9a − 1)/4 が入らないこと」を調べた。
- `code/k40_chains.js`（`data/k40_chains.txt`）で、N = 22, 44, 66, 88 について次の 2 つの距離の鎖を、ブロック 0 まで BigInt でたどった。
  - f = h + d₁/4 = (33a − 9)/16
  - g = h + d₁/2 = (21a − 5)/8
  - あわせて、E 型ブロックでの所属を遅延評価で求めた。

**前提**：ブロック漸化式 R（主張 H(j)、定理 K3）。

## 結果

### わかったこと `[非形式証明]`（一部）と観察

**E 型ブロックでの d₁**：1 つ前の間隔が m+1 なので、[d₁ ∈ S_P] = ¬[d₁/2 ∈ S_P] ∧ ¬[g ∈ S_{P−1}]（d₁ は偶数）。
- g ∈ S_{P−1} なら、(ii) により d₁ ∉ S_P。
- 観察：N = 22, 44, 66, 88 のすべてで g ∈ S_{P−1} だった。

**f の鎖**（N/2 の偶奇で値が変わる）：f は奇数で、(M + f)/2 = (81a − 9)/32 も奇数、さらに (M + ·)/2 = (177a − 9)/64（v2 = 1）。
- (177a − 9)/128 = M − 9·2^{N−7}。これは 207a + 9 = 9(23a + 1) = 9·2^N による。
- c′_t := M − 9·2^t は奇数で、(M + c′_t)/2 = c′_{t−1}。O 型ブロックを 1 つ戻るごとに値が反転する。
- この結果、[f ∈ S_{P−1}] = ¬(−1)^{N/2−3}（始まりのブロックで c′ は入る）となる。
  - N/2 が奇数なら f ∉ S_{P−1}。このとき d₁/2 ∈ S_P で、(i) からも d₁ ∉ S_P。
  - N/2 が偶数なら f ∈ S_{P−1}。
  - これは計算と一致した（N/2 が奇数の N = 22, 66 で f は入らず、偶数の N = 44, 88 で入る）。

**g の鎖**（N によらない形）：
- g（奇数）→ (M + g)/2 → … と進み、ブロック P − 3 で 2a − 5·2^{N−7} の鎖に入る。
- 以後は、ブロック j で y″_j = 2a − 5·2^{2j−1}（偶数）と z″ = a − 5·2^{2j−2}（奇数）が交互に並び、[y″ ∈ S_j] = [y″_{j−1} ∈ S_{j−1}]（K35 の y の鎖と同じ）。
- 指数とブロック番号の対応 2j − 1 が N によらないので、鎖は周期の始まりのすぐ後（ブロック 1）で 2a − 10 になり、そこから先は a − 5、(a − 5)/2^k … と不規則な距離で終わる。

### 残っていること

- 鎖の終わりの部分（ブロック 0, 1 で使う、a − 5 から先の距離）の値が、周期の始まりがブロック 0（K3）のときと E 型ブロックのときで同じであること。
  - これが示せれば、g ∈ S_{P−1} がすべての周期で成り立ち、予想 K40（q = 23、N 偶数）の証明が閉じる。
  - E 型ブロックでの値は 1 つ前の O 型ブロックに依存するので、有限個の距離の集合で閉じることを示す必要がある。
