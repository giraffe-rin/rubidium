# 定理 K38（すべての奇数 v ≥ 5）の Lean 4 での形式化

## やったこと

`lean/Rubidium/K38gen.lean` に、定理 K38 を一般の奇数 v ≥ 5 で、sorry なしで証明した。

```lean
theorem K38_gen (m v u : Nat) (hv5 : 5 ≤ v) (hvo : v % 2 = 1) (hmu : m + 1 = 2 ^ v * u) (hu : u % 4 = 3)
    (he1 : v2 ((m + 2 + u) / 2) % 2 = 0 ∧ v2 ((m + 2 + u) / 2) ≤ v - 1) (n : Nat) :
    IsP m n 0 ↔ (n % L = 0 ∨ (m + 2 ≤ n % L ∧ (n % L - (m + 2)) % (m + 1) = 0))
    -- L = (m + 2) + ((v + 1)/2)(m + 1)
```

主張の意味：型は前周期なしで、周期は 1 0^{(v+1)/2}。間隔 m+2 が 1 つ、続いて間隔 m+1 が (v+1)/2 個。
公理は `[propext, Classical.choice, Quot.sound]`。

**仮定について**：もとの定理 K38 の仮定は「w = v2(u+1) が奇数で 3 ≤ w ≤ v − 2、または w ≥ v + 1」。
Lean では、それを e₁ = (m+2+u)/2 の付値の条件（v2(e₁) が偶数で v − 1 以下）で書いた。
2 つが同じであることは、5 ≤ v ≤ 15、u < 2^16（u ≡ 3 (mod 4)）のすべてで数で確かめた（`data/k38_hyp_check.txt`）。理由は、u + 1 = 2^w·t から v2(e₁) = min(w, v) − 1 となること。
ただし、この同値は Lean ではまだ示していない。

## 証明の組み立て

もとの証明（ノート 2026-11-24-claude-1-k38-proof.md）の事実 B、補題 P_n（= Blk）、補題 Inh′_n、主張（3H/2 の所属）を、そのまま局面の言葉で形式化した。H(j) は使わない。

記号：h = H·u（H = 2^{v−1}）、b = a + (m+2)、c_j = b + j(m+1)。v = 2s + 5 とおく。

**汎用の補題**
- `o_half`・`o_iter`：O 型のブロック b で、(b + 2^i x) が P ⇔ ((b + x) が P ⇔ i が偶数)。K11 の `g_iter` の、基点 a 版。
- `e_iff`：E 型のブロック c = p + (m+1) の偶数 D で、(c + D) が P ⇔ (c + D/2) が N かつ (p + h + D/2) が N。
- `v2_pow_mul`：v2(2^b·x) = b + v2(x)。

**証明の部品**
- `k38_S0`（事実 B）：q ≡ 3 (mod 4) か q = 1 なら、(b + 2^b·qu) が P ⇔ b が奇数。
  (b + qu) は N。手 (m+2+qu)/2 の行き先が P だから（q ≡ 3 のときは奇数、q = 1 のときは仮定 he1 による）。そのうえで `o_iter` を使う。
- `k38_istep`（補題 Inh′ の 1 段、b の強い帰納法）：q ≡ 3 (mod 4)、2j ≤ b ≤ v − 3 なら、(c_j + 2^b·qu) が P ⇔ b が奇数。
  - `e_iff` を使う。h + 2^{b−1}·qu = 2^{b−1}·q′u（q′ = q + 2^{v−b} ≡ q (mod 8)）と書き直し、1 つ前のブロックの Inh′（q′、b − 1）を使う。
  - b = 2j のときは、半分の局面を Blk m (2j−1) で扱う。
- `k38_K`：3H/2 = 2^{v−2}·3u の局面は P。
  - `e_iff` を使う。半分 2^{v−3}·3u と、1 つ前のブロックの h + 2^{v−3}·3u = 2^{v−3}·7u が、どちらも Inh′ より N（b = v − 3 は偶数）。
- `k38_N`：(c_j + h) は N。手 3H/2 で (c_{j−1} + 3H/2) に移れる。
- `k38g_step`（ブロック j についての帰納法）：各 j について、次をまとめて示す。
  - 行 c_j はすべての p で P（`row_next`）。
  - Blk m (2j−1) c_j（`blk_step2`）。
  - j ≤ s+1 なら、Inh′ と 3H/2 の所属。
  - (c_j + h) は N。

  最後の行 c_{s+3} = a + L では、Blk m (v−1) が成り立つ（`blk_step2`）。
- `k38g_rows`：周期 i についての帰納法。
- `K38_gen`：n mod L で場合分けする。r ≥ m+2 なら、r − (m+2) を m+1 で割った商 j（≤ s+2）と余り d に分ける。d = 0 なら P、d ≥ 1 なら `not_isP_of_row` で N。

**技術的なこと**：q·u や 2^b·(q·u) のような積は、omega が扱えるように、必要なところで変数に置き換えた（`generalize`）。2 のべきの関係（2^{v−1} = 2^{b−1}·2^{v−b} など）は `Nat.pow_add` で示した。
