# K9 の十分性：v2(3t+1) = 3 の場合の非形式証明

  どれも大きさ 15 で、中身が q = (3t+1)/8 の倍数（と h の和）で書けることが分かった。
  m = 8t + 1 で、h = 4t + 1。
- これを一般の m の定理として証明した（定理 K9-v3）。
- 不変量 L(j) そのものも、R で v2(3t+1) = 3 の m ≤ 1200、j < 30 について数値で確かめた（その場のコマンドで確認。失敗なし）。

  K9 の条件を満たす 665 個すべてで証明書が得られ、大きさが 2^{(v2(3h+1)+3)/2} − 1 だった（予想 K9-S）。

**前提**：`notes/2026-11-23-claude-1-proof-structure.md` の系 1.1、主張 H(j)、定理 K3（どれも `[非形式証明]`、未査読）。
帰納法の組み方は `notes/2026-11-23-claude-1-proof-k9-25mod32.md` の定理 K9-25 と同じ。

## 結果

### 定理 K9-v3 `[非形式証明]`

m = 8t + 1 で v2(3t+1) = 3 なら、m は交互型。
つまり、すべての n ≥ 1 で (n, 0) が P ⇔ n ≡ 0 または m+2 (mod 2m+3)。

（このとき v2(m+1) = 1、v2(3h+1) = 2 + v2(3t+1) = 5 は奇数で、K9 の条件を満たす。）

#### 準備

- 3t + 1 = 8q（q は奇数）とおく。3t = 8q − 1 が 3 の倍数なので q ≡ 2 (mod 3)。q は奇数なので q ≡ 5 (mod 6)、q ≥ 5。
- 各量を q で表す。
  - t = (8q − 1)/3
  - h = 4t + 1 = (32q − 1)/3（奇数）
  - m = 8t + 1 = (64q − 5)/3
  - m + 2 = 8t + 3
  - m + 2 + h = 12t + 4 = 32q

追跡する事実は次のとおり。
- **偶数番目のブロック E**：
  - 奇数はすべて入る
  - 2q ∉
  - 4q ∈
  - 8q ∉
  - 16q ∈
  - 10q ∉
  - 20q ∈
- **奇数番目のブロック O**：
  - h ∉
  - h + 2q ∉
  - h + 8q ∉
  - h + 10q ∉

**範囲の確認**：上に出てくる距離と、(ii) の e の値は、どれも 1 以上 m 以下。
- 最大のものは 21q（下の O の計算で出る）と h + 10q。
  - 21q ≤ m ⇔ 63q ≤ 64q − 5 ⇔ q ≥ 5。
  - h + 10q = (62q − 1)/3 ≤ (64q − 5)/3 ⇔ q ≥ 2。
- ほかの値はこれ以下。
  - 2q, 4q, 5q, 8q, 10q, 16q, 17q, 20q は 21q 以下。
  - h, h + 2q, h + 8q は h + 10q 以下。

**(iii) の対象**：(iii) は d = h − 1（偶数）の 1 つにだけ効く。
- O で追う距離（h, h + 2q, h + 8q, h + 10q）はどれも奇数なので、関係しない。
- E では、1 つ前の間隔が m+1 なので (iii) は効かない（j ≥ 2 のとき）。

#### 主張 L(j)

- j が偶数なら、上の E の事実がすべて成り立ち、g_j = m+2。
- j が奇数なら、上の O の事実がすべて成り立ち、g_j = m+1。

L(j) を j についての強い帰納法で示す。帰納法の仮定は「L(0), …, L(j−1) が成り立つ」こと。

#### j = 0

定理 K3（d ∈ S₀ ⇔ v2(d) が偶数）で確かめる。q は奇数なので、次のようになる。
- 奇数：v2 = 0 なので入る。
- 2q：v2 = 1 なので入らない。
- 4q：v2 = 2 なので入る。
- 8q：v2 = 3 なので入らない。
- 16q：v2 = 4 なので入る。
- 10q = 2·5q：v2 = 1 なので入らない。
- 20q = 4·5q：v2 = 2 なので入る。

h は奇数なので h ∈ S₀。H(0)(c) より g₀ = m+2。

#### j ≥ 2 が偶数

1 つ前の間隔は g_{j−1} = m+1（偶数）。
- 偶数 d = 2x の (ii) は e = h + x（d ≤ m − 1 なので e ≤ m）。
- (iii) は効かない。
- 奇数 d は (i)(ii)(iii) のどれも成り立たないので入る。

偶数の距離を順に示す。
- **2q**：(i) q ∈ S_j（奇数）なので入らない。
- **4q**：
  - (i)：2q ∉ S_j なので成り立たない。
  - (ii)：e = h + 2q ∉ S_{j−1}（仮定）なので成り立たない。
  - よって入る。
- **8q**：(i) 4q ∈ S_j なので入らない。
- **16q**：
  - (i)：8q ∉ S_j なので成り立たない。
  - (ii)：e = h + 8q ∉ S_{j−1} なので成り立たない。
  - よって入る。
- **10q**：(i) 5q ∈ S_j（奇数）なので入らない。
- **20q**：
  - (i)：10q ∉ S_j なので成り立たない。
  - (ii)：e = h + 10q ∉ S_{j−1} なので成り立たない。
  - よって入る。

h は奇数なので h ∈ S_j。H(j)(c) より g_j = m+2。

#### j ≥ 1 が奇数

1 つ前のブロックは偶数番目で、間隔 g_{j−1} = m+2（奇数）。
- 奇数 d では (i) は成り立たず、(iii) も効かない。
- (ii) は e = (m + 2 + d)/2 で、e ∈ S_{j−1} なら d ∉ S_j。

O で追う距離を示す。
- **h**：e = 32q/2 = 16q ∈ S_{j−1} なので h ∉ S_j。
- **h + 2q**：e = (32q + 2q)/2 = 17q（奇数）∈ S_{j−1} なので ∉。
- **h + 8q**：e = (32q + 8q)/2 = 20q ∈ S_{j−1} なので ∉。
- **h + 10q**：e = (32q + 10q)/2 = 21q（奇数）∈ S_{j−1} なので ∉。

h ∉ S_j なので、H(j)(c) より g_j = m+1。

#### 結論

帰納法により、すべての j で L(j) が成り立つ。よって g_j は m+2, m+1 の交互になる。
定理 K9-25 と同じく、K6 の証明の「A 行の位置」と系 1.1 から主張が成り立つ。∎

### K9 の十分性の現状

定理 K6（v2(3h+1) = 1）、K9-25（v2(3h+1) = 3）、K9-v3（v2(3h+1) = 5）で、v2(3h+1) ≤ 5 の場合はすべて一般の m で示した（どれも `[非形式証明]`）。
- 一般の証明が残るのは、v2(3h+1) ≥ 7 の奇数の場合（v2(3t+1) ≥ 5 の奇数）。
- m ≤ 4000 では、そのような m は 9 個（m = 425, 937, 1449, 1705, 1961, 2473, 2985, 3497, 3753）。どれも計算機による証明書がある。

### 予想 K9-S（証明書の形）`[予想]`

K9 の条件を満たす m（v2(m+1) = 1、v2(3h+1) = 2k + 1）では、健全な伝播による証明書が存在する。
その大きさは 2^{k+2} − 1。

- 確かめた範囲：5 ≤ m ≤ 4000 の 665 個（`data/k9_certificates_m4000.txt` と、その場の集計）。
- 証明書の形は、K6（k = 0）、K9-25（k = 1）、K9-v3（k = 2）の順に、追う距離の鎖が 1 段ずつ伸びていく。
  - v2(3t+1) = 2k − 1 として q = (3t+1)/2^{2k−1} とおく。
  - E では 2^i q（i = 0, …, 2k）が「入る、入らない」を交互に繰り返す。
  - O の h + 2^{odd}·q の事実が、それを支える。

  この形を一般の k で書き下せば、K9 の十分性の完全な証明になる見込み。
  ただし、鎖の中で現れる値が m を超えないことの評価が必要。
