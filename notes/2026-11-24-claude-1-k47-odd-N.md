# 定理 K47 の族の N 奇数（v = 3、ρ = 2）：予想 K34 と予想 K58

## やったこと

- 予想 K34 の族 m = 8(36·16^k − 1)/5 − 1 が、定理 K47 の族の一部であることに気づいた。
  - a = (m + 2)/3 とおくと、5a + 1 = 3·2^{4k+5}。
  - これは v = 3、ρ = 2（q = 2^3 − 2^2 + 1 = 5、r = 1）、s = 3、N = 4k + 5（奇数）の場合である。
- 定理 K47 は N が偶数の場合だけを扱っている。そこで ρ = 2 で N が奇数の族の型を、v = 3, 5, 7 で調べた（その場のスクリプト、N ≤ v + 40）。
- v = 3 では型が N mod 4 で 2 つに分かれた。v = 5, 7 では、s が N ごとにばらばらで、型も不規則だった。
- `code/k58_family.js` で、v = 3 の 2 つの族を、21 ≤ N ≤ 401 の奇数 N のそれぞれで、周期についての帰納法（prove3）により確定させた（`data/k58_family.txt`）。
- 最初に v = 3, 5, 7 を調べたとき、N の開始値を v + 9 にしていたため N が偶数になり、K47 の場合をもう一度見ていた。v + 10 に直して取り直した。

**前提**：prove3 の前提（H(j)、K3、補題 Q_n。査読済み）と prove3 の実装（gemini-2 が検証済み）。

## 結果

v = 3、q = 5、r = 1、N 奇数とする。s は 5 | s·2^N − 1 となる最小の正の奇数で、N ≡ 1 (mod 4) なら 3、N ≡ 3 (mod 4) なら 7。a = (s·2^N − 1)/5、m = 3a − 2、R = (N − 3)/2 とする。

- **N ≡ 1 (mod 4)**：型は前周期なし、周期 1^{2R} 0 (1^R 0 0)^2。
  - これは予想 K34 そのもの（N = 4k + 5、2R = 4k + 2、R = 2k + 1）。
  - 21 ≤ N ≤ 401（4 ≤ k ≤ 99）の 96 個のすべてで確定した（`[非形式証明]`、計算機による）。以前は k ≤ 30（`data/period_induction_k34.txt`）。
- **N ≡ 3 (mod 4)**：`[予想]` K58。型は前周期なし、周期 1^{R+2} 0 1^R 0。
  - 23 ≤ N ≤ 399 の 95 個のすべてで確定した（`[非形式証明]`、計算機による）。
  - N = 15, 19 でも同じ形だった（その場のスクリプト）。

**仮定の数**：どれも 1〜2 個。

**先頭の連についての観察**：定理 K47 の鎖の議論では、i < R のブロックで h ∈ S_i となる。i = R では、終点の β がちょうど 2^N になり、値は v2(a − s) の偶奇で決まる。

- s = 3 では a − 3 = (3·2^N − 16)/5 で、v2 = 4。
- s = 7 では a − 7 = (7·2^N − 36)/5 で、v2 = 2。
- どちらも偶数なので、h ∈ S_R となって連が R を越える。その先（2R、または R + 2 まで続くこと）は、鎖が v2(β) ≥ N の範囲に入るので、K47 の記述では扱えない。
