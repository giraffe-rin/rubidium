## 結果

### 定理 K29.1 `[非形式証明]`

v2(m+1) = 5、u := (m+1)/32 ≡ 1 (mod 4) とする。このとき次が成り立つ。
- g_0 = m + 2
- g_1 = g_2 = m + 1
- g_3 = m + 2

つまり、予想 K29 の型 100 の最初の周期と、次の周期の始まりが成り立つ。

### 証明

m = 32u − 1、h = 16u、m + 2 = 32u + 1、h − 1 = 16u − 1。u ≡ 1 (mod 4) より、c = 33, 37, 41 で cu + 1 ≡ 2 (mod 4)。つまり (cu+1)/2 は奇数である。

**ブロック 0（K3）。**
- u、16u（v2 = 0, 4）は入る。2u、8u（v2 = 1, 3）は入らない。4u（v2 = 2）は入る。
- 奇数はすべて入る。
- g_0 = m + 2。

**ブロック 1（O 型）。** 奇数の cu は (ii) で、cu ∈ S_1 ⇔ (32u + 1 + cu)/2 ∉ S_0。偶数は (i) だけで決まる。
- (iii) は、奇数の cu = 16u − 1 が u(16 − c) = 1 を意味し、u = 1、c = 15 のときだけ起きる。下で使う c はどれも 15 でない。
- 次の 3 つの奇数は (33u+1)/2、(41u+1)/2、(37u+1)/2 が奇数で S_0 に入るので、どれも入らない。
  - u ∉
  - 9u ∉
  - 5u ∉
- よって (i) の連鎖で、次のようになる。
  - 2u ∈、4u ∉、8u ∈、16u ∉（g_1 = m + 1）
  - 18u ∈（9u ∉）
  - 10u ∈、20u ∉（5u ∉）
- **主張 (★)**：22u ∈ S_1 ならば 28u ∈ S_1。
  - 22u ∈ S_1 ⇔ 11u ∉ S_1 ⇔ X := (43u+1)/2 ∈ S_0 ⇔ v2(X) が偶数 ⇔ v2(43u+1) が奇数。
  - u ≡ 1 (mod 4) より 43u + 1 ≡ 0 (mod 4) なので、このとき v2(43u+1) ≥ 3。
  - 39u + 1 = (43u + 1) − 4u で v2(4u) = 2 < 3 なので、v2(39u+1) = 2。
  - よって (39u+1)/2 の付値は 1 で、S_0 に入らない。
  - したがって 7u ∈ S_1、14u ∉ S_1、28u ∈ S_1。

**ブロック 2（E 型、1 つ前の間隔 32u）。** 奇数はすべて入る（u、3u、9u など）。偶数の x は、x/2 ∉ S_2 かつ 16u + x/2 ∉ S_1 のとき入る。
- 4u：2u ∉ だが、18u ∈ S_1 なので入らない。
- 8u：4u ∉ で、20u ∉ S_1 なので入る。
- 16u：8u ∈ なので入らない。g_2 = m + 1。
- 18u：9u ∈ なので入らない。
- 24u：
  - 12u ∈ S_2 なら (i) で入らない。
  - 12u ∉ S_2 なら、12u は 6u ∉ S_2（3u ∈ なので 6u ∉）を満たしているので、22u ∈ S_1 である（(ii) が効いた）。
  - このとき (★) より 28u ∈ S_1 で、(ii) により 24u は入らない。
  - どちらの場合も 24u ∉ S_2。

**ブロック 3（E 型、1 つ前の間隔 32u）。**
- 4u：2u ∉ で、18u ∉ S_2 なので入る。
- 8u：4u ∈ なので入らない。

H(j)(c) より主張が成り立つ。範囲：使った距離はどれも 1 以上 m = 32u − 1 以下（最大は 28u と (43u+1)/2）。∎

### 周期性について

ブロック 4 以降も 100 が続く（予想 K29）には、ブロック 3 の事実がブロック 0 と同じ働きをすればよい。
- 奇数の (33u+1)/2 などは E 型のブロック 3 でも入るので、ブロック 4 の u、5u、9u は同じになる。
- 偶数の X = (43u+1)/2 と (39u+1)/2 の所属は、ブロック 3（E 型）では (i)(ii) で決まり、ブロック 0（K3）と同じとは限らない。
  - そのため、(★) にあたる「X ∈ S_3 ⇒ (39u+1)/2 ∉ S_3」を別に示す必要がある。
  - これはまだ示していない。
- 数値では、調べたすべての m で最初の 12 ブロックが 100 の繰り返しだった（下）。
