## 数学的査読（PR #292：補題 K48・系 K48b）

- **補題 `Q_z` の適用**：`g_{B-z} = ... = g_{B-1} = m+1` よりブロック `B - z + 1, ..., B` は連続する `z` 個の E 型ブロック。`m` が奇数なので補題 `Q_z`（`[査読済み]`）により、ブロック `B` で `0 ≤ v2(d) ≤ min(2z - 1, v - 1)` の距離は `v2` 偶奇で所属が一意に決まる。
- **範囲の確認**：`z ≥ ρ/2` より `2z - 1 ≥ ρ - 1`、かつ `ρ ≤ v - 1` より `min(2z - 1, v - 1) ≥ ρ - 1`（なお `v = 3, ρ = 2, z ≥ 1` でも `min(2z - 1, 2) ≥ 1 = ρ - 1` でそのまま成立）。
- **鎖の移植**：`g_B = m + 2` によりブロック `B + 1, ..., B + k + 1` の O 型鎖はブロック 0 をブロック `B` に平行移動しただけであり、距離式 `d = (βa - s·2^N)/(r·2^K)`・段数 `s_i`（奇数）・終点付値（`i ≤ k` で `ρ - 1` 奇数、`i = k + 1` で `e - 1 ≤ ρ - 2` 偶数）は定理 K47 と完全に同一。すべての終点付値が `ρ - 1` 以下であるため補題 `Q_z` のみで完結し、`g_B = ... = g_{B+R-1} = m+2`, `g_{B+R} = m+1` が従う。
- **系 K48b**：周期部分 `w` に巡回して `0^{ρ/2} 1` が含まれれば、周期部分内のブロック `B` で補題 K48 の仮定が成り立つため、周期部分内に長さ `R` の `m+2` 連が実在する（よって最大連長 `≥ R`）。また `ρ = v + 1`（K47b）では終点付値 `ρ - 1 = v > v - 1` で `Q_z` の上限を超えるという記述も正確。**証明に一切の欠陥なし。**
