### 主張ごとの査読結果

#### 1. 定理 K7′（周期性）：**正しい（最後まで確認した）**
- **`m = 1` の証明（39〜49 行）**：
  - `r ≥ 1` に対する帰納法で全行が `S(1)` であることを示す。`min(1, r) = 1` より候補手は `k = 1` のみ。基底 `r = 1` は行 0 が A 行なので `T(1) = {1}`、帰納段階 `r ≥ 2` は行 `r − 1` が `S(1)` 行なので系 1.2 より `T(r) = {1}`。K1 より `L(r) = {1}`。
  - よって `r₀ = 1 ≥ 0, Λ = 1 ≥ 1` で全 `r ≥ 1` に対し `L(r + 1) = L(r)`（なお `L(0) = {0, 1} ≠ {1}` なので `r₀ = 1` は必須かつ最小）。誤り・穴なし。
- **`m ≥ 2` の証明（51〜93 行）**：
  - **状態数**：`x_j = (S_j, g_j)` で `S_j ⊆ {1, …, m}`（`2^m` 通り）、`g_j ∈ {m+1, m+2}`（`H(j)(a)`、2 通り）なので高々 `2^{m+1}` 通り（実際には `g_j` は `S_j` から決まるので高々 `2^m` 通りだが、上界 `2^{m+1}` は当然正しい）。
  - **遷移関数 `F`**：`H(j)(c)(d)` より `j ≥ 1` で `S_j` は `d` の昇順に `x_{j−1}` のみから決まり、`g_j` は `S_j` のみから決まるため、`j` に依らない関数 `F` で `x_j = F(x_{j−1})`（`j ≥ 1`）。
  - **鳩の巣原理と帰納法**：`x₀, …, x_{2^{m+1}}` の `2^{m+1} + 1` 個から `0 ≤ j₀ < j₁ ≤ 2^{m+1}` で `x_{j₀} = x_{j₁}` となる組が存在し、`L₀ = j₁ − j₀ ≥ 1` に対し `j ≥ j₀` の帰納法で `x_{j+L₀} = x_j`（`j + 1 ≥ 1` かつ `j + 1 + L₀ ≥ 2 ≥ 1` で `F` の適用条件を満たす）。
  - **行の型が `(x_j, d)` で決まること**：`0 ≤ d < g_j` は `d = 0`（A 行）、`1 ≤ d ≤ m`（`d ∈ S_j` なら `{d}`、さもなくば `∅`、`H(j)(b)` と K1）、`d = m+1`（`g_j = m+2` のみで `{h}`、`H(j)(c)` と K1）で網羅され、`x_j` と `d` のみで `L(a_j + d)` が一意に決まる。
  - **周期の決定（展開確認）**：`Λ = \sum_{i=j₀}^{j₁-1} g_i ≥ m+1 ≥ 3 ≥ 1`、`r₀ = a_{j₀} ≥ 0`。`j ≥ j₀` に対し `a_{j+L₀} − a_j = Λ` は `j = j₀` で定義通り、`j → j+1` では `(a_{j+L₀} + g_{j+L₀}) − (a_j + g_j) = Λ + (g_{j+L₀} − g_j) = Λ`（`x_{j+L₀} = x_j` より `g_{j+L₀} = g_j`）で帰納法により厳密に成立。任意の `r ≥ r₀` は一意の `j ≥ j₀` と `0 ≤ d < g_j` で `r = a_j + d` と書け、`r + Λ = a_{j+L₀} + d` かつ `0 ≤ d < g_j = g_{j+L₀}`、`x_{j+L₀} = x_j` より `L(r + Λ) = L(r)`。
  - **上界**：`j₀ < j₁ ≤ 2^{m+1}`、`L₀ = j₁ − j₀ ≤ 2^{m+1}`、各 `g_i ≤ m+2` より `r₀ ≤ j₀(m+2) ≤ 2^{m+1}(m+2)`、`Λ ≤ L₀(m+2) ≤ 2^{m+1}(m+2)`。
  - **開始局面列**：系 1.1（または直接 `0 ∈ L(n)`）により、`n ≥ r₀` で `(n + Λ, 0)` と `(n, 0)` の勝敗が一致する。
