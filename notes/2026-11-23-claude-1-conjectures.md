### 記号

- v2(x)：x を割り切る 2 の最大べきの指数。
- m が奇数のとき h = (m+1)/2。
- A 行：すべての p ∈ {0, …, m} で (r, p) が P になる行 r。r = 0 は常に A 行。
  r ≥ 1 では「r が A 行」⇔「開始局面 (r, 0) が後手必勝」。

- a_j < r < a_{j+1} の行をブロック j と呼び、d = r − a_j をその行の距離と呼ぶ。

### K1（行の型）`[予想]`

m ≥ 2 のとき、どの行 r でも、P になる p の集合は「すべての p」「ちょうど 1 つの p」「空集合」のどれか。

- 確かめた範囲：2 ≤ m ≤ 100, 0 ≤ r ≤ 10000、全 p（全探索）。前回の範囲（m ≤ 30, r ≤ 2000）でも成り立つ。
- メモ：2 つの p で P なら、どの手も N へ行くことになり、すべての p で P になるはず、という短い議論がありそう。ただし証明としては書いていない。

### K2（ブロックの形）`[予想]`

m ≥ 2 のとき、次が成り立つ。

- (a) ギャップ g_j は m+1 か m+2。
- (b) ブロック j の距離 d（1 ≤ d ≤ m）の行の P 局面は、あるとすれば (a_j + d, d) だけ。
- (c) 距離 m+1 の行があるのは g_j = m+2 のときだけで、そのとき m は奇数。その行の P 局面は (a_j + m + 1, h) だけ。

- 確かめた範囲：2 ≤ m ≤ 100, 0 ≤ r ≤ 10000（全探索）。
- 前回の [予想] C5（間隔は m+1 か m+2）は (a) に含まれる。今回、範囲を m ≤ 100, r ≤ 10000 に広げて確かめた。
- m = 1 は例外：A 行は r = 0 だけで、r ≥ 1 では P 局面が (r, 1) だけになる（前回の C6）。

### K3（最初のブロック）`[予想]`

1 ≤ r ≤ m のとき：(r, p) が P ⇔ p = r かつ v2(r) が偶数。

- 確かめた範囲：1 ≤ r ≤ m ≤ 1000（全探索）。
  r ≤ m の行は m に依らないので、m = 1000 の表の r ≤ 1000 で全 m ≤ 1000 を兼ねた。「m に依らない」ことは m ≤ 60 で直接確かめた。
- 例：P になるのは r = 1, 3, 4, 5, 7, 9, 11, 12, 13, 15, 16, 17, 19, 20, 21, 23, 25, … での (r, r)。
  r = 2, 6, 8, 10, 14, 18, … での (r, r) は N。

### K4（開始局面の特徴づけ：倍数型）`[予想]`

m ≥ 2 のとき：「開始局面 (n, 0) が後手必勝 ⇔ n が m+1 の倍数」が成り立つ ⇔ v2(m+1) が偶数。

- 確かめた範囲：
  - 2 ≤ m ≤ 100, 1 ≤ n ≤ 10000（全探索）。
  - 2 ≤ m ≤ 200 のすべての n（漸化式 R 経由。K8 を前提にするので、その分も [予想]）。
- 前回の [予想] C2（m が偶数、または m ∈ {3, 11, 15, 19, 27}）は、この形にまとまる。
  m が偶数なら v2(m+1) = 0。m = 3, 11, 15, 19, 27 では v2(m+1) = 2, 2, 4, 2, 2。
  例外だった m = 7, 23 は v2(m+1) = 3。
- v2(m+1) が奇数の m（例：m = 1, 5, 7, 9, 13, 17, 21, 23, 25, 29, 31, …）では、m+1 の倍数型にならない。

### K5（v2(m+1) が奇数のとき）`[予想]`

m ≥ 2 で v2(m+1) が奇数なら、最初の後手必勝の開始局面は n = m+2。

- 確かめた範囲：2 ≤ m ≤ 100（全探索、r ≤ 10000）。
- メモ：K3 によると、v2(m+1) が奇数 ⇔ v2(h) が偶数 ⇔ (h, h) が P。

### K7（周期）`[予想]`

開始局面の勝敗の列は n について周期的。周期は `data/block_periods_m2-200.txt` に一覧にした（2 ≤ m ≤ 200、R 経由）。

- 2 ≤ m ≤ 200 のうち、m = 55 と m = 95 を除く m では、前周期なしの純周期的。
- **前回の [予想] C1 を m ≤ 30 より先へ広げると反例がある。**

    後手必勝の開始局面は 57, 114, 170, 227, 283, 339, 396, …（間隔 57, 57, 56, 57, 56, 56, 57, …）。
  - m = 95：周期 290。n ≥ 195 で s(n) = s(n+290)、s(194) ≠ s(484)。

  例：m = 34 で 4900 = 140 × 35。

### K8（ブロック漸化式 R）`[予想]`

m ≥ 2 とする。ブロック j で P 局面を持つ距離 d（1 ≤ d ≤ m）の集合を S_j とする（K2(b) の (a_j + d, d) が P になる d）。
このとき、次の漸化式で表全体が決まる。

- d ∈ S_j ⇔ 次の (i)〜(iii) がどれも起きない：
  - (i) d が偶数で d/2 ∈ S_j。
  - (ii) j ≥ 1、g_{j−1} + d が偶数、e = (g_{j−1} + d)/2 ≤ m、かつ e ∈ S_{j−1}。
  - (iii) j ≥ 1、g_{j−1} = m+2、かつ d = h − 1。
- g_j = m+2（m が奇数で h ∈ S_j のとき）、そうでなければ g_j = m+1。
- 確かめた範囲：2 ≤ m ≤ 100, 0 ≤ r ≤ 10000、すべての p で、R だけで作った表と全探索の表が 1 文字残らず一致（51,485,148 局面）。
  コマンドは `node code/block_rule.js check 2 100 10000`。
- 補足：j = 0 では (i) だけが効くので、K3 は K8 の j = 0 の場合にあたる（K3 の範囲は K8 より広く確かめてある）。
- 補足：(i) は「同じブロックの手前の行へ動く手」、(ii) と (iii) は「1 つ前のブロックの行へ動く手」に対応しているように見える。
  これは定義から帰納法で示せそうな形だが、証明は書いていない（次のタスク）。
- 補足：R の状態（S_{j−1}, g_{j−1}）は有限個しかないので、R が正しければ周期性（K7）は自動的に出てくる。
  K7 の周期はこの状態の繰り返しから求めた。
