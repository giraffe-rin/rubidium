### 1. 補題 K52（PR #311）

- **(a) 距離の形**：`v2(3a - 1) = v` より `u = (3a - 1)/2^v` は奇数、したがって `x = c(3a - 1)/2^k = c·u·2^{v-k}` は `k < v` で偶数、`k = v` で奇数。`x/2` は `(c, k+1)`、`e = h + x/2 = (2^k + c)(3a - 1)/2^{k+1}` は `(2^k + c, k+1)` となり、`c < 2^k`・`c` 奇数・`1 ≤ k ≤ v` の不変条件が完全に保存される。
- **(b) `e ≤ m` の無条件成立**：任意の `c' ≤ 2^{k'} - 1`・`k' ≤ v` で `(3a - 1)/2^{k'} = u·2^{v - k'} ≥ 1` なので `e ≤ 3a - 1 - 1 = 3a - 2 = m`（`a` の大きさに依らず常に成立）。
- **(c)(d) 再帰 `E_j(c, k)`**：K8 の E 型規則そのままの Kleene 3 値単調再帰であり、`c = 1` の `F(1, k) = [k 偶数]`（O 型ブロック `B+R` で `h ∉ S_{B+R}` から `k - 1` 回の偶数段反転）も厳密。**完全に正しい。**

### 2. 補題 K53（PR #313）

- **(1)** `b + M = (b - 1) + 2^ρ`（`M = 2^ρ - 1`, `0 < b < M` 奇数）：`b > 1` なら `t = v2(b - 1) ∈ [1, ρ - 1]` は最下位 `1` から次の `1` までの距離であり、`(b - 1)/2^t + 2^{ρ - t}` は `ρ` 桁 2 進語の右 `t` 桁巡回シフトに厳密一致（`b = 1` なら `t = ρ`, `T(1) = 1`）。`b` は `0` と `1` を両方含むので `0 < T(b) < M` かつ奇数。
- **(2)** 巡回シフトの逆写像（左の直前の `1` への回転）が存在するため全単射、よって軌道はすべて**純周期的**（PR #303 で確認した `max_pre = 0` の完全な理論的説明）。
- **(3)** 基本周期 `d | ρ`・1 基本周期内の `1` の個数 `p` に対し、`T` は `1` を 1 つずつ進めるのでちょうど `p` 回で合計 `d` 桁回転して初めて `b` に戻る（途中 `1 ≤ m < p` 回の回転量 `0 < S < d` では `d` の最小性に矛盾）。よって `ℓ = p`・`Σt = d`。
- **(4)** `d ≤ ρ, ℓ ≥ 1` より `d/ℓ = ρ ⇔ d = ρ ∧ ℓ = 1 ⇔ b` の `1` の個数が 1 ⇔ `b = 1`。
- **帰結 (i)–(iv)**：`e` 遷移 `c ↦ 2^k + c`（`c < 2^k`）で `1` の個数が 1 ずつ増えるため `j_0 ≤ z - 1` からの入口は `popcount(c) = j_0 + 1 ≤ z`、`ℓ = p ≤ z` より `ℓ | L = lcm(1..z)`。`R ≡ 1 (mod 2L)` では `R - 1` が `2ℓ` の倍数なので `b_R = c`、`v2(終点) = t(c) - 1 ≤ ρ - 2 < ρ - 1`（補題 `Q_z` の適用範囲内）、段数 `s ≡ v - k + 1 ≡ k (mod 2)`、したがって `F(c, k) = [t(c) - 1 偶数] XOR [k 奇数] = [t(c) + k 奇数]`（真偽値表の全 4 通りを確認済み）。**完全に正しい。**
