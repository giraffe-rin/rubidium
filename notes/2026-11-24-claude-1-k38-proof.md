## 結果

### 定理 K38 `[非形式証明]`

v ≥ 5 を奇数、u = (m+1)/2^v、w = v2(u+1) とする。
- w が奇数で 3 ≤ w ≤ v − 2、または w ≥ v + 1 なら、m の型は前周期なし、周期 1 0^{(v+1)/2}。
- 密度：v2(m+1) = v の m の中で、1/8 + 1/32 + … + 2^{−(v−2)} + 2^{−v}（v が大きいと 1/6 に近い）。

### 命題 K38c `[非形式証明]`

v ≥ 5 を奇数、w が偶数で 2 ≤ w ≤ v − 1 なら、g_1 = m + 2。

### 証明

**記号**：
- N = 2^v、H = 2^{v−1}（h = Hu）、L = (v+1)/2
- 距離 cu（1 ≤ c ≤ N − 1）について、ブロック n で cu ∈ S_n のとき S_n[c] = T と書く
- u ≡ 3 (mod 4)（w ≥ 2）なので、u ≥ 3

**R からの規則**（K29.3 のログと同じ導き方。m + 1 = Nu、M = m + 2 = Nu + 1）：
- **O 型ブロック**（1 つ前の間隔が m+2。ここではブロック 1）：
  - 偶数の c：S[c] = ¬S[c/2]。M + cu は奇数なので (ii) は起きない。(iii) は奇数の距離 h − 1 だけ。
  - 奇数の c：S[c] = ¬[e_c ∈ S_prev]。e_c := ((N + c)u + 1)/2 ≤ m。
    - c ≤ N − 2 なら e_c ≤ m。
    - u ≥ 3 なので cu ≠ h − 1。
- **E 型ブロック**（1 つ前の間隔が m+1）：
  - 奇数の c は T。
  - 偶数の c：S_n[c] = ¬S_n[c/2] ∧ ¬S_{n−1}[H + c/2]。(m+1 + cu)/2 = (H + c/2)u ≤ m。

**ブロック 1 の値（事実 B）**：ブロック 1 の 1 つ前は、ブロック 0（K3：d ∈ S_0 ⇔ v2(d) が偶数）とする（後で、周期の始まりにも当てはめる）。
- (B1) q ≡ 3 (mod 4) の奇数 q：qu ≡ 1 (mod 4) なので v2(qu + 1) = 1。v2(Nu) = v ≥ 5 なので、e_q = (Nu + qu + 1)/2 は奇数。よって e_q ∈ S_0、S_1[q] = F。
- (B2) c = 1：u + 1 = 2^w s（s は奇数）。
  - w < v：Nu + u + 1 の付値は w。v2(e_1) = w − 1。
  - w ≥ v + 1：Nu + u + 1 = 2^v(u + 2^{w−v}s) の括弧は奇数。v2(e_1) = v − 1。
  - よって、w が奇数（w < v）か w ≥ v + 1 なら v2(e_1) は偶数で、e_1 ∈ S_0、S_1[1] = F。
  - w が偶数（w < v）なら v2(e_1) は奇数で、S_1[1] = T。
- (B3) 偶数の c：S_1[2^b q] = S_1[q]（b 偶数）、¬S_1[q]（b 奇数）。

**命題 K38c の証明**：S_1[H] = S_1[2^{v−1}] = S_1[1]（v − 1 は偶数）= T（(B2)、w が偶数）。H(j)(c) により g_1 = m+2。∎

以下、定理の仮定（w が奇数で 3 ≤ w ≤ v − 2、または w ≥ v + 1）をおく。このとき (B2) より S_1[1] = F。

**補題 P_n**（K29、= 補題 Q_{n−1}）：ブロック 2, …, n が E 型（2 ≤ n）のとき、ブロック n で b = v2(c) ≤ 2n − 3 なら、S_n[c] = T ⇔ b が偶数。

**補題 Inh′_n**（2 ≤ n ≤ L）：ブロック 2, …, n が E 型のとき、q ≡ 3 (mod 4) の奇数 q と 2n − 2 ≤ b ≤ v − 3 について、S_n[2^b q] = S_1[2^b q]（(B1)(B3) より、これは「b が奇数なら T」）。

証明：K29 の補題 Inh_n の証明と同じ。n についての帰納法、各 n では b についての帰納法で示す。K29 の事実 A（S_1[q′] = S_1[q]）の代わりに、次を使う。
- c = 2^b q のとき、H + c/2 = 2^{b−1} q′、q′ = q + 2^{v−b}。v − b ≥ 3 なので q′ ≡ q (mod 8)。特に q′ ≡ 3 (mod 4)。(B1) より S_1[q′] = S_1[q] = F。

手順：
- (a) S_{n−1}[H + c/2] = ¬S_1[c]。
  - 付値 b − 1 は 2(n−1) − 2 以上 v − 3 以下。n − 1 = 1 ならそのまま、n − 1 ≥ 2 なら Inh′_{n−1} を使う。
  - S_{n−1}[2^{b−1}q′] = S_1[2^{b−1}q′] = ¬S_1[2^b q]（(B3) と S_1[q′] = S_1[q]）。
- (b) b = 2n − 2 のとき：c/2 の付値 2n − 3 は奇数なので、P_n で S_n[c/2] = F。
- (b′) b > 2n − 2 のとき：b についての帰納法で S_n[c/2] = S_1[c/2] = ¬S_1[c]。
- (c) どちらの場合も、S_n[c] = ¬S_n[c/2] ∧ ¬S_{n−1}[H + c/2] = S_1[c]（x ∧ x = x、T ∧ x = x）。∎

**主張（3H/2 の所属）**：1 ≤ n ≤ L − 1 で、ブロック 2, …, n が E 型なら、S_n[3·2^{v−2}] = T。
- n = 1：(B3) より S_1[3·2^{v−2}] = ¬S_1[3·2^{v−3}] = ¬S_1[3]（v − 3 は偶数）= ¬F = T。
- 2 ≤ n ≤ L − 1：E 型の規則で S_n[3·2^{v−2}] = ¬S_n[3·2^{v−3}] ∧ ¬S_{n−1}[H + 3·2^{v−3}]。H + 3·2^{v−3} = 7·2^{v−3}。
  - b = v − 3 は 2n − 2 ≤ v − 3（n ≤ L − 1 = (v−1)/2）を満たす。q = 3, 7 は 3 (mod 4)。
  - Inh′_n より S_n[3·2^{v−3}] = S_1[3·2^{v−3}] = S_1[3] = F。
  - S_{n−1}[7·2^{v−3}] は、n − 1 = 1 なら S_1[7] = F、n − 1 ≥ 2 なら Inh′_{n−1} より S_1[7] = F。
  - よって T ∧ T = T。∎

**h の所属**：
- ブロック 0：v2(h) = v − 1 は偶数なので h ∈ S_0、g_0 = m+2。
- ブロック 1：S_1[H] = S_1[1] = F なので g_1 = m+1。
- 2 ≤ n ≤ L のブロック n は E 型（帰納法）。S_n[H] = ¬S_n[H/2] ∧ ¬S_{n−1}[3H/2]。n − 1 ∈ [1, L − 1] なので、主張より S_{n−1}[3H/2] = T。よって S_n[H] = F、g_n = m+1。
- ブロック L + 1 は L = (v+1)/2 番目の E 型ブロック。補題 Q_L の範囲は v2 ≤ min(v, v − 1) = v − 1 なので、v2(h) = v − 1（偶数）の h は入る。g_{L+1} = m+2。
- 以上で、ブロック 0〜L の間隔は 1 0^L。

**周期性**：ブロック L + 1 は L 番目の E 型ブロックで、間隔は m+2。次のブロック L + 2 は O 型で、その計算で 1 つ前のブロックについて使う事実は、ブロック 0 のときと同じである。
- 使う事実は、奇数の e_q（q ≡ 3 (mod 4)）が入ることと、v2(e_1) が偶数（≤ v − 1）の e_1 が入ること。
- E 型ブロックでは奇数はすべて入る。補題 Q_L により、v2 ≤ v − 1 の距離は「入る ⇔ v2 が偶数」。
- よって、ブロック L + 2 以降はブロック 1 以降と同じ計算になる。q についての帰納法で、型は 1 0^L のくり返し。∎

### 補足

- K29（w = 1）との違い：
  - K29 では S_1[3]、S_1[7] の少なくとも一方が T で、ブロック L で h が入った（周期 1 0^{L−1}）。
  - u ≡ 3 (mod 4) では S_1[3] = S_1[7] = F なので、ブロック L でも h は入らず、E 型ブロックがもう 1 つ続く。
