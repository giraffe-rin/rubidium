### 証明の方法

**1 次式。**
- 類 m = A·t + B（A は 2^{v+1} 以上の 2 の累乗、B は奇数）を固める。
- 距離を a·t + b（a, b は整数）で表す。例：m = A·t + B、h = (A/2)·t + (B+1)/2。
- ブロック漸化式 R の (i)(ii)(iii) で出てくる値（x/2、(g+x)/2、h−1）も 1 次式になる。g は m+1 か m+2。

**t によらない判定。** 証明書では、次の判定を t によらずに行う。
- **偶奇**：a が偶数なら a·t + b の偶奇は b の偶奇。a が奇数なら t の偶奇によるので、類を分ける。
- **K3 の値**（v2 の偶奇）：a = 0 か v2(a) > v2(b) なら v2(a·t + b) = v2(b)。そうでなければ類を分ける。
- **大小**（e ≤ m）：差 (a′·t + b′) の符号は、t が十分大きければ a′ の符号（a′ = 0 なら b′ の符号）で決まる。
  その答えが正しくなる t の下限を記録し、すべての下限の最大値を t_min とする。
- **等号**（(iii) の d = h − 1）：1 次式として恒等的に等しいかで判定する。
  1 つの t でだけ等しい場合は、その t より大きい値を t_min の候補にする。

**節点。**
- ブロック j を節点 ν(j) にまとめる。j < p + L なら ν(j) = j、それ以上なら ν(j) = p + ((j − p) mod L)。p は前周期、L は周期。
- 証明書は、各節点 ν と必要な距離 x について「x ∈ S が成り立つか」と、節点の間隔を記号で求める。
  - 節点 ν の 1 つ前は ν − 1。ν = 0 は K3。
  - 節点 p だけは、1 つ前が 2 通りある：p − 1（p = 0 なら K3）と p + L − 1。
  - 節点 p で使ったすべての事実が、2 通りの導き方で同じ値になることを確かめる。
- (p, L) は、類の代表の m（3000 以上）で数値から推測する。推測が誤っていれば、証明書が失敗するだけである。
  - 失敗したら L を 2, 3, 4, 6 倍に、p を p + (1, 2, 4, 8)·L にして試す。

**健全性（証明書から定理へ）。** 証明書が成功し、t ≥ t_min とする。主張 Ψ(j) を次のように定める。
- 証明書の節点 ν(j) の各事実 (x, v) について、x(t) ∈ S_j ⇔ v。
- g_j は節点 ν(j) の間隔に等しい。

Ψ(j) を j についての強い帰納法で示す。
- **j = 0**：S₀ は K3 で決まる。節点 0 の事実（p = 0 の場合は、K3 による導き方の事実）は K3 で求めたものなので成り立つ。
- **j ≥ 1**：
  - ν(j) ≠ p なら、ν(j − 1) = ν(j) − 1 である。
  - ν(j) = p なら、ν(j − 1) は p − 1（j = p）か p + L − 1（j > p）で、どちらの導き方でも同じ値になる。
  - 節点 ν(j) の各事実は、証明書の中で次の 2 つから R によって導かれている。
    - 同じ節点のより小さい距離の事実（x/2）
    - 1 つ前の節点の事実（e）
  - ブロック j の種類（1 つ前の間隔）は Ψ(j − 1) で決まる。
  - 偶奇・v2 の判定はすべての t で正しく、大小・等号の判定は t ≥ t_min で正しい。
  - よって、x についての帰納法で、各事実は S_j について正しい。
  - h についての事実と H(j)(c) より、g_j は節点の間隔に等しい。

M_min := A·t_min + B とすれば、定理が成り立つ。∎
