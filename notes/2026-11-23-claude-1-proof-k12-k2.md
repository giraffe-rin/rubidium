## 結果

### 型の定義

「m が **11010 型**」とは、すべての i ≥ 0 で次が成り立つこととする。
- g_{5i} = g_{5i+1} = g_{5i+3} = m+2
- g_{5i+2} = g_{5i+4} = m+1

間隔の和は 5(m+1) + 3 = 5m+8。A 行は i(5m+8) に 0、m+2、2m+4、3m+5、4m+7 を足したものになる（i についての帰納法）。
系 1.1 より、11010 型 ⇔ すべての n ≥ 1 で「(n, 0) が P ⇔ n mod (5m+8) ∈ {0, m+2, 2m+4, 3m+5, 4m+7}」。

### 定理 K12″ `[非形式証明]`

m ≥ 5 で v2(m+1) = 1 とし、h = (m+1)/2 とおく（h は奇数）。v2(3h+1) = 2k（k ≥ 1）とする。
w := (3h+1)/2^{2k}（奇数）、Q_k := (m+2+w)/2 とおく。

- (a) k = 2 で Q₂ が奇数なら、m は 11010 型。
  h で書くと Q₂ = (35h+17)/32。
- (b) m ≠ 9 なら、g₀ = g₁ = m+2 で、g₂ = m+2 ⇔ v2(Q_k) が奇数。
  1(10)^k 型では g₂ = m+1 なので、v2(Q_k) が奇数なら m は 1(10)^k 型でない。

k = 1 の場合、(b) は K12 (b) と同じ。

#### 記号

- e_i := 2^i w（0 ≤ i ≤ 2k−1）。e* := e_{2k−1} = (3h+1)/2。
- m + 2 = 2h + 1、m + 2 + h = 3h + 1 = 2e*。

#### 証明 (b)

**値の範囲。**
- e* ≤ m ⇔ 3h+1 ≤ 4h−2 ⇔ h ≥ 3。
- Q_k ≤ m ⇔ w ≤ 2h−3。これは w ≤ (3h+1)/4 から従う。
- Q_k は整数である。m+2 も w も奇数なので、m+2+w は偶数。

**e_i ≠ h − 1 であること。** h − 1 = 2^i w なら、3h + 1 = 4^k w より 4^k w − 4 = 3·2^i w となる。
- すると w は 4 を割るので w = 1。
- 4(4^{k−1} − 1) = 3·2^i となる。k ≥ 2 では 4^{k−1} − 1 は奇数なので、4^{k−1} − 1 = 3、i = 2 となり、k = 2、h = 5、m = 9。
- k = 1 では 4^{k−1} − 1 = 0 なので起きない。
- よって m ≠ 9 なら、偶数の e_i は (iii) の対象にならない。

**g₀, g₁。**
- 定理 K3 より h（奇数）∈ S₀、よって g₀ = m+2。
- ブロック 1 は O 型。h ∈ S₁ ⇔ e* ∉ S₀ である。v2(e*) = 2k−1 は奇数なので、K3 より e* ∉ S₀。よって g₁ = m+2。

**g₂。** ブロック 1 は O 型。
- w（奇数）∈ S₁ ⇔ Q_k ∉ S₀ ⇔ v2(Q_k) が奇数（K3）。
- O 型の偶数の規則より、e_i ∈ S₁ ⇔ e_{i−1} ∉ S₁（1 ≤ i ≤ 2k−1）。
  よって e* = e_{2k−1} ∈ S₁ ⇔ w ∉ S₁ ⇔ v2(Q_k) が偶数。
- ブロック 2 も O 型。h ∈ S₂ ⇔ e* ∉ S₁ ⇔ v2(Q_k) が奇数。
- H(2)(c) より主張が成り立つ。∎

**m = 9 の場合。** k = 2、w = 1、Q₂ = 6（v2 = 1）。
(iii) により e₂ = 4 = h − 1 ∉ S₁ となり、e₃ = 8 ∈ S₁、g₂ = m+1 となる。よって (b) の例外になる。

#### 証明 (a)

k = 2 とし、Q₂ が奇数とする。

**準備。**
- 3h + 1 = 16w なので、h = (16w−1)/3、m + 2 = (32w+1)/3、m = (32w−5)/3、e* = 8w。
- Q₂ = (35w+1)/6。h は奇数なので、Q₂ = h + (w+1)/2 と書ける。Q₂ が奇数 ⇔ (w+1)/2 が偶数 ⇔ w ≡ 3 (mod 4)。
  - h が整数なので w ≡ 1 (mod 3)。よって w ≡ 7 (mod 12)、w ≥ 7、m ≥ 73。
  - 特に m ≠ 9。
- 追う距離は次のとおり。
  - 奇数：w、5w、9w、h、f₁ := h + 2w、f₂ := h + 4w、Q₂、X := (59w+1)/6、Y := (47w+1)/6
  - 偶数：2w、4w、8w、10w
- **X, Y が奇数であること**：6X = 59w + 1、6Y = 47w + 1 である。w ≡ 3 (mod 4) なので、どちらも ≡ 3·3 + 1 ≡ 2 (mod 4)。
  よって 3X、3Y は奇数で、X、Y は奇数。f₁、f₂ は h が奇数なので奇数。
- **値の範囲**（どれも 1 以上 m = (32w−5)/3 以下）。w ≥ 7 なら次のとおり。
  - Q₂ = (35w+1)/6 ≤ (64w−10)/6
  - X = (59w+1)/6 ≤ (64w−10)/6 ⇔ 5w ≥ 11
  - Y = (47w+1)/6 ≤ (64w−10)/6
  - 10w ≤ (32w−5)/3 ⇔ 2w ≥ 5
  - 9w、8w、5w はこれより小さい。
  - f₂ = (28w−1)/3 ≤ (32w−5)/3 ⇔ w ≥ 1。f₁ < f₂。
- **(ii) で使う e の値**：
  - O 型で奇数 d を調べるとき、e = (m+2+d)/2 となる。
    - d = w なら e = Q₂、d = 5w なら e = Y、d = 9w なら e = X、d = h なら e = e* = 8w。
    - d = f₁ なら e = (3h+1+2w)/2 = 9w、d = f₂ なら e = 10w。
  - E 型で偶数 d を調べるとき、e = h + d/2 となる。d = 4w なら e = f₁、d = 8w なら e = f₂。
- **(iii) について**：h − 1 = (16w−4)/3 は、偶数の 2w、4w、8w、10w のどれとも等しくない（w ≥ 7）。

**ブロックの種類（11010 型を仮定したとき）。** j ≡ r (mod 5) とすると次のとおり。
- r = 0：j = 0 なら K3。j ≥ 5 なら、1 つ前の間隔 g_{j−1} = m+1 なので E 型。
- r = 1：O 型
- r = 2：O 型
- r = 3：E 型
- r = 4：O 型

**主張 Ψ(j)。**
- r = 0：
  - (Z1) すべての奇数が S_j に入る
  - (Z2) 2w ∉ S_j、4w ∈ S_j、8w ∉ S_j
  - g_j = m+2
- r = 1：
  - (U1) 8w ∈ S_j
  - (U2) 10w ∈ S_j
  - (U3) 9w ∉ S_j
  - g_j = m+2
- r = 2：
  - (V1) f₁ ∈ S_j
  - (V2) f₂ ∉ S_j
  - g_j = m+1
- r = 3：
  - (W1) すべての奇数が S_j に入る
  - (W2) 8w ∈ S_j
  - g_j = m+2
- r = 4：
  - (T1) f₁ ∉ S_j
  - g_j = m+1

Ψ(j) を j についての強い帰納法で示す。帰納法の仮定は「Ψ(0), …, Ψ(j−1) が成り立つ」こと。

- **r = 0、j = 0**：K3 より奇数はすべて入る。v2(2w) = 1、v2(8w) = 3 なので入らず、v2(4w) = 2 なので入る。h ∈ S₀ より g₀ = m+2。
- **r = 0、j ≥ 5**（E 型、1 つ前は r = 4 で (T1)）：
  - 奇数は入る。
  - 2w は (i)（w ∈ S_j）で入らない。
  - 4w：(i) は 2w ∉ S_j なので成り立たない。(ii) は e = f₁ ∉ S_{j−1}（(T1)）なので成り立たない。よって 4w ∈ S_j。
  - 8w：(i) により入らない（4w ∈ S_j）。
  - h ∈ S_j より g_j = m+2。
- **r = 1**（O 型、1 つ前は r = 0 で (Z1)(Z2)）：
  - w：e = Q₂（奇数）∈ S_{j−1} なので、w ∉ S_j。O 型の偶数の規則より、2w ∈、4w ∉、8w ∈（(U1)）。
  - 5w：e = Y（奇数）∈ S_{j−1} なので、5w ∉ S_j。よって 10w ∈ S_j（(U2)）。
  - 9w：e = X（奇数）∈ S_{j−1} なので、9w ∉ S_j（(U3)）。
  - h：e = 8w ∉ S_{j−1}（(Z2)）なので、h ∈ S_j。g_j = m+2。
- **r = 2**（O 型、1 つ前は r = 1 で (U1)〜(U3)）：
  - f₁：e = 9w ∉ S_{j−1}（(U3)）なので、f₁ ∈ S_j（(V1)）。
  - f₂：e = 10w ∈ S_{j−1}（(U2)）なので、f₂ ∉ S_j（(V2)）。
  - h：e = 8w ∈ S_{j−1}（(U1)）なので、h ∉ S_j。g_j = m+1。
- **r = 3**（E 型、1 つ前は r = 2 で (V1)(V2)）：
  - 奇数は入る（(W1)）。2w は (i) で入らない。
  - 4w：(ii) は e = f₁ ∈ S_{j−1}（(V1)）なので成り立ち、4w ∉ S_j。
  - 8w：(i) は 4w ∉ S_j なので成り立たない。(ii) は e = f₂ ∉ S_{j−1}（(V2)）なので成り立たない。よって 8w ∈ S_j（(W2)）。
  - h ∈ S_j より g_j = m+2。
- **r = 4**（O 型、1 つ前は r = 3 で (W1)(W2)）：
  - f₁：e = 9w（奇数）∈ S_{j−1}（(W1)）なので、f₁ ∉ S_j（(T1)）。
  - h：e = 8w ∈ S_{j−1}（(W2)）なので、h ∉ S_j。g_j = m+1。

帰納法により、すべての j で Ψ(j) が成り立つ。よって m は 11010 型。∎

## うまくいかなかったこと

- **一般の k ≥ 3 の (a)**：k = 2 と同じ形の主張を立てようとした。必要な条件は次のとおり。
  - 周期の中の E 型のブロック r = 2s+1 では、「e_i ∈ ⇔ (i が偶数で i < 2s) または (i が奇数で i > 2s)」。
  - そのためには、その前の O 型のブロック r = 2s で、f_t := h + e_t について次の条件が要る。
    - t = 2s−1 では f_t ∈。
    - 奇数 t < 2s−1 では f_t ∉。
    - 偶数 t ≥ 2s では f_t ∉。
  - f_t を調べると e* + e_{t−1} に、さらにその半分と h の和に、と前のブロックへ遡る。
  - s = 1 の場合と、s ≥ 2 で t = 1 の場合は、出てくる値がすべて奇数になり、k = 2 と同じく閉じた。
    （mod 4 の計算で、Q_k が奇数なら奇数と分かる。）
  - s ≥ 2 で t ≥ 3 の場合は、追う値の木が k とともに深くなり、まだ一般の形を書き切れていない。
  - k = 3 の数値（m = 297 など）では木が有限で閉じているので、K9 の木 Φ と同じ形の帰納法で一般化できる見込みはある。
