# v2(m+1) = 5, 7 の族の探索（見つからなかった）

## やったこと

- 定理 K33a（v2(m+1) = 1）と定理 K35（v2(m+1) = 3）の族は、どちらも m + 2 = 3a の形をしている。
  - K33a：a = 3·2^e + 1（2 進的には a ≈ 1）
  - K35：a = (16^k − 1)/5（2 進的には a ≈ −1/5）
  - どちらも v2(3a − 1) = v2(m+1)。
- この形で v2(m+1) = 5, 7 の族を探した。
  - (1) a = c·2^e + α（c ≤ 15 の奇数、|α| ≤ 200、v2(3α − 1) = v）、e = 16, 18, 20, 22 で、周期 L が増え続けるもの。v = 3, 5, 7 で 0 件（その場のスクリプトで調べた。データは残していない）。
  - (2) a = (c·2^N + b)/q（`code/family_search.js`）。
    - q は 17 個の奇数（3〜127）、c ≤ 15 の奇数、|b| ≤ 150。
    - N ≥ 16 から 2 の位数ずつ 4 つの N を取り、L が一定の幅で増えるもの。
    - 結果は `data/family_search_v{3,5,7}.txt`。
- `code/lazy_bigint.js` の gapsBig に、評価する事実の数の上限（引数 cap、既定は無制限）を足した。既定の動作は変わらない（`data/k35_bigint.txt` を作り直して一致）。
- そのほか、v2(m+1) = 5 で m+2 の連が最も長い m を 2^{k−1} < m ≤ 2^k ごとに調べた（k ≤ 24、その場のスクリプト）。2 進表示に目立つ規則は見つからなかった。
