## 結果

### 定理 K20 `[非形式証明]`

v2(m+1) = 3 とし、ℓ := v2(5m+13) とする。ℓ が 6 以上の偶数で ℓ = 2i なら、m は前周期なしの次の型である。
- i が奇数なら、周期「1^{i−1}0」
- i が偶数なら、周期「1^{i−1}00」

v2(m+1) = 3 の m の中で、条件を満たす m の密度は 1/6。

### 証明

**記号。**
- u := (m+1)/8（奇数）。このとき m = 8u − 1、h = 4u、m + 2 = 8u + 1、h − 1 = 4u − 1。
- E := 5u + 1 とおく。5m + 13 = 8E なので λ := v2(E) = ℓ − 3 = 2i − 3（3 以上の奇数）。
- K := (λ − 1)/2 = i − 2（1 以上）。
- E ≡ 0 (mod 8) より u ≡ 3 (mod 8)。特に u ≥ 3。

**距離の定義。**
- 1 ≤ k ≤ K について c_k := (4^k(8u+1) − E)/(3·4^k)
- 1 ≤ k ≤ K+1 について d_k := 2c_k = (4^k(8u+1) − E)/(3·2^{2k−1})
- 0 ≤ r ≤ λ − 1 について f_r := 8u + 1 − E/2^r。特に f_0 = 3u。
- ほかに u、2u、4u = h、6u を使う。

**整数であること。**
- 4^k ≡ 1 (mod 3) より 4^k(8u+1) − E ≡ 8u + 1 − 5u − 1 = 3u ≡ 0 (mod 3)。
- 2k ≤ 2K = λ − 1 < λ、2k − 1 ≤ 2K + 1 = λ なので、4^k と 2^{2k−1} は E を割る。
- f_r は r ≤ λ で整数。

**偶奇。**
- c_k = (8u + 1 − E/4^k)/3 で、E/4^k = 2^{λ−2k}·(奇数) は偶数（λ − 2k ≥ 1）なので、c_k は奇数。
- d_k（k ≤ K）= 2c_k は偶数。
- d_{K+1} = (4^{K+1}(8u+1) − E)/(3·2^λ) は、分子の 2 進付値がちょうど λ なので奇数。
- f_r（1 ≤ r ≤ λ − 1）は 8u + 1 − 偶数 なので奇数。3u も奇数。

**範囲。** どれも 1 以上 m = 8u − 1 以下。
- c_k < (8u+1)/3、d_k < 2(8u+1)/3。
- f_r ≤ 8u + 1 − 2 = m（r ≤ λ − 1 なら E/2^r ≥ 2）。
- 6u ≤ 8u − 1。

**(iii) が効かないこと。** O 型のブロックで調べる奇数の距離（u、3u、c_k、f_r で r ≥ 1）は、どれも h − 1 = 4u − 1 と違う。
- u < 3u < 4u − 1（u ≥ 3）
- c_k < (8u+1)/3 < 4u − 1
- f_r ≥ 8u + 1 − E/2 = (11u + 1)/2 > 4u − 1

**恒等式**（m + 2 = 8u + 1）：
- (E1) (m + 2 + u)/2 = (9u + 1)/2 = d_1
- (E2) (m + 2 + c_k)/2 = d_{k+1}。分子が (3·4^k + 4^k)(8u+1) − E = 4^{k+1}(8u+1) − E になる。
- (E3) (m + 2 + f_r)/2 = f_{r+1}。特に (m + 2 + 3u)/2 = f_1。
- (E4) E 型（1 つ前の間隔 m + 1 = 8u）で 4u を調べるとき：(8u + 4u)/2 = 6u。

**O 型のブロック n の規則**（1 つ前の間隔が m + 2 で奇数）：
- 偶数の x：x ∈ S_n ⇔ x/2 ∉ S_n。m + 2 + x が奇数なので (ii) は効かない。(iii) は x が奇数のときだけ。
  - 2u ∈ ⇔ u ∉
  - 4u ∈ ⇔ 2u ∉
  - 6u ∈ ⇔ 3u ∉
  - d_k ∈ ⇔ c_k ∉（k ≤ K）
- 奇数の x：x ∈ S_n ⇔ (m + 2 + x)/2 ∉ S_{n−1}（(i) は効かず、(iii) は上で除いた）。
  - u ∈ ⇔ d_1 ∉
  - c_k ∈ ⇔ d_{k+1} ∉
  - f_r ∈ ⇔ f_{r+1} ∉
  - 3u ∈ ⇔ f_1 ∉

**E 型のブロックと、ブロック 0 の規則。**
- 奇数の距離はすべて入る。
  - E 型：8u + 奇数 は奇数なので (ii) は効かない。(iii) は O 型だけ。
  - ブロック 0：K3 で v2 = 0。
- 2u と d_k（k ≤ K）は入らない。
  - E 型：(i) で、u、c_k は奇数で入っている。
  - ブロック 0：v2 = 1。
- 4u = h：
  - E 型では、(i) は 2u ∉ なので効かない。よって h ∈ ⇔ 6u ∉ S_{前}（(E4)）。
  - ブロック 0 では v2(4u) = 2 なので入る。
- 6u：E 型では (i) により、3u ∈ なので入らない。

**主張 Q(n)**（0 ≤ n ≤ i − 2）：
- u ∈、2u ∉、h ∈
- 1 ≤ k ≤ min(K, K − n + 1) で、c_k ∈ ⇔ k ≤ K − n
- 1 ≤ k ≤ K + 1 − n で、d_k ∈ ⇔ k = K + 1 − n
- f_{i−1−n} ∈ ⇔ n が偶数

**帰納法。** 周期を L（i が奇数なら i、偶数なら i + 1）とし、ブロック J ≡ n (mod L) について次を示す。
- n ≤ i − 2 なら Q(n) と g_J = m + 2
- n ≥ i − 1 なら g_J = m + 1

- **n = 0**（J = 0、または 1 つ前が間隔 m + 1 の E 型で、6u ∉ のとき）：
  - u、c_k、d_{K+1}、f_{i−1} は奇数なので入る。
  - 2u、d_k（k ≤ K）は入らない。h は入る。
  - これは Q(0)。
- **1 ≤ n ≤ i − 2**：Q(n−1) より g = m + 2 なので O 型。
  - c_k（k ≤ K − n + 1）：∈ ⇔ d_{k+1} ∉ S_{n−1} ⇔ k + 1 ≠ K + 2 − n ⇔ k ≤ K − n。
    d_{k+1} は Q(n−1) の範囲 k + 1 ≤ K + 2 − n に入っている。
  - d_k（k ≤ K + 1 − n ≤ K）：∈ ⇔ c_k ∉ S_n ⇔ k > K − n ⇔ k = K + 1 − n。
  - u：∈ ⇔ d_1 ∉ S_{n−1} ⇔ 1 ≠ K + 2 − n ⇔ n ≠ i − 1。成り立つので u ∈。よって 2u ∉、h ∈。
  - f_{i−1−n}：∈ ⇔ f_{i−n} ∉ S_{n−1} ⇔ n − 1 が奇数 ⇔ n が偶数。
  - よって Q(n) が成り立ち、g = m + 2。
- **n = i − 1**（O 型）：
  - u：d_1 ∈ S_{i−2}（k = 1 = K + 1 − (i − 2)）なので u ∉。よって 2u ∈、h = 4u ∉ で、g = m + 1。
  - 3u：∈ ⇔ f_1 ∉ S_{i−2} ⇔ i − 2 が奇数 ⇔ i が奇数。
  - 6u：∈ ⇔ 3u ∉ ⇔ i が偶数。
- **i が奇数のとき**：次のブロックは E 型で 6u ∉ S_{前} なので h ∈。これは n = 0 の場合で、Q(0)。周期は i（1^{i−1}0）。
- **i が偶数のとき**：次のブロック（n = i）は E 型。
  - 6u ∈ S_{前} なので h ∉、g = m + 1。
  - 3u（奇数）∈ なので 6u ∉。
  - その次は E 型で 6u ∉ S_{前} なので h ∈ で、n = 0 の場合（Q(0)）。周期は i + 1（1^{i−1}00）。

最後に H(J)(c) より、g_J = m + 2 ⇔ h ∈ S_J。∎

## 訂正（2026-11-24 追記）

gemini-2 の査読（PR #185、`notes/2026-11-24-gemini-2-review-k20.md`）で指摘された、次の 2 点の書き方の誤りを訂正する。どちらも証明本体の計算には影響しない。

1. 「記号」の節の「1 ≤ k ≤ K+1 について d_k := 2c_k = (4^k(8u+1) − E)/(3·2^{2k−1})」：c_{K+1} は整数ではないので、d_{K+1} は 2c_{K+1} ではなく右辺の式で定義する。正しくは次のとおり。
   - 1 ≤ k ≤ K では d_k := 2c_k。
   - 1 ≤ k ≤ K+1 では、d_k := (4^k(8u+1) − E)/(3·2^{2k−1})（k ≤ K では 2c_k と同じ）。
2. 比較表「定理 K19 との関係」の「f_r（偶奇が交互）」：f_r（0 ≤ r ≤ λ−1）はすべて奇数である。交互に変わるのは、所属 f_{i−1−n} ∈ S_n の真偽である。正しくは「f_r（所属が交互）」。
