# 定理 K5 と定理 K4 の一部の Lean 4 での形式化

## やったこと

- Lean の定理 K3（PR #364）を使い、`lean/Rubidium/K5.lean` を書いた。このブランチは `claude-1/lean-k3` から切った。
- 形式化した主張：
  - `not_isP_small`：1 ≤ n ≤ m なら (n, 0) は N 局面。
  - `isP_succ`：p ≤ 1 のとき、(m+1, p) が P ⇔「m+1 が偶数、(m+1)/2 ≠ p、v2((m+1)/2) が偶数」でない。
  - `K4_first`（定理 K4 の一部）：m ≥ 1 なら、(m+1, 0) が P ⇔ v2(m+1) が偶数。
  - `K5`（定理 K5）：m ≥ 2 で v2(m+1) が奇数なら、(m+2, 0) は P 局面。
  - `K5_before`：m ≥ 1 で v2(m+1) が奇数なら、1 ≤ n ≤ m+1 の (n, 0) は N 局面。
- 途中で直したこと：`by_contra` は Mathlib の戦術で core にはないので、`Classical.byContradiction` に置き換えた。

**前提**：Lean の定理 K3（PR #364、`sorry` なし）。

## 結果

`[Lean検証済み]`（提案。ラベルは査読者が変える）：

- 開始局面 (n, 0) が最初に後手必勝になる n は、次のとおり。
  - v2(m+1) が偶数なら m+1：`not_isP_small` と `K4_first`。
  - v2(m+1) が奇数（m ≥ 2）なら m+2：`K5_before` と `K5`。
- これは、定理 K5 と、定理 K4 の「最初の P 局面」の部分である。
- 定理 K4 の全体（v2(m+1) が偶数なら、すべての n で (n, 0) が P ⇔ (m+1) | n）は、まだ形式化していない。ブロックの構造（定理 K8 など）が要る。

**証明の要点**：

- (m+1, p) から移った先 (m+1−k, k) は、1 ≤ m+1−k ≤ m なので K3 の範囲にある。K3 により、それが P ⇔ k = m+1−k かつ v2(k) が偶数。
- (m+2, 0) から k ≥ 2 で移った先も K3 の範囲にある。P なら k = m+2−k だが、v2(m+1) が奇数なら m は奇数なので、これは起こらない。
- k = 1 で移った先 (m+1, 1) は、k′ = (m+1)/2（m ≥ 2 なので ≠ 1）で P 局面に移れるので N 局面。
