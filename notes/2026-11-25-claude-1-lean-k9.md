# 定理 K9 の十分性の Lean 4 での形式化（木 T を使わない証明）

## やったこと

`lean/Rubidium/K9.lean` に、定理 K9 の十分性（(3) ⇒ (1)）を sorry なしで証明した（Lean 4.36、Mathlib なし）。

```lean
theorem K9_suff (m : Nat) (hm4 : m % 4 = 1) (hm5 : 5 ≤ m)
    (hodd : v2 (3 * ((m + 1) / 2) + 1) % 2 = 1) (n : Nat) :
    IsP m n 0 ↔ (n % (2 * m + 3) = 0 ∨ n % (2 * m + 3) = m + 2)
```

`#print axioms Rubidium.K9_suff` は `[propext, Quot.sound]`。m % 4 = 1 は v2(m+1) = 1 と同じ。

## 新しい不変量（もとの証明の木 T の代わり）

もとの証明（ノート 2026-11-23-claude-1-proof-k9-general.md）は、深さ k の二分木 T の値の集合で事実を並べ、値の上界を等比級数で評価していた。
ここでは、K4 の形式化（PR #377）と同じ形の、v2 だけで書ける不変量に置き換えた。

記号：h = (m+1)/2（奇数）、e* = (3h+1)/2、s = v2(e*) = v2(3h+1) − 1（偶数）。a = i(2m+3)、b = a + (m+2) とする。

- **Blk m s a**（偶数番目のブロック）：1 ≤ d ≤ m、v2(d) ≤ s なら、(a + d, d) が P ⇔ v2(d) が偶数。
  先に数値で確かめた：v2(m+1) = 1、v2(3h+1) が奇数の m ≤ 400 のすべてで、ブロック 0〜4 で成り立つ。
- **BlkO m s b**（奇数番目のブロック）：v2(x) が奇数で v2(x) < s、h + x ≤ m なら、(b + h + x, h + x) は N。

木 T の値 2^c·r（c 偶数）は「v2 が偶数で ≤ s」、2^{c−1}·r は「v2 が奇数」なので、T の事実はこの 2 つの不変量に含まれる。

## 証明の組み立て

- **`blkO_of_blk`**：Blk a から BlkO b。
  (b + h + x, h + x) から手 k = e* + x/2 を打つと、行き先は (a + k, k)（m + 2 + h = 2e* を使う）。
  v2(x/2) = v2(x) − 1 < s = v2(e*) なので、`v2_add` より v2(k) = v2(x/2)。これは偶数で s 以下なので、Blk a より (a + k, k) は P。
  k ≤ m であること：k ≤ m + 1 はすぐ言える。k = m + 1 にはならない。v2(m+1) = 1 は奇数だが、v2(k) は偶数だから。
- **`blkE_step`**：K4 の `blk_step` と同じ、d についての強い帰納法。違いは、手 k > d で 1 つ前のブロックに戻る場合だけ。
  行き先が P になりうるのは k = h + d/2 のときだけで、そのとき v2(d/2) は奇数で s 未満なので、BlkO b より N。
- **`k9_rows`**：i についての帰納法で、次の 3 つを示す。
  - 行 a はすべての p で P。
  - 行 b はすべての p で P。
  - Blk a。

  1 段は K6 と同じ形で、次の 5 つから成る。
  1. `row_long`：(a + h, h) は P（v2(h) = 0）なので、行 b は P。
  2. `blkO_of_blk`：BlkO b。
  3. (b + h, h) は N。手 e* で (a + e*, e*) に移れて、v2(e*) = s は偶数なのでそこは P。
  4. `row_next`：行 a + (2m+3) は P。
  5. `blkE_step`：Blk (a + (2m+3))。
- 最後の場合分けは K6 と同じ。

## 意味

- 定理 K9 の十分性が [Lean検証済み] の候補になった（査読待ち）。K6（k = 0）を含む。
- もとの証明の前提だった H(j)（K8）と、木 T の値の上界の評価が、どちらも要らなくなった。
- 定理 K9 の必要性（v2(3h+1) が偶数なら交互型でない）は、まだ Lean にしていない。次の候補。
