## 補題 K56.1 `[非形式証明]`

ρ ≥ 4 を偶数、z = ρ/2、L = lcm(1, …, z) とする。c < 2^{ρ−1} が奇数で、1 の個数 p ≤ z とする。c の ρ 桁の 2 進の語の基本周期を d、その 1 周期の中の 1 の個数を ℓ とする（補題 K53 により、ℓ は閉路の長さ、閉路 1 周での r の和は d）。

このとき ℓ | L で、δ(c) = L + (L/ℓ)(d − ℓ) は偶数である。

**証明**：L は 2 を因数にもつ（z ≥ 2）。2^a を z 以下の最大の 2 の冪とすると、v2(L) = a ≥ 1 で、2^a > z/2。

- **語が周期的でない（d = ρ）場合**：ℓ = p ≤ z なので ℓ | L。
  - p が偶数なら、d − ℓ = ρ − p は偶数。
  - p が奇数なら、L/p の 2 の付値は a ≥ 1 なので、L/p は偶数。
  - どちらでも (L/ℓ)(d − ℓ) は偶数。
- **語が周期的（d < ρ）な場合**：d | ρ なので d ≤ ρ/2。p = ℓ·(ρ/d) ≤ z = ρ/2 から ℓ ≤ d/2 ≤ ρ/4 = z/2 < 2^a。
  - よって v2(ℓ) < a で、L/ℓ は偶数。また ℓ ≤ z なので ℓ | L。

L も偶数なので、δ(c) は偶数。∎

## 定理 K56 `[非形式証明]`

定理 K54 と定理 K55 の結論は、R ≡ 1 (mod 2L) を R ≡ L + 1 (mod 2L) に置き換えても成り立つ（R の下限は同じ）。

系：予想 K51 は、R ≡ 1, L + 1 (mod 2L) の両方で成り立つ（R が下限以上のとき）。定理 K50 の剰余類 {1, P/2 + 1} も、これで説明される。

**証明**：補題 K54.1 で使うのは、O 型ブロック B+R での値 F(c, k) だけである。

- 入口 c ≥ 3 の鎖は、R − 1 = L(2t + 1) 回の閉路をたどる。ℓ | L なので、R − 1 は ℓ の倍数で、終点の b は c に戻る。
- 段数 s = (v − k) + R + Σ_{i<R}(r(b_i) − 1) の偶奇は、R ≡ 1 のときと比べて、次の和だけ変わる。
  - R の偶奇の差：L。
  - 閉路の周回数 (R − 1)/ℓ = (L/ℓ)(2t+1) に、1 周での和 d − ℓ を掛けたもの：(L/ℓ)(d − ℓ)。
- この差は δ(c) で、補題 K56.1 により偶数。補題 K54.1 の範囲の入口は、c < 2^{ρ−1} で 1 の個数 ≤ z なので、補題 K56.1 の条件を満たす。
- よって、F(c, k) は R ≡ 1 のときと同じ値 Ψ(c, k) になり、補題 K54.1 と (B) の証明がそのまま成り立つ。
- (A)、(C)、鎖の条件（R の下限）は R の剰余類によらない。∎
