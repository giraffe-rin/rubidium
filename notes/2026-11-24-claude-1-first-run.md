# 定理 K47：偶数 w ≤ v − 1 のすべての類で型は無限に多い

## やったこと

- 予想 K46（Issue #280）の族について、周期の形を調べた。1^n 0^z のときもあれば、連が複数あるときもあり、周期の形から一般に示すのは難しかった。
- 一方で、間隔の列の先頭には必ず長い m+2 の連がある。ブロック 0 では K3 で事実がすべて決まるので、ここなら一般の (v, ρ) で h の鎖を最後まで追える。
- 型は「前周期の列 | 周期の列」（`notes/2026-11-24-claude-1-type-growth.md` の定め方）なので、間隔の列が違えば型も違う。
- そこで、先頭の連の長さを正確に求めて、型が無限に多いことを示した。
- `code/k47_first_run.js` で数値でも確かめた（`data/k47_first_run.txt`）。

**前提**：H(j)（ブロック漸化式 R）、K3（いずれも gemini-2 が査読済み）。

## 記号

- v ≥ 3 は奇数、ρ は偶数で 2 ≤ ρ ≤ v − 1 とする。
- q = 2^v − 2^ρ + 1（奇数、q < 2^v）、r = (2^ρ − 1)/3（奇数）とする。このとき q + 3r = 2^v、1 + 3r = 2^ρ。
- N は偶数で N ≥ v + ρ + 1、X = 2^N とする。s は奇数で q | sX − r とする。
- a = (sX − r)/q とする。分子が奇数なので a は奇数。m = 3a − 2、M = m + 2 = 3a、h = (m+1)/2 = (3a−1)/2 とする。
- s は N ごとに選んでよい。各 N に対し、s ≡ r·2^{−N} (mod q) の奇数の代表がある。

## 定理 K47 `[非形式証明]`

上の m について、次が成り立つ。

1. v2(m+1) = v、w = v2(u+1) = ρ（u = (m+1)/2^v）。
2. 間隔の列の先頭は、g_0 = g_1 = … = g_{R−1} = m+2、g_R = m+1。ここで R = ⌈(N − v)/ρ⌉。

系：奇数 v ≥ 3 と偶数 ρ ≤ v − 1 のそれぞれで、v2(m+1) = v、w = ρ の m の型は無限に多い。

- N を動かすと R はいくらでも大きくなり、間隔の列は R で区別できるからである。
- 予想 K38 の残り（w が偶数で w ≤ v − 1 の類）のすべてで、「w だけでは型は決まらない」ことになる。
- 系 K36e（w = 2）、定理 K44（v = 5、w = 4）を含む。予想 K46 の結論のうち「型が無限に多い」部分も、周期の形によらずに従う。

### 1 の証明

- 3a − 1 = (3sX − 3r − q)/q = (3sX − 2^v)/q。3sX の付値は N > v なので、v2(m+1) = v2(3a − 1) = v。
- u = (3sX/2^v − 1)/q なので、u + 1 = (3sX/2^v + 2^v − 2^ρ)/q。
- 2^v − 2^ρ の付値は ρ で、3sX/2^v の付値は N − v > ρ。よって v2(u+1) = ρ。∎

### 2 の証明

**ブロック 0**：v2(h) = v − 1 は偶数なので、K3 により h ∈ S_0、つまり g_0 = m+2。

**帰納法**：i ≥ 1 で g_0, …, g_{i−1} = m+2 と仮定する。このときブロック 1..i は O 型（直前の間隔が m+2）で、R は次の一本道になる。

- 偶数 d が入る ⇔ d/2 が同じブロックで入らない。
- 奇数 d が入る ⇔ (M+d)/2 が 1 つ前のブロックで入らない。ただし (M+d)/2 > m なら入り、d = h − 1 なら入らない。

ブロック i の h から、この道をブロック 0 まで追い、最後は K3 で決める。

**記述**：鎖の上の距離を d = (αa − 1)/2^K と書き、β = rα + q とおく。

- q a + r = sX から r(αa − 1) = βa − (qa + r) = βa − sX。よって d = (βa − sX)/(r·2^K) …(*)
- v2(sX) = N なので、v2(β) < N なら v2(d) = v2(β) − K。
- h では α = 3、K = 1、β = 3r + q = 2^v。
- 偶数の段では K が 1 増える。奇数の段 d → (M+d)/2 = ((3·2^K + α)a − 1)/2^{K+1} では α → α + 3·2^K、β → β + 3r·2^K、K → K + 1。

**鎖の進み方**（j 回目の奇数の点を、ブロック i − j + 1 での奇数の点とする）：

- 最初に v − 1 回半分にして、K = v、β = 2^v で奇数の点に着く。
- j 回目の奇数の点では K = v + ρ(j−1)、β = 2^K。
- そこでの奇数の段で β = 2^K(1 + 3r) = 2^{K+ρ}、K + 1 となり、続いて ρ − 1 回半分にすると、次の奇数の点に着く。
- これが正しいためには、各 j < i で v + ρj < N であればよい。

**奇数の点での条件**：(*) から d = (a − s·2^{N−K})/r なので、次が成り立つ。

- 0 < d < a。正であることは、K ≥ v、q < 2^v から s·2^N(1 − q/2^K) ≥ 2^{N−v}(2^ρ − 1) > r による。
- よって (M+d)/2 < 2a ≤ m で、例外「> m」は起こらない。
- また d < a < (3a − 3)/2 = h − 1 なので、例外「d = h − 1」も起こらない。

**段数**：s_i = (v − 1) + i + (ρ − 1)(i − 1) = ρi + v − ρ は奇数（v は奇数、ρ は偶数）。よって h ∈ S_i ⇔ 終点 d_end がブロック 0 で入らない ⇔ v2(d_end) が奇数（K3）。

**終点**：β = 2^E（E = v + ρi）、K = v + ρ(i−1) + 1 で、d_end = (2^E a − sX)/(r·2^K)。

- E < N なら v2(d_end) = E − K = ρ − 1（奇数）。
- E > N なら、2^{E−N}a − s が奇数なので v2(d_end) = N − K。

**R を決める**：N − v は奇数（N 偶数、v 奇数）なので、N − v = ρk + e（e は奇数で 1 ≤ e ≤ ρ − 1）と書ける。k ≥ 1 である。

- i ≤ k のとき：v + ρ(i−1) < v + ρi ≤ N − e < N。条件を満たし、E < N なので h ∈ S_i。
- i = k + 1 のとき：v + ρk = N − e < N で条件を満たす。E = N − e + ρ > N で、v2(d_end) = N − (N − e) − 1 = e − 1 は偶数なので、h ∉ S_{k+1}。

よって R = k + 1 = ⌈(N − v)/ρ⌉。∎

## 確かめたこと

- `data/k47_first_run.txt`：v = 3..11 のすべての偶数 ρ < v と、N = v+ρ+1..120 のすべて（s は最小の奇数）。
