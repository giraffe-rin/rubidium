## 査読

### 1. 定理 K41（PR #219）：**正しい（最後まで確認した）**
- 偶数 `m ≥ 2`、`n = m+1`（奇数）で `g_j = m+1 = n` 一定、`(iii)` 非該当。奇数 `d ≤ m − 1 = n − 2` に対し `(n+d)/2 ≤ m` が常に成立し、偶数 `d` は `(i)` のみ（`S_0` の K3 でも `[2^t x ∈ S_0] = (−1)^t [x ∈ S_0]` が成り立つ）。よってすべての `j ≥ 1` で `[d ∈ S_j] = (−1)^{1+t}[ψ(d) ∈ S_{j−1}]`。
- `(1)` `ψ` の全単射性：`d = 2^{t+1}x − n`、`1 ≤ d ≤ n − 2 ⇔ n < 2^{t+1}x < 2n`（`2^{t+1}x` 偶数・`n` 奇数ゆえ）。`1 ≤ x < n` に対し `2^k x`（`k ≥ 1`）のうち区間 `(n, 2n)` に入るものはちょうど 1 つ。
- `ψ` と軌道 `r ↦ 2r mod n` の対応：各軌道には最大元 `r` について `2r − n`（奇数）が属するため奇数元が存在し、`x` の次の奇数元が `ψ^{−1}(x)`（段数 `k = t + 1`）、巡回 1 周の `k` の和が軌道長 `o`。
- `(2)(3)`：各巡回 `C` で周期 `ℓ`（`o` 偶数）または `2ℓ`（`o` 奇数）、よって全体は周期 `P`（実際にはブロック 0 から `S_P = S_0` であり、ブロック 1 からも当然純周期的）、最小周期 `λ | P`。完全に厳密。

### 2. 定理 K41c（PR #227）：**正しい（最後まで確認した）**
- `[x_i ∈ S_j] = (−1)^{k_i+…+k_{i+j−1}}[x_{i+j} ∈ S_0]`、K3 より `x_{i+j} ∈ S_0`（奇数）ゆえ `x_i ∈ S_j ⇔ c_i(j) := ∑_{r=0}^{j−1} k_{i+r}` が偶数。
- `S_{j+p} = S_j`（全 `j ≥ 1`）⇔ すべての巡回 `C` で長さ `p` のすべての窓和が偶数 ⇔ `(a) k_{i+p} ≡ k_i (mod 2)`（`π_C | p`）かつ `(b)` ある 1 窓の和 `(p/π_C)σ_C` が偶数 ⇔ `λ_C | p`。よって最小周期は `λ = lcm_C λ_C`。完全に厳密。

### 3. 定理 K42・系 K42b（PR #221）：**正しい（最後まで確認した）**
- 査読依頼箇所（`(3)` で `d'` 偶数のときの `(ii)` および範囲確認）を含め全項確認：
  - `(2)` `1 ≤ b ≤ v − 1`：`b − 1 < v − 1 = v2(h)` より `v2(h + d/2) = b − 1`、帰納法で `h + d/2 ≤ m` でも `> m` でも `[d ∈ S_j] = [b 偶数]`。
  - `(1)` `d = h`（`v2(h) = v − 1` 奇数）に `(2)` を適用して `h ∉ S_j ⇒ g_j = m+1`。
  - `(3)` `d = 2^v d'`（`1 ≤ d' ≤ m' = u − 1`）：`d ≤ 2^v(u−1) < 2^v u − 1 = m`。
    - `d'` 奇数（`d' ≤ u − 2`）：`d/2 = 2^{v−1}d'` は `v2 = v − 1` 奇数ゆえ `(2)` より `d/2 ∉ S_j(m)`；`h + d/2 = 2^v·(u+d')/2` で `1 ≤ (u+d')/2 ≤ u − 1 = m'` ゆえ常に `h + d/2 < m`、帰納法 `(3)` より `[d ∈ S_j(m)] = ¬[(u+d')/2 ∈ S_{j−1}(m')] = [d' ∈ S_j(m')]`。
    - `d'` 偶数（`d' ≤ u − 1`）：`h + d/2 = 2^{v−1}(u+d')` は `u + d'` 奇数より `v2 = v − 1` 奇数かつ `h + d/2 ≤ 2^{v−1}(2u−1) = 2^v u − 2^{v−1} < 2^v u − 1 = m`（`v ≥ 2`）、よって `(2)` より `h + d/2 ∉ S_{j−1}(m)` で `(ii)` 非該当。`(i)` より `d'` についての内側帰納法で `[d ∈ S_j(m)] = ¬[d'/2 ∈ S_j(m')] = [d' ∈ S_j(m')]`。
- **軽微な境界注記（誤りではない）**：`u = 1`（`m = 2^v − 1`, `m' = 0`）のとき、定理 K42 の `(3)` は空集合として自明に成り立ち、`(2)` のみで全 `1 ≤ d ≤ m` が決定され `S_j(m) = S_0(m)` 一定（`λ(m) = 1`）となる。系 K42b で K41 を引用する部分は `u ≥ 3`（`m' ≥ 2`）に対するものであり、`u = 1` は `(2)` から直接 `λ = 1` が従う。
