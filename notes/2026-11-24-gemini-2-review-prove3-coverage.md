## 数学的健全性の確認

### 1. `prove3(m, pre, w)` の健全性（`m` 奇数、前周期 `pre` 長さ `p`、周期 `w` 長さ `L`）

- 文字列 `word(i)` を `i < p` で `pre[i]`、`i ≥ p` で `w[(i - p) mod L]` と定義し、出発ブロックを `b = p + L` とする。
- **前段 `(0)`・`(0″)`**：ブロック 0 の間隔 `g_0`（K3 による `v2(h)` 偶奇）が `word(0)` と一致することを確認し、ブロック `j = 1, ..., b` について K3 から遷移規則 `R` で厳密評価した `T(j, h)` が `word(j)` と一致することを直接確認する。帰納的にブロック `0, 1, ..., b` の間隔列は `word(0), ..., word(b)`（特に `g_b = w[0]`）と確定する。
- **帰納仮定（周期開始ブロック `B = b + rL`, `r ≥ 0`）**：
  - `w` の末尾が 0（連続 `s ≥ 1` 個、`useG = true`）のとき：`(G)` として「奇数距離は入る、`v2(d) ≤ min(2s - 1, v - 1)` は `v2` 偶奇で決まる」を仮定する。ブロック `b` の直前 `s` ブロック `b - s, ..., b - 1` の間隔は `w[L - s] = ... = w[L - 1] = 0`（すなわちすべて `m + 1`）であり、`m` 奇数なので補題 `Q_s`（`[査読済み]`）によりブロック `b` で `(G)` が成立する。また帰納段階 `B → B + L` でも直前 `s` ブロックが `m + 1` となるため補題 `Q_s` で `(G)` が再現される。
  - **`w` の末尾が 1（`s = 0`、`useG = false`）のとき**：`(G)` を一切使わず、ブロック `B` で参照されるすべての距離を有限集合 `(A)` に入れる。ブロック `b` での `(A)` の値は K3 + R から厳密計算した `T(b, d)` そのものであるため基底段階は無条件に成り立ち、帰納段階は `(2)` の有限検証だけで完全に閉じる。末尾が 1 のブロック直後は O 型遷移のため `Q_s` が使えないが、`(G)` を完全に無効化しているため数学的な欠落は一切ない。
- **周期の `k` 倍化および出発点の `c` 周期遅延（`prove3(m, pre + w^{c-1}, w^k)`）**：
  - `pre' = pre + w^{c-1}`、`w' = w^k` に対して無限列 `pre' + (w')^∞` は `pre + w^∞` と完全に同一である。よって状態の前周期・周期が型の前周期・周期より大きい場合に `(c, k)` を増やして `prove3` を閉じる操作は、元の型 `(pre, w)` の厳密な証明として完全に健全である。

### 2. 個数算術の確認（`5 ≤ m ≤ 2^22` の `v2(m+1)` 奇数）

- `4 < m ≤ 200,000`：`v=1` は 49,999 個、`v=3` は 12,500 個、`v≥5` 奇数は 4,166 個（計 66,665 個）。
- `200,000 < m ≤ 2^20`：`v=1` は 212,144 個、`v=3` は 53,036 個、`v≥5` 奇数は 17,679 個（計 282,859 個）。小計 `5 ≤ m ≤ 2^20` は 349,524 個。
- `2^20 < m ≤ 2^22`：`v=1` は `3·2^18 = 786,432` 個、`v=3` は `3·2^16 = 196,608` 個、`v≥5` 奇数は `3·(4^8-1)/3 + 1 = 65,536` 個（計 1,048,576 個）。
- 合計：`349,524 + 1,048,576 = 1,398,100` 個。残る `v2(m+1)` 偶数のすべての `m` は `[査読済み]` 定理 K4 により全間隔 `m + 1`（開始局面 `P` は `m + 1` の倍数）と確定する。
