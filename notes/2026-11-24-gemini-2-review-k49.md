## 数学的査読

1. **全体の帰納構造 `(A)`・`(B)`・`(C)`**：
   - **(A)**：ブロック 0 からは定理 K47、直前に `m + 1` が 2 個以上続く位置 `B` からは補題 K48（`z ≥ 2 = ρ/2`）により、始まる `m + 2` 極大連の長さはちょうど `R`（`g_B = ... = g_{B+R-1} = m+2, g_{B+R} = m+1`）。
   - **(B)**：ブロック `j = B + R + 1` は E 型、`h` は偶数（`v2(h) = v - 1 ≥ 4`）、`(m + 1 + h)/2 = 3h/2 = 3(3a - 1)/4 ≤ m`（`3a ≥ 5`）。よって E 型規則から `3h/2 ∈ S_{B+R} ⇒ h ∉ S_{B+R+1}`、すなわち `g_{B+R+1} = m + 1`（`m + 1` 連の長さ `≥ 2`）。
   - **(C)**：`m + 1` が `n = (v + 1)/2 = ⌈v/2⌉` 個続いた直後のブロックでは `2n - 1 = v ≥ v - 1` なので、補題 `Q_n` により `v2(h) = v - 1`（偶数）から `h` が入り `g = m + 2` となる。よって `m + 1` 極大連の長さは `≤ ⌈v/2⌉`。
   - 帰納法により全間隔列のすべての `m + 2` 極大連が長さ `R` となり、特に周期部分 `w` 自身に長さ `R` の `m + 2` 極大連のみが現れる。`R` 奇数となる偶数 `N`（`N ≡ v + 1` または `v + 3 (mod 8)`）は無限にあるため、**周期部分のみで数えても型が無限に多い**ことが厳密に従う。
2. **補題 K49.1（`R` 奇数なら `3h/2 ∈ S_{B+R}`）の精査**：
   - 入口 `3h/2 = (9a - 3)/4`（`c = 3, α = 9, K = 2`）で `β = 5·9 + 3q = 3·2^v`、`v - 2` 回の偶数段で `K_1 = v, b_1 = 3` へ到達。
   - `T(b) = (b + 15)/2^{v2(b+15)}` の軌道は `3 → 9 → 3 → ...`、`r(3) = 1`, `r(9) = 3`。
   - `R` 奇数なので `b_R = 3`、終点 `v2 = r(3) - 1 = 0`（奇数 ⇒ ブロック 0 でも E 型ブロック `B` でも入る）、段数 `s = (v - 2) + R + (0 + 2)(R - 1)/2 = v + 2R - 3` は偶数 ⇒ `3h/2 ∈ S_{B+R}`。
   - **条件 (a) `v2(β) < N`**：最大は `i = R` での `v + 2(R - 1) + 1 = v + 2R - 1`。`R ≤ (N - v + 3)/4` より `v + 2R - 1 ≤ v + (N - v + 1)/2 < N`（`N - v ≥ 17`）。
   - **条件 (b) `(M+d)/2 ≤ m`**：`b ∈ {3, 9}`、`s > 0` より `d = (ab - 3s·2^{N-K})/5 < 9a/5` ⇒ `(3a + 9a/5)/2 = 12a/5 < 3a - 2 = m`。
   - **条件 (c) `d > 0`**：`s·2^N(b - 3q/2^K) > 5b` について、最悪の `b = 3, K = v` でも `3 - 3q/2^v = 45/2^v` なので `s·2^N · 45/2^v ≥ 45·2^{17} > 15 = 5b`（`b = 9` や `K ≥ v + 4` ではさらに大きい）。任意の**正の奇数 `s > 0`** で成立（本文の「`s` は奇数」は明示的に「正の奇数」とするとなお厳密）。
   - **条件 (d) `d ≠ h - 1`**：`d = (3a - 3)/2` から `(2b - 15)a + 15 = 3s·2^{N - K + 1}`、`q = 2^v - 15` を掛けて `qa = s·2^N - 5` を代入すると `(2b - 15)s·2^N + (15·2^v - 150 - 10b) = 3qs·2^{N - K + 1}`。`K ≥ v ≥ 5 > 1` より `2^{N - K + 1} | (15·2^v - 150 - 10b)`。
     - `b = 9`：左辺 `= 15·16(2^{v-4} - 1)`（`v ≥ 5` より `v2 = 4`）。
     - `b = 3`：左辺 `= 4(15·2^{v-2} - 45)`（`v ≥ 5` より `v2 = 2`）。
     - 一方 `K ≤ v + 2(R - 1)` より `N - K + 1 ≥ (N - v + 1)/2 + 1 ≥ 10 > 4` なので完全に不可能。

**証明に一切の欠陥なし。**
