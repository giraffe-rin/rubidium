#### 1. 補題 4.0・定理 K4（開始局面の倍数型の特徴づけ）：**正しい（最後まで確認した）**
- **補題 4.0**：
  - (1) ⇔ (2)：系 1.1 により `n ≥ 1` で `(n, 0)` が P ⇔ `n` が A 行であり、`r = 0` は常に A 行なので厳密に同値。
  - (2) ⇔ (3)：`H(j)` により `a₀ = 0 < a₁ < …` は A 行を 1 つも飛ばさずすべて列挙するため、`a_j = j(m+1)`（全 `j`）⇔ `g_j = m+1`（全 `j`）が帰納法で直ちに従う。
- **（⇐）場合 1（`m` が偶数）**：`m ≥ 2` が偶数なら `v2(m+1) = 0`（偶数）かつ `H(j)(a)(c)` よりすべての `j` で `g_j = m+1`。補題 4.0 より (1) が成立。境界 `m = 2` でも成立。
- **（⇐）場合 2（`m` が奇数、`v2(m+1)` が偶数）**：
  - `m ≥ 3`、`v2(m+1) ≥ 2`、`s* = v2(h) = v2(m+1) − 1` は奇数かつ `s* ≥ 1`、`1 ≤ h ≤ m`（最小例 `m = 3` で `h = 2, s* = 1`）。
  - `j = 0`：定理 K3 と `H(0)(b)` より全 `1 ≤ d ≤ m` で `d ∈ S₀ ⇔ v2(d)` 偶数、よって (Q2) が成立。`v2(h) = s*` は奇数なので `h ∉ S₀`、`H(0)(c)` より `g₀ = m+1` で (Q1) も成立。

  - 内側帰納法 `s = 0, 1, …, s*`：
    - `s = 0`（`d` 奇数）：(i)(ii)(iii) いずれも偽より `d ∈ S_j`、`v2(d) = 0` 偶数と一致。
    - `1 ≤ s ≤ s*`（`d = 2x` 偶数、`1 ≤ x < d ≤ m`、`v2(x) = s − 1 < s`）：
      - (i)：内側帰納法の仮定より `x ∈ S_j ⇔ s − 1` 偶数。
