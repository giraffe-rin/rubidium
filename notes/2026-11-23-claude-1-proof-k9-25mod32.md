## 結果

### 定理 K9-25 `[非形式証明]`

m ≡ 25 (mod 32) なら、m は交互型。
つまり、すべての n ≥ 1 で (n, 0) が P ⇔ n ≡ 0 または m+2 (mod 2m+3)。

（m ≡ 25 (mod 32) なら v2(m+1) = 1 で、K9 の条件 v2(3h+1) が奇数も満たす。下の準備を参照。）

#### 準備

m = 8t + 1 とおく。m ≡ 25 (mod 32) ⇔ t ≡ 3 (mod 4)。t ≥ 3。
- h = 4t + 1（奇数）、m + 1 = 8t + 2、m + 2 = 8t + 3（奇数）。
- 3t + 1 ≡ 10 ≡ 2 (mod 4) なので v2(3t+1) = 1。よって 3h + 1 = 4(3t+1) から v2(3h+1) = 3 は奇数（K9 の条件を満たす）。

追跡する距離を次のように決める。
- x₁ := (3t+1)/2（奇数）
- x₂ := 3t + 1 = 2x₁（v2 = 1）
- e* := 6t + 2 = 2x₂（v2 = 2）
- h = 4t + 1（奇数）
- z := 7t + 2（t は奇数なので奇数）
- y := (15t + 5)/2（t ≡ 3 (mod 4) なので 15t + 5 ≡ 50 ≡ 2 (mod 4)、よって y は奇数の整数）

**範囲の確認**：すべて 1 以上 m = 8t + 1 以下。
- z ≤ m ⇔ 7t + 2 ≤ 8t + 1 ⇔ t ≥ 1。
- y ≤ m ⇔ 15t + 5 ≤ 16t + 2 ⇔ t ≥ 3。
- 残り（x₁, x₂, e*, h）は z 以下。

**(iii) の対象**：H(j)(d) の (iii) が効くのは d = h − 1 = 4t（偶数）だけ。追跡する距離のうち偶数は x₂, e* で、どちらも 4t と等しくない。
- 3t + 1 = 4t ⇔ t = 1
- 6t + 2 = 4t ⇔ t = −1

t ≥ 3 なので、どちらも起きない。

#### 主張 J(j)

- **j が偶数のとき**：
  - (E1) 1 ≤ d ≤ m のすべての奇数 d で d ∈ S_j
  - (E2) x₂ ∉ S_j
  - (E3) e* ∈ S_j
  - (E4) g_j = m+2
- **j が奇数のとき**：
  - (O1) h ∉ S_j
  - (O2) z ∉ S_j
  - (O3) g_j = m+1

J(j) を j についての強い帰納法で示す。帰納法の仮定は「J(0), …, J(j−1) が成り立つ」こと。

#### j = 0

定理 K3（d ∈ S₀ ⇔ v2(d) が偶数）より、次が成り立つ。
- (E1)：奇数 d は v2(d) = 0 なので入る。
- (E2)：v2(x₂) = 1 なので入らない。
- (E3)：v2(e*) = 2 なので入る。
- (E4)：h は奇数なので h ∈ S₀。H(0)(c) より g₀ = m+2。

#### j ≥ 2 が偶数

仮定 J(j−1) より g_{j−1} = m+1（偶数）。
- (iii)：効かない（g_{j−1} ≠ m+2）。
- (ii)：g_{j−1} + d が偶数 ⇔ d が偶数。そのとき e = (m+1+d)/2 = h + d/2。

各主張を示す。
- **(E1)**：奇数 d は (i)(ii)(iii) のどれも成り立たないので入る。
- **(E2)**：x₂ = 2x₁ で x₁ は奇数なので、(E1) より x₁ ∈ S_j。よって (i) が成り立ち、x₂ ∉ S_j。
- **(E3)**：d = e* = 2x₂ について調べる。
  - (i)：「x₂ ∈ S_j」は (E2) より成り立たない。
  - (ii)：e = h + x₂ = 4t + 1 + 3t + 1 = z ≤ m。仮定 J(j−1) の (O2) より z ∉ S_{j−1}。よって成り立たない。
  - (iii)：効かない。
  - よって e* ∈ S_j。
- **(E4)**：h は奇数なので (E1) より h ∈ S_j。H(j)(c) より g_j = m+2。

#### j ≥ 1 が奇数

仮定 J(j−1) より、次が成り立つ。
- g_{j−1} = m+2（奇数）
- S_{j−1} はすべての奇数を含む
- e* ∈ S_{j−1}

H(j)(d) の (ii) は、g_{j−1} + d が偶数 ⇔ d が奇数のときに考える。そのとき e = (8t + 3 + d)/2。

各主張を示す。
- **(O1)**：d = h（奇数）。
  - (i)：成り立たない。
  - (iii)：効かない（h ≠ h − 1）。
  - (ii)：e = (8t + 3 + 4t + 1)/2 = 6t + 2 = e* ≤ m で、e* ∈ S_{j−1}。よって成り立つ。
  - よって h ∉ S_j。
- **(O2)**：d = z（奇数）。
  - (i)：成り立たない。
  - (iii)：効かない（z は奇数、h − 1 は偶数）。
  - (ii)：e = (8t + 3 + 7t + 2)/2 = y ≤ m で、y は奇数なので y ∈ S_{j−1}。よって成り立つ。
  - よって z ∉ S_j。
- **(O3)**：(O1) と H(j)(c) より g_j = m+1。

#### 結論

帰納法により、すべての j で J(j) が成り立つ。よって g_j は m+2, m+1 の交互になる。
A 行の位置と開始局面の判定は、K6 の証明（`notes/2026-11-23-claude-1-proof-k6.md`）の「A 行の位置」と同じ計算で出る。
系 1.1 と合わせて主張が成り立つ。∎

### 計算機による証明書 `[非形式証明]`（計算機による。K3・K8 が前提）

`code/k9_certificate.js` の健全な伝播は、上の証明の形（偶数／奇数番目のブロックごとの事実の集合と、j についての帰納法）を、m ごとに自動で作るもの。
K9 の条件（v2(m+1) = 1 かつ v2(3h+1) が奇数）を満たす 5 ≤ m ≤ 1000 の 165 個すべてで、h ∈ E かつ h ∉ O が導けた（`data/k9_certificates.txt`）。

これにより、K9 の十分性は m ≤ 1000 のそれぞれで示されたことになる。前回の R の状態の繰り返しによる確認は m ≤ 400 までだった。
ただし、コードが正しいことが前提。特に次の点を査読してほしい。
- E の事実を K3 と一致するものに限っていること。
- 同じブロック内の依存が d/2 だけであること。

証明書の大きさ：
- m ≡ 5 (mod 8)（125 個）：3。中身は K6 の証明と同じ。
- m ≡ 25 (mod 32)（31 個）：7。上の定理 K9-25 と同じ形。
- 残りの 9 個（m ≡ 1 (mod 8) で v2(3t+1) ≥ 3 のもの）：もっと大きい。例：m = 105 で 15、m = 233 で 15。

表の各行の確認（m = 8t + 1、h = 4t + 1、v2(3h+1) = 2 + v2(3t+1)）：
- t ≡ 0, 2 (mod 4)（m ≡ 1, 17 (mod 32)）：3t + 1 は奇数で v2 = 0。v2(3h+1) = 2 は偶数なので、K9（⇒）により交互型でない。
- t ≡ 1 (mod 4)（m ≡ 9 (mod 32)）：3t + 1 ≡ 0 (mod 4) で v2(3t+1) ≥ 2。

したがって、K9 の十分性で一般の証明が残っているのは「m ≡ 9 (mod 32) かつ v2(3t+1) が 3 以上の奇数」の場合だけ。
m ≤ 1000 では、m = 105, 233 などの 9 個がこれに当たる（`data/k9_certificates.txt` で m mod 32 = 9 の行）。
