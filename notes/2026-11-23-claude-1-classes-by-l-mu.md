# 証明書の一覧の ℓ・μ による分類（観察 K25）

## やったこと

- K22 で型の始まりを決めた量で、K16 の証明書の一覧（v2(m+1) = 1, 3, 5, 7）の類を分けた。
  - 量は ℓ = v2(m + 2 − 3u) と、ℓ が偶数のときの μ = v2(c)（c = (m + 2 − E/2^ℓ)/3）。
  - 区分ごとに、証明できた類とできなかった類の密度を集計した（`code/classes_by_l_mu.js`、`data/classes_by_l_mu.txt`）。
- これは観察 K18（v2(m+1) = 1 で、s = v2(3h+1)、w による分類）を、すべての奇数の v に広げたものである。

**前提**：K16 の証明書の一覧（`notes/2026-11-23-claude-1-affine-deeper.md`、`[非形式証明]`、未査読）、定理 K22（`notes/2026-11-23-claude-1-proof-k22.md`）。

## 結果

### 観察 K25 `[予想]`（一覧から確かめた事実）

区分ごとの「証明できなかった割合」は次のとおり。v = 1 は A ≤ 2^18、ほかは A ≤ 2^17 の一覧。

| v2(m+1) | ℓ 奇数（密度 2/3） | ℓ 偶数・μ 奇数（2/9） | ℓ 偶数・μ 偶数（1/9） |
|---|---|---|---|
| 1 | 0 | 0.086 | 0.319 |
| 3 | 0.020 | 0.164 | 0.396 |
| 5 | 0.075 | 0.168 | 0.509 |
| 7 | 0.088 | 0.223 | 0.741 |

- どの v でも、証明できなかった割合は「ℓ 奇数」<「μ 奇数」<「μ 偶数」の順に大きい。
  - K22・K23 で型の始まりが短い式で決まる区分ほど、型全体も証明書で決まりやすい。
- v = 1 で「ℓ 奇数」の区分が 0 なのは、定理 K19（ℓ = v2(h−1) が奇数なら 1^{j+1}0 型）による。
- v = 3 で「ℓ 奇数」の区分に残る 0.013 は、ℓ = 1 の部分である。K20 は ℓ = v2(5u+1) ≥ 3 だけを扱っている。
  - 一覧の ℓ ≥ 3 の類はすべて証明できている（ℓ = 1 の類にだけ未証明が残る）。
- 「未定」（類の法で ℓ や μ が決まらない区分）は、法が大きい類だけで、密度は小さい。

区分の密度（2/3、2/9、1/9）は、集計の合計とも合っている。v = 1 では 0.6667、0.2221、0.1111。

## 確かめたこと

- 各区分の密度の合計は 1 になった（v = 1 で 0.945358 + 0.054642）。
- v = 3 の「ℓ 奇数」の区分を ℓ の値ごとに分けて集計した（`code/classes_by_l_mu.js` と同じ判定を ℓ ごとに出した。出力は保存していない）。
  - ℓ = 1：証明できた 0.486572、できなかった 0.013428
  - ℓ = 3, 5, …, 13：すべて証明できている（密度 0.125、0.03125、…）

## うまくいかなかったこと

- 「μ 偶数」の区分は、v が大きいほど証明できない割合が大きい（v = 7 で 74%）。
  - K23 の再帰が深くなる区分なので、型の続きもより深い 2 進の条件で決まるためと思われる。
  - ただし、型の続きを決める式は見つかっていない。
