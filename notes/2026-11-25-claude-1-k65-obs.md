# v2(m+1) = 1、k ≥ 2、Q 偶数のときの型（予想 K65 と観察）

## 背景

v2(m+1) = 1 では、Lean で次が示されている。
- k = 1（v2(3h+1) = 2）：Q が奇数なら 110 型（K12 (a)）。X の鎖が v2 = 1 を j 回たどって奇数で止まれば 1^{j+2} 0 型（K64、PR #449）。
- k ≥ 2：Q が奇数なら 1(10)^k 型（K15、PR #443）。

残りのうち、k ≥ 2 で Q が偶数の場合を調べた。

## やったこと

`code/k65_obs.js`：3h+1 = 4^k·w とする。X₀ = Q、X_{t+1} = (m+2+X_t/2)/2 を v2(X_t) = 1 の間たどり、X_j が奇数で止まる m（j ≥ 1）について、漸化式 R で型を求めた（m ≤ 60000）。

## 結果（`data/k65_obs.txt`）

ほとんどの型は 1^{j+1}(10)^r（1 ≤ r ≤ k）の形だった。r は (k, j, X_j mod 8) で決まることが多い。

- **k = 2、j = 1**：
  - X₁ ≡ 1, 5 (mod 8) なら r = 1（1110 型）。59 個すべて。
  - X₁ ≡ 3 (mod 8) なら r = 2（111010 型）。29 個すべて。
  - X₁ ≡ 7 (mod 8) は混在。r = 1 が 21 個、r = 2 が 2 個、ほかの型が 7 個。
- **k = 2、j = 2**：X₂ mod 8 によらず r = 1（11110 型）。29 個すべて。
- **k ≥ 3、j = 1、X₁ ≡ 3 (mod 8)**：
  - k = 4, 5, 6, 7, 8 では r = k − 1（それぞれ 2 個、1 個、1 個、1 個、1 個）。
  - k = 3 では、r = 2 が 6 個、r = 3 が 2 個。
- ほかの組み合わせは、ほとんどが混在。

### 予想 K65 `[予想]`（claims/K65.yaml）

v2(m+1) = 1、k = 2（3h+1 = 16w）、X の鎖が v2 = 1 を j 回（j ≥ 1）たどって奇数 X_j で止まるとき、型は前周期なしで次のとおり。
- (a) j = 1、X₁ ≡ 1, 5 (mod 8)：1110
- (b) j = 1、X₁ ≡ 3 (mod 8)：111010
- (c) j = 2：11110

m ≤ 60000 で反例なし（漸化式 R による）。

## 見通し

- (a)(c) は K64 と同じ「1^{j+2} 0」の形（j を数え直すと、K64 の型 1^{j+2} 0 で間隔が 1 つ短い）。K64 の証明（O 型の連続での X の鎖）に、k = 2 での E 型のブロックの事実（K15 の Inh）を合わせれば示せる見込み。
- (b) と k ≥ 3 の r = k − 1 は、K15 の Inh の鎖が途中で X に入れ替わる形に見える。
- X₁ ≡ 7 (mod 8) の混在は、さらに深い量で決まると思われる。
