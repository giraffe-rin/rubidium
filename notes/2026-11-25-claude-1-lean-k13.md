# 定理 K13（100 型）の Lean 4 での形式化

## やったこと

`lean/Rubidium/K13.lean` に、定理 K13 を sorry なしで証明した（公理は `[propext, Quot.sound]`）。

```lean
theorem K13 (m : Nat) (hm : m % 8 = 7)
    (hc : (v2 (9u+1) = 1 ∧ v2 (11u+1) = 3) ∨ (v2 (9u+1) = 3 ∧ v2 (11u+1) = 1)) (n : Nat) :   -- u = (m+1)/8
    IsP m n 0 ↔ (n % (3m+4) = 0 ∨ n % (3m+4) = m+2 ∨ n % (3m+4) = 2m+3)
```

## 証明の組み立て

記号：h = 4u、X₁ = (9u+1)/2、X₃ = (11u+1)/2。仮定より、一方は奇数、他方は Y = 4y（y は奇数）。
L = 3m+4、a = iL、b = a + (m+2)、c = b + (m+1) とする。

もとの証明（ノート 2026-11-23-claude-1-proof-k13.md）の主張 Λ(j) の事実を、ブロックの理論 H(j) を使わずに局面の言葉で示した。

新しい汎用の補題は次の 3 つ。
- `not_isP_move`：手 k で P 局面に移れれば N。
- `p_four`：行 a がすべての p で P で、奇数 d の (a + d, d) が P とする。さらに、1 つ前の行 c がすべての p で P で、(c + h + 2z, h + 2z) が N とする。このとき、z が奇数なら (a + 4z, 4z) は P。
  - 手 2z の行き先は、手 z で P に移れるので N。
  - 手 h + 2z の行き先は、仮定より N。
  - ほかの手の行き先は、`not_isP_of_row` より N。
- `p_two`：(b + z, z) が N なら、(b + 2z, 2z) は P。
  - 手 2z + 1 の行き先 (a + m + 1, 2z+1) は `not_isP_near` より N。
  - ほかの手の行き先は、m + 2 + 2z が奇数なので `not_isP_of_row` より N。

**`k13_step`**（1 周期分）は、次の順で示す。
1. 行 b：`row_long` で、すべての p で P。
2. (b + u, u) は N（手 X₁）。(b + 3u, 3u) は N（手 X₃）。行き先 (a + X₁, X₁)・(a + X₃, X₃) は、奇数か Y なので P。
3. (b + 2u, 2u)・(b + 6u, 6u) は P（`p_two`）。(b + h, h) は N（手 2u）。
4. 行 c：`row_next` で、すべての p で P。奇数 d は P（`odd_of_rows`）。
5. (c + 6u, 6u) は N（手 3u）。(c + h + 2y, h + 2y) は N（手 2u + y、奇数）。(c + h, h) は N（手 6u で (b + 6u, 6u) に移れる）。
6. 行 a + L：`row_next` で、すべての p で P。奇数 d は P。Y と h は `p_four` で P。それぞれ z = y、z = u で、h + 2u = 6u。

**`k13_rows`**：i についての帰納法。
**K13**：v2 の仮定を剰余の形に直す（補題 `mod4_of_v2_one`、`mod16_of_v2_three`）。そのうえで、n mod L で場合分けする。

## 意味

- 定理 K13 が [Lean検証済み] の候補になった（査読待ち）。これで Lean にあるのは K3・K4・K5・K6・K9・K10 (a)・K13。
- もとの証明で必要だった「(iii) の対象を避ける」議論（u ≥ 3 など）は、直接の局面の議論では要らなかった。手を 1 つ示すだけで N が言えるから。
- `p_four`・`p_two` は、ほかの有限個の事実を追う型の証明（K12 など）にも使える見込み。
