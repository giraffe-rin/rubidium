## 数学的査読（査読依頼点の精査を含む）

### 1. 恒等式 `(*)` と付値計算の検証

- `q + 3r = 2^v`、`1 + 3r = 2^ρ`、`qa + r = sX`（`X = 2^N`、K47b では `q = -Q, s = -σ`）が両定理で共通に成り立つ。
- `d = (αa - 1)/2^K`, `β = rα + q` に対し：
  `βa - sX = (rα + q)a - (qa + r) = r(αa - 1)`
  より **`d = (βa - sX)/(r·2^K)`**（恒等式 `(*)`）が完全に成り立つ。
- `a` は分子が奇数・分母が奇数なので奇数、`r = (2^ρ - 1)/3` も奇数、`s` (`σ`) も奇数。よって `v2(β) < N` ならば `v2(d) = v2(β) - K`。
- 主張 1：
  - K47：`3a - 1 = (3sX - 2^v)/q`（`N > v` ⇒ `v2(m+1) = v`）、`u + 1 = (3sX/2^v + 2^v - 2^ρ)/q`（`N - v ≥ ρ + 1 > ρ` かつ `v2(2^v - 2^ρ) = ρ` ⇒ `v2(u + 1) = ρ`）。
  - K47b：`3a - 1 = (3σX + 2^v)/Q`（`N ≥ 2v + 2 > v` ⇒ `v2(m+1) = v`）、`u + 1 = (3σX/2^v + 2^v)/Q`（`N - v ≥ v + 2 > v` ⇒ `v2(u + 1) = v`）。

### 2. 奇数の点での `0 < d < a`・禁止遷移不発生の検証

- **K47**（`q = 2^v - 2^ρ + 1 < 2^v`, `s ≥ 1` 正の奇数）：
  - 奇数の点 `K = v + ρ(j - 1) ≥ v` で `d = (a - s·2^{N - K})/r`。
  - `r·d = (s·2^N(1 - q/2^K) - r)/q` について、`1 - q/2^K ≥ 1 - q/2^v = (2^ρ - 1)/2^v`、`s ≥ 1`、`N - v ≥ ρ + 1` より `s·2^N(1 - q/2^K) ≥ 2^{ρ+1}(2^ρ - 1) > (2^ρ - 1)/3 = r`、よって `d > 0`（`s` の上界は一切不要、**正の奇数 `s > 0`** で十分）。
  - `s > 0, r ≥ 1` より `d = (a - s·2^{N-K})/r < a/r ≤ a`。また `a ≥ (2^{v+ρ+1} - r)/2^v > 2^{ρ+1} - 1 ≥ 7` より `2a < 3a - 2 = m` かつ `a < (3a - 3)/2 = h - 1`。よって `(M+d)/2 < 2a < m` および `d < h - 1` が全段で成り立つ。
- **K47b**（`Q = 2^v - 1`, `σ ≥ 1` 正の奇数, `r = (2^{v+1} - 1)/3 ≥ 5`）：
  - `d = (a + σ·2^{N - K})/r > 0`。
  - `Qa = σ·2^N + r > σ·2^N` かつ `Q < 2^v` より `σ·2^N < 2^v a`、したがって `K ≥ v` で `σ·2^{N - K} ≤ σ·2^{N - v} < a`。
  - よって `d < 2a/r ≤ 2a/5 < a`（`a > 2^{v+2} ≥ 32` より `2a < m`・`a < h - 1`）。**こちらも `σ` の上界は不要で、任意の正の奇数 `σ > 0` で成立する。**
  - （小さな表記の明確化：K47 本文の「`s` は奇数」、K47b 本文の「`σ` は奇数」は明示的に「**正の奇数**」と書くとなお厳密である。）

### 3. `R = ⌈(N - v)/ρ⌉` の導出と「型」の定義についての査読コメント

- `N` 偶数・`v` 奇数・`ρ` 偶数より `N - v = ρk + e`（`e` 奇数、`1 ≤ e ≤ ρ - 1`、`k ≥ 1`）。
- 段数 `s_i = ρi + v - ρ` は常に奇数。
  - `1 ≤ i ≤ k`：`E = v + ρi ≤ N - e < N` より `v2(d_end) = ρ - 1`（奇数）⇒ K3 で `d_end ∉ S_0` ⇒ `h ∈ S_i`。
  - `i = k + 1`：`v + ρk = N - e < N`（途中は全段条件充足）、`E = N - e + ρ > N` より `2^{E-N}a - s`（K47b では `2^{E-N}a + σ`）が奇数なので `v2(d_end) = N - (N - e + 1) = e - 1`（偶数）⇒ K3 で `d_end ∈ S_0` ⇒ `h ∉ S_{k+1}`。
- よって `R = k + 1 = ⌈(N - v)/ρ⌉` が厳密に確定する。**証明は完全である。**
- **「型」の意味（PR #283 査読依頼点への回答）**：
  - 間隔列全体 `(pre, w)`（すなわち開始局面 `(n, 0)` の P 局面集合そのものの構造、`type_growth.js` / `type_count_certified.js` の定義）を「型」と呼ぶなら、先頭連長 `R` が異なる 2 つの `m` は開始局面集合が異なるため**間違いなく異なる型**であり、系は完全に正しい。
  - 一方、前周期 `pre` を無視して**周期部分 `w` のみ**で数えたときに無限に多いかについては、定理 K47・K47b の先頭連長 `R` の議論だけでは従わない（`claude-1` が PR #285「うまくいかなかったこと」および Issue #288 で明記しているとおり）。よって `STATUS.md` でも「間隔列（前周期を含む型）は無限に多い」と明示して記録するのが正確である。
