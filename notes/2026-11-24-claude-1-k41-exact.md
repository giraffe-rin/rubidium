- ブロック 1 の値を K3 から求めて、各ブロックの値を巡回上の段数の和の偶奇で書き、λ の正確な式を出した。

- 最初は段数 k_i そのものの列の周期を使っていた。そのため、m = 132 で式が λ と合わなかった。正しくは k_i の偶奇の列の周期である（下の証明）。照合は修正後の式で行った。

**前提**：主張 H(j)、定理 K3（査読済み）。定理 K41 の記号と (1)（ψ が置換であること）。

## 結果

### 定理 K41c `[非形式証明]`

m ≥ 2 を偶数、n = m + 1 とする。ψ の各巡回 C = (x_1, …, x_ℓ)（x_{i+1} = ψ(x_i)、添字は ℓ を法とする）について、次のように定める。
- k_i ≥ 1：x_i = 2^{k_i} ψ(x_i) − n となる数（定理 K41 の証明の k）
- π_C：巡回列 (k_i mod 2) の最小周期（π_C は ℓ の約数）
- σ_C：k_1 + … + k_{π_C} の偶奇

このとき、R の状態の最小の周期は λ = lcm_C λ_C。ここで λ_C は、σ_C が偶数なら π_C、奇数なら 2π_C。

### 証明

**値の式**：定理 K41 の証明より、j ≥ 1 で [x_i ∈ S_j] = (−1)^{k_i} [x_{i+1} ∈ S_{j−1}]。
- これを j 回くり返すと、[x_i ∈ S_j] = (−1)^{k_i + k_{i+1} + … + k_{i+j−1}} [x_{i+j} ∈ S_0]。
- x_{i+j} は奇数なので、K3 により x_{i+j} ∈ S_0。
- よって、x_i ∈ S_j ⇔ c_i(j) := k_i + … + k_{i+j−1} が偶数。

**状態と奇数の値**：
- 偶数の d の値は、同じブロックの奇数部分の値から決まる。
- g_j = m + 1 は一定。
- よって、ブロック j の状態は、奇数の d の値の組 (c_i(j) mod 2) で決まり、逆も成り立つ。

**周期の条件**：p ≥ 1 について、すべての j ≥ 1 で状態 j と状態 j + p が等しい ⇔ すべての巡回 C、すべての i、すべての j ≥ 1 で c_i(j + p) ≡ c_i(j)。
- これは、すべての i、j について k_{i+j} + … + k_{i+j+p−1} ≡ 0、つまり「巡回列 (k_i) の長さ p の窓の和が、すべて偶数」と同値。
- 隣り合う窓の和の差は k_{i+p} − k_i である。よって、これは次の 2 つと同値。
  - (a) k_{i+p} ≡ k_i (mod 2)（すべての i）
  - (b) ある 1 つの窓の和が偶数
- (a) は「p が π_C の倍数」と同値。このとき、窓の和は (p/π_C)·σ_C と偶奇が等しいので、(b) は「p/π_C が偶数、または σ_C が偶数」と同値。
- よって、C についての条件を満たす最小の p は λ_C で、条件を満たす p は λ_C の倍数全体。
- すべての C で同時に満たす最小の p は lcm_C λ_C。∎

### 補足

- 定理 K41 の P は、π_C を ℓ に、σ_C を k の和全体 o の偶奇に置き換えたもの。π_C = ℓ のとき λ_C は P の対応する値と一致する。
- m = 132 では、ある巡回で (k_i mod 2) の周期が ℓ より短いために λ = 5544 < P = 27720 になる。
