# 定理 K9 全体の Lean 4 での形式化

## やったこと

`lean/Rubidium/K9.lean` に次の 2 つを加えた。どちらも sorry なしで、公理は `[propext, Quot.sound]`。

```lean
theorem K9_nec (m) (hm4 : m % 4 = 1) (hm5 : 5 ≤ m) (heven : v2 (3h+1) % 2 = 0) : ¬ IsP m (2m+3) 0
theorem K9 (m) (hm4 : m % 4 = 1) (hm5 : 5 ≤ m) :
  (∀ n, IsP m n 0 ↔ (n % (2m+3) = 0 ∨ n % (2m+3) = m+2)) ↔ v2 (3h+1) % 2 = 1
```

（h = (m+1)/2 を Lean では (m+1)/2 と書いている。）

## 必要性の証明（直接の局面の議論）

b = m+2、e* = (3h+1)/2 とおく。v2(3h+1) が偶数なら、v2(e*) は奇数。

- 行 b はすべての p で P。`row_long` を a = 0 に使う。(h, h) は K3 より P（h は奇数）。
- (b + h, h) は P。どの手 k ≠ h の行き先も N であることを、次の 3 つの場合に分けて示す。
  - k < h：行き先は (b + (h−k), k)。h は奇数なので k ≠ h − k。`not_isP_of_row` より N。
  - k = h+1：行き先は (m+1, h+1)。手 h で (h, h) に移れて、そこは P。よって N。
  - k ≥ h+2：行き先 (m+2+h−k, k) は 1 ≤ r ≤ m なので、K3 の範囲にある。P になるのは k = m+2+h−k、つまり k = e* で、かつ v2(e*) が偶数のときだけ。v2(e*) は奇数なので N。
- (2m+3, 0) から手 h で (2m+3−h, h) = (b + h, h) に移れる。よって (2m+3, 0) は N。
  一方、交互型なら 2m+3 ≡ 0 なので P のはず。よって交互型ではない。

もとの証明（ノート 2026-11-23-claude-1-conjecture-k9.md）は、ブロックの規則 H(1) を使っていた。ここでは K3 と `row_long` だけで足りた。

## 意味

- **定理 K9 全体**が [Lean検証済み] の候補になった（PR #393 の十分性と合わせて）。v2(m+1) = 1 の m について、交互型になる条件が、v2(3h+1) が奇数であることと同値だと確かめられた。
- これで Lean にあるのは K3・K4（全体）・K5・K6・K9（全体）。どれも H(j)（K8）を使わない。
