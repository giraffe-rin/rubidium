## 命題 K57

族 q·a + r = s·2^N（q, r, s は奇数、a > 0 は奇数）、m = 3a − 2、M = 3a、h = (3a−1)/2 とし、β₀ = 3r + q、v = v2(β₀)、b₀ = β₀/2^v とする。T(b) = (b + 3r)/2^{t(b)}、t(b) = v2(b + 3r) とし、b_1 = b₀、b_{j+1} = T(b_j) とおく。K_1 = v、K_{j+1} = K_j + t(b_j) とする。

- **ブロック 0**：v − 1 が偶数なら g_0 = m+2、奇数なら g_0 = m+1（K3）。
- **ブロック i ≥ 1**：g_0..g_{i−1} = m+2 で、K_i + t(b_i) < N なら、次が成り立つ。
  - h ∈ S_i ⇔ [t(b_i) − 1 が偶数] ≠ [s_i が奇数]。
  - ここで s_i = (v − 1) + i + Σ_{j<i}(t(b_j) − 1)。
  - ただし、鎖の各奇数の点で (M+d)/2 ≤ m、d ≠ h − 1、d > 0 が成り立つときに限る。

**証明**（`[非形式証明]`、上の条件のもとで）：定理 K47 の証明と同じ。

- 鎖の距離を d = (αa − c)/2^K、β = rα + qc と書くと、r(αa − c) = βa − cs·2^N が成り立つ。よって v2(β) < N なら v2(d) = v2(β) − K。
- 奇数の段では β → β + 3r·2^K となるので、奇数の点の b は T で動く。
- 終点（ブロック 0）の v2 は t(b_i) − 1 で、K3 により「入る ⇔ 偶数」。段数 s_i の偶奇だけ反転する。∎

**意味**：間隔の列の先頭は、b の軌道 b₀, T(b₀), … と t(b_j) の列だけで決まる。N にも s にもよらない（v2(β) が N に届くまで）。

- 定理 K47 は、b₀ = 1 で t(1) = ρ が偶数の場合にあたる。このとき t − 1 は奇数（終点で入らない）で、s_i も奇数なので、いつも入る。
- 予想 K45 の族（q = 29、r = 4641、s = 1）では、v = 7、b₀ = 109 で、閉路は {109, 877, 925, 29}、t = 4, 4, 9, 7。
  - i = 1, 2, 3 では h ∈ S_i、i = 4 で h ∉ S_4 となり、先頭の連は N によらず 3（1^3 0）。
  - K45 の長い連（およそ N/6）は先頭ではなく、周期の途中にある。閉路の t の平均 24/4 = 6 は、この長さ N/6 と一致する。途中の連については、補題 K48 のような議論（周期の途中のブロックからの鎖）が必要である。
