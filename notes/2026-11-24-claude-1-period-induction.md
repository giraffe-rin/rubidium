# 周期についての帰納法による型の確定

## やったこと

- K36d（K 偶数）と K40（N 偶数）で、帰納法が閉じることを計算で確かめた（`notes/2026-11-24-claude-1-k36d-even.md`、`…-k40-induction.md`）。その方法を一般化して `code/period_induction.js` を作った。仮定の集合は自動で求める。
- 入力は m と、予想される型の周期の列 w（ブロック 0 から純周期的で、末尾が 0）。手順は次のとおり。
  1. 周期の始まり B の事実として、次を仮定する。
     - (G) 奇数の距離は入る。v2(d) ≤ min(2s − 1, v − 1) の距離は「v2 が偶数 ⇔ 入る」。s は w の末尾の 0 の個数。ブロック 0 では K3、E 型の始まりでは補題 Q_s による。
     - (A) 有限個の距離とその値。初めは空。
  2. 1 周期分（B+1〜B+L）を R で遅延評価する。各ブロックの間隔は w で与える。
  3. B で (G)(A) から決まらない事実が出たら、その距離をブロック 0（K3）での値とともに (A) に加え、やり直す。
  4. 最後に、次の 2 つを確かめる。
     - (1) 各ブロックで h が入るかが w と一致する。
     - (2) (A) の各距離の値が、次の始まり B + L で再現される。
- 健全性：
  - ブロック 0 は (G)(A) を満たす。(A) の値は K3 の値として選んでいる。
  - B が (G)(A) を満たせば、1 周期の計算は上のとおりで、B + L も (G)(A) を満たす。
    - (G) は、直前に m+1 の間隔が s 個続くので Q_s から成り立つ。
    - (A) は (2) で確かめている。
  - よって、帰納法により間隔の列は w のくり返しになり、型が確定する。
- 健全性の確認（`code/check_period_induction.js`、`data/check_period_induction.txt`）：
  - (1) 誤った w（K33 の族で、最初の 1 の連を 1 つ短くしたもの）では、8 個中 0 個しか「確定」と出なかった。
  - (2) 奇数 m ≤ 3000 で、200 ブロックから求めた周期の列 w を与えると 1449 個が「確定」した。そのすべてで、200 ブロックの直接の計算と一致した。

**前提**：主張 H(j)、定理 K3、補題 Q_n（いずれも査読済み）。

## 結果

### 型の確定 `[非形式証明]`（計算機による、下の各 m について）

| 族 | 範囲 | 確定した個数 | 周期の列 w |
|---|---|---|---|
| 予想 K33（e 奇数）：m = 9·2^e + 1 | e = 7, 9, …, 199 | 97（すべて） | 1^{e−1} 0 1^{(e−1)/2} 0 |
| 予想 K34：m = 8(36·16^k − 1)/5 − 1 | k = 4, …, 30 | 27（すべて） | 1^{4k+2} 0 (1^{2k+1} 0 0)^2 |
| a = (2^N − 1)/23、m = 3a − 2（N 奇数） | N = 33, 55, …, 429 | 19（すべて） | 1^{(N−3)/2} 0 |

（`data/period_induction_k33odd.txt`、`…_k34.txt`、`…_k40odd.txt`。m は最大 129 桁。）

- 仮定の集合 (A) の大きさは族ごとに異なる。
  - K33：e − 1 個
  - K34：2 個
  - K40（N 奇数）：N に比例
- これで、予想 K33（e 奇数）、K34 は、それぞれ上の範囲のすべての m で型が確定した。
- a = (2^N − 1)/23 の族は、予想 K40 の N 偶数の場合（前回、N ≤ 440）に加えて、N 奇数でも型 1^{(N−3)/2} 0 が確定した（N ≤ 429）。
