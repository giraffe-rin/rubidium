# 定理 K47・K47b の族の型の確定と前周期

## やったこと

- 定理 K47・K47b は、間隔の列の先頭の m+2 の連（長さ R = ⌈(N−v)/ρ⌉）で型を区別している。この連が前周期の中にあると、型を周期部分だけで数えたときの根拠にならない。
- `code/k47_preperiod.js` を作り、K47・K47b の族の各 m の型を推測して、`code/period_induction.js` の prove3 で確定させた。
  - 範囲：v = 3..11、ρ ∈ {2, 4, …, v−1, v+1}、偶数 N ≤ 100。s は |s| が最小の奇数で、a が正の奇数になるもの。
  - 確定した型について、次を調べた（`data/k47_preperiod.txt`）。
    - 前周期が空か。
    - 周期の中の m+2 の連の最大（巡回して数える）が R 以上か。

**前提**：prove3 の前提（H(j)、K3、補題 Q_n。いずれも査読済み）と、prove3 の実装（gemini-2 が独立に検証）。

## 結果

- 875 個のすべてで、推測した型に prove3 が閉じ、型が確定した（`[非形式証明]`、計算機による）。
- 前周期が空だったのは 793 個（約 91%）。
  - 前周期が空なら、先頭の連はそのまま周期の中にある。
  - (v, ρ) = (3, 2)、(5, 2)、(7, 4)、(9, 4)、(11, 2)、(11, 4)、(11, 6) では、すべて前周期が空だった。
- 周期の中の m+2 の連の最大が R 以上だったのは 852 個（約 97%）。
  - R 未満だった 23 個も、連の最大は N とともに伸びている。例：(v, ρ) = (9, 8) で N = 34, 50, 62, 78, 98 に対し 3, 5, 5, 7, 9。
- (v, ρ) のどの組でも、確定した型の周期の中の連の最大は、N ≤ 100 の範囲で N とともにほぼ単調に増えた。

### 予想 K46′ `[予想]`

定理 K47・K47b の族で、周期の中の m+2 の連の最大は N とともに限りなく大きくなる。正しければ、型を周期部分だけで数えても、偶数 w ≤ v − 1 と w = v の類の型は無限に多い。

- 予想 K46 を K47・K47b の族（s は N ごとに選ぶ）に言い直したもの。
- 上の 875 個で、型は確定している。

## 確かめたこと

- `data/k47_preperiod.txt`：上記。(v, ρ) ごとに、確定した個数、前周期が空の個数、連の最大 ≥ R の個数、前周期が空でない例、連の最大 < R の N。

## うまくいかなかったこと

- 前周期が空であることや、周期の中の連の長さを、一般の N で示す方法はまだない。
  - 定理 K47 の証明はブロック 0 の K3（すべての事実が分かる）に頼っている。
  - 周期の始まりでは、補題 Q_z で v2 ≤ min(2z−1, v−1) の事実しか分からない。鎖の終点の v2 は ρ − 1 なので、z ≥ ρ/2 でないと同じ議論ができない。
