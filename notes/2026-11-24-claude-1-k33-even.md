## 結果

### 定理 K33a `[非形式証明]`

e ≥ 2 が偶数で m = 9·2^e + 1 なら、型は前周期なし、周期 1^{e/2} 0（L = e/2 + 1）。
- 例：e = 2 で 10、e = 4 で 110、e = 6 で 1110。
- v2(m+1) = 1 である。

### 系 K33b `[非形式証明]`

v2(m+1) = 1 の m の型は無限に多い。m+2 の間隔の連の長さに上限はない。
- 理由：e/2 が違えば周期の長さが違うので、型が違う。
- これで、予想 K31 の前半（v2(m+1) が奇数の m の型は無限に多い）が、v2(m+1) = 1 の場合に示せた。

### 証明

**記号**
- M := m + 2 = 9·2^e + 3
- h := (m+1)/2 = 9·2^{e−1} + 1（奇数）
- o* := M/3 = 3·2^e + 1（奇数）
- K := (e − 2)/2
- 奇数の距離：o_i := o* + 3·2^{e−1−2i}（0 ≤ i ≤ K）
  - o_0 = h である。
  - e − 1 − 2i ≥ 1 なので、o_i は奇数。
- 距離：x_i := 2o* + 3·2^{e−2i}（1 ≤ i ≤ K+1）
  - 1 ≤ i ≤ K では、x_i = 2(o* + 3·2^{e−2i−1})、e − 2i − 1 ≥ 1 なので、v2(x_i) = 1。
  - i = K + 1 では、x_{K+1} = 2o* + 3 で奇数。
- 関係：x_{i+1} = (M + o_i)/2（0 ≤ i ≤ K）。1 ≤ i ≤ K では、x_i / 2 = o_i。
- 大きさ：
  - x_i ≤ 2o* + 3·2^{e−2} < 9·2^e < m なので、どの距離も 1 以上 m 以下。
  - x_i > 6·2^e > h − 1 = 9·2^{e−1} なので、どの x_i も h − 1 と違う。

**O 型ブロックの 2 つの規則**：ブロック j ≥ 1 の 1 つ前の間隔が m+2 のとき。
- (O1) 奇数の d：(i) は起きない。(iii) は d = h − 1（偶数）のときだけなので起きない。M + d は偶数なので、d ∈ S_j ⇔ (M + d)/2 ∉ S_{j−1}（(M+d)/2 ≤ m のとき）。
  - 特に、0 ≤ i ≤ K で [o_i ∈ S_j] = ¬[x_{i+1} ∈ S_{j−1}]。
- (O2) 偶数の d ≠ h − 1：M + d は奇数なので (ii) は起きない。よって d ∈ S_j ⇔ d/2 ∉ S_j。
  - 特に、1 ≤ i ≤ K で [x_i ∈ S_j] = ¬[o_i ∈ S_j]。

**「始まりのブロック」の性質 (Z)**：ブロック B で、1 ≤ i ≤ K で x_i ∉ S_B、かつ x_{K+1} ∈ S_B。
- ブロック 0 は (Z) を満たす。K3 により d ∈ S_0 ⇔ v2(d) が偶数。v2(x_i) = 1（i ≤ K）、v2(x_{K+1}) = 0 なので。
- E 型ブロック（1 つ前の間隔が m+1）も (Z) を満たす。
  - 奇数の d はすべて入るので、x_{K+1} ∈ S。
  - 1 ≤ i ≤ K では、x_i / 2 = o_i は奇数なので S に入り、(i) により x_i ∉ S。

**主張**：ブロック B が (Z) を満たし、その間隔が m+2 なら、ブロック B+1, …, B+e/2 の間隔は、B+1〜B+e/2−1 で m+2、B+e/2 で m+1。

証明：ブロック B+1, …, B+n が O 型のとき（つまり g_B, …, g_{B+n−1} = m+2 のとき）、1 ≤ n ≤ K+1 と 0 ≤ i ≤ K+1−n について
[o_i ∈ S_{B+n}] = ¬[x_{i+n} ∈ S_B]
を n についての帰納法で示す。
- n = 1：(O1) そのもの。
- n ≥ 2：
  - (O1) により [o_i ∈ S_{B+n}] = ¬[x_{i+1} ∈ S_{B+n−1}]。
  - ブロック B+n−1 は O 型で、1 ≤ i+1 ≤ K なので、(O2) により ¬[o_{i+1} ∈ S_{B+n−1}]。
  - 帰納法の仮定（n − 1、i + 1）により ¬[x_{i+n} ∈ S_B]。

i = 0 とすると、h = o_0 なので [h ∈ S_{B+n}] = ¬[x_n ∈ S_B]。(Z) により：
- 1 ≤ n ≤ K のとき：x_n ∉ S_B なので h ∈ S_{B+n}、H(j)(c) により g_{B+n} = m+2。これで、次のブロックも O 型であることが順に保証される。
- n = K+1 = e/2 のとき：x_{K+1} ∈ S_B なので h ∉ S_{B+e/2}、g_{B+e/2} = m+1。∎

**定理の証明**：
- ブロック 0：h は奇数で v2(h) = 0 なので、h ∈ S_0、g_0 = m+2。(Z) も満たす。
- 主張により、g_1, …, g_{e/2−1} = m+2、g_{e/2} = m+1。
- ブロック e/2 + 1 は E 型なので、h（奇数）が入り、g_{e/2+1} = m+2。(Z) も満たす。
- 主張をブロック B = e/2 + 1 に当てはめ、これをくり返すと、間隔の列は (1^{e/2} 0) のくり返しになる（周期 P = e/2 + 1、ブロック qP が始まりのブロック）。∎

### 補足

- 主張の証明で使った (Z) 以外の事実は、O 型ブロックの規則 (O1)(O2) だけである。ブロック 0（K3）と E 型ブロックで (Z) が同じになることが、前周期がない理由である。
- e が奇数の場合（予想 K33 の後半、周期 1^{e−1} 0 1^{(e−1)/2} 0）では、x_{K+1} にあたる距離の付値の偶奇が逆になる。始まりのブロックの性質が (Z) と違ってくるので、もう 1 段の場合分けが要ると考える（未完）。
