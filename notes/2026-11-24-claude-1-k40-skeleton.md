# 予想 K40（q = 23、N 偶数）の証明の骨格

## やったこと

- `notes/2026-11-24-claude-1-k40-closure.md` で残った 2 つの事実の鎖を、O 型ブロックの一本道の規則でたどった（`code/k40_skeleton.js`、`data/k40_skeleton.txt`、N = 22〜440 の 20 個）。
  - (1) E 型の始まりで d₁ = (9a − 1)/4 が入らないこと
  - (2) N/2 が偶数のとき、E 型の始まりで v2 = 4 の距離 X が入ること

**前提**：ブロック漸化式 R（主張 H(j)、定理 K3）。O 型ブロックの規則 (O1)(O2)（定理 K33a のログ）。E 型ブロックの規則（偶数の d：[d ∈ S_E] = ¬[d/2 ∈ S_E] ∧ ¬[h + d/2 ∈ S_{E−1}]、奇数の d は入る）。

## 結果

### 鎖の段数と終わり（`[予想]`：N ≤ 440 で確認）

最後の O 型ブロック P − 1 から周期の始まり B までの一本道の鎖：

| 鎖の始め | 段数 | B での終わり |
|---|---|---|
| g = (21a − 5)/8 | N | X（v2 = 4） |
| f = (33a − 9)/16 | N/2 | 奇数 |
| h + X/8 | N/2 | 奇数 |
| h + X/4 | N | 奇数 |
| h + X/2 | N/2 + 1 | 奇数 |

- 途中で h − 1 になる段や、(M + d)/2 > m になる段はなかった。
- O 型ブロックの 1 段ごとに値が反転する。よって、P − 1 での値は「段数が偶数なら終わりの値、奇数ならその否定」。

### 骨格

周期の始まり B（ブロック 0 または E 型の始まり）について、次の帰納法の仮定をおく。
- 奇数の距離は入る。v2 = 1 の距離は入らない（K3、E 型ブロックの規則で自動的）。
- d₁ ∉ S_B。
- N/2 が偶数なら X ∈ S_B。

ブロック 0 では K3 で成り立つ。v2(d₁) = 3、v2(X) = 4。

次の周期の始まり E（E 型ブロック）で同じことが成り立つことを示す。
- **N/2 が奇数**：
  - f の鎖（N/2 段、奇数段）から f ∉ S_{P−1}。
  - E 型の規則で、d₁/2 ∈ S_E。d₁/4 は v2 = 1 なので入らず、h + d₁/4 = f は入らない。
  - よって d₁ ∉ S_E（(i)）。
- **N/2 が偶数**：
  - g の鎖（N 段、偶数段）と X ∈ S_B から、g ∈ S_{P−1}。よって d₁ ∉ S_E（(ii)）。
  - X については、E 型の規則で順に求める。
    - X/8（v2 = 1）は入らない。
    - h + X/8 は入る（N/2 段、偶数段、終わりは奇数）ので、X/4 は入らない。
    - h + X/4 は入る（N 段）ので、X/2 は入らない。
    - h + X/2 は入らない（N/2 + 1 段、奇数段）。
    - よって X ∈ S_E。
- 周期の中の h の値は、h の鎖（`notes/2026-11-24-claude-1-class9-clean.md`）で、始まりの d₁ と v2 = 1 の事実、奇数の事実だけから決まり、間隔は 1^{N/2−1} 0 になる。
- 以上で、帰納法により、型は前周期なし、周期 1^{N/2−1} 0。

- よって予想 K40 は `[予想]` のままとする（証明の骨格つき）。
