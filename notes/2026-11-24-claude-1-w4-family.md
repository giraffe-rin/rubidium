# w = 4 の類で周期が伸び続ける族（予想 K44）

## やったこと

- 系 K36e（w = 2）の続き。予想 K38 で型が決まらない類のうち、v = 5 の w = 4 と w = 5（= v）を調べた。
- まず、m ≤ 2^22 で、これらの類の型の数が m の桁数とともに増えることを確かめた（その場のスクリプト、`code/type_vs_t.js` の typeOf を 400 ブロックで使用）。
  - 21 桁目（2^21 ≤ m < 2^22）では、v = 5 の w = 2, 4, 5 で 258、88、118 種類。
  - v = 7 の w = 4, 6, 7 で 47、21、34 種類。
  - どれも桁ごとにほぼ増えている。
- `code/w_class_family_search.js` を作った。族 a = (c·2^N + b)/q、m = 3a − 2（または m = (c·2^N + b)/q）を、2 進の条件を満たす b に限って調べる。
  - 条件：v2(m+1) = v かつ w = 目標値。
  - N ≥ 30 では m の下位の桁が b/q で決まるので、b は条件を満たす剰余類から選んだ。
  - 範囲：q ≤ 63、|b| ≤ 4096、c ≤ 15、30 ≤ N ≤ 160 の最初の 4 個の N。
  - 検算：w = 2 で走らせると、K36 の v = 5 の族（q = 29、b = −1）が見つかった。
- 周期が等差で伸びる族：v = 5 の w = 4、w = 5 ともに、この範囲では見つからなかった。
- 条件を「4 個の N で型が 1 つでも違う」に緩めて出し直した（`data/w_class_family_v5_w{4,5}_{a,m}.txt`）。
  - w = 4、q = 17、c = 3、b = −5 の族は、周期がはっきり伸びていた。
  - それ以外の候補は、ほとんどが小さい N でだけ型が違い、その後は一定の型に落ち着いていた。

## 結果

### 予想 K44 `[予想]`

N ≡ 6 (mod 8)、N ≥ 30、a = (3·2^N − 5)/17、m = 3a − 2 とする。

- m は v2(m+1) = 5、w = v2(u+1) = 4 を満たす。この部分は手で確かめられる：a ≡ −5/17 なので、m + 1 = 3a − 1 の下位の桁が N によらず決まる。数値でも N ≤ 1006 で確認した。
- 予想：型は前周期なし、周期 1^{(N−2)/4} 0^z。z = 3（N ≡ 6 (mod 24)）、z = 2（それ以外）。
- 確認：N = 30, 38, …, 1006 の 123 個のすべてで、最初の 3 周期分 + 20 ブロックの間隔が予想と一致（`data/k44_family.txt`）。
- 正しければ、v = 5 の w = 4 の類の型は無限に多い。m+2 の連の長さ (N−2)/4 に上限がないからである。
