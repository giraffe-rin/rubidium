## 結果

### 定理 K7′（周期性）`[非形式証明]`

すべての m ≥ 1 について、次を満たす整数 r₀ ≥ 0 と Λ ≥ 1 がある。
すべての r ≥ r₀ で L(r + Λ) = L(r)。ここで L(r) は行 r の P 集合。

特に、開始局面の勝敗の列 (n, 0) は、n ≥ r₀ で周期 Λ を持つ。

m ≥ 2 では、さらに次のようにとれる。
- r₀ ≤ 2^{m+1}·(m+2)
- Λ ≤ 2^{m+1}·(m+2)

#### 証明（m = 1）

行 r ≥ 1 がすべて S(1) 行であることを、r についての帰納法で示す。

- r ≥ 1 では、合法手の候補は k = 1 だけ。系 1.2 より、1 ∈ T(r) ⇔ 行 r − 1 が A 行か S(1) 行。
- **r = 1**：行 0 は A 行なので T(1) = {1}。
- **r ≥ 2**：帰納法の仮定より行 r − 1 は S(1) 行なので T(r) = {1}。
- どちらの場合も、K1 より行 r は S(1) 行で、L(r) = {1}。

よって r₀ = 1、Λ = 1 でよい。∎

#### 証明（m ≥ 2）

**状態の定義**：ブロック j の状態を x_j = (S_j, g_j) とする。
- S_j ⊆ {1, …, m}
- g_j ∈ {m+1, m+2}（H(j)(a)）

状態の取りうる値は高々 2^m · 2 = 2^{m+1} 通り。

**状態の遷移**：H(j)(c)(d) より、j ≥ 1 では x_j は x_{j−1} だけから決まる。
- S_j は d の小さい順に (i)(ii)(iii) で決まる。(i) は S_j の小さい要素、(ii)(iii) は S_{j−1} と g_{j−1} だけを使う。
- g_j は S_j で決まる。

つまり、j ≥ 1 で x_j = F(x_{j−1}) となる関数 F がある。F は m だけで決まり、j に依らない。

**状態の繰り返し**：
- x₀, x₁, …, x_{2^{m+1}} の 2^{m+1} + 1 個は、高々 2^{m+1} 通りの値しかとらない。
  鳩の巣原理より、0 ≤ j₀ < j₁ ≤ 2^{m+1} で x_{j₀} = x_{j₁} となるものがある。
- L₀ := j₁ − j₀ とおく。すべての j ≥ j₀ で x_{j+L₀} = x_j であることを、j についての帰納法で示す。
  - j = j₀ では仮定どおり。
  - j ≥ j₀ で成り立つなら、x_{j+1+L₀} = F(x_{j+L₀}) = F(x_j) = x_{j+1}。
    （ここで j + 1 ≥ 1 と j + 1 + L₀ ≥ 1 なので、F が使える。）

**行の型が状態で決まること**：ブロック j の行 a_j + d（0 ≤ d < g_j）の P 集合は、x_j と d だけで決まる。
- d = 0：A 行（L = 全体）。
- 1 ≤ d ≤ m：d ∈ S_j なら L = {d}、そうでなければ L = ∅（H(j)(b) と K1）。
- d = m+1：g_j = m+2 のときだけ現れ、L = {h}（H(j)(c)）。

**周期の決定**：
- Λ := g_{j₀} + g_{j₀+1} + … + g_{j₁−1}、r₀ := a_{j₀} とおく。
- j ≥ j₀ なら g_{j+L₀} = g_j なので、a_{j+L₀} = a_j + Λ（a_{j+L₀} − a_j = g_j + … + g_{j+L₀−1} は、周期 L₀ の列の連続する L₀ 項の和で、Λ に等しい）。
- r ≥ r₀ をとる。r はあるブロック j ≥ j₀ に属し、r = a_j + d（0 ≤ d < g_j）と書ける。
  このとき r + Λ = a_{j+L₀} + d で、g_{j+L₀} = g_j なので 0 ≤ d < g_{j+L₀}。
  x_{j+L₀} = x_j なので、上の「行の型が状態で決まること」より L(r + Λ) = L(r)。

**大きさの評価**：
- j₁ ≤ 2^{m+1} と g_i ≤ m+2 より、r₀ = a_{j₀} ≤ j₀·(m+2) ≤ 2^{m+1}·(m+2)。
- Λ ≤ L₀·(m+2) ≤ 2^{m+1}·(m+2)。

**開始局面列**：系 1.1 より、(n, 0) が P ⇔ L(n) が全体。よって開始局面列も、n ≥ r₀ で周期 Λ を持つ。∎

### 補足

- **周期性の確認が有限の計算で済む**：K7′ の証明から、R の状態 x_j が繰り返すまで計算すれば、周期と前周期の上界が確定する。
  `code/block_rule.js periods` はまさにこれを計算している。
  前提（K8）が査読を通れば、`data/block_periods_m2-200.txt` の周期の値は「計算による証明」の扱いにできる。
  なお、行単位の最小の前周期は別途調べる必要がある。
- **2^{m+1} の評価は粗いが、状態の周期が大きい m もある**：m ≤ 200 の多くでは状態の周期は小さい。
  一方で、ブロック数で 1000 を超える m もある。例：m = 114 で 26,600、m = 134 で 203,490、m = 164 で 360,360 ブロック。
  m = 164 は v2(165) = 0 なので、開始局面列の周期はそれでも 165（K4）。
  この場合も、表全体（p ≠ 0 を含む）の周期だけが長い（`data/block_periods_m2-200.txt`）。

## うまくいかなかったこと

**方法：h の所属を決めるのに必要な距離だけを追う**

- **ねらい**：開始局面列は g_j の列で決まり、g_j は「h ∈ S_j かどうか」で決まる（H(j)(c)）。
  R の (i)(ii) で h の所属が依存する距離をたどり、その集合 D（h を含み、依存先で閉じた最小の集合）の上だけで R を回せば、状態が小さくなるはずだと考えた。
  依存先は次の 2 つ。
  - (i) から d/2（d が偶数のとき）
  - (ii) から (g + d)/2（g ∈ {m+1, m+2}、整数で m 以下のとき）
- **結果**：g をどちらとも決めずに依存先をたどったところ、奇数 3 ≤ m ≤ 200 のうち D が {1, …, m} より小さくなるのは次の 8 個だけだった。
  m = 5（|D| = 2）、13（3）、19（8）、29（4）、61（5）、71（26）、83（15）、125（6）。
  残りの m では D = {1, …, m} 全体になってしまい、状態は小さくならなかった。
  K6 の対象（m ≡ 5 (mod 8)）でも、ほとんどの m で D は全体になる。
  m ≡ 5 (mod 8) で K6 の証明がうまくいったのは、g の偶奇が交互に決まることを使って、依存先の片方を消せたから。
- **残っていること**：g の実際の値を使って依存先を絞る形（g が決まるたびに依存先が変わる）にすれば、まだ見込みがあるかもしれない。
  ただし、それは状態ごとに分岐する計算になり、閉じた式は出てこないと思われる。
