# 定理 K41：m が偶数のときの R の状態の周期

## やったこと

- 観察 K41（`notes/2026-11-24-claude-1-state-period-even.md`）を手で証明した。
- 証明に出てくる P の式（n = m+1 を法として 2 を掛ける写像の軌道による）を、ψ の巡回から求めた P と照合した（`code/k41_orbit.js`、`data/k41_orbit.txt`）。

**前提**：主張 H(j)（規則 R）。gemini-2 が PR #111 で `[査読済み]`。

## 結果

### 定理 K41 `[非形式証明]`

m ≥ 2 を偶数、n := m + 1（奇数）とする。
- (1) ψ(d) := 「(n + d)/2 の奇数部分」は、奇数 1, 3, …, n − 2 の集合 D の上の置換である。
- (2) 漸化式 R の状態 (S_j, g_j) は、ブロック 1 から純周期的である。
- (3) その周期 λ は次の P の約数である。
  - 1, …, n − 1 を「r ↦ 2r mod n」の軌道に分ける。
  - 各軌道 O について、o := |O|、ℓ := O の中の奇数の個数とする。
  - P := lcm_O（o が偶数なら ℓ、奇数なら 2ℓ）。

### 証明

**R の形**：m が偶数なので、H(j)(c) より、すべての j で g_j = m + 1 = n。よって (iii) は起きない。ブロック j ≥ 1 では次のようになる。
- 奇数の d：(i) は起きない。n + d は偶数なので、[d ∈ S_j] = ¬[(n+d)/2 ∈ S_{j−1}]。
  - (n+d)/2 ≤ m は d ≤ n − 2 と同値。m は偶数なので、奇数の d は d ≤ m − 1 = n − 2 を満たす。
- 偶数の d：n + d は奇数なので (ii) は起きない。[d ∈ S_j] = ¬[d/2 ∈ S_j]。

よって偶数の d の値は、同じブロックの d の奇数部分の値から決まる。v2(d) が偶数なら同じ値、奇数なら否定。

奇数の d について e := (n+d)/2、t := v2(e) とおくと、e = 2^t ψ(d)。偶数の規則を t 回使って
[d ∈ S_j] = ¬[e ∈ S_{j−1}] = (−1)^{1+t} [ψ(d) ∈ S_{j−1}]
（(−1)^k は否定を k 回取ることを表す）。

**(1)**：x ∈ D に対し、ψ(d) = x となる d ∈ D がちょうど 1 つあることを示す。
- ψ(d) = x ⇔ (n + d)/2 = 2^t x（ある t ≥ 0）⇔ d = 2^{t+1} x − n。
- d ∈ D ⇔ 1 ≤ d ≤ n − 2 ⇔ n + 1 ≤ 2^{t+1} x ≤ 2n − 2。
- 2^{t+1}x は偶数で n は奇数なので、これは n < 2^{t+1}x < 2n と同値。
- x < n なので、2^k x（k ≥ 1）のうちちょうど 1 つが区間 (n, 2n) に入る。∎

**ψ と軌道の関係**：ψ(d) = x のとき、d = 2^k x − n（k = t + 1 ≥ 1）なので、d ≡ 2^k x (mod n)。
- k は「x から 2 を掛けて初めて n を超えるまでの回数」。
- 途中の 2x, …, 2^{k−1}x は n より小さい偶数である。
- したがって、x の「r ↦ 2r mod n」の軌道をたどると、x の次に現れる奇数が ψ^{−1}(x) = d で、その間の段数が k。
- よって、ψ の各巡回は、ある軌道 O の中の奇数全体で、長さは ℓ。また、巡回を 1 周する間の k の和は o。

**(2)(3)**：ψ の巡回 C = (x_1, …, x_ℓ) の上では、[x_i ∈ S_j] = (−1)^{k_i} [x_{i+1} ∈ S_{j−1}]（添字は ℓ を法とする）。
- ℓ 回たどると、[x_i ∈ S_j] = (−1)^{Σk} [x_i ∈ S_{j−ℓ}] = (−1)^o [x_i ∈ S_{j−ℓ}]（j − ℓ ≥ 1 のとき）。
- よって、C の上の値は、o が偶数なら周期 ℓ、奇数なら周期 2ℓ でくり返す（ブロック 1 から）。
- 奇数の値がすべて周期 P でくり返し、偶数の値は同じブロックの奇数の値で決まり、g_j は一定なので、状態はブロック 1 から周期 P でくり返す。
- したがって、状態の最小の周期 λ は P の約数で、前周期はない（ブロック 1 から純周期的）。∎

### 補足

- 各軌道には奇数が少なくとも 1 つある。軌道の最大の元 r は 2r > n を満たし、2r − n は奇数だからである。
- 例：m = 164（n = 165）では P = 360360。m = 132 では P = 27720 だが λ = 5544。ブロック 1 の値の並びによっては、λ < P になる。
- これは全局面の表の周期性（K7′）の、m が偶数の場合の具体的な形になっている。開始局面の型（K4）は、間隔が一定なので状態の周期とは関係なく決まる。
