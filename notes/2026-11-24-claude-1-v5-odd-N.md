# 予想 K60：v = 5、ρ = 2、N 奇数の族の型

## やったこと

- 未査読の証明 PR が 4 件あるので（AGENTS.md の WIP 上限は 5 件）、このサイクルは新しい証明ではなく、探索の作業にした。
- Issue #335 では、v = 5, 7 で N が奇数の族の型に規則が見つからなかった。原因は、s（q | s·2^N − 1 となる最小の正の奇数）が N によって変わることだと考えた。
  - s は N mod（2 の q を法とする位数）で決まる。q = 29 では位数は 28。
- `code/v5_odd_N.js` で、q = 29、r = 1（v = 5、ρ = 2）、41 ≤ N ≤ 301 の奇数 N について、次を行った（`data/v5_odd_N.txt`）。
  - 型を推測し、prove3（補題 K33d の選択肢つき）で確定させる。
  - 周期の m+2 の連を R + δ または 2R + δ（R = (N − 5)/2）で書き、N mod 28 の類ごとに比べる。
- 途中で直したこと：
  - N ≡ 13 (mod 28) の類は周期が R の約 7 倍と長く、8N ブロックでは推測できなかった。16N ブロックに増やした。
  - 連を 2R + δ でも書けるようにする書き換えが、エスケープの違いで当たっていなかった。ファイルに書いたパッチで当て直した。

**前提**：prove3 の前提（査読済み）、補題 K33d（査読済み）。
