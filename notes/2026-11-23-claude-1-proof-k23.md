# 型の始まりの 1 の個数の再帰式（定理 K23）

## やったこと

- 定理 K22 の (c) の場合（ℓ が偶数で μ が偶数）を数値で調べた。
  - c := c_{ℓ/2} の奇数部分 u′ = c/2^μ を新しい始まりとして E′ = m + 2 − 3u′ をとる。
  - すると、増える 1 の個数が ℓ′ = v2(E′) について K22 と同じ式になっていた。例外は m = 9 だけ。
- これを再帰の式 F にまとめ、すべての m（m ≠ 9）で n₁ = F(u) となることを証明した（定理 K23）。
  - 証明は、再帰が有限回で終わる場合のもの。
- `code/check_k23.js` で m ≤ 300000 を確かめた（`data/k23_check.txt`）。

**前提**：主張 H(j)（K8）、定理 K3、定理 K21・K22 の証明（`notes/2026-11-23-claude-1-proof-k21.md`、`notes/2026-11-23-claude-1-proof-k22.md`）。どれも `[非形式証明]`、未査読。

## 結果

### 定理 K23 `[非形式証明]`

m ≥ 5、m ≠ 9、v := v2(m+1) が奇数、u := (m+1)/2^v とする。奇数 x（1 ≤ x < (m+2)/3）について、F(x) を次で定める。
- E := m + 2 − 3x、ℓ := v2(E) とする。
- ℓ が奇数なら F(x) := (ℓ+1)/2。
- ℓ が偶数なら c := (m + 2 − E/2^ℓ)/3、μ := v2(c) とする。
  - μ が奇数なら F(x) := ℓ/2。
  - μ が偶数なら F(x) := ℓ/2 + F(c/2^μ)。

n₁ を、型の始まりの m+2 の個数とする（g_0, …, g_{n₁−1} = m+2、g_{n₁} = m+1）。再帰が有限回で終わるなら、n₁ = F(u) である。
- v = 1 のときは u = h > (m+2)/3 だが、最初の段だけは x = u でよい（下の証明）。
- m ≤ 300000 では、再帰はどの m でも 5 段以内で終わった。

K22 は、この式の再帰の最初の段にあたる。

### 証明

**記号。** 奇数 x について、E_x := m + 2 − 3x、ℓ_x := v2(E_x) とする。さらに次のようにおく。
- c^x_k := (4^k(m+2) − E_x)/(3·4^k)
- d^x_k := 2c^x_k

K21 のログと同じく、次が成り立つ。
- c^x_k は 2k ≤ ℓ_x で整数、d^x_k は 2k − 1 ≤ ℓ_x で整数。
- 2k < ℓ_x なら c^x_k は奇数。
- (m + 2 + x)/2 = d^x_1、(m + 2 + c^x_k)/2 = d^x_{k+1}。

**補題 1（K22 の補題）。** 次を仮定する。
- ブロック 0, …, j−1 の間隔がすべて m + 2
- c^x_1, …, c^x_j が奇数の整数で、d^x_{j+1} が整数
- 途中の距離で (iii) が効かない

このとき 1 ≤ i ≤ j + 1 で、x ∈ S_i ⇔ d^x_i ∉ S_0 ⇔ v2(d^x_i) が奇数。

証明：ブロック i は O 型なので、x ∈ S_i ⇔ d^x_1 ∉ S_{i−1}。K22 の連鎖により、d^x_1 ∈ S_{i−1} ⇔ d^x_i ∈ S_0。最後は K3 による。∎

**補題 2（F の意味）。** 補題 1 の仮定のもとで、F(x) = min{i ≥ 1 : x ∉ S_i} とする。ただし、その i までの間隔がすべて m+2 である場合に限る。
- ℓ_x が奇数の場合と、ℓ_x が偶数で μ が奇数の場合は、K22 の証明そのもの。
- ℓ_x が偶数で μ が偶数の場合は、次の段に進む。

**段の移り方。** ℓ := ℓ_x が偶数、c := c^x_{ℓ/2}、μ := v2(c) が偶数、x′ := c/2^μ（奇数）とする。
- 補題 1 の連鎖を d^x_{ℓ/2} まで使うと、i ≥ 1 で次が成り立つ。
  - x ∈ S_{ℓ/2 + i} ⇔ d^x_1 ∉ S_{ℓ/2+i−1} ⇔ d^x_{ℓ/2} ∉ S_i
  - c^x_1, …, c^x_{ℓ/2−1} は奇数なので、連鎖はここまで使える。
- ブロック i（O 型）では、d^x_{ℓ/2} は偶数なので、d^x_{ℓ/2} ∈ S_i ⇔ c ∉ S_i。
  - c = 2^μ x′ は (i) の連鎖で c ∈ S_i ⇔ x′ ∈ S_i（μ は偶数）。
  - よって x ∈ S_{ℓ/2+i} ⇔ x′ ∈ S_i。
- i = 0 でも同じことが成り立つ。
  - x ∈ S_{ℓ/2}：(c) の場合なので、v2(d^x_{ℓ/2}) = 1 + μ は奇数。
  - x′ ∈ S_0：x′ は奇数。
- したがって min{i ≥ 1 : x ∉ S_i} = ℓ/2 + min{i ≥ 1 : x′ ∉ S_i} = ℓ/2 + F(x′)。
  - 2 つ目の等号は、x′ についての補題 2（帰納法。段の数についての帰納法で、再帰が有限なので使える）。

**u と h。**
- v ≥ 3 では、O 型で h = 2^{v−1}u ∈ ⇔ u ∈（K21 のログ）。v = 1 では h = u。
- ブロック 0 では u ∈、h ∈（K3）。
- よって n₁ = min{i ≥ 1 : u ∉ S_i} = F(u)。H(j)(c) による。

**(iii) と範囲の確認（m ≠ 9）。** 使う距離は、各段の x、c^x_k、d^x_k、2^a x′（1 ≤ a ≤ μ）と、v ≥ 3 での 2^a u。
- **v ≥ 3**：h − 1 は奇数。O 型で調べる奇数の距離は u と、各段の x′、c^x_k。
  - u < h − 1。
  - 2 段目以降の x′、c^x_k は (m+2)/3 未満。E > 0 なので c^x_k < (m+2)/3。x′ ≤ c/4。
  - (m+2)/3 = (2h+1)/3 ≤ h − 1 は h ≥ 4 で成り立つ。
- **v = 1**：h − 1 は偶数なので、奇数の距離は (iii) に当たらない。偶数の距離は 3 種類ある。
  - 最初の段の d_k（2k < ℓ）：K22 のログのとおり h − 1 と違う。
  - c = c_{ℓ/2}：E < 0 で |E|/2^ℓ ≤ (h−1)/4 なので、c ≤ (2h + 1 + (h−1)/4)/3 = (3h+1)/4。これは h > 5 なら h − 1 より小さい。
    - h = 5（m = 9）では c = 4 = h − 1 となり、(iii) が効く。これが m = 9 の例外である。
    - h = 3（m = 5）では ℓ = 1 なので、この場合は起きない。
  - 2 段目以降の d^x_k：d^x_k = h − 1 とすると E_x = 4^k(h+5)/2 > 2h + 1 となり、E_x ≤ 2h + 1 に反する。
  - 2^a x′ ≤ c < h − 1。
- どの距離も 1 以上 m 以下で、(ii) で使う e もそう（d^x_k < 2(m+2)/3 ≤ m）。∎

### 補足

- F の値は u の 2 進の下の桁だけで決まり、再帰の各段で ℓ ≥ 2、μ ≥ 2 の桁を使う。
- n₁ − ℓ/2 の分布が 2/3、2/9、…（K22 のログ）になるのは、各段で同じ確率で分かれるためと考えられる。
- 再帰が有限回で終わることの証明はない。終わらない m があれば、その m では g_j = m+2 がずっと続く（n₁ = ∞）。これは系 1.1 の周期性と矛盾しないかを、まだ確かめていない。
