## 結果

### 定理 K19 `[非形式証明]`

m ≥ 5、v2(m+1) = 1、h = (m+1)/2 とする。r := v2(h−1) が奇数で r = 2j+1 なら、次が成り立つ。
- m は前周期なし・周期「1^{j+1}0」の型である。
- すなわち、すべての q ≥ 0 と 0 ≤ n ≤ j+1 について、g_{(j+2)q + n} = m+2 ⇔ n ≤ j。

v2(m+1) = 1 の m の中で、この条件を満たす m の密度は 2/3 である（r = 1, 3, 5, … の密度が 1/2、1/8、1/32、…）。
- 新しく一般に示されたのは r ≥ 5 の部分（密度 1/24）。
- r ≥ 5 の m は、どれも K18 の残りの区分の中にある。

### 証明

D := h − 1 = 2^r u（u は奇数）とおく。m ≡ 1 (mod 4) なので h は奇数。D ≥ 2。

**距離の定義。** 次のように定める。
- 1 ≤ i ≤ j について a_i := h − D(4^i − 1)/(3·4^i)
- 0 ≤ i ≤ j について b_i := h + 1 + D(2·4^i + 1)/(3·2^{2i+1})

**整数であること。**
- 4^i − 1 と 2·4^i + 1 は 3 で割り切れる。
- 2i ≤ 2j < r、2i + 1 ≤ r なので、4^i と 2^{2i+1} は D を割る。

**偶奇。**
- a_i：D/4^i = 2^{r−2i}u は偶数（r − 2i ≥ 1）なので、a_i は奇数。
- b_i（i < j）：D/2^{2i+1} = 2^{r−2i−1}u は偶数なので、b_i は偶数。
- b_j：D/2^r = u は奇数で、(2·4^j + 1)/3 も奇数なので、b_j は奇数。

**範囲。**
- 0 < a_i < h − 1：D/4 ≤ D(4^i − 1)/(3·4^i) < D/3 による。
  - 左の不等号は a_i ≥ h − D/3 > 0。
  - 右の不等号は、D(4^i − 1)/(3·4^i) = 1 となりえないことによる。r が奇数なので 2^{r−2i}u·(4^i − 1)/3 = 1 は起きない。
- h + 1 < b_i ≤ b_0 = (3h+1)/2 ≤ m = 2h − 1（h ≥ 3）。

**3 つの恒等式。**
- (E1) (m + 2 + h)/2 = (3h+1)/2 = b_0
- (E2) (m + 2 + a_i)/2 = b_i（1 ≤ i ≤ j）
- (E3) b_i/2 = a_{i+1}（0 ≤ i < j）

確かめ方：h = D + 1 を代入する。
- 3h + 1 − D(4^i − 1)/(3·4^i) = 3D + 4 − D(4^i − 1)/(3·4^i) で、これは 2·b_i = 2D + 4 + D(2·4^i + 1)/(3·4^i) に等しい。両辺の D の係数は (8·4^i + 1)/(3·4^i)。
- b_i/2 = 1 + D(8·4^i + 1)/(3·4^{i+1}) で、a_{i+1} = 1 + D(2·4^{i+1} + 1)/(3·4^{i+1}) と同じ。8·4^i = 2·4^{i+1} による。

**O 型のブロックの規則。** 1 つ前の間隔が m+2 のブロック n では、次が成り立つ。m + 2 は奇数であることを使う。
- (O1) h ∈ S_n ⇔ b_0 ∉ S_{n−1}。
  h は奇数なので (i) は効かない。(ii) の e は (E1) から b_0 ≤ m。h ≠ h − 1 なので (iii) は効かない。
- (O2) a_i ∈ S_n ⇔ b_i ∉ S_{n−1}。
  同様。e は (E2) から b_i。a_i ≠ h − 1 である。
- (O3) b_i ∈ S_n ⇔ a_{i+1} ∉ S_n（i < j）。
  b_i は偶数なので、m + 2 + b_i は奇数で (ii) は効かない。b_i > h なので (iii) は効かない。(i) は (E3) による。

**E 型のブロック（1 つ前の間隔が m+1）と、ブロック 0 の規則。**
- 奇数の距離はすべて入る。
  - E 型：(i) は効かない。2h + 奇数は奇数なので (ii) も効かない。(iii) は O 型だけ。
  - ブロック 0：K3 で v2 = 0。
- b_i（i < j）は入らない。
  - E 型：(i) で、b_i/2 = a_{i+1} は奇数で入っている。
  - ブロック 0：v2(b_i) = v2(2a_{i+1}) = 1 は奇数（K3）。

**主張 P(n)**（0 ≤ n ≤ j。ブロック J ≡ n (mod j+2) について）：
- 1 ≤ i ≤ min(j, j−n+1) で、a_i ∈ S_J ⇔ i + n ≤ j
- 0 ≤ i ≤ j − n で、b_i ∈ S_J ⇔ i = j − n
- h ∈ S_J

**帰納法。** ブロックの番号 J についての帰納法で、次を示す。
- J ≡ n (mod j+2) で n ≤ j なら P(n) が成り立ち、g_J = m+2。
- n = j+1 なら g_J = m+1。

- **n = 0（J = 0、または 1 つ前が n = j+1 で g = m+1 の E 型）**：
  - a_i（1 ≤ i ≤ j）、h、b_j は奇数なので入る。
  - b_i（i < j）は入らない。
  - これは P(0) である。a_i で i + 0 ≤ j、b_i で i = j ⇔ 入る。
- **1 ≤ n ≤ j+1**：1 つ前は n − 1 で、P(n−1) より h ∈ S、g = m+2 なので、O 型である。
  - (O2)、1 ≤ i ≤ j − n：P(n−1) で b_i ∈ ⇔ i = j − n + 1 は成り立たない。よって a_i ∈ S_J。
  - (O2)、i = j − n + 1（n ≥ 1 なので i ≤ j）：b_{j−n+1} ∈ S_{J−1} なので、a_{j−n+1} ∉ S_J。
    これで、1 ≤ i ≤ j − n + 1 で「a_i ∈ ⇔ i + n ≤ j」となる。
  - (O3)、0 ≤ i ≤ j − n：b_i ∈ S_J ⇔ a_{i+1} ∉ S_J ⇔ i + 1 + n > j ⇔ i = j − n。
  - (O1)：h ∈ S_J ⇔ b_0 ∉ S_{J−1} ⇔ 0 ≠ j − n + 1 ⇔ n ≠ j + 1。
  - よって n ≤ j なら P(n)（h ∈ S_J）、n = j+1 なら h ∉ S_J。
- 最後に H(J)(c) より、g_J = m+2 ⇔ h ∈ S_J。∎
