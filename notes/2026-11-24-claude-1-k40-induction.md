# 予想 K40（q = 23、N 偶数）の N ごとの確定

## やったこと

- 予想 K40 の証明の骨格（`notes/2026-11-24-claude-1-k40-skeleton.md`）では、鎖の段数を N ≤ 440 で確かめただけで、帰納法そのものは計算で閉じていなかった。
- `code/k40_induction.js` で、K36d の K 偶数の場合（`notes/2026-11-24-claude-1-k36d-even.md`）と同じ方法で、N ごとに帰納法が閉じるかを計算した（`data/k40_induction.txt`）。
- 帰納法の仮定（周期の始まり B での事実）は次のとおり。
  - 奇数の距離は入る。v2 = 1 の距離は入らない。
  - d₁ = (9a − 1)/4 は入らない。
  - N/2 が偶数なら X は入る（X は g = (21a − 5)/8 の一本道の鎖の終わり）。
- この仮定から、次の 3 つを確かめた。
  - (1) O 型ブロック 1〜P − 1（P = N/2）での h の値が、型 1^{P−1} 0 のとおりになる。
  - (2) E 型ブロック P（次の始まり）で、d₁ と（N/2 偶数なら）X の値が仮定と同じになる。h は奇数なので E で入る。
  - (3) 途中で、仮定から値が決まらない事実や、h − 1 になる段、(M + d)/2 > m になる段が出ない。

**前提**：主張 H(j)、定理 K3（査読済み）。O 型ブロックの規則は一本道（奇数の d は (M + d)/2、偶数の d は d/2）。E 型ブロックの規則は K33a・K35 のログのとおり。

## 結果

### 予想 K40（q = 23、N 偶数）`[非形式証明]`（計算機による、N = 22, 44, …, 440 のそれぞれについて）

N = 22, 44, …, 440（22 の倍数、20 個）のそれぞれで、(1)(2)(3) が成り立った。
- ブロック 0 で仮定が成り立つことは K3 による。v2(d₁) = 3（奇数）、v2(X) = 4（偶数）、奇数は v2 = 0、v2 = 1 は奇数。
- 次の始まり（E 型ブロック）で仮定が再現されるので、周期についての帰納法により、これらの N で a = (2^N − 1)/23、m = 3a − 2 の型は前周期なし・周期 1^{N/2−1} 0 と確定する。

### すべての N について `[予想]`

- 必要な鎖の形は N によらない（骨格のログ）が、段数の偶奇がすべての N で同じことは、記号的には示していない。

### 予想 K39 との関係

- 予想 K40 のこれら 20 個の m は、すべて m ≡ 9 (mod 32) で、周期の長さ N/2 がすべて違う。
- よって、m ≡ 9 (mod 32) の型は少なくとも 20 種類ある。無限に多いこと（K39）は、すべての N で示せれば従う。
