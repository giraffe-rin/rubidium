# 定理 K38（v = 7）の Lean 4 での形式化

## やったこと

`lean/Rubidium/K38v7.lean` に、定理 K38 の v = 7 の場合を sorry なしで証明した。

```lean
theorem K38_v7 (m : Nat) (hm : (m + 1) % 128 = 0)
    (hu : u % 16 = 7 ∨ u % 64 = 31 ∨ u % 256 = 255) (n : Nat) :   -- u = (m+1)/128
    IsP m n 0 ↔ n % (5m+6) ∈ {0, m+2, 2m+3, 3m+4, 4m+5}
```

u の 3 つの条件は、それぞれ w = v2(u+1) = 3、5、≥ 8 と同じ（どの場合も u ≡ 3 (mod 4)）。
公理は `[propext, Classical.choice, Quot.sound]`。

書く前に、主張を直接の DP で確かめた。u ∈ {7, 23, 31, 39, 55, 71, 95}（m ≤ 12159）で、n ≤ 2(5m+6) まで一致した。

## 証明の組み立て

PR #424（v = 5）と同じ方法を使った。h = 64u、e₁ = (129u+1)/2 で、v2(e₁) は 2、4、6 のどれか。
行は a、b = a + (m+2)、c₁、c₂、c₃（間隔 m+1）、a' = c₃ + (m+1) の 6 つ。

- **行 a**：Blk m 6 a が成り立つ。よって (a + h) と (a + e₁) は P で、奇数 d も P。
- **行 b**（O 型）：
  - q ∈ {1, 3, 7, 11, 15, 27, 43} について、(b + qu) は N。手 (m+2+qu)/2 の行き先が P だから（q = 1 は v2(e₁) が偶数、ほかは奇数）。
  - そこから `P2`・`N2`（半分にする鎖を c·u の形で書いたもの）を使い、次を示した。
    - P：2u、8u、32u、6u、24u、96u、14u、56u、22u、88u、30u、120u、54u、86u
    - N：4u、16u、64u、12u、48u、28u、112u、44u、60u、108u
- **行 c₁**：Blk m 1。
  - (c₁ + 64u)・(c₁ + 48u)・(c₁ + 112u)・(c₁ + 44u) は N。手 96u・88u・120u・86u で、行 b の P の局面に移れるから。
  - (c₁ + 96u)・(c₁ + 88u) は P（`e_even`）。
- **行 c₂**：Blk m 3（`blk_step2`）。
  - (c₂ + 64u)・(c₂ + 48u) は N（手 96u・88u）。
  - (c₂ + 96u) は P（`e_even`、(c₁ + 112u) が N を使う）。
- **行 c₃**：Blk m 5。(c₃ + 64u) は N（手 96u）。
- **行 a'**：Blk m 6。

これらの事実は、もとの証明（ノート 2026-11-24-claude-1-k38-proof.md）の補題 Inh′_n と、「3H/2 = 96u が各ブロックで入る」という主張を、v = 7 で具体的に書いたものにあたる。

## 意味

- 定理 K38 の v = 5、7 の場合が、Lean で確かめられた（査読待ち）。
- 一般の奇数 v では、q の集合と鎖の長さが v とともに増える。Inh′_n を q と b について一般に述べる帰納法が要る。
