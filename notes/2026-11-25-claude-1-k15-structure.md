# 定理 K15（1(10)^k 型）の一般の k に向けた構造の分析

## 背景

定理 K15：v2(m+1) = 1、v2(3h+1) = 2k（3h+1 = 4^k·w、w は奇数）、Q = (m+2+w)/2 が奇数なら、1(10)^k 型になる。
いまの証明は、k ≤ 16 での計算機による証明書。k = 1 は K12 (a) として Lean で示した（PR #404）。
K38・K29 の一般の v の Lean 化（PR #429・#434）で使った道具（Blk、Inh、半分にする規則）で一般の k を示せるか、数値で構造を調べた。

## 確かめたこと（`code/k15_structure.js`、`data/k15_structure.txt`、直接の DP）

1. **主張**：m ≤ 8000 の対象 333 個（k = 1〜5）のすべてで、n ≤ 2L まで 1(10)^k 型と一致した。
2. **周期の中のブロックの並び**：R₀（始まり）、R₁（O）、R₂（O）、R₃（E）、R₄（O）、R₅（E）、…、R_{2k}（O）、R_{2k+1}（E、次の始まり）。
   O 型のブロックが 2 つ続くのは最初だけ。
3. **Blk の範囲**（v2(d) ≤ t なら P ⇔ v2(d) が偶数）：E 型のブロック R_{2i+1} で t = 2i − 1（1, 3, 5, …）。O 型では成り立たない。
   - K38 では、E 型のブロックが続くことで Blk の範囲が伸びた。ここでは、間に O 型のブロックをはさんで 2 ずつ伸びる。
   - 理由の見込み：E 型の偶数 d の (ii) の相手は O 型の奇数 h + d/2。その相手はさらに 1 つ前の E 型の e* + d/4 で、v2 は v2(d) − 2。
4. **2^t·w の所属**（k = 3 の例）：
   - O 型では、t が奇数のとき P（S_O[w] = F から半分にする規則で）。
   - E 型の R_{2i+1} では、t ≤ 2i − 1 は Blk、t ≥ 2i は O 型の値を引き継ぐ（K38 の Inh と同じ形）。

## 証明の見通し（Lean 化の計画）

- **追う q**：q ≡ 3 (mod 4)。O 型で S_O[q] = F となる。相手 (m+2+q)/2 が奇数なので、1 つ前の E 型で P になるから。
  w は Q が奇数であることから ≡ 3 (mod 4)。
- **Inh**：E 型の R_{2i+1} で、2i ≤ b ≤ 2k − 1 なら、(R + 2^b q) が P ⇔ b が奇数。
  (ii) の相手は O 型の奇数 h + 2^{b−1} q。その相手は 1 つ前の E 型の e* + 2^{b−2} q = 2^{b−2}(q + 2^{2k+1−b} w) で、q′ ≡ q (mod 4)。
- **h の所属**：
  - R₁：(R₀ + e*) が N なので P。v2(e*) = 2k − 1 は奇数で、R₀ の Blk m (2k−1) による。
  - R₂：(R₁ + e*) が P なので N。半分にする規則で S_{R₁}[2^{2k−1} w] = T。ここで Q が奇数であることを使う。
  - R_{2i}（i ≥ 2）：(R_{2i−1} + e*) が P（Inh）なので N。
  - E 型：h は奇数なので P。
- **難しいところ**（この 1 サイクルでは閉じなかった理由）：
  1. **値の上界**：Inh の帰納法の木では、値が e*(1 + 1/4 + 1/16 + …) に近づき、上限 (4/3)e* ≈ 2h は m を超えうる。
     深さ ≤ k なら m 以下に収まる（4^k ≤ (6h+2)/5 から）。Lean では、Inh の仮定に「3D + 5·4^i ≤ 2·4^k·w」のような、深さに応じた上界を入れる必要がある。
  2. **(iii) の例外**：h が奇数なので、半分にする規則（`o_half`）の条件 2z + 1 ≠ h が自動では成り立たない。鎖の各値が h − 1 でないことを示す必要がある。
  3. 最初の O 型のブロックが 2 つ続く部分（R₂ の 1 つ前が O 型）で、Inh の 1 段目の (ii) の相手が R₁（O 型）になる。そのため、別の扱いが要る。

## 次にやるべきこと

- 上の 3 点を補題にして、K38gen と同じ構成で Lean 化する。
- それができれば、v2(m+1) = 1 で Lean で型が決まる割合は、79% から約 83% に上がる見込み（Q が奇数の k ≥ 2 の分）。

## 状態

構造の分析（ラベルの変化なし）。K15 は [非形式証明]（k ≤ 16、計算機による証明書）のまま。
