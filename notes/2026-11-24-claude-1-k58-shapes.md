## 記号

## 定理 K58 `[非形式証明]`（計算機による形の比較を含む）

N ≡ 3 (mod 4)、N ≥ 23 なら、m の型は前周期なし・周期 1^{R+2} 0 1^R 0。

- 23 ≤ N ≤ 39：prove3 で確定済み（`data/k58_family.txt`、gemini-2 が PR #340 で査読済み）。
- N ≥ 43：以下による。

### 証明

**帰納法の仮定**：周期の始まり B で、次が成り立つ。

- 奇数の距離は入る。
- v2 = 1 の距離は入らない（補題 K33d）。
- 2(a − 7) ∉ S_B。

t = 0（ブロック 0）では K3 から成り立つ。2(a − 7) の v2 は 1 + v2(a − 7) = 3 で、奇数だからである。

**1 段**：B の仮定から、次の 2 つを示せばよい。

- g_1..g_L が w と一致すること。
- 2(a − 7) ∉ S_L。

評価は 3 つの部分に分かれる。

1. **自明な部分**：h の連の各ブロックからの鎖の多くは、定理 K59 の証明と同じ形をしている。b = 1 で進み、R ブロック目で N を越える（補題 K59.1）。終点は次のどれかになる。
   - v2 = 1 の距離：入らない。
   - 2(a − 7)：B では入らない（仮定）、E1 では下の評価木で「入る」。
   - 奇数：入る。
   これで、連の長さが R + 2（B から）と R（E1 から）になる。

2. **自明でない E 型の事実**（`data/k58_shapes.txt`）：どの N でも、次の 6 個だけである。
   - B：a − 7（不）、2(a − 7)（不）、(3a − 1)/2（入）。
   - E1：a − 7（不）、2(a − 7)（入）、(3a − 1)/2（入）。

3. **評価木の中の鎖**：これらの事実を決めるために入る O 型の鎖は、どの N でも 6 本だけである。
   - 入口は (9a − 3)/4、2a − 4、(5a − 15)/2 の 3 種類で、それぞれ B と E1 の評価から 1 本ずつ。
   - 各鎖の「半分にする段の数」の列の連長表示は、値の列がどの N でも同じで、ある 1 つの連の長さだけが R − 定数で変わる。
   - 例：2a − 4 の鎖は 1×1 0×2 2×1 1×(R − 4) 0×1。

**N によらないことの理由**：鎖の形は、入口の形と、奇数の点での b の軌道（定理 K47 の記述）と、N を越える場面（補題 K59.1）だけで決まる。

- b の軌道は N によらない。
- 越える場面で現れる量（v2(b′a − cs) など）は、a の下位の桁（a ≡ −1/5 (mod 2^N)）と s = 7 だけで決まる。
- N による違いは、b = 1（t = 2、半分にする段 1）にとどまる部分の長さだけで、その長さは「K が N に達するまでのブロック数」= R − 定数。
- この部分が段数に加える数は (R − 定数) の 2 倍（奇数の段と半分にする段）なので、段数の偶奇を変えない。R は偶数なので、R − 定数の偶奇も N によらない。
- よって、各鎖の値は N によらず、評価の結果も N によらない。

43 ≤ N ≤ 199 の 40 個で、1 段が閉じ、形が一致することを確かめた。∎

**注意**：「N によらないことの理由」は、定理 K36d″（gemini-2 が査読済み）と同じ種類の議論である。鎖の形の連長表示を記号的に導いたのではなく、40 個の N での比較と、上の理由を合わせている。

### 記号と恒等式

q = 5、r = 1、s = 7、X = 2^N、7X = 5a + 1、R = (N − 3)/2（偶数）、L = 2R + 4 とする。E 型ブロックは B と E1（= ブロック R + 3）。

鎖の距離を d = (αa − c)/2^K、β = rα + qc = α + 5c と書くと、恒等式 αa − c = βa − csX（r = 1）が成り立つ。奇数の点で β = 2^K b なら d = ba − 7c·2^{N−K}。

### 鎖 1：入口 (9a − 3)/4 = 3h/2（α = 9、c = 3、K = 2）

- β = 9 + 15 = 24 = 2^3·3。1 回半分にして K = 3、b = 3 の奇数の点に着く。T(3) = (3 + 3)/2 = 3、t(3) = 1 なので、b = 3 の不動点にとどまる。
- k 番目の奇数の点は K = k + 2、d_k = 3a − 21·2^{N−k−2} = 3a − 3(5a + 1)/2^{k+2}。
- 長さ n（R + 2 または R）の鎖で、最後の段の後の E = n + 3 ≤ R + 5 < N。N を越えず、終点の v2 は t(3) − 1 = 0（奇数、E 型ブロックでも B でも入る）。
- 段数は 1 + n で、R が偶数なので奇数。よって値は「入らない」。
- 条件：0 < d_k < 3a − 4（3(5a + 1)/2^{k+2} は (0, 3a) にあり 4 以上）。d_k = h − 1 ⇔ (a + 1)2^{k+1} = 5a + 1 で、k ≥ 1 では a が整数の解をもたない（k = 1 で a = 3 だけ）。

### 鎖 2：入口 2a − 4（α = 2、c = 4、K = 0）

- 1 回半分にして a − 2（α = 1、c = 2、K = 0）。β = 1 + 10 = 11 は奇数なので、b = 11 の奇数の点。
- c = 2 は偶数なので csX = 14X の付値は N + 1 で、越える基準は E = N + 1 になる。
- 軌道は 11 →（t = 1）7 →（t = 1）5 →（t = 3）1 →（t = 2）1 → …。奇数の点の K は 0, 1, 2, 5, 7, …（j ≥ 4 で K_j = 2j − 3）。
- 最後の段の後の E は、n = R + 2 で 2n − 1 = N、n = R で N − 4。どちらも N + 1 未満で、越えない。終点の v2 は t(1) − 1 = 1（入らない）。
- 段数は 1 + n + (0 + 0 + 2 + (n − 4)) = 2n − 1（奇数）。よって値は「入る」。
- 条件：奇数の点の d は a − 2、2a − 1、(5a − 1)/2、a − 14·2^{N−K}（b = 1、K ≥ 5）で、どれも (0, 3a − 4) にあり h − 1 = (3a − 3)/2 と等しくない。

### 鎖 3：入口 (5a − 15)/2（α = 5、c = 15、K = 1）

- β = 5 + 75 = 80 = 2^4·5。3 回半分にして K = 4、b = 5。
- T(5) = 1（t = 3）、その後 b = 1（t = 2）。奇数の点の K は 4, 7, 9, …（j ≥ 2 で K_j = 2j + 3）。
- j = R − 1 番目の奇数の段の後で E = K_{R−1} + 2 = 2R + 3 = N となり、越える（補題 K59.1）。
  - u = v2(b′a − cs) = v2(a − 105)。5(a − 105) = 7X − 526 なので u = v2(526) = 1。
  - 半分にする段は (N − K − 1) + u = 1 + 1 = 2。
  - 新しい鎖は c′ = 105、β″ = 1 + 5·105 = 526 = 2·263、K′ = 1、b = 263。
- 越えた後の軌道は 263 →（t = 1）133 →（t = 3）17 →（t = 2）5。
- **B の評価からの鎖（長さ R）**：越えた後の奇数の点は 1 つ（b = 263）。終点の v2 は t(263) − 1 = 0（入る）。
  - 段数は 3 + R + (2 + (R − 3) + 2) = 2R + 4（偶数）なので、値は「入る」。
- **E1 の評価からの鎖（長さ R + 2）**：越えた後の奇数の点は 3 つ（263, 133, 17）。終点の v2 は t(17) − 1 = 1（入らない）。
  - 段数は 3 + (R + 2) + (2 + (R − 3) + 2 + 0 + 2) = 2R + 8（偶数）なので、値は「入らない」。

### 1 段の全体

周期の始まり B の仮定は、奇数は入る、v2 = 1 は入らない、2(a − 7) ∉ S_B。

- **最初の連（ブロック 1..R + 2）**：h の鎖（b = 1、c = 1）は定理 K59 の証明と同じ。
  - i ≤ R − 1 では、終点の v2 は 1（入らない）なので h ∈ S_i。
  - i = R では、終点は 2(a − 7)（仮定で入らない）なので h ∈ S_R。
  - i = R + 1, R + 2 では、越えた後の新しい鎖（c′ = 7、b = 9 → 3）で、終点はそれぞれ v2 = 1 と奇数。よって h ∈ S_{R+1}、h ∉ S_{R+2}。
- **E1（ブロック R + 3）での h**：h/2 は v2 = 1 で入らない。3h/2 はブロック R + 2 で鎖 1（長さ R + 2）により入らない。よって h ∈ S_{R+3}。
- **2 本目の連（ブロック R + 4..2R + 3）**：h の鎖は E1 で終わる。
  - i ≤ R − 1 では、終点の v2 は 1（入らない）なので h ∈ S。
  - i = R では、終点は 2(a − 7) で、下の評価木により E1 で入るので、h ∉ S_{2R+3}。
- **自明でない E 型の事実**（E 型の規則。第 2 項は 1 つ前の O 型ブロックからの鎖）：
  - E1 で a − 7：(a − 7)/2 は v2 = 1 で入らない。h + (a − 7)/2 = 2a − 4 は鎖 2（長さ R + 2）で入る。よって a − 7 ∉ S_{E1}。
  - E1 で 2(a − 7)：a − 7 ∉ S_{E1}。h + (a − 7) = (5a − 15)/2 は鎖 3（長さ R + 2）で入らない。よって 2(a − 7) ∈ S_{E1}。
  - L で h：3h/2 は鎖 1（長さ R）で入らない。よって h ∈ S_L。
  - L で a − 7：2a − 4 は鎖 2（長さ R）で入る。よって a − 7 ∉ S_L。
  - L で 2(a − 7)：a − 7 ∉ S_L。(5a − 15)/2 は鎖 3（長さ R）で入る。よって 2(a − 7) ∉ S_L。これで仮定が次の周期で再現される。

以上は N ≡ 3 (mod 4) のすべての N で記号的に成り立つ。小さい N で必要な条件（R > 2 など）は N ≥ 23 で満たされる。23 ≤ N ≤ 39 は prove3 による確定とも一致する。∎
