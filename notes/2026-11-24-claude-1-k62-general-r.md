# 命題 K62：一般の奇数 r での越える場面の規則

## やったこと

- 命題 K61（Issue #357）は、越える場面の新しい鎖の式が 1/r = r を前提にしていたので、r = ±1 に限っていた。これを一般の奇数 r に広げた。
- `code/k62_general_r.js` で、b と c を「奇数を分母にもつ有理数」（BigInt の分数）として扱う予測を書いた。比べるために、命題 K61 の整数の式（1/r の代わりに r を使う）での予測も出した。実際の間隔の列と比べた（`data/k62_general_r.txt`）。
  - 族は、予想 K45 の族（29:4641:1:N）、定理 K47 の形の族を無作為に 3000、一般の族（|r| ≤ 4999）を無作為に 5000。

**前提**：H(j)、K3（査読済み）。命題 K57、補題 K59.1（査読済み）。

## 命題 K62 `[非形式証明]`

族 q·a + r = s·2^N（q, r, s は奇数、a > 0 は奇数）、β₀ = 3r + q ≠ 0、v = v2(β₀) < N とする。命題 K61 の計算は、次のように変えれば、一般の奇数 r で成り立つ。

- b と c を、奇数を分母にもつ有理数として扱う。v2 は分子の 2 の付値とする。
- 越える場面（c_o = c/2^{v2(c)}、γ = v2(c)）での新しい鎖を、次のようにする。
  - E = N + γ：c″ = c_o s / r、u = v2(b′ + q c_o s / r)、K″ = u、b″ = (b′ + q c_o s / r)/2^u。
  - E > N + γ（o = E − N − γ）：c″ = c_o s / r、K″ = 0、b″ = 2^o b′ + q c_o s / r。

**証明**：

- 恒等式 r(αa − c) = βa − cs·2^N は、α、β、c が有理数でも成り立つ（qa + r = s·2^N による）。
- 越える場面の後の奇数の距離は d′ = (b′a − c_o s)/(r·2^u)（E > N + γ では (2^o b′a − c_o s)/r）。
- これを β″a − c″s·2^N の形に書くと、sX = qa + r から c″r = c_o s、β″ = b′ + q c″ となる。
- 分母は奇数なので、2 の付値は分子だけで決まる。よって、b の写像 T(b) = (b + 3r)/2^{v2(b+3r)}、終点の v2、段数の偶奇の議論は、命題 K57・K61 と同じに進む。∎

r = ±1 では 1/r = r なので、命題 K61 の式と同じになる。

## 結果（`data/k62_general_r.txt`）

4308 族（うち r = ±1 が 1706 族）で比べた。

- 有理数の規則：すべての族で、予測した先頭の m+2 の連の長さが実際と一致した。
- 整数の規則（命題 K61 の式を r ≠ ±1 に当てたもの）：1 族で外れた。
  - q = 497、r = 5、s = 839、N = 109 で、実際は 26、有理数の規則は 26、整数の規則は 27。
  - 一般の r では命題 K61 の式はそのままでは正しくなく、1/r で考える必要があることが、実例でも確かめられた。
  - 前のサイクル（Issue #357）の 505 族では、2 つの規則の予測が食い違う族がなく、区別できていなかった。
- 予想 K45 の族（q = 29、r = 4641、s = 1）では、先頭の連の長さ 3 を再現した（命題 K57 の観察と同じ）。
