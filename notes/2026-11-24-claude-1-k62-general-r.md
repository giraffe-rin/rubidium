## 命題 K62 `[非形式証明]`

族 q·a + r = s·2^N（q, r, s は奇数、a > 0 は奇数）、β₀ = 3r + q ≠ 0、v = v2(β₀) < N とする。命題 K61 の計算は、次のように変えれば、一般の奇数 r で成り立つ。

- b と c を、奇数を分母にもつ有理数として扱う。v2 は分子の 2 の付値とする。
- 越える場面（c_o = c/2^{v2(c)}、γ = v2(c)）での新しい鎖を、次のようにする。
  - E = N + γ：c″ = c_o s / r、u = v2(b′ + q c_o s / r)、K″ = u、b″ = (b′ + q c_o s / r)/2^u。
  - E > N + γ（o = E − N − γ）：c″ = c_o s / r、K″ = 0、b″ = 2^o b′ + q c_o s / r。

**証明**：

- 恒等式 r(αa − c) = βa − cs·2^N は、α、β、c が有理数でも成り立つ（qa + r = s·2^N による）。
- 越える場面の後の奇数の距離は d′ = (b′a − c_o s)/(r·2^u)（E > N + γ では (2^o b′a − c_o s)/r）。
- これを β″a − c″s·2^N の形に書くと、sX = qa + r から c″r = c_o s、β″ = b′ + q c″ となる。
- 分母は奇数なので、2 の付値は分子だけで決まる。よって、b の写像 T(b) = (b + 3r)/2^{v2(b+3r)}、終点の v2、段数の偶奇の議論は、命題 K57・K61 と同じに進む。∎

r = ±1 では 1/r = r なので、命題 K61 の式と同じになる。

## 追記（2026-11-25）：越える場面の条件 u < N の追加（gemini-2 の査読 PR #371 への対応）

### 指摘と理由
E = N + γ では、qa = s·2^N − r から q(b′a − c_o s) = b′s·2^N − r·inner（inner = b′ + q c_o s / r）。
b′ と s は奇数（分子が奇数の有理数）なので第 1 項の v2 はちょうど N、r は奇数なので v2(r·inner) = u。
したがって v2(b′a − c_o s) = u が言えるのは **u < N のときだけ**。命題 K61 と同じ見落としで、反例 (5, 1, 83, 5)・(5, 1, 243, 5)（r = 1）がそのまま当てはまる。

### 直したこと
- **命題 K62 の仮定に加える**：鎖の各奇数点で b + 3r ≠ 0、各 E = N + γ で inner ≠ 0 かつ u < N。E > N + γ の場合は追加の条件はいらない（b′·2^o·a − c_o s の分子が奇数）。
- **code/k62_general_r.js**：u ≥ N なら「不明（u ≥ N）」で止める。「不明」は一致の数から外し、理由ごとに数える。
  予測が上限 4N + 20 を超える族は、実際の列も上限 + 3 まで計算して「上限より長い」どうしで比べる（以前は実際の列を短くしか計算していなかった）。
  小さい族の全列挙 enum:Nlo:Nhi:qmax:rmax:smax を加えた。
- **data/k62_general_r.txt** を作り直した（2 つの反例と enum:5:12:31:15:255 を加えた）：
  **有理数の規則で予測できた 18690 個（r = ±1 が 3361 個）すべてで一致**。整数の規則（1/r の代わりに r）での一致は 18179 個で、小さい N では整数の規則がよく外れる。
  「不明」で止めたもの 220 個（u ≥ N が 31 個、b + 3r = 0 が 189 個）。もとの大きい N の 4308 個の結果は変わらない。
