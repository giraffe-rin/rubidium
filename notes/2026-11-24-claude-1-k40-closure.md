# 予想 K40：周期の始まりで参照される事実の分類

## やったこと

- `code/k40_closure.js` で、N = 22〜220 の 8 個について、各周期の始まり B = 0, P, 2P（P = N/2）で参照された事実を分類した（`data/k40_closure.txt`）。
  - 奇数
  - v2 = 1
  - d₁ = (9a − 1)/4 とその半分
  - その他
- 奇数の事実と v2 = 1 の事実は、ブロック 0（K3）でも E 型ブロックでも、規則だけで値が決まる。
  - 奇数は入る。
  - v2 = 1 は、半分が奇数で入るので、(i) により入らない。
  - そのため、周期が変わっても値は同じになる。

**前提**：ブロック漸化式 R。

## 結果 `[予想]`（観察）

- どの N、どの B でも、奇数の事実はすべて「入る」、v2 = 1 の事実はすべて「入らない」だった（規則どおり）。
- それ以外の事実：
  - d₁：どの始まりでも入らない。ブロック 0 では v2(d₁) = 3（奇数）なので K3 から、E 型の始まりでは直前の O 型ブロックで g = (21a − 5)/8 が入ることから（前のログ）。
  - d₁/2：E 型の始まりでだけ参照される（N/2 が奇数なら入る、偶数なら入らない）。d₁ を求めるときの (i) の確認で現れる。
  - N/2 が偶数のときだけ、v2 = 4 の距離 X が 1 つ現れる。ブロック 0 と P で入る。B = P では、その半分（v2 = 3, 2）も入らないとして参照される。
- したがって、証明（周期についての帰納法）で、自動的に一致しないものは次の 2 つだけになる。
  - (1) E 型の始まりで d₁ が入らないこと（直前の O 型ブロックで g が入ること）
  - (2) N/2 が偶数のとき、E 型の始まりで X が入ること
  - どちらも、直前の周期の O 型ブロックの値から決まる。その値は鎖をたどると、その周期の始まりの「奇数・v2 = 1・d₁」の事実だけで決まる（鎖の形は前のログのとおり N によらない）。
