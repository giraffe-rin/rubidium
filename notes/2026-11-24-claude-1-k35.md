- k = 5, 6 で、型を決めるのに参照される (ブロック, 距離) を書き出した。距離は 2 本の鎖と数個の距離だけだった。これを一般の k で証明した。

**前提**：主張 H(j)、定理 K3（gemini-2 が PR #111 で `[査読済み]` にした。PR は未マージ）、定理 K32 の補題 Q_n（`notes/2026-11-24-claude-1-type-runs.md`、`[非形式証明]`、未査読）。

## 結果

### 定理 K35 `[非形式証明]`

k ≥ 2 で m = (3·16^k − 13)/5 なら、v2(m+1) = 3 で、型は前周期なし、周期 1^{2k−1} 0 0（L = 2k + 1）。
- 例：k = 2 で m = 151、型は 11100。k = 3 で m = 2455、型は 1111100。

### 系 K35b `[非形式証明]`

v2(m+1) = 3 の m の型は無限に多い。系 K33b（v2(m+1) = 1）と合わせると、予想 K31 の前半は v2(m+1) = 1, 3 で成り立つ。

### 証明

**記号と合同式**：
- a := (16^k − 1)/5（奇数。2 進表示は 0011 のくり返し）
- M := m + 2 = 3a、m = 3a − 2、h = (m+1)/2 = (3a − 1)/2
- k ≥ 2 なら 16^k ≡ 0 (mod 64) なので、5a ≡ −1、a ≡ 51 (mod 64)。これから次が出る。
  - 3a − 1 ≡ 24 (mod 64)：v2(h) = 2、h/4 = (3a − 1)/8 は奇数。
  - 27a − 1 ≡ 32 (mod 64)：d3 := (27a − 1)/16 は v2(d3) = 1、d4 := d3/2 は奇数。
  - 9a − 3 ≡ 8 (mod 64)：3h/2 = (9a − 3)/4 は v2 = 1、w := (9a − 3)/8 は奇数。
- v2(m+1)：m + 1 = (3·16^k − 8)/5 = 8(3·2^{4k−3} − 1)/5 なので v2(m+1) = 3。
- 鎖：
  - y_i := 2a − 4^i（0 ≤ i ≤ 2k − 3）。i ≥ 1 では v2(y_i) = 1、y_0 は奇数。
  - z_i := a − 2·4^i（奇数）。y_i / 2 = z_{i−1}、(M + z_i)/2 = y_i。
  - c_t := M − 3·2^t（奇数、t ≥ 1）。(M + c_t)/2 = c_{t−1}。
- つながり（5a + 1 = 16^k を使う）：
  - (M + h/4)/2 = d3
  - (M + d4)/2 = (123a − 1)/64 = 2a − 16^k/64 = y_{2k−3}
  - (M + w)/2 = (33a − 3)/16 = M − 3(5a+1)/16 = c_{4k−4}
  - (m+1+h)/2 = 3h/2
- 大きさ：
  - 上の距離はどれも 1 以上 m 以下（y_i < 2a、c_t ≤ M − 6 < m、d3 < 2a など）。
  - 奇数の距離はどれも h − 1 = (3a − 3)/2 と違う。z_i < a、d4 < a、h/4 < a、y_0 = 2a − 1、c_t ≥ c_{4k−4} > 2a。
  - 偶数の距離は、奇数の h − 1 とは当然違う。

**O 型ブロック（1 つ前の間隔が m+2）の規則**（定理 K33a のログと同じ）。M は奇数なので：
- (O1) 奇数の d ≠ h − 1 で (M+d)/2 ≤ m なら、[d ∈ S_j] = ¬[(M+d)/2 ∈ S_{j−1}]
- (O2) 偶数の d ≠ h − 1 なら、[d ∈ S_j] = ¬[d/2 ∈ S_j]

**始まりのブロックの性質 (Z)**：ブロック B で次が成り立ち、g_B = m+2 であること。
- d3 ∉ S_B
- y_i ∉ S_B（1 ≤ i ≤ 2k−3）、y_0 ∈ S_B
- c_{2k−2} ∈ S_B

成り立つブロック：
- ブロック 0（K3：d ∈ S_0 ⇔ v2(d) 偶数）：v2 はそれぞれ 1、1、0、0 なので (Z) が成り立つ。v2(h) = 2 は偶数なので h ∈ S_0、g_0 = m+2。
- 2 番目の E 型ブロック（m+1 の間隔が 2 つ続いた直後）：補題 Q_2 により、v2(d) ≤ min(3, v−1) = 2 の d は「d ∈ S ⇔ v2(d) 偶数」。よって (Z) の値はブロック 0 と同じ。h も v2(h) = 2 で入るので、間隔は m+2。

**主張**：ブロック B が (Z) を満たすとき、次が成り立つ。
- g_{B+1}, …, g_{B+2k−2} = m+2
- g_{B+2k−1} = m+1
- g_{B+2k} = m+1
- ブロック B + 2k + 1 は (Z) を満たす

証明：
- **(a) O 型ブロックでの h**：ブロック B+1, …, B+n が O 型のとき、(O2) を 2 回（h、h/2 は偶数）、(O1) を 1 回（h/4 は奇数）使って、[h ∈ S_{B+n}] = [h/4 ∈ S_{B+n}] = ¬[d3 ∈ S_{B+n−1}]。
  - n = 1：(Z) より d3 ∉ S_B なので h ∈ S_{B+1}。
  - n ≥ 2：ブロック B+n−1 も O 型。(O2)(O1) で [d3 ∈ S_{B+n−1}] = ¬[d4 ∈ S_{B+n−1}] = [y_{2k−3} ∈ S_{B+n−2}]。
- **(b) 鎖 y**：O 型ブロック j では、(O2)(O1) で [y_i ∈ S_j] = ¬[z_{i−1} ∈ S_j] = [y_{i−1} ∈ S_{j−1}]（1 ≤ i）。
  - くり返すと、t ≤ i で [y_i ∈ S_{B+t}] = [y_{i−t} ∈ S_B]。
  - (a) と合わせて、2 ≤ n ≤ 2k−1 で [h ∈ S_{B+n}] = ¬[y_{2k−1−n} ∈ S_B]。
  - (Z) により、これは n ≤ 2k − 2 で T、n = 2k − 1 で F。
  - よって g_{B+1}, …, g_{B+2k−2} = m+2、g_{B+2k−1} = m+1（ブロックが O 型であることは順に保証される）。
- **(c) 1 番目の E 型ブロック B+2k での h**：h は偶数。
  - (i)：v2(h/2) = 1 なので、補題 Q_1 により h/2 ∉ S。(i) は起きない。
  - (ii)：(m+1+h)/2 = 3h/2 ≤ m なので、[h ∈ S_{B+2k}] = ¬[3h/2 ∈ S_{B+2k−1}]。(iii) は 1 つ前の間隔が m+1 なので起きない。
  - ブロック B+2k−1 は O 型なので、(O2)(O1) で [3h/2 ∈ S_{B+2k−1}] = ¬[w ∈ S_{B+2k−1}] = [c_{4k−4} ∈ S_{B+2k−2}]。
  - 鎖 c は (O1) で [c_t ∈ S_j] = ¬[c_{t−1} ∈ S_{j−1}]（O 型ブロック j）。ブロック B+1, …, B+2k−2 は O 型なので、2k − 2 回くり返して [c_{4k−4} ∈ S_{B+2k−2}] = [c_{2k−2} ∈ S_B] = T（2k − 2 は偶数、(Z)）。
  - よって 3h/2 ∈ S_{B+2k−1}、h ∉ S_{B+2k}、g_{B+2k} = m+1。
- **(d)**：ブロック B+2k+1 は 2 番目の E 型ブロックなので、上で見たとおり (Z) を満たし、間隔は m+2。∎

**定理の証明**：ブロック 0 は (Z) を満たす。主張をくり返し当てはめると、間隔の列は (1^{2k−1} 0 0) のくり返しになる。∎
