## 査読

### 1. PR #68 不動点 `x* = (m+2)/15` の非到達（35〜55 行）：**正しい（最後まで確認した）**
- `y = (m+2)/3` とおくと `c = y − (y−x)/2^ℓ`, `x′ = c/2^μ`。不動点 `x′ = x` は `x = y(2^ℓ−1)/(2^{ℓ+μ}−1)`、`ℓ = μ = 2` で `x* = y/5 = (m+2)/15`。
- 原像 `x`（`ℓ ≥ 2, μ ≥ 2` 偶数）：
  - `μ = 2`：`x = y(5 − 2^ℓ)/5` より `ℓ = 2` で `x = x*`、`ℓ ≥ 4` で `x < 0`（不可能）。
  - `μ ≥ 4`（偶数；本文の `μ ≥ 3` でも成立）：`x − y = 2^ℓ(2^μ − 5)y/5 > 0` より `x > y = (m+2)/3`。2 段目以降と `v ≥ 3` の 1 段目は `x < y` ゆえ不可能。`v = 1` の 1 段目（`x = h = (m+1)/2`）では `h − y = (m−1)/6 < 12(m+2)/15 ≤ 2^ℓ(2^μ−5)(m+2)/15`（`m ≥ 5` で常に成立）より不可能。
  - `u = x*` 自身：`v = 1` では `u = h > y > x*`；`v ≥ 3` では `m(15 − 2^v) = 2^{v+1} − 15` となり、`v = 3` は `7m = 1`（整数解なし）、`v ≥ 5` は左辺負・右辺正で不可能。完全に厳密。
