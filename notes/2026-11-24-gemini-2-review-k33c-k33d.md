## 数学的査読

### 1. 補題 K33d（PR #324）→ **`[査読済み]`**

- **主張**：奇数 $m \ge 3$（E 型・O 型ブロックの定義域）と任意の E 型ブロック $B$（$L_B - L_{B-1} = m + 1$）に対し、$1 \le d \le m$ かつ $v_2(d) = 1$ を満たす距離 $d$ は $d \notin S_B$ である。
- **前提確認**：$H(j)$・$K3$・$K8$ の E 型遷移規則（すべて `[査読済み]`）。$v = v_2(m + 1)$ の値には依存しない（$v = 1$ でも、$v$ が偶数でも成立）。
- **証明の完全性確認（`PROBLEM.md` からの直接確認を含む）**：
  1. $m = 2h - 1$ が奇数なので $m + 1 = 2h$ は偶数。E 型ブロック $B$ の直前の負け位置は $L_{B-1} = L_B - 2h$ であり、$(L_{B-1}, L_B)$ に負け位置はない。
  2. 任意の奇数 $d$（$1 \le d \le m$）に対して、$d = 2d'$ も $2e' = 2h + d$ も整数解を持たないため、局面 $(L_B + d, d)$ から合法手 $k \neq d$ で負け局面に遷移できない。よって $d \in S_B$（E 型ブロックではすべての奇数距離が入る）。
  3. 任意の偶数 $d$（$1 \le d \le m$）に対して、$d \in S_B$ となる必要条件として $d/2 \notin S_B$ が要請される（もし $d/2 \in S_B$ なら手 $k = d/2 \neq d$ で負け局面 $(L_B + d/2, d/2)$ に移れるため）。
  4. $v_2(d) = 1$ なら $d$ は偶数かつ $d/2$ は $1 \le d/2 \le (m-1)/2 < m$ の奇数である。ステップ 2 より $d/2 \in S_B$、ステップ 3 より $d \notin S_B$。
  5. なお $m = 1$ では $v_2(d) = 1$ の $d \in \{1\}$ が存在せず自明に成立。ブロック 0（$L_0 = 0$）については K3 により $v_2(d) = 1$（奇数）なので同じく $d \notin S_0$ が成り立つ。
- **結論**：証明に論理的欠陥・抜け・暗黙の仮定はない。`[査読済み]` に昇格する。
  - 軽微な明記の補足：E 型ブロックは奇数 $m$ の枠組みで定義されるため、主張中も「奇数 $m$ に対して」を明示すると一層明確である（偶数 $m$ では $m+1$ が奇数となるため議論の前提外）。

### 2. 命題 K33c および `code/period_induction.js` の変更（PR #322）

- **`code/period_induction.js` の変更監査**：
  - 変更は `prove` 成功時の返り値オブジェクトに `Aset: [...A.entries()]` を追加する 1 行のみ。帰納法の判定条件・再帰評価・終了条件には一切影響せず、健全性を損なわない。
- **5 族の代数的整合性確認（すべての奇数 $e \ge 9$、$X = 2^e$、$m = 9X + 1$）**：
  1. $7X - 2^{e-2} + 2 = 6.75 X + 2$：$e \ge 9$ より $4 \mid (7X - 2^{e-2})$ なので $\equiv 2 \pmod 4$、$v_2 = 1$、範囲 $(0, m)$ 内。
  2. $5X - 2^{e-3} + 2 = 4.875 X + 2$：同じく $v_2 = 1$、範囲内。
  3. $6X + 6 \cdot 4^j + 2$（$0 \le j \le (e - 5)/2$、$(e - 3)/2$ 個）：
     - $j = 0$ のみ $6X + 8$ となり、$e \ge 9$ より $16 \mid 6X$ なので $v_2(6X + 8) = 3$。
     - $j \ge 1$ はすべて $\equiv 2 \pmod 4$ で $v_2 = 1$。最大値は $6.1875 X + 2 < 6.75 X + 2 < m$。
  4. $6X - 9 \cdot 4^{j+1} + 2$（$0 \le j \le (e - 7)/2$、$(e - 5)/2$ 個）：すべて $\equiv 2 \pmod 4$ で $v_2 = 1$。範囲 $[5.71875 X + 2,\, 6X - 34]$。
  5. $6X + 1442$：$1442 = 2 \times 721$ より $v_2 = 1$。$e \ge 9$（$X \ge 512$）で $6X + 1442 \le 4514 < 4609 = m$（$e = 7$ では $2210 > 1153 = m$ のため範囲外であり、K33c が $e \ge 9$ から始まる理由と整合）。
  - **重複がないことの確認**：$6 \cdot 4^j = 1440 \iff 4^j = 240$（解なし）、$0.75 \cdot 2^e = 1440 \iff 2^e = 1920$（解なし）より、上記 5 族はすべての奇数 $e \ge 9$ で互いに素であり、総数は $1 + 1 + (e-3)/2 + (e-5)/2 + 1 = e - 1$、そのうち $v_2 = 1$ がちょうど $e - 2$ 個、$v_2 = 3$ が $6X + 8$ の 1 個のみ。
- **ラベルの確認**：命題 K33c および PR #324 の系（仮定が $6X + 8 \notin S_B$ の 1 個に減ること）はいずれも有限範囲（$9 \le e \le 199$ 奇数）での計算結果であり、PR 本文・ログでも「計算による」「まだ証明ではない」と正しく位置づけられている。
