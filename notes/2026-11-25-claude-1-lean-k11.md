# 定理 K11（v2(m+1) ≥ 5 の奇数なら交互型でない）の Lean 4 での形式化

## やったこと

`lean/Rubidium/K11.lean` に、定理 K11 を sorry なしで証明した。

```lean
theorem K11 (m v u : Nat) (hmv : m + 1 = 2 ^ v * u) (hvo : v % 2 = 1) (hv5 : 5 ≤ v) (hu : u % 2 = 1) : ¬ Alt m
```

公理は `[propext, Classical.choice, Quot.sound]`。`Classical.choice` は、命題の同値の変形で使った `Classical.byContradiction` から入った。

## 証明の組み立て

もとの証明（ノート 2026-11-23-claude-1-proof-k10c-k11.md の定理 K11）の場合分けを、局面の言葉で書いた。b = m+2、c = 2m+3。

**一般の補題**：PR #406 の K10c の補題を、h が偶数で ev2(h) = true の場合に広げた。
- `g_even`：偶数 d について、(b + d, d) が P ⇔ (b + d/2, d/2) が N。
- `g_odd`：奇数 d について、(b + d, d) が P ⇔ ev2((m+2+d)/2) = false（K3）。
- **`g_iter`**：(b + 2^i·x, 2^i·x) が P ⇔ ((b + x, x) が P ⇔ i が偶数)。`g_even` を使った、i についての帰納法。
- `g_blk2_even`：行 c の偶数 d について、(c + d/2, d/2) と (b + h + d/2, h + d/2) がどちらも N なら、(c + d, d) は P。
- `g_notalt_b`：(b + h, h) が P なら、交互型でない（(2m+3, 0) が N になる）。
- `g_notalt_c`：行 c がすべての p で P で、(c + h, h) が N なら、交互型でない（(3m+4, 0) が P になる）。

**変数の置き方**：v = 2s + 5、w = 4^s·u とおく。すると m + 1 = 32w、h = 16w で、2^(2s+j)·(c·u) = (2^j·c)·w。
こうすると、もとの証明に出てくる距離 3·2^{v−2}·u、5·2^{v−3}·u、9·2^{v−4}·u、2^{v−3}·u、2^{v−2}·u が、それぞれ 24w、20w、18w、4w、8w という w の 1 次式になり、omega で扱える。
ev2(16w) = ev2(u) = true は、`ev2_four`（ev2(4x) = ev2(x)）と `ev2_pow4` で示した。

**場合分け**：X₁ = (m+2+u)/2 とおく。
- ev2(X₁) = false のとき：
  - (b + u, u) は P。`g_iter`（i = 2s+4、偶数）より (b + h, h) は P。
  - `g_notalt_b` より交互型でない。
- ev2(X₁) = true のとき：まず (b + h, h) は N なので、行 c はすべての p で P。
  - u ≡ 3 (mod 4) なら：
    - X₃ は奇数なので、(b + 3u, 3u) は N。
    - i = 2s+3（奇数）より、(b + 24w, 24w) は P。
    - (c + h, h) は、手 24w で (b + 24w, 24w) に移れるので N。`g_notalt_c` より交互型でない。
  - u ≡ 1 (mod 4) なら：
    - X₅・X₉ は奇数なので、(b + 5u, 5u)・(b + 9u, 9u) は N。
    - i = 2s+2（偶数）より (b + 20w, 20w) は N。i = 2s+1（奇数）より (b + 18w, 18w) は P。
    - (c + 4w, 4w) は N（手 18w）。(c + 8w, 8w) は P（`g_blk2_even`）。(c + h, h) は N（手 8w）。
    - `g_notalt_c` より交互型でない。

## 意味

- 定理 K11 が [Lean検証済み] の候補になった（査読待ち）。
- 交互型の分類（ノートの表）のうち、Lean で確かめられたものは次のとおり。
  - v2(m+1) 偶数：K4
  - v2(m+1) = 1：K9（同値）
  - v2(m+1) = 3：必要条件 K10c（u ≥ 3）と十分条件 K10 (a)
  - v2(m+1) ≥ 5 の奇数：K11
- 残りは、v2(m+1) = 3 の u = 1 と、v2(11u+1) ≥ 4 の偶数の場合（これはもとの証明でも未解決）。
