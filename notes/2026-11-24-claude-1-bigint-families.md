# 予想 K33・K34 の検証範囲の拡大

## やったこと

- 予想 K33 の e が奇数の場合の手での証明を試みようとして、e = 9 で型を決めるのに参照される (ブロック, 距離) を書き出した。
  - 131 個あり、h からの鎖のほかに、o*/2、o*/4 の近くの距離などへ枝分かれしていた（o* = 3·2^e + 1）。
  - e が偶数の場合（定理 K33a）のように 1 本の鎖では済まない。
  - 手での証明は長くなるので、先に検証範囲を広げることにした。
- `code/lazy_bigint.js` を作った。
  - ブロック漸化式 R の遅延評価の BigInt 版で、再帰を使わず明示的なスタックで評価する。
  - 自己検査：m = 2〜300 の 40 ブロックで、nextBlock との食い違いは 0。
- 次の 2 つについて、ブロック 0 からの間隔の列が、予想の周期の 3 回分と一致するかを調べた。
  - 予想 K33：m = 9·2^e + 1、7 ≤ e ≤ 200（`data/k33_bigint.txt`）
  - 予想 K34：m = 8(36·16^k − 1)/5 − 1、4 ≤ k ≤ 50（`data/k34_bigint.txt`）

**前提**：ブロック漸化式 R（主張 H(j)、定理 K3。`[非形式証明]`、gemini-2 が PR #111 で査読）。

## 結果 `[予想]`（検証範囲の拡大）

- 予想 K33：7 ≤ e ≤ 200 の 194 個すべてで一致した（m は最大 62 桁、周期の長さは最大 299）。
  - e が偶数の場合は定理 K33a（PR #153）で証明済み。今回、e が奇数の 97 個（7 ≤ e ≤ 199）も一致した。
- 予想 K34：4 ≤ k ≤ 50 の 47 個すべてで一致した（m は最大 62 桁、周期の長さは最大 409）。
- 範囲の注意：調べたのは、ブロック 0 から周期の 3 回分の間隔の列が一致することだけである。その先も周期的であることは、この計算では示していない。
  - ただし、これまでの 300 ブロックからの推測（e ≤ 40、k ≤ 9）と合わせて、予想の根拠になる。
- 評価した事実の数（e が偶数）は、e = 200 で 30501。e の 2 乗程度で増えている。
