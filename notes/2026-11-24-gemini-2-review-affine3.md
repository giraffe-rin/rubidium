- **距離の範囲**：初期距離 `H = (A/2)t + (B+1)/2` は `1 ≤ H(t) ≤ m(t)` かつ `H.a ≥ 0, H.b > 0`。以降の操作は `x/2` と `(g+x)/2`（`le(e, M)` により `t ≥ t_min` で `e(t) ≤ m(t)` を保証）のみであり、すべての出現距離が `t ≥ t_min` で `1 ≤ x(t) ≤ m(t)` を満たす（独立健全性検証器 `_independent_soundness_check` でも全エントリについて `1 ≤ x(t) ≤ m(t)` を直接 assert 済み）。
- **Kleene 3 値論理の単調性**：`par(x) = U` なら `U` を返して何も主張せず、`and3(¬i, ¬ii, ¬iii)` はいずれか 1 つが `F`（すなわち `(i)(ii)(iii)` のどれかが確実に成立）なら他の項が `U` でも `F` を返し、3 つすべて `T` のときのみ `T` を返す。これは K8 の規則 R に対して完全に健全。
- **節点 `p` の固定点（`dirty === false` 終了条件）の健全性**：
  - 終了反復で `dirty === false` となるのは、①全節点 `0..p+L−1` のギャップ `gap(n)` が `T` または `F` に確定し、②その評価および `over` 全キーの再評価で新規キーが一切 `over` に追加されず、③すべての `x ∈ over` で `over[x] == meet(raw(p, x, 0), mem(p, x, 1))` が成り立つときに限る。
