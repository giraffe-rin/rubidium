# 定理 K47b：w = v の類の型は無限に多い

## やったこと

- w = v の類で、族 q·a + r = s·2^N（q = 2^v − 3r）を r を動かして数値で調べた（その場のスクリプト）。
  - w = v になるのは v2(3r + 1) ≥ v + 1 のときで、このとき q < 0 になるか、q > 2^v になる。
  - v = 5 の r = 21（q = −31）と、v = 7 の r = 85（q = −127）で、先頭の m+2 の連が N とともに伸びた。
- これは定理 K47 の式 q = 2^v − 2^ρ + 1、r = (2^ρ − 1)/3 で ρ = v + 1 とした場合だった。ρ = v + 1 は偶数で、q = −(2^v − 1)。

  - w = ρ の計算。
  - 奇数の点での 0 < d < a の評価。
- この 2 か所を ρ = v + 1 用に直した。

## 定理 K47b `[非形式証明]`

v ≥ 3 は奇数とし、Q = 2^v − 1、r = (2^{v+1} − 1)/3 とする。N は偶数で N ≥ 2v + 2、σ は奇数で Q | σ·2^N + r とする。a = (σ·2^N + r)/Q、m = 3a − 2 とおく。このとき、次が成り立つ。

1. v2(m+1) = v、w = v2(u+1) = v。
2. 間隔の列の先頭は、ちょうど R = ⌈(N − v)/(v + 1)⌉ 個の m+2 の後に m+1。

系：各奇数 v ≥ 3 で、v2(m+1) = v、w = v の m の型は無限に多い。

### 証明（定理 K47 との違いだけ）

q = −Q、s = −σ とおくと q·a + r = s·2^N、q + 3r = 2^v、1 + 3r = 2^ρ（ρ = v + 1）で、定理 K47 と同じ形になる。a は奇数（分子 σ·2^N + r が奇数）で正。

**1 の証明**：

- 3a − 1 = (3sX − 2^v)/q から v2(m+1) = v。
- u + 1 = (3sX/2^v + 2^v − 2^{v+1})/q = (3sX/2^v − 2^v)/q。3sX/2^v の付値は N − v ≥ v + 2 > v なので、v2(u+1) = v。

**2 の証明**：鎖の記述（恒等式 d = (βa − sX)/(r·2^K) と、b = 1 にとどまる鎖）は、定理 K47 の証明と同じ。

- 奇数の点では d = (a − s·2^{N−K})/r = (a + σ·2^{N−K})/r。
- これは正で、K ≥ v と σ·2^N < Qa から σ·2^{N−K} ≤ σ·2^{N−v} < a。
- よって d < 2a/r ≤ 2a/5 < a（r ≥ 5）。
- したがって (M+d)/2 < 2a ≤ m、d < h − 1 で、一本道の例外は起こらない。

段数の偶奇（ρ は偶数、v は奇数）と終点の付値の計算（N − v は奇数なので、N − v = ρk + e、e は奇数で 1 ≤ e ≤ ρ − 1）は、定理 K47 と同じ。よって R = k + 1 = ⌈(N − v)/ρ⌉。∎

### 予想 K38 の残りの類のまとめ

v ≥ 5 が奇数、w = v2(u+1) とする。

- w = 1：型は 1 0^{(v−1)/2}（定理 K29）。
- w が奇数で 3 ≤ w ≤ v − 2、または w ≥ v + 1：型は 1 0^{(v+1)/2}（定理 K38）。
- w が偶数で w ≤ v − 1：型は無限に多い（定理 K47）。
- w = v：型は無限に多い（定理 K47b）。

これで、K38 の「どちらでもない」類のどれにも、有限個の型の一覧はないことが分かった。
