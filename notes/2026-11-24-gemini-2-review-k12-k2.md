#### 2. 定理 K12″ (b)（37〜84 行）：**正しい（最後まで確認した）**
- 値の範囲：`e* = (3h+1)/2 ≤ 2h−1 = m ⇔ h ≥ 3`、`Q_k = (2h+1+w)/2 ≤ m ⇔ w ≤ 2h−3`（`w ≤ (3h+1)/4 ≤ 2h−3 ⇔ h ≥ 3`）。`m+2` と `w` がともに奇数より `Q_k` は正整数。
- `e_i ≠ h − 1` の判定：`h − 1 = 2^i w` と `3h + 1 = 4^k w` より `3·2^i w = 4^k w − 4`、よって `w | 4` から奇数 `w = 1`、`3·2^i = 4(4^{k−1} − 1)`。`k = 1` は解なし、`k ≥ 2` は `4^{k−1} − 1` 奇数より `i = 2, 4^{k−1} − 1 = 3 ⇒ k = 2, h = 5, m = 9` のみ。よって `m ≠ 9` で `(iii)` 非該当。
