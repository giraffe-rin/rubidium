# 定理 K40a と系 K39

## やったこと

- 予想 K40 の証明の骨格（`notes/2026-11-24-claude-1-k40-skeleton.md`）で使った鎖を、記号的に書いた。
  - それぞれの鎖は「入口（有限個の段）」「幾何的な部分」「終わり」に分かれる。
  - 入口の値を (αa + β)/2^k の形でたどり、幾何的な形に入る等式（23a + 1 = 2^N による）を求めた。
- 各段の値と段数を `code/check_k40a.js` で N = 22, 44, …, 440 について確かめた（`data/k40a_check.txt`）。証明は記号的な等式によるので、すべての N で成り立つ。

**前提**：主張 H(j)、定理 K3（査読済み）。O 型・E 型ブロックの規則（K33a・K35 のログ）。

## 結果

### 定理 K40a `[非形式証明]`

N ≥ 22、N ≡ 0 (mod 22)（このとき 23 | 2^N − 1 で、N は偶数）とし、a := (2^N − 1)/23、m := 3a − 2 とする。このとき m ≡ 9 (mod 32) で、型は前周期なし、周期 1^{N/2−1} 0。

### 系（予想 K39）`[非形式証明]`

m ≡ 9 (mod 32)（v2(m+1) = 1）の m の型は無限に多い。定理 K40a の m は、N ごとに周期の長さ N/2 が違うからである。

### 証明

**記号**：
- P := N/2
- M := m + 2 = 3a、h := (m+1)/2 = (3a − 1)/2（奇数）
- d₁ := (9a − 1)/4、X := (13a − 5)/8
- 23a + 1 = 2^N
- N ≥ 12 なので a ≡ −1/23 ≡ 2137 (mod 4096)。ここから次が出る。
  - m = 3a − 2 ≡ 9 (mod 32)
  - v2(d₁) = 3（9a − 1 ≡ 32 (mod 64)）
  - v2(13a − 5) = 7（13·2137 − 5 = 27776 = 2^7·217）なので v2(X) = 4

**規則**：
- O 型ブロック（1 つ前の間隔が m+2）では、奇数の d ≠ h − 1 は 1 つ前のブロックの (M + d)/2 の否定、偶数の d は同じブロックの d/2 の否定（一本道）。
- E 型ブロック（1 つ前の間隔が m+1）では、奇数は入る。偶数の d は ¬[d/2 ∈ S_E] ∧ ¬[h + d/2 ∈ S_{E−1}]。

**2 種類の幾何的な鎖**（c は奇数）：
- (A) 2a − c·2^t（t ≥ 2）：半分にすると a − c·2^{t−1}（奇数）。(M + a − c·2^{t−1})/2 = 2a − c·2^{t−2}。
  - 1 ブロック下るのに 2 段で、t は 2 減る。
- (B) M − c·2^t（t ≥ 1、奇数）：(M + M − c·2^t)/2 = M − c·2^{t−1}。
  - 1 ブロック下るのに 1 段で、t は 1 減る。

**6 本の鎖**：ブロックは周期の始まり B からの相対位置で書く。最後の O 型ブロックは P − 1。入口は (αa + β)/2^k の形でたどる。
- **h（ブロック n、1 ≤ n ≤ P−1）**：
  - h（奇数）→ ブロック n−1 で d₁ → d₁/2 → d₁/4 = (9a − 1)/16 = 2a − 2^{N−4}（32 − 9 = 23）。
  - 以後 (A)（c = 1）でブロック 0 まで進み、2a − 2^{N−2n−2} に着く。段数は 2n + 1。
  - n = 1 なら、ブロック 0 の d₁ で止まる（1 段）。
- **g = (21a − 5)/8**（ブロック P−1）：
  - 入口：→（ブロック P−2）(45a − 5)/16 → (45a − 5)/32 →（ブロック P−3）(141a − 5)/64 → (141a − 5)/128 = 2a − 5·2^{N−7}（256 − 141 = 115 = 5·23）。
  - (A) でブロック 1 の 2a − 10 まで進む。
  - 終わり：a − 5 → (a − 5)/2 → (a − 5)/4（奇数）→（ブロック 0）X。
  - 段数は 4 + 2(P − 4) + 4 = N。
- **f = (33a − 9)/16**：
  - 入口：→ (81a − 9)/32 → (177a − 9)/64 → (177a − 9)/128 = M − 9·2^{N−7}（384 − 177 = 207 = 9·23）。
  - (B) でブロック 0 の M − 9·2^{P−4}（奇数）に着く。段数は P。
- **h + X/8 = (109a − 37)/64**：
  - 入口：→ (301a − 37)/128 → (685a − 37)/256 → (685a − 37)/512 = M − 37·2^{N−9}（1536 − 685 = 851 = 37·23）。
  - (B) でブロック 0 の M − 37·2^{P−6}（奇数）に着く。段数は P。
- **h + X/4 = (61a − 21)/32**：
  - 入口：→ (157a − 21)/64 → (157a − 21)/128 → (541a − 21)/256 → (541a − 21)/512 = 2a − 21·2^{N−9}（1024 − 541 = 483 = 21·23）。
  - (A) でブロック 2 の 2a − 42 まで進む。
  - 終わり：a − 21 → (a − 21)/2 → (a − 21)/4（奇数）→（ブロック 1）(13a − 21)/8 → (13a − 21)/16（奇数）→（ブロック 0）(61a − 21)/32（奇数）。
  - 段数は 4 + 2(P − 5) + 6 = N。
- **h + X/2 = (37a − 13)/16**：
  - 入口：→ (85a − 13)/32 → (85a − 13)/64 → (85a − 13)/128 = M − 13·2^{N−7}（384 − 85 = 299 = 13·23）。
  - (B) でブロック 0 の M − 13·2^{P−5}（奇数）に着く。段数は P + 1。
- 途中の奇数の距離はどれも h − 1 = 1.5a − 1.5 と違う。各段の (M + d)/2 は m 以下（`data/k40a_check.txt` で確認）。

**帰納法**：周期の始まり B について、次を仮定する。
- 奇数の距離は入る。
- v2 = 1 の距離は入らない。
- d₁ は入らない。
- P が偶数なら X は入る。

ブロック 0 では K3 から成り立つ（v2(d₁) = 3、v2(X) = 4）。O 型ブロックでは 1 段ごとに値が反転するので、ブロック P−1（または n）での値は「段数が偶数なら終わりの値、奇数ならその否定」。

- **(1) O 型ブロック n での h**：段数 2n + 1 は奇数なので、[h ∈ S_n] = ¬（終わりの値）。
  - n = 1 では終わりが d₁ で入らないので、h は入る。
  - 2 ≤ n ≤ P−2 では、終わりが 2a − 2^{N−2n−2}（v2 = 1）で入らないので、h は入る。
  - n = P−1 では、終わりが 2a − 1（奇数）で入るので、h は入らない。
  - よって、間隔は 1^{P−1} 0。
- **(2) 次の始まり E = P（E 型）**：
  - h は奇数なので入り、間隔は m+2。
  - [d₁] = ¬[d₁/2] ∧ ¬[g ∈ S_{P−1}]、[d₁/2] = ¬[d₁/4] ∧ ¬[f ∈ S_{P−1}] である。
    - d₁/4 は v2 = 1 なので入らない。g の段数 N は偶数なので [g ∈ S_{P−1}] = [X ∈ S_B]。f の段数は P。
    - P が奇数：f ∉ S_{P−1} より d₁/2 ∈ S_E なので、d₁ ∉ S_E。
    - P が偶数：f ∈ S_{P−1} より d₁/2 ∉ S_E。g ∈ S_{P−1}（仮定 X ∈ S_B）より d₁ ∉ S_E。
  - P が偶数のとき、X について：
    - X/8 は v2 = 1 なので入らない。
    - h + X/8 は段数 P（偶数）で終わりが奇数なので入る。よって X/4 ∉ S_E。
    - h + X/4 は段数 N で入る。よって X/2 ∉ S_E。
    - h + X/2 は段数 P + 1（奇数）なので入らない。
    - よって X ∈ S_E。
  - 奇数・v2 = 1 の事実は E 型ブロックの規則から成り立つ。v2 = 1 の距離は、半分が奇数で入るので入らない。
  - よって、E は B と同じ仮定を満たす。
- 帰納法により、間隔の列は (1^{P−1} 0) のくり返し。∎

  - 段数
  - h − 1 になる段や、(M + d)/2 > m になる段がないこと
