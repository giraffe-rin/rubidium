# 定理 K59：予想 K34・K58 の族の間隔の列の先頭

## やったこと

- v = 3、ρ = 2、N 奇数の族（Issue #335）で、ブロック 0 からの h の鎖を数値で追った（その場のスクリプト、N = 41, 43, 45）。鎖が「v2(β) = N」を越える場面の形を調べた。
- 越える場面の扱い（補題 K59.1）を手で書き、先頭の m+2 の連が 2R（s = 3、予想 K34）、R + 2（s = 7、予想 K58）であることを示した。
- `code/k59_first_run.js` で、9 ≤ N ≤ 401 の奇数 N のすべてで確かめた（`data/k59_first_run.txt`）。

**前提**：H(j)、K3（査読済み）。定理 K47 の鎖の記述（査読済み）。

## 記号

- q = 5、r = 1、v = 3（3r + q = 8）とする。N は奇数で N ≥ 9、X = 2^N とする。
- s は N ≡ 1 (mod 4) なら 3、N ≡ 3 (mod 4) なら 7（5 | sX − 1 となる最小の正の奇数）。
- a = (sX − 1)/5（奇数）、m = 3a − 2、M = 3a、h = (3a − 1)/2、R = (N − 3)/2 とする。

鎖の記述（定理 K47）：距離を d = (αa − c)/2^K と書き、β = rα + qc とすると、r(αa − c) = βa − csX。

- 奇数の段で α → α + 3·2^K、β → β + 3r·2^K = β + 3·2^K。
- r = 1 なので、奇数の点で β = 2^K b なら d = ab − cs·2^{N−K}。

## 補題 K59.1 `[非形式証明]`（鎖が N を越える場面）

鎖の奇数の点（c を固定、β = 2^K b、K < N）で奇数の段を行い、β' = 2^K(b + 3) = 2^E b'（b' 奇数、E = K + v2(b + 3)）になったとする。

- **E < N**：v2(d) = E − (K + 1)（定理 K47 と同じ）。
- **E = N**：分子 β'a − csX = 2^N(b'a − cs) なので、d = 2^{N−K−1}(b'a − cs)。d を半分にする段は (N − K − 1) + u 回（u = v2(b'a − cs)）で、その後の奇数の距離は d' = (b'a − cs)/2^u。
  - これは新しい鎖の入口 α' = b'、c' = cs、K' = u の形をしている。β'' = rα' + qc' = b' + 5cs。
- **E > N**：分子の v2 は N（2^{E−N} b'a は偶数、cs は奇数）。d = 2^{N−K−1}(2^{E−N}b'a − cs) で、半分にする段は N − K − 1 回。

証明は、恒等式に v2 を当てるだけである。∎

## 定理 K59 `[非形式証明]`

- s = 3（N ≡ 1 (mod 4)）なら、g_0 = … = g_{2R−1} = m+2、g_{2R} = m+1。
- s = 7（N ≡ 3 (mod 4)）なら、g_0 = … = g_{R+1} = m+2、g_{R+2} = m+1。

これは、予想 K34（周期 1^{2R} 0 (1^R 0 0)^2）と予想 K58（周期 1^{R+2} 0 1^R 0）の周期の先頭の連と一致する。

### 証明

**ブロック 0**：v2(h) = 2 は偶数なので、h ∈ S_0（K3）。

**ブロック i（g_0..g_{i−1} = m+2 を仮定）**：ブロック 1..i は O 型。h の鎖（c = 1、α = 3、K = 1、β = 8）は、次のように進む。

- 2 回半分にして K = 3、b = 1 の奇数の点に着く。T(1) = (1 + 3)/4 = 1 なので、各ブロックで奇数の段 1 回と半分にする段 1 回を行う。j 回目の奇数の点は K = 2j + 1、その段の後の β は 2^{2j+3}。
- **i ≤ R − 1**：E = 2i + 3 < N。終点の v2 は 1（奇数、K3 で入らない）。段数は 2 + i + (i − 1) = 2i + 1（奇数）なので、h ∈ S_i。
- **i = R**：最後の奇数の段で E = N。補題 K59.1 により、終点 d = 2(a − s)、v2 = 1 + u。
  - u = v2(a − s) は、s = 3 なら a − 3 = (3X − 16)/5 から 4、s = 7 なら a − 7 = (7X − 36)/5 から 2。
  - どちらも v2 = 1 + u は奇数なので入らない。段数は 2R + 1（奇数）なので、h ∈ S_R。
- **i > R**：ブロック i − R + 1 での R 回目の奇数の段で E = N となり、補題 K59.1 により、ブロック i − R で新しい鎖 d' = (a − s)/2^u（c' = s、K' = u）に入る。残る奇数の段は n' = i − R 回。β'' = 1 + 5s。
  - これまでの段数は 2 + R + (R − 1) + (1 + u) = 2R + 2 + u。
  - **s = 3（u = 4）**：β'' = 16 = 2^4 なので、新しい鎖も b = 1、t = 2 で進む。j 回目の奇数の点は K' = 2j + 2、その段の後は E' = 2j + 4（偶数）。
    - 新しい鎖の恒等式は c' s X = 9X なので、E' < N なら終点の v2 は 1、E' > N なら補題 K59.1 の第 3 の場合になる。
    - **n' ≤ R − 1**（i ≤ 2R − 1）：E' = 2n' + 4 ≤ 2R + 2 < N なので、終点の v2 は 1（入らない）。段数は 2R + 2 + 4 + n' + (n' − 1) = 2i + 5（奇数）。よって h ∈ S_i。
    - **n' = R**（i = 2R）：E' = 2R + 4 = N + 1 > N。終点 d = 2a − 9（奇数）なので入る。段数は 2i + 5（奇数）なので、h ∉ S_{2R}。
  - **s = 7（u = 2）**：β'' = 36 = 2^2·9 なので、新しい鎖の b は 9 → T(9) = (9 + 3)/4 = 3 → T(3) = (3 + 3)/2 = 3 → …（t(9) = 2、t(3) = 1）。
    - **n' = 1**（i = R + 1）：終点の v2 は t(9) − 1 = 1（入らない）。段数は 2R + 4 + 1 = 2R + 5（奇数）。よって h ∈ S_{R+1}。
    - **n' = 2**（i = R + 2）：終点の v2 は t(3) − 1 = 0（奇数の距離、入る）。段数は 2R + 4 + 2 + (t(9) − 1) = 2R + 7（奇数）なので、h ∉ S_{R+2}。

**鎖の条件**（奇数の点で (M+d)/2 ≤ m、d ≠ h − 1）：

- 最初の鎖（b = 1、c = 1）では、d = a − s·2^{N−K} ∈ (0, a)。
- s = 3 の新しい鎖（b = 1、c' = 3）では、d = a − 9·2^{N−K} ∈ (0, a)。
  - 0 < d は、K ≥ 4 と 9·2^N = 3(5a + 1) から 9·2^{N−K} ≤ 3(5a + 1)/16 < a。
- s = 7 の新しい鎖では、使う奇数の点は 2 つだけである。
  - d' = (a − 7)/4。
  - b = 3、K' = 4 の点で d = 3a − 49·2^{N−4} = (13a − 7)/16（7·2^N = 5a + 1 による）。
  - どちらも (0, 3a − 4) にあり、h − 1 = (3a − 3)/2 とは等しくない（等しいとすると 11a = 17 などで、a が整数にならない）。

∎
