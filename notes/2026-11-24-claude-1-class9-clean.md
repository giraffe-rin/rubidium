# m ≡ 9 (mod 32) の前周期のない族（予想 K40）

## やったこと

- 予想 K39（`notes/2026-11-24-claude-1-class9-infinite.md`）の族は前周期が不規則で、証明しにくい。そこで、前周期がなく周期が等差で伸びる族を探した。
  - 探した形：m = 3a − 2、a = (c·2^N + b)/q。q ≤ 129 の奇数（2 の位数 ≤ 40）、c ≤ 31、|b| ≤ 200。その場のスクリプトで探し、データは残していない。
- 6 つ見つかった。いちばん簡単な a = (2^N − 1)/23（N は 11 の倍数）と a = (2^N − 1)/119（N は 24 の倍数）の型を調べた（`code/class9_clean.js`、`data/class9_clean.txt`）。
- q = 23、N = 44 で、型を決めるのに参照される (ブロック, 距離) を書き出した（その場のスクリプト）。

**前提**：ブロック漸化式 R。

## 結果

### 予想 K40 `[予想]`

- a = (2^N − 1)/23（N ≥ 22、11 の倍数）、m = 3a − 2 なら、m ≡ 9 (mod 32) で、型は前周期なし、周期 1^{⌊N/2⌋−1} 0。
- a = (2^N − 1)/119（N は 24 の倍数）なら、m ≡ 9 (mod 32) で、型は前周期なし、周期 1^{N/2−2} 0。

範囲：q = 23 で N ≤ 242、q = 119 で N ≤ 240 の 31 個すべてで、ブロック 0 から周期の 3 回分が一致した（BigInt 版の遅延評価）。

予想 K40 が正しければ、予想 K39（m ≡ 9 (mod 32) の型は無限に多い）が従う。

### 証明の見通し（q = 23、N 偶数）

参照される距離は、定理 K35・K36 と同じ鎖と、そこへの入り口からなる。
- 鎖：y_i = 2a − 4^i、z_i = a − 2·4^i
- 入り口：
  - h（奇数）
  - d₁ = (M + h)/2 = (9a − 1)/4（v2 = 3）
  - d₂ = d₁/8（奇数）
  - e₂ = (M + d₂)/2 = (105a − 1)/64（v2 = 1）
  - d₃ = e₂/2（奇数）
  - (M + d₃)/2 = (489a − 1)/256 = 2a − 2^{N−8} = y_{(N−8)/2}
  - 最後の等式は 23a + 1 = 2^N による。付値は a ≡ 89 (mod 256) から出る。
- これで、O 型ブロックでは [h ∈ S_{B+n}] = ¬[y_{(N−8)/2 − (n−3)} ∈ S_B]（n ≥ 3）となり、h が入らないのは n = N/2 − 1 のブロックだけになる。周期の長さ N/2 と合う。
- 残る問題：周期の始まり（E 型ブロック）で d₁ ∉ S を示すこと。
  - v2(m+1) = 1 では、補題 Q_n は E 型ブロックで偶数の距離について何も言わない。
  - そのため、直前の O 型ブロックでの h + d₁/4 = (33a − 9)/16 の値を、別の鎖でたどる必要がある。
  - これがまだできていない。
