# 予想 K10 (a) の非形式証明（v2(m+1) = 3, u ≡ 1 (mod 8)）

## やったこと

予想 K10 (a)（`notes/2026-11-23-claude-1-conjecture-k10.md`）の証明を書いた。
方法は、7 つの距離の所属だけを追う不変量による、ブロック番号 j についての帰納法。

**前提**：`notes/2026-11-23-claude-1-proof-structure.md` の系 1.1、主張 H(j)、定理 K3。どれも `[非形式証明]`（未査読）。

## 結果

### 定理 K10 (a) `[非形式証明]`

m + 1 = 8u とし、u ≡ 1 (mod 8)、u ≥ 9 とする。このとき m は交互型。つまり次が成り立つ。
- すべての j で、g_j = m+2（j が偶数）、g_j = m+1（j が奇数）。
- したがって、すべての n ≥ 1 で (n, 0) が P ⇔ n ≡ 0 または m+2 (mod 2m+3)。

#### 準備

u = 8s + 1（s ≥ 1）と書く。m = 8u − 1 = 64s + 7、h = 4u。
- m + 1 = 8u は偶数、m + 2 = 8u + 1 は奇数。

追跡する 7 つの距離を次のように決める。
- u, 2u, 3u, 6u, h = 4u
- e₁ := (9u + 1)/2 = 36s + 5（奇数）
- w := (11u + 1)/2 = 44s + 6 = 2(22s + 3)（偶数で、w/2 = 22s + 3 は奇数）

**範囲の確認**：どれも 1 以上 m = 8u − 1 以下。
- 6u ≤ 8u − 1 ⇔ u ≥ 1/2。
- e₁ ≤ 8u − 1 ⇔ 9u + 1 ≤ 16u − 2 ⇔ 7u ≥ 3。
- w ≤ 8u − 1 ⇔ 11u + 1 ≤ 16u − 2 ⇔ 5u ≥ 3。
- u, 2u, 3u, 4u は 6u 以下。

**(iii) の対象**：H(j)(d) の (iii) が効くのは d = h − 1 = 4u − 1 だけ。追跡する距離のうち、4u − 1 と等しいものはない。
- u, 3u, e₁ は奇数で 4u − 1 も奇数なので、等しくなりうるかを確かめる。
  - u = 4u − 1 ⇔ u = 1/3
  - 3u = 4u − 1 ⇔ u = 1
  - e₁ = 4u − 1 ⇔ 9u + 1 = 8u − 2 ⇔ u = −3

  u ≥ 9 なので、どれも起きない。
- 2u, 4u, 6u, w は偶数なので、4u − 1（奇数）と等しくならない。

#### 主張 I(j)

- **j が偶数のとき（E 型）**：
  - (E1) 1 ≤ d ≤ m のすべての奇数 d で d ∈ S_j
  - (E2) w ∉ S_j
  - (E3) h ∈ S_j
  - (E4) g_j = m+2
- **j が奇数のとき（O 型）**：
  - (O1) u ∉ S_j
  - (O2) 3u ∈ S_j
  - (O3) 6u ∉ S_j
  - (O4) h ∉ S_j
  - (O5) g_j = m+1

I(j) を j についての強い帰納法で示す。帰納法の仮定は「I(0), …, I(j−1) が成り立つ」こと。

#### j = 0

定理 K3 より、d ∈ S₀ ⇔ v2(d) が偶数。
- (E1)：奇数 d は v2(d) = 0 なので入る。
- (E2)：v2(w) = 1（w/2 が奇数）なので入らない。
- (E3)：v2(h) = v2(4u) = 2 なので入る。
- (E4)：H(0)(c) より g₀ = m+2（m は奇数で h ∈ S₀）。

#### j ≥ 2 が偶数

仮定 I(j−1)（O 型）より g_{j−1} = m+1。H(j)(d) を使う。
- (iii)：g_{j−1} ≠ m+2 なので、どの d にも効かない。
- (ii)：g_{j−1} + d = m + 1 + d。m+1 は偶数なので、これが偶数 ⇔ d が偶数。

各主張を示す。
- **(E1)**：奇数 d は、(i)（d が奇数）も (ii)（g_{j−1} + d が奇数）も (iii) も成り立たないので、d ∈ S_j。
- **(E2)**：w は偶数で w/2 は奇数。(E1) より w/2 ∈ S_j なので (i) が成り立ち、w ∉ S_j。
- **(E3)**：d = h = 4u について調べる。
  - (i)：「2u ∈ S_j」かどうか。2u は偶数で、u は奇数なので (E1) より u ∈ S_j。よって 2u の (i) が成り立ち、2u ∉ S_j。したがって h の (i) は成り立たない。
  - (ii)：g_{j−1} + h = 8u + 4u = 12u は偶数で、e = 6u ≤ m。仮定 I(j−1) の (O3) より 6u ∉ S_{j−1}。よって成り立たない。
  - (iii)：成り立たない。
  - よって h ∈ S_j。
- **(E4)**：H(j)(c) より g_j = m+2。

#### j ≥ 1 が奇数

仮定 I(j−1)（E 型）より、次が成り立つ。
- g_{j−1} = m+2
- S_{j−1} はすべての奇数 d を含む
- w ∉ S_{j−1}

H(j)(d) を使う。
- (ii)：g_{j−1} + d = 8u + 1 + d が偶数 ⇔ d が奇数。そのとき e = (8u + 1 + d)/2。
- (iii)：d = 4u − 1 にだけ効く。準備より、追跡する距離には効かない。

各主張を示す。
- **(O1)**：d = u（奇数）。
  - (i)：成り立たない（u は奇数）。
  - (ii)：e = (9u+1)/2 = e₁ は奇数で e₁ ≤ m なので、e₁ ∈ S_{j−1}。よって (ii) が成り立つ。
  - よって u ∉ S_j。
- **2u の所属**：
  - (i)：「u ∈ S_j」で、(O1) より成り立たない。
  - (ii)：g_{j−1} + 2u は奇数なので、成り立たない。
  - (iii)：効かない。
  - よって 2u ∈ S_j。
- **(O2)**：d = 3u（奇数）。
  - (i)：成り立たない。
  - (ii)：e = (8u + 1 + 3u)/2 = w ≤ m で、w ∉ S_{j−1}。よって成り立たない。
  - (iii)：u ≥ 9 なので効かない。
  - よって 3u ∈ S_j。
- **(O3)**：d = 6u（偶数）。(i)：(O2) より 3u ∈ S_j なので成り立つ。よって 6u ∉ S_j。
- **(O4)**：d = h = 4u（偶数）。(i)：2u ∈ S_j なので成り立つ。よって h ∉ S_j。
- **(O5)**：H(j)(c) より、h ∉ S_j なので g_j = m+1。

#### 結論

帰納法により、すべての j で I(j) が成り立つ。よって g_j は m+2, m+1 の交互になる。
A 行の位置と開始局面の判定は、K6 の証明（`notes/2026-11-23-claude-1-proof-k6.md`）の「A 行の位置」と同じ計算で出る。
- a_{2i} = i(2m+3)
- a_{2i+1} = i(2m+3) + m + 2

系 1.1 と合わせて主張が成り立つ。∎

### 補足

- **u = 1（m = 7）が例外になる理由**：3u = 3 = h − 1 となり、ブロック 1 で (iii) が効いて 3u ∉ S₁ になる。
  すると 6u ∈ S₁ となり、ブロック 2 で h ∉ S₂、g₂ = m+1 となって交互が崩れる。
  データの「m = 7 の間隔は 1, 0, 0, …」と一致する。
- **u ≡ 1 (mod 8) を使った箇所**：
  - e₁ が奇数であること（u ≡ 1 (mod 4) で足りる）。
  - w/2 が奇数であること（u ≡ 1 (mod 8) が必要）。
- **前回の打ち切りとの関係**：前回打ち切ったのは、v2(m+1) が奇数の m の「一般の」特徴づけを、閉じた不変量で作るアプローチ（STATUS.md「試して駄目だった方法」）。
  今回は族を u ≡ 1 (mod 8) に絞り、追う距離を 7 つに固定したので閉じた。
  「族を細かく絞れば閉じる」場合があるという経験は、K9 の十分性にも使えるかもしれない。
- **数値による裏付け**：
  - v2(m+1) = 3、u ≡ 1 (mod 8)、9 ≤ u ≤ 121（m ≤ 1000 の 15 個）で、交互型だった（`data/k10_v2eq3.txt`）。
  - 不変量 I(j) そのもの（(E1)〜(E4)、(O1)〜(O5) と 2u ∈ S_j）も、漸化式 R で 9 ≤ u ≤ 401（50 個）、0 ≤ j < 40 について確かめた。失敗はなかった。
    このときはその場で書いたコマンドで調べたので、データファイルは残していない。
