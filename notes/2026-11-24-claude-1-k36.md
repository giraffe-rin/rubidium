# 定理 K36：v2(m+1) が奇数なら型は無限に多い

## やったこと

- 定理 K33a（v = 1、a = 3·2^e + 1 ≈ 1）と定理 K35（v = 3、a = (16^k − 1)/5 ≈ −1/5）の族を見比べた。どちらも m + 2 = 3a で、a は 2 進的に −1/(2^v − 3) に近い。
  - v = 1 では −1/(2 − 3) = 1、v = 3 では −1/5。
- そこで一般の奇数 v ≥ 3 で a := (4^N − 1)/(2^v − 3)、m := 3a − 2 とおいた。数値で調べると、型は 1^{N−(v−1)/2} 0^s（s は 1 か 2）だった。
- K35 の証明の O 型ブロックの部分が、一般の v でそのまま使えることがわかった。また、始まりの性質 (Z) は補題 Q_n によりどの E 型ブロックでも成り立つ。
  - これで、E 型ブロックの数 s を決めなくても、m+2 の連の長さが決まる。
- 確認：`code/check_k36.js`、`data/k36_check.txt`。

**前提**：
- 主張 H(j)、定理 K3（gemini-2 が PR #111 で `[査読済み]`、未マージ）
- 定理 K32 とその補題 Q_n（`notes/2026-11-24-claude-1-type-runs.md`、未査読）
- 「型」（間隔の列の周期部分）が定まることは、周期性の定理 K7′（`notes/2026-11-23-claude-1-proof-periodicity.md`、未査読）による

## 結果

### 定理 K36 `[非形式証明]`

v ≥ 3 を奇数、q := 2^v − 3 とする。N ≥ (v+3)/2 で q | 4^N − 1 のとき、a := (4^N − 1)/q、m := 3a − 2 とおくと、次が成り立つ。
- (1) v2(m+1) = v。
- (2) 間隔の列は 1^{K+1} 0^{s_1} 1^{K+1} 0^{s_2} … の形になる。ここで K := N − (v+1)/2 で、1 ≤ s_i ≤ (v+1)/2。
  - つまり、m+2 の間隔の極大な連は、どれもちょうど長さ N − (v−1)/2。
- q は奇数なので、q | 4^N − 1 となる N は無限にある（4 の q を法とする位数の倍数）。

### 系 K36b（予想 K31 の前半）`[非形式証明]`

v2(m+1) が奇数のとき、各 v について、型は無限に多い。
- v = 1 は系 K33b、v ≥ 3 は定理 K36 による。
- 定理 K36 の m では、型の周期部分の m+2 の連の長さがすべて N − (v−1)/2 なので、N が違えば型が違う。

### 証明

**記号**：
- M = m + 2 = 3a、h = (m+1)/2 = (3a − 1)/2
- y_i := 2a − 4^i（0 ≤ i ≤ K）
- z_i := a − 2·4^i
- qa + 1 = 4^N、a は奇数

**(1)**：m + 1 = 3a − 1 = (3·4^N − 3 − q)/q = (3·4^N − 2^v)/q。2N ≥ v + 3 > v で q は奇数なので、v2(m+1) = v。

**付値と大きさ**：
- v2(h) = v − 1（偶数、≥ 2）なので、h' := h/2^{v−1} は奇数。
- y_i（i ≥ 1）は v2(y_i) = 1。y_0 = 2a − 1 は奇数。z_i は奇数（a は奇数）。
- y_i / 2 = z_{i−1}、(M + z_i)/2 = y_i。
- 計算：4a − (3a + h') = 4^N(1 − 3·2^{−v})/q = 4^N/2^v。よって **(M + h')/2 = 2a − 4^N/2^{v+1} = y_K**。v が奇数なので 2N − v − 1 は偶数で、4^N/2^{v+1} = 4^K。
- 大きさ：
  - y_i < 2a < m。z_i ≥ a − 2·4^{K−1} > 0（4^{K−1} = 4^N/2^{v+3}、a > 4^N/2^v − 1）。
  - 奇数の距離 h'、z_i はどれも a 以下で、h − 1 = (3a − 3)/2 より小さい。
  - 偶数の距離は奇数の h − 1 と違う。

**O 型ブロックの規則**（定理 K33a・K35 のログと同じ）：
- (O1) 奇数の d ≠ h − 1 で (M+d)/2 ≤ m なら、[d ∈ S_j] = ¬[(M+d)/2 ∈ S_{j−1}]
- (O2) 偶数の d ≠ h − 1 なら、[d ∈ S_j] = ¬[d/2 ∈ S_j]

**性質 (Z)**：ブロック B で、y_i ∉ S_B（1 ≤ i ≤ K）、y_0 ∈ S_B、かつ h ∈ S_B（g_B = m+2）。

**補題 1（O 型ブロックの連）**：ブロック B が (Z) を満たせば、g_B = g_{B+1} = … = g_{B+K} = m+2、g_{B+K+1} = m+1。

証明：ブロック B+1, …, B+n が O 型（1 ≤ n ≤ K+1）のとき、次の 3 つを組み合わせる。
- (O2) を v − 1 回（偶数回）使うと、[h ∈ S_{B+n}] = [h' ∈ S_{B+n}]。
- (O1) より [h' ∈ S_{B+n}] = ¬[y_K ∈ S_{B+n−1}]。
- y の鎖：O 型ブロック j で [y_i ∈ S_j] = ¬[z_{i−1} ∈ S_j] = [y_{i−1} ∈ S_{j−1}]（i ≥ 1、(O2) と (O1)）。

よって [h ∈ S_{B+n}] = ¬[y_{K−n+1} ∈ S_B]。(Z) により、これは n ≤ K で T、n = K+1 で F。n についての帰納法で、ブロックが O 型であることも順に保証される。∎

**補題 2（E 型ブロックの連の後）**：m+1 の間隔の連の直後で、間隔が m+2 のブロックは (Z) を満たす。
- そのようなブロックがあることは定理 K32 による（m+1 の連は (v+1)/2 以下）。
- そのブロックを n 番目の E 型ブロックとする（n ≥ 1）。v ≥ 3 なので min(2n − 1, v − 1) ≥ 1。
- 補題 Q_n により、v2(y_i) = 1 の y_i は入らず、奇数の y_0 は入る。h が入ることは、間隔が m+2 であることそのもの。∎

**定理の証明**：
- ブロック 0 は (Z) を満たす（K3：v2(y_i) = 1 は奇数、y_0 は奇数で v2 = 0、v2(h) = v − 1 は偶数）。
- 補題 1 と補題 2 を交互に使うと、間隔の列は (2) の形になる。∎

**系の証明**：K7′ により、間隔の列はいずれ周期的になる。(2) により、周期部分の m+2 の極大な連はどれも長さ N − (v−1)/2 である。周期部分には m+1 も m+2 も現れるので、連は必ず現れる。よって、N が違えば型が違う。∎

### 補足

- s_i（E 型ブロックの数）は、数値では v = 5, 9 で 1、v = 3, 7, 11, 13 で 2 だった（`data/k36_check.txt`）。この定理では s_i を決めていない。
- v = 3、N = 2k は定理 K35 の族と同じ m で、K35 はそこで s_i = 2 まで示している。
