### 0. 定義と記号

- m ≥ 1 を固定する。局面は (r, p)（r ≥ 0、0 ≤ p ≤ m）。
- (r, p) の合法手は、1 ≤ k ≤ min(m, r) かつ k ≠ p を満たす k。手 k で (r − k, k) に移る。
- 合法手がない局面は P（手番側の負け）。
  合法手のうち P 局面へ移るものが 1 つでもあれば N、合法手がすべて N 局面へ移るなら P。
- 各局面が N か P のどちらか一方に決まることは、r についての強い帰納法で言える。手 k の行き先は r − k < r だから。
- 行 r の **P 集合** を L(r) = { p ∈ {0, …, m} : (r, p) が P } とする。
- 行 r の **勝ち手集合** を T(r) = { k : 1 ≤ k ≤ min(m, r)、かつ (r − k, k) が P } とする。
  T(r) の要素は「p の制限がなければ、P 局面へ移れる手」。
- v2(x) は正の整数 x を割り切る 2 の最大べきの指数。m が奇数のとき h = (m+1)/2。

### 補題 1（P 集合と勝ち手集合の関係）`[非形式証明]`

すべての r ≥ 0 と 0 ≤ p ≤ m について：(r, p) が P ⇔ T(r) ⊆ {p}。

証明：
- (r, p) の合法手の集合は M = {1, …, min(m, r)} \ {p}。
- (r, p) が P ⇔ M のどの k でも (r − k, k) が N ⇔ M ∩ T(r) = ∅。
  合法手がない（M = ∅）場合も、この同値は成り立つ。両辺とも真になるから。
- T(r) ⊆ {1, …, min(m, r)} なので、M ∩ T(r) = T(r) \ {p}。
- よって (r, p) が P ⇔ T(r) \ {p} = ∅ ⇔ T(r) ⊆ {p}。∎

### 定理 K1（行の型）`[非形式証明]`

すべての m ≥ 1 と r ≥ 0 について、L(r) は次のどれか 1 つ。

- (A) T(r) = ∅ のとき、L(r) = {0, 1, …, m}。この行を **A 行** と呼ぶ。
- (S) T(r) = {t}（要素 1 つ）のとき、L(r) = {t}。この行を **S(t) 行** と呼ぶ。このとき 1 ≤ t ≤ m。
- (E) T(r) が 2 つ以上の要素を持つとき、L(r) = ∅。この行を **E 行** と呼ぶ。

証明：補題 1 から、p ∈ L(r) ⇔ T(r) ⊆ {p}。T(r) の大きさで場合分けする。
- T(r) = ∅ のとき：どの p でも ∅ ⊆ {p} が成り立つので、L(r) はすべての p。
- T(r) = {t} のとき：{t} ⊆ {p} ⇔ p = t。t ≤ min(m, r) ≤ m なので、t は p の範囲 0..m に入る。よって L(r) = {t}。
- T(r) が相異なる t₁, t₂ を含むとき：T(r) ⊆ {p} なら t₁ = p = t₂ となって矛盾。よって L(r) = ∅。∎

系 1.1：r が A 行 ⇔ (r, 0) が P。
- 証明（⇒）：A 行ならすべての p で P なので、p = 0 でも P。
- 証明（⇐）：(r, 0) が P なら、補題 1 より T(r) ⊆ {0}。T(r) の要素は 1 以上なので T(r) = ∅。よって A 行。∎

系 1.2（勝ち手集合の計算）：1 ≤ k ≤ min(m, r) のとき、k ∈ T(r) ⇔ 行 r − k が A 行であるか、S(k) 行である。
- 証明：k ∈ T(r) ⇔ (r − k, k) が P ⇔ k ∈ L(r − k)。
- K1 で行 r − k の型ごとに場合分けする。
  - A 行なら、L = 全体なので k を含む。
  - S(t) 行なら、L = {t} なので、k を含む ⇔ t = k。
  - E 行なら、L = ∅ なので含まない。∎

以下では、行の列が系 1.2 で決まることだけを使う。

### 定理 K2・K8（ブロックの形とブロック漸化式）`[非形式証明]`

m ≥ 2 とする。A 行を小さい順に a₀ < a₁ < a₂ < … と並べる。
r = 0 は T(0) = ∅ なので A 行で、a₀ = 0。

次の主張 H(j)（j = 0, 1, 2, …）を、j についての帰納法で示す。
同時に、A 行が無限個あること（a_{j+1} が存在すること）も示す。

**主張 H(j)**：A 行 a_j が存在し、g_j を「a_j の次の A 行までの間隔」として、次が成り立つ。

- (a) 次の A 行 a_{j+1} が存在し、g_j = a_{j+1} − a_j ∈ {m+1, m+2}。
- (b) 1 ≤ d ≤ m のとき、行 a_j + d は S(d) 行か E 行のどちらか。
  S(d) 行になる d の集合を S_j とする。
- (c) g_j = m+2 なのは、m が奇数で h ∈ S_j のときに限る。そのとき行 a_j + m + 1 は S(h) 行。
  g_j = m+1 なのはそれ以外のとき。
- (d) S_j は次の規則で決まる。1 ≤ d ≤ m について、d ∈ S_j ⇔ 次の (i)〜(iii) のどれも成り立たない。
  - (i) d が偶数で、d/2 ∈ S_j。
  - (ii) j ≥ 1、g_{j−1} + d が偶数、e := (g_{j−1} + d)/2 が e ≤ m を満たし、e ∈ S_{j−1}。
  - (iii) j ≥ 1、g_{j−1} = m + 2、かつ d = h − 1（この場合 m は奇数）。

(d) で d ∈ S_j を判定するとき、(i) が参照するのは d/2 < d の要素だけ。だから S_j は d の小さい順に決まる。
(ii) と (iii) は 1 つ前のブロックの情報（S_{j−1} と g_{j−1}）だけを使う。

**証明**：j についての帰納法。帰納法の仮定は「H(0), …, H(j−1) が成り立つ」こと（j = 0 では仮定なし）。
この仮定の下で H(j) を示す。a_j の存在は、j = 0 なら a₀ = 0、j ≥ 1 なら H(j−1)(a) による。

**ステップ 1（j ≥ 1 なら a_j ≥ m+1）**：
- H(0)(a), …, H(j−1)(a) より、a_j = g₀ + … + g_{j−1} ≥ j(m+1) ≥ m+1。

**ステップ 2（距離 d = 1, …, m の行）**：
- d についての帰納法で、行 a_j + d（1 ≤ d ≤ m）が A 行でないこと、および (b) と (d) を示す。
- 内側の帰納法の仮定：1 ≤ e < d の各 e で、行 a_j + e は A 行でなく、S(e) 行か E 行であり、e ∈ S_j かどうかは (d) の規則どおり。

r = a_j + d とおく。系 1.2 で T(r) を求める。k の範囲は 1 ≤ k ≤ min(m, r)。

- **d ≤ r の確認**：r = a_j + d ≥ d なので、k = d は範囲に入る（d ≤ m も満たす）。
- **k = d の場合**：行 r − d = a_j は A 行なので、d ∈ T(r)。
  よって T(r) ≠ ∅ で、行 r は A 行ではない。
  K1 より、行 r は S(d) 行（T(r) = {d} のとき）か E 行（T(r) に d 以外の要素もあるとき）。これで (b) が示せた。
  あとは、「d 以外の k が T(r) に入るのは、(i)〜(iii) のどれかが成り立つときに限る」ことを示せば (d) が示せる。

- **k < d の場合**：行 r − k = a_j + (d − k)、距離 e = d − k は 1 ≤ e < d。
  内側の帰納法の仮定より、この行は A 行でなく、S(e) 行か E 行。
  系 1.2 より、k ∈ T(r) ⇔ この行が S(k) 行 ⇔ 「S(e) 行で e = k」⇔ 「d = 2k かつ k ∈ S_j」。
  したがって、k < d で k ∈ T(r) となるものが存在する ⇔ d が偶数かつ d/2 ∈ S_j ⇔ (i)。

- **k > d の場合**（k ≤ min(m, r)）：
  - **j = 0 のとき**：r = d なので k ≤ r = d となり、k > d は範囲にない。また (ii)(iii) は j ≥ 1 が条件なので成り立たない。この場合の主張は自明に一致する。
  - **j ≥ 1 のとき**：ステップ 1 より r ≥ a_j ≥ m+1 > m なので、k の範囲は d < k ≤ m。
    - **行き先の位置**：r − k = a_j + d − k。d − k ≤ −1 より r − k ≤ a_j − 1。
      k ≤ m と d ≥ 1 より r − k ≥ a_j + 1 − m。
      H(j−1)(a) より a_{j−1} = a_j − g_{j−1} ≤ a_j − (m+1) < a_j + 1 − m。
      よって a_{j−1} < r − k < a_j で、行 r − k はブロック j−1 の、距離 e = r − k − a_{j−1} = g_{j−1} + d − k の行。
    - **距離 e の範囲**：k ≤ m より e ≥ g_{j−1} + d − m ≥ (m+1) + 1 − m = 2。k ≥ d+1 より e ≤ g_{j−1} − 1。
      H(j−1)(a) より a_{j−1} と a_j の間に A 行はないので、この行は A 行でない。
    - H(j−1) の (b) と (c) より、ブロック j−1 の距離 e の行は次のどれか。
      - e ≤ m：S(e) 行か E 行。
      - e = m+1（g_{j−1} = m+2 のときだけ。g_{j−1} − 1 ≥ e なので）：S(h) 行。
    - 系 1.2 より、k ∈ T(r) ⇔ この行が S(k) 行。e で場合分けする。
      - **e ≤ m の場合**：S(k) 行 ⇔ 「e = k かつ e ∈ S_{j−1}」。
        e = k ⇔ g_{j−1} + d − k = k ⇔ k = (g_{j−1} + d)/2。
        よって、この場合に k ∈ T(r) となる k が存在する ⇔ g_{j−1} + d が偶数で、e = (g_{j−1} + d)/2 が次の 3 つをすべて満たす。
        - d < e（手 k = e が k > d を満たすこと）
        - e ≤ m（手 k = e が k ≤ m を満たすこと。このとき距離 e も e ≤ m の場合に入る）
        - e ∈ S_{j−1}
        d < e は g_{j−1} > d と同値で、g_{j−1} ≥ m+1 > m ≥ d から常に成り立つ。
        これは (ii) と同値。
      - **e = m+1 の場合**（g_{j−1} = m+2）：行は S(h) 行なので、k ∈ T(r) ⇔ k = h。
        e = m+1 ⇔ g_{j−1} + d − k = m+1 ⇔ k = d + 1（g_{j−1} = m+2 を代入）。
        k = d + 1 は d < k を満たす。k = d+1 ≤ m は d ≤ m − 1 のとき。
        よって、この場合に k ∈ T(r) となる k が存在する ⇔ g_{j−1} = m+2 かつ h = d + 1 ≤ m。
        h ≤ m は m ≥ 1 で常に成り立つ。d = h − 1 ≥ 1 が必要なので m ≥ 3（m は奇数）。
        これは (iii) と同値（d ≥ 1 は前提なので、h − 1 ≥ 1 でない場合 (iii) は成り立たない）。

- **まとめ**：T(r) = {d} ∪（(i) による要素）∪（(ii) による要素）∪（(iii) による要素）。
  d 以外の要素があるのは、(i)〜(iii) のどれかが成り立つときに限る。
  よって行 r が S(d) 行 ⇔ (i)〜(iii) のどれも成り立たない。これで (d) が示せた。
  また内側の帰納法の仮定も d まで延びる。

**ステップ 3（距離 m+1 の行）**：r = a_j + m + 1 とする。k の範囲は 1 ≤ k ≤ m（r ≥ m+1 なので）。
- 行き先 r − k = a_j + (m + 1 − k) の距離 e = m + 1 − k は 1 ≤ e ≤ m。
  ステップ 2 より、この行は A 行でなく、S(e) 行か E 行。
- 系 1.2 より、k ∈ T(r) ⇔ S(k) 行 ⇔ e = k かつ k ∈ S_j ⇔ m + 1 = 2k かつ k ∈ S_j。
- よって T(r) は次のとおり。
  - m が奇数で h ∈ S_j のとき：T(r) = {h}。
  - それ以外のとき：T(r) = ∅。
- K1 より、次のどちらか。
  - (α) m が偶数、または h ∉ S_j：行 a_j + m + 1 は A 行。ステップ 2 より距離 1..m の行は A 行でないので、a_{j+1} = a_j + m + 1、g_j = m+1。
  - (β) m が奇数かつ h ∈ S_j：行 a_j + m + 1 は S(h) 行で、A 行ではない。

**ステップ 4（(β) の場合の距離 m+2 の行）**：m は奇数で、m ≥ 2 より m ≥ 3。r = a_j + m + 2、k の範囲は 1 ≤ k ≤ m。
- 行き先の距離 e = m + 2 − k は 2 ≤ e ≤ m+1。e で場合分けする。
  - **e ≤ m（2 ≤ k ≤ m）の場合**：その行は S(e) 行か E 行（ステップ 2）。
    k ∈ T(r) には e = k、つまり m + 2 = 2k が必要。m は奇数なので m + 2 も奇数で、これは起きない。
  - **e = m+1（k = 1）の場合**：その行は S(h) 行（ステップ 3 (β)）。
    k ∈ T(r) ⇔ 1 = h ⇔ m = 1。m ≥ 3 なので起きない。
- よって T(r) = ∅ で、行 a_j + m + 2 は A 行。
  距離 1..m+1 の行は A 行でないので、a_{j+1} = a_j + m + 2、g_j = m+2。

**H(j) のまとめ**：
- (a)：ステップ 3 (α) とステップ 4 から。
- (b)：ステップ 2 から。
- (c)：g_j = m+2 となるのは (β) の場合だけで、そのとき行 a_j + m + 1 は S(h) 行（ステップ 3、4）。
- (d)：ステップ 2 から。

これで H(j) が示せた。帰納法により、すべての j で H(j) が成り立つ。
また、各 j で a_{j+1} が存在するので、A 行は無限個ある。∎

**系 2.1**：m ≥ 2 で、ブロック内の行（A 行でない行）の型は (b)(c) で尽きる。
つまり、ブロック j の行 a_j + d（1 ≤ d < g_j）の P 局面は次のどちらか。
- d ≤ m：d ∈ S_j なら (a_j + d, d) だけ、d ∉ S_j ならなし。
- d = m+1：(a_j + m + 1, h) だけ。

### 定理 K3（最初のブロック）`[非形式証明]`

m ≥ 2、1 ≤ r ≤ m のとき：(r, p) が P ⇔ p = r かつ v2(r) が偶数。

（m = 1 のとき r ≤ m は r = 1 だけ。T(1) = {1}（行 0 が A 行）なので L(1) = {1}。v2(1) = 0 は偶数なので、主張は m = 1 でも成り立つ。）

証明：
- **行の型**：H(0) の (b) と系 2.1 より、行 r = a₀ + r（1 ≤ r ≤ m）の P 局面は、r ∈ S₀ なら (r, r) だけ、そうでなければなし。
  よって「r ∈ S₀ ⇔ v2(r) が偶数」を示せばよい。
- **S₀ の規則**：j = 0 なので、(d) の (ii)(iii) は成り立たない。よって r ∈ S₀ ⇔ 「r が偶数で r/2 ∈ S₀」ではない。
- **帰納法**：r についての強い帰納法で示す。帰納法の仮定は「1 ≤ r' < r のすべての r' で r' ∈ S₀ ⇔ v2(r') が偶数」。
  - r が奇数のとき：(i) は成り立たないので r ∈ S₀。v2(r) = 0 は偶数。一致する。
  - r が偶数のとき：r ∈ S₀ ⇔ r/2 ∉ S₀ ⇔（帰納法の仮定、r/2 < r）v2(r/2) が奇数 ⇔ v2(r) = v2(r/2) + 1 が偶数。一致する。∎
