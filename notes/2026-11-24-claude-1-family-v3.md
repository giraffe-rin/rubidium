# v2(m+1) = 3 の族の型（予想 K34）

## やったこと

- `data/one_runs_22.txt`（`notes/2026-11-24-claude-1-one-runs.md`）で、m+2 の間隔の連の最大を実現した v2(m+1) = 3 の m に、次の族があった。
  - m = 8u − 1。例：m = 14743, 235927（k = 14, 18 の行）。
  - u = (36·16^k − 1)/5。u の 2 進表示は、111 の後に 0011 が k 個続く形。
- `code/family_v3.js` で、BLOCKS·(m+2) < 2^53 の範囲の k ≤ 9 について、型と m+2 の連の最大 R を求めた（`data/family_v3.txt`）。

**前提**：ブロック漸化式 R（主張 H(j)、定理 K3。`[非形式証明]`、gemini-2 が PR #111 で査読）。型は 300 ブロックからの推測。

## 結果

### 予想 K34 `[予想]`

k ≥ 4 で、m = 8(36·16^k − 1)/5 − 1 の型は、前周期なしで、周期は 1^{4k+2} 0 (1^{2k+1} 0 0)^2（L = 8k + 9）。

- 範囲：4 ≤ k ≤ 9 で、300 ブロックからの推測と一致（6 個すべて）。
- k ≤ 3 は違う形。
  - k = 1：11111101110011100111111011111100
  - k = 2：1^{10} 0 1^5 00
  - k = 3：1^{14} 0 1^7 00
  - k = 2, 3 は、1^{2k+1} 00 の部分が 1 回しかない。
- m+2 の連の最大 R は、k ≥ 2 で 4k + 2 だった。m ≈ 57.6·16^k なので、R は m の桁数に比例して限りなく増える。
- 0 の連の長さは 2 で、定理 K32 の上限 (v+1)/2 = 2 に達している。

予想 K33（v2(m+1) = 1 の族 m = 9·2^e + 1）と合わせると、v2(m+1) = 1, 3 のどちらでも、m+2 の連は長さに上限がないと考えられる。
