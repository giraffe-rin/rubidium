## 記号

- 定理 K47 の族を考える：v は奇数、ρ は偶数で 4 ≤ ρ ≤ v − 1、q = 2^v − 2^ρ + 1、r = (2^ρ − 1)/3、N は偶数、s は奇数。
- R = ⌈(N − v)/ρ⌉、z = ρ/2、L = lcm(1, …, z)、M = 2^ρ − 1 とする。
- 奇数 c ≥ 3 について、t(c) = v2(c − 1) とする（2 番目に低い 1 の位置）。
- Ψ(c, k) = [t(c) + k が奇数] とする。

## 定理 K54 `[非形式証明]`

v ≥ 5 が奇数、ρ が偶数で 4 ≤ ρ ≤ v − 1 とする。R ≡ 1 (mod 2L) かつ R − 1 ≥ 2(v + 1)/ρ + ρ なら、定理 K47 の族の m について次が成り立つ。

- 間隔の列のすべての m+2 の極大な連の長さは R。
- すべての m+1 の極大な連の長さは z 以上 ⌈v/2⌉ 以下。

**系**：奇数 v ≥ 3 とすべての偶数 w ≤ v − 1 について、v2(m+1) = v、w の類の型は、周期部分だけで数えても無限に多い。

- w = 2 は定理 K36（v ≥ 3）。w ≥ 4 は上の定理。
- R ≡ 1 (mod 2L) で下限以上の R は無限にあり、各 R に ⌈(N − v)/ρ⌉ = R となる偶数 N がある。

### 証明

定理 K49、K50 と同じく、次の (A)(B)(C) による。

- **(A)** m+2 の連の長さは R。ブロック 0 からの連は定理 K47、直前に m+1 が z 個以上続く位置からの連は補題 K48 による。
- **(B)** 各連の直後に m+1 が z 個以上続く。
- **(C)** m+1 の連は ⌈v/2⌉ 個以下（補題 Q_n）。

(B) は、連 g_B..g_{B+R−1} = m+2、g_{B+R} = m+1（B はブロック 0 か、直前に m+1 が z 個以上続く位置）について、h ∉ S_{B+R+j}（1 ≤ j ≤ z − 1）を示せばよい。

**補題 K52（再帰）**：E_j(c, k)（c 奇数、c < 2^k、k ≤ v）を「距離 c(3a−1)/2^k がブロック B+R+j で入るか」とする。

- k = v なら「入る」。
- k < v なら、A = E_j(c, k+1) と、次の B を使う。
  - j ≥ 2 のとき B = E_{j−1}(2^k + c, k + 1)。
  - j = 1 のとき B = F(2^k + c, k + 1)（O 型ブロック B+R での値）。
- B が「入る」なら E は「入らない」。そうでなく、A も B も「入らない」なら E は「入る」。

**補題 K53 の (iv)（F の閉じた式）**：3 ≤ c < M、c の 2 進の語の基本周期の中の 1 の個数 ≤ z、R ≡ 1 (mod 2L)、R が下限以上なら、F(c, k) = [t(c) + k が奇数] = Ψ(c, k)。

- 閉路の長さ ℓ は 1 の個数以下なので、ℓ | L。
- R − 1 は 2ℓ の倍数なので、鎖は軌道をちょうど偶数周し、終点の b は c に戻る。
- 段数の偶奇は v − k + 1 ≡ k、終点の v2 は t(c) − 1 で、ブロック B ではこれが補題 Q_z（または K3）で分かる範囲 ≤ ρ − 1 に入る。
- 値は [t(c) − 1 が偶数] XOR [k が奇数] = [t(c) + k が奇数]。

**補題 K54.1**：1 ≤ i ≤ z − 1、c ≥ 3 奇数、c < 2^k、2 ≤ k ≤ ρ − 1 − 2i、(c の 1 の個数) + i ≤ z なら、E_i(c, k) = Ψ(c, k)。

まず、次の (∗) を確かめる。c < 2^k なので、c' = 2^k + c は c の上に新しい 1 を 1 つ加えたものになる。

- c ≥ 3 なら、c の下位の 2 つの 1 は変わらないので、t(c') = t(c)。
- よって Ψ(c', k + 1) = [t(c) + k + 1 が奇数] = ¬Ψ(c, k)。
- c' の 1 の個数は c より 1 多い。

**i = 1 の場合**：B = F(c', k + 1)。

- c' < 2^{k+1} ≤ 2^{ρ−2} < M で、c' の 1 の個数 = (c の 1 の個数) + 1 ≤ z。よって F の閉じた式が使え、B = Ψ(c', k + 1) = ¬Ψ(c, k)。
- **Ψ(c, k) = 0 のとき**：B = 1 なので、E_1(c, k) = 0 = Ψ(c, k)。
- **Ψ(c, k) = 1 のとき**：B = 0。
  - A = E_1(c, k + 1) で、Ψ(c, k + 1) = 0。
  - k + 1 ≤ ρ − 2 なら、前の場合と同じく、F(2^{k+1} + c, k + 2)（2^{k+1} + c < 2^{k+2} ≤ 2^ρ − 1）から A = 0。よって E_1 = 1 = Ψ。
  - これには k ≤ ρ − 3 が要る。範囲 k ≤ ρ − 1 − 2 = ρ − 3 はちょうどこれである。

**i ≥ 2 の場合**（i − 1 で成り立つとする）：B = E_{i−1}(c', k + 1)。

- c' は (c' の 1 の個数) + (i − 1) = (c の 1 の個数) + i ≤ z を満たす。
- k + 1 ≤ ρ − 2i ≤ ρ − 1 − 2(i − 1) なので、帰納法の仮定の範囲にある。よって B = Ψ(c', k + 1) = ¬Ψ(c, k)。
- **Ψ(c, k) = 0 のとき**：B = 1 なので、E_i = 0 = Ψ。
- **Ψ(c, k) = 1 のとき**：B = 0。
  - A = E_i(c, k + 1) で、Ψ(c, k + 1) = 0 なので、前の場合（k + 1 について）を使う。
  - そのためには、B' = E_{i−1}(2^{k+1} + c, k + 2) が仮定の範囲にあればよい。k + 2 ≤ ρ − 1 − 2(i − 1) ⇔ k ≤ ρ − 1 − 2i で、範囲どおり。
  - よって A = 0、E_i = 1 = Ψ。∎

**(B) の証明**：E_j(1, 1)（1 ≤ j ≤ z − 1）を考える。e の項は (2^1 + 1, 2) = (3, 2) である。

- j = 1 のとき：B = F(3, 2) = Ψ(3, 2) = [1 + 2 が奇数] = 1（3 < M、3 の 1 の個数 2 ≤ z）。
- j ≥ 2 のとき：B = E_{j−1}(3, 2)。補題 K54.1 の範囲は 2 ≤ ρ − 1 − 2(j − 1) ⇔ j ≤ (ρ + 1)/2 と、2 + (j − 1) ≤ z ⇔ j ≤ z − 1 で、どちらも満たす。よって B = Ψ(3, 2) = 1。
- どちらでも B = 1 なので、E_j(1, 1) = 0、つまり h ∉ S_{B+R+j}。∎

**R の下限**：補題 K53 の (4) とその証明から、入口 c ≥ 3 の軌道での r の平均 d/ℓ は ρ/2 以下である。

- ℓ = 1 なら d は ρ の真の約数なので d ≤ ρ/2。ℓ ≥ 2 なら d/ℓ ≤ ρ/2。

鎖の条件は次のとおり。

- **(a) v2(β) < N と (d) d ≠ h − 1**：奇数の点の K ≤ v + (R − 1)ρ/2 + zρ と、N ≥ v + ρ(R − 1) + 1 から、N − K ≥ ρ(R − 1)/2 − zρ + 1。これが v + 2 以上なら成り立つ（R − 1 ≥ 2(v + 1)/ρ + ρ で十分）。
- **(b) (M+d)/2 ≤ m**：b < 3r による（補題 K53）。

∎
