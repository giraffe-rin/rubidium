# 定理 K64（1^{j+2} 0 型）の Lean 4 での証明

## やったこと

PR #446 で立てた予想 K64 を、Lean で直接証明した（`lean/Rubidium/K64.lean`、sorry なし）。

```lean
def k64X (m w : Nat) : Nat → Nat
  | 0 => (m + 2 + w) / 2
  | t + 1 => (m + 2 + k64X m w t / 2) / 2
theorem K64 (m h w j : Nat) (hmh : m + 1 = 2 * h) (hW : 3 * h + 1 = 4 * w) (hwo : w % 2 = 1) (hm9 : 9 ≤ m)
    (hX : ∀ t, t < j → k64X m w t % 4 = 2) (hXj : k64X m w j % 2 = 1) (n : Nat) :
    IsP m n 0 ↔ (n % L % (m + 2) = 0 ∧ n % L ≤ (j + 2) * (m + 2))   -- L = (j+2)(m+2) + (m+1)
```

公理は `[propext, Classical.choice, Quot.sound]`。予想 K64 の主張（型は前周期なしで 1^{j+2} 0）と同じ。仮定の X_t ≡ 2 (mod 4) は v2(X_t) = 1 と同じ。

## 証明（局面の言葉）

周期の中の行は、a（始まり）、B_r = a + r(m+2)（r = 1, …, j+2。O 型が続く）、a' = B_{j+2} + (m+1)（次の始まり）。

- **`k64_shift`**：O 型の B_r では、X_s ≡ 2 (mod 4) について (B_r + X_s) が P ⇔ (B_{r−1} + X_{s+1}) が P。
  - 半分にする規則（`o_half'`）で、(B_r + X_s) が P ⇔ (B_r + X_s/2) が N。
  - X_s/2 は奇数。奇数の規則（`o_odd_iff`）で、その相手は (m+2+X_s/2)/2 = X_{s+1}。
  - 例外の条件（2z+1 ≠ h など）は、X_s ≡ 2 (mod 4)、h ≡ 1 (mod 4)、4X_s ≤ 3m + 6 から出る。
- **`k64_chain`**：これをくり返すと、(B_r + X_s) が P ⇔ (a + X_{s+r}) が P（s + r ≤ j）。
- **`k64_hfact`**：i ≥ 1 について、(B_i + h) が P ⇔ i ≤ j + 1。
  - i = 1 では、相手 (a + 2w) の v2 が 1 なので N。よって P。
  - i ≥ 2 では、次の順にたどる。
    1. (B_i + h) が P ⇔ (B_{i−1} + 2w) が N
    2. ⇔ (B_{i−1} + w) が P
    3. ⇔ (B_{i−2} + X₀) が N
    4. ⇔ (a + X_{i−2}) が N
    5. ⇔ X_{i−2} が偶数 ⇔ i − 2 < j

    最後の 2 段は、始まりの行の Blk m 1（v2 ≤ 1 なら P ⇔ v2 が偶数）による。
- **`k64_step`**：行 B_1, …, B_{j+2} は `row_long` で、a' は `row_next` で、すべての p で P。a' では `blk1_direct` より Blk m 1。
  - 始まりの行に要るのは Blk m 1 だけなので、周期についての帰納法（`k64_rows`）が閉じる。

## 意味

- 予想 K64 が、非形式証明を経ずに [Lean検証済み] の候補になった（査読待ち）。H(j) を使わない。
- Lean で型が決まる m の割合（m ≤ 10^6、`data/lean_coverage.txt`）：
  - v2(m+1) = 1 で 83.33% → **87.50%**
  - 全体で 92.00% → **93.04%**
- v2(m+1) = 1 で残るのは、v2(3h+1) が偶数で、列のどこかで v2(X_t) ≥ 2 になるもの（k = 1）と、k ≥ 2 で Q が偶数のもの。
