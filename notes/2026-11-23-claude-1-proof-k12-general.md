- 証明書が成功すれば、その k について Q_k が奇数のすべての m が 1(10)^k 型になることを示した（定理 K15 の証明の補題 A〜D）。

## 結果

### 定理 K15 `[非形式証明]`（計算機による証明書つき）

v2(m+1) = 1、v2(3h+1) = 2k（2 ≤ k ≤ 16）、Q_k が奇数とする。このとき m は 1(10)^k 型である。
すなわち、すべての i ≥ 0 と 0 ≤ r ≤ 2k について、g_{(2k+1)i + r} = m+2 ⇔ (r = 0 または r が奇数)。

### 系 K15.1 `[非形式証明]`

v2(m+1) = 1、v2(3h+1) = 2k で 2 ≤ k ≤ 16 なら、次が成り立つ。
- m が 1(10)^k 型 ⇔ v2(Q_k) = 0。
- 「⇐」は K15。「⇒」は系 K14.1 (1)。系 K14.1 (1) では m = 9 だけ計算で確かめている。

### 証明（定理 K15）

k を固め、L = 2k + 1 とする。

**準備。**
- Q_k = h + (w+1)/2 で h は奇数なので、Q_k が奇数 ⇔ w ≡ 3 (mod 4)。
- 4^k w = 3h + 1 ≡ 1 (mod 3) より w ≡ 1 (mod 3)。
- よって w ≡ 7 (mod 12)、特に w ≥ 7。
- 次の値は奇数である：w、h、Q_k、m + 2 = 2h + 1。

**3 つの形。** 整数 c, b について次のようにおく。
- W(c) := c·w
- H(c) := h + c·w
- Q(b) := Q_k + b·w

偶奇は w によらない。
- W(c) は c と同じ偶奇。
- H(c) と Q(b) は、それぞれ c + 1、b + 1 と同じ偶奇。

**補題 B（範囲）。** w ≥ 7 なら、次が成り立つ。
- 1 ≤ W(c) ≤ m ⇔ 1 ≤ c ≤ A。ここで A := (2·4^k − 2)/3。
- H(c) ≤ m ⇔ c ≤ B。ここで B := (4^k − 1)/3（c ≥ 0）。
- c が奇数で c ≤ A なら、(m+2+W(c))/2 ≤ m。

証明：
- m = (2·4^k w − 5)/3、h − 1 = (4^k w − 4)/3 である。
- W(c) ≤ m ⇔ 3c ≤ 2·4^k − 5/w = 3A + 2 − 5/w。0 < 5/w < 1 なので、⇔ c ≤ A。
- H(c) ≤ m ⇔ c·w ≤ h − 1 ⇔ 3c ≤ 4^k − 4/w = 3B + 1 − 4/w。0 < 4/w < 1 なので、⇔ c ≤ B。
- 3 つ目：(m+2+cw)/2 ≤ m ⇔ cw ≤ m − 2 ⇔ 3c ≤ 3A + 2 − 11/w。
  w ≥ 7 なら 2 − 11/w > 0 なので、c ≤ A なら成り立つ。∎

**補題 C（(iii) は効かない）。** w ≥ 7 なら、h − 1 は W(c)（c ≥ 1）、H(c)（c ≥ 0）、Q(b)（b ≥ 0）のどれとも等しくない。
- W(c) = h − 1 なら 3cw = 4^k w − 4 となり、w は 4 を割る。これは w ≥ 7 に反する。
- H(c) ≥ h > h − 1。
- Q(b) ≥ Q_k = h + (w+1)/2 > h − 1。∎

**補題 D（規則は形の中で閉じる）。**

まず、1(10)^k 型を仮定する。このとき剰余 r（j ≡ r (mod L)）のブロックの種類は次のとおり。
- r = 0（j ≥ L）：E 型
- r = 1：O 型
- r が 2 以上の偶数：O 型
- r が 3 以上の奇数：E 型

（K12″ のログと同じ。r の 1 つ前の間隔 g_{r−1} から決まる。）

ブロック漸化式の (i)(ii) で出てくる値は次のとおりで、どれもまた 3 つの形のどれかになる。
- (i)：x = W(c)（c は偶数）なら x/2 = W(c/2)。
- (ii)、E 型（1 つ前の間隔 m+1 = 2h）：
  - x が奇数なら (ii) は成り立たない（2h + x が奇数）。よって E 型の奇数はすべて入る。
  - x = W(c)（c は偶数）なら e = h + (c/2)w = H(c/2)。
- (ii)、O 型（1 つ前の間隔 m+2）：
  - x が偶数なら (ii) は成り立たない。
  - x = W(c)（c は奇数）なら e = (m+2+cw)/2 = Q((c−1)/2)。
  - x = H(c)（c は偶数）なら e = (3h+1+cw)/2 = ((4^k + c)/2)·w = W((4^k + c)/2)。

証明書の作り方は次のとおり（`code/k12_symbolic.js`）。
- 「剰余 r のブロックに x が入るか」を、上の規則で再帰的に求める。
- (i) が成り立てば、その時点で「入らない」とし、(ii) は調べない。
- (ii) の e が m を超えるとき（補題 B で判定）は、(ii) は成り立たないとする。
- Q 型の値は、E 型のブロックで奇数として現れたときだけ扱う（「入る」）。
- 次のどれかが起きたら「失敗」とする。
  - 上の形にならない値が出た。
  - Q 型の値が O 型のブロックか、偶数として現れた。
  - 依存が循環した。
- 最後に次の 2 つを確かめる。
  - 各 r で h が入るか（= g_r が m+2 か）が、1(10)^k 型の要求と一致すること。
  - r = 0 で使った事実がすべて定理 K3 の値と一致すること。
    - W(c) なら v2(c) が偶数 ⇔ 入る。
    - 奇数の H(c)、Q(b) なら入る。
    - 偶数の H(c) が出たら失敗とする（K3 の値が w によるため）。

**証明書から定理へ。** 証明書が成功したとし、その事実の集まりを F とする。F の要素は (r, x, v) で、「剰余 r のブロックで x ∈ S ⇔ v」を表す。

主張 Ψ(j) を次のように定める。
- 剰余 r ≡ j の F の事実 (r, x, v) について、x ∈ S_j ⇔ v。
- g_j は 1(10)^k 型の値に等しい。

Ψ(j) を j についての強い帰納法で示す。
- **j = 0**：S₀ は K3 で決まる。最後の確認より、r = 0 の F の事実は K3 と一致する。h ∈ S₀ なので g₀ = m+2 で、型と一致する。
- **j ≥ 1**：Ψ(j−1) より g_{j−1} は型の値なので、ブロック j の種類は上の表のとおり。
  - j = 1 では、1 つ前のブロックは K3 のブロック 0 である。証明書は r = 0 を E 型として計算したが、使った r = 0 の事実は K3 と一致するので、これでよい。
  - F の各事実 (r, x, v) は、証明書の中で次の 2 つから導かれている。
    - 同じブロックの x/2 についての事実（x/2 < x なので、x についての帰納法で先に成り立つ）
    - 1 つ前のブロックの e についての事実（Ψ(j−1)）
  - 補題 B より、範囲の判定は実際の値と一致する。補題 C より (iii) は効かない。補題 D より、規則の適用は記号のままで正しい。
  - よって x ∈ S_j ⇔ v。h についての事実と H(j)(c) より、g_j は型の値になる。

したがって、すべての j で Ψ(j) が成り立ち、m は 1(10)^k 型である。∎

**計算の結果**（`data/k12_symbolic.txt`）：2 ≤ k ≤ 16 のすべてで証明書は成功した。
- 事実の個数は、k = 2 で 27 個、k = 3 で 74 個、…、k = 16 で 2359277 個。
- k = 2 の 27 個は、K12″ (a) の手による証明（Ψ(j)）と同じ内容を含む。
