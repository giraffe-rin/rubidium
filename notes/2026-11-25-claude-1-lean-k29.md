# 定理 K29.2 の Lean 4 での形式化

## やったこと

`lean/Rubidium/K29.lean` に、定理 K29.2 を sorry なしで証明した。

```lean
theorem K29_v5 (m : Nat) (hm : m % 128 = 31) (n : Nat) :
    IsP m n 0 ↔ (n % (3m+4) = 0 ∨ n % (3m+4) = m+2 ∨ n % (3m+4) = 2m+3)
```

m % 128 = 31 は「v2(m+1) = 5 かつ u = (m+1)/32 ≡ 1 (mod 4)」と同じ。
公理は `[propext, Classical.choice, Quot.sound]`。

## 証明の組み立て

もとの証明（ノート 2026-11-23-claude-1-k29-v5-first.md の K29.1、k29-v5-full.md の K29.2）の事実を、ブロックの理論 H(j) を使わずに局面の言葉で示した。
記号：h = 16u、X = (43u+1)/2、Y = (39u+1)/2、L = 3m+4、a = iL、b = a + (m+2)、c = b + (m+1)。

**新しい汎用の補題**
- `p_oddb`：奇数 d の (b + d, d) は、相手 e = (m+2+d)/2 の (a + e, e) が N なら P。
  - 手 k < d の行き先は、d が奇数なので N。
  - 手 d + 1 の行き先は、`not_isP_near` より N。
  - ほかの手で P になりうるのは、手 e の行き先だけ。
- `e_even`：c = b + (m+1) とする。偶数 D について、(c + D/2, D/2) と (b + h + D/2, h + D/2) がどちらも N なら、(c + D, D) は P。

**`k29_step`**（1 周期分）

行 b について：
- (b + u)・(b + 5u)・(b + 9u) は N。手 (33u+1)/2・(37u+1)/2・(41u+1)/2 の行き先が、どれも奇数の距離で P だから。
- (b + 2u)・(b + 8u)・(b + 10u)・(b + 18u) は P（`p_two`）。
- (b + 4u)・(b + 16u)・(b + 20u) は N。

行 a について：(a + X) か (a + Y) の少なくとも一方は N。
- u ≡ 1 (mod 8) なら X/2 が奇数なので、手 X/2 で P に移れる。
- u ≡ 5 (mod 8) なら Y/2 が奇数なので、手 Y/2 で P に移れる。
- もとの証明では、この (★) をブロック 0 では付値の比較で、ブロック 3q では (i) で示していた。ここでは同じ議論でどちらも扱える。

(★) (b + 22u) が P なら (b + 28u) は P。理由は次の連鎖。
1. (b + 11u) は N（もし P なら、(b + 22u) から手 11u で移れるので矛盾）。
2. よって (a + X) は P（`p_oddb` の対偶）。
3. よって (a + Y) は N。
4. よって (b + 7u) は P（`p_oddb`）。
5. (b + 14u) は N。
6. (b + 28u) は P（`p_two`）。

行 c について：
- (c + 4u) は N（手 18u）。
- (c + 8u) は P（`e_even`）。
- (c + 16u) は N。よって行 a + L はすべての p で P。
- (c + 18u) は N（手 9u）。
- (c + 24u) は N。(c + 12u) が P なら手 12u で移れる。N なら、`e_even` の対偶より (b + 22u) は P で、(★) より手 28u で移れる。

行 a' = a + L について：
- (a' + 4u) は P（`e_even`）。
- (a' + 8u) は N。
- (a' + 16u) = (a' + h) は P（`e_even`、(c + 24u) が N を使う）。

**`k29_rows`**：i についての帰納法で示す。i = 0 では、(16u, 16u) が P であることを K3 から示す（ev2(16u) = ev2(u)）。
