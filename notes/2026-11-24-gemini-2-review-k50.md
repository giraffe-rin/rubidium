## 数学的・計算機証明の健全性監査（査読依頼点の精査を含む）

### 1. 鎖の条件 `(a)`・`(b)`・`(c)`・`(d)` と `c = 1` 入口

- **`c = 1` の入口**：ブロック `B + R` は O 型で `h ∉ S_{B+R}`（定理 K47 / 補題 K48）かつ `v2(h) = v - 1` より、`1 ≤ k ≤ v` のとき `(3a - 1)/2^k = h / 2^{k - 1}` は O 型偶数遷移を `k - 1` 回たどった点であり、`[h/2^{k-1} ∈ S_{B+R}] = ((k - 1) 奇数)` は完全に厳密。
- **条件 `(b)`（`b < 3r` ⇒ `(M+d)/2 ≤ m`）**：`b` 奇数・`3r = 2^ρ - 1` 奇数より `b ≤ 3r - 2`。よって奇数の点で `d < ab/r ≤ (3 - 2/r)a`、`(M+d)/2 < (3 - 1/r)a = 3a - a/r < 3a - 2 = m`（`a/r > 2`）。
- **条件 `(c)`（`d > 0`、ログ省略部の完全補完）**：`β_i = b_i · 2^{K_i}` は奇数の段ごとに `β_{i+1} = β_i + 3r·2^{K_i}` と**狭義単調増加**するため、全段で `β_i ≥ β_1 = c·2^v` が成り立つ。したがって `b_i - cq/2^{K_i} = (β_i - cq)/2^{K_i} ≥ 3rc/2^{K_i}` となり、任意の正の奇数 `s ≥ 1` に対して `s·2^N(b_i - cq/2^{K_i}) ≥ 3rc·2^{N - K_i} ≥ 3rc·2^{v+3} > r·b_i`、すなわち全段で `d > 0` が無条件に成立する。
- **条件 `(a)`・`(d)`（`Kodd + v + 2 < v + ρ(R - 1) + 1 ≤ N`）**：
  - `b < 3r = 2^ρ - 1` より `b + 3r < 2^{ρ+1} ≤ 2^v` なので `t = v2(b + 3r) ≤ ρ ≤ v - 1 < v + 2`、よって `v2(β) = Kodd + t < Kodd + v + 2 < N`（条件 `(a)`、および終点 `vend = t - 1 ≤ ρ - 1`）。
  - `d = h - 1` とすると `(2b - 3r)s·2^N + r(3(q + r) - 2b) = cqs·2^{N - K + 1}`。`K ≥ v > 1`・`r` 奇数より `2^{N - K + 1} | (3·2^v - 6r - 2b)`。`b < 3r`・`3r < 2^{v-1}` より `6r + 2b < 12r < 2·2^v` なので `0 < 3·2^v - 6r - 2b < 3·2^v < 2^{v+2}`。一方 `N - K + 1 ≥ v + 4 > v + 2` なので完全に不可能（条件 `(d)`）。

### 2. 査読依頼点：Kleene 3 値評価と `R` についての周期性・単調性

- **3 値評価の単調性**：`E(j, x)` の評価則（`bb === true || aa === true ⇒ false`、`aa === false && bb === false ⇒ true`、それ以外 `null`）は Kleene 3 値 NOR であり、情報順序 `null ⊑ true, null ⊑ false` に関して**完全に単調**である。したがって、ある `R_1` で `E(j, H) = false` と確定していれば、より大きい `R_1 + mP` で一部の `null` 入力が確定値（`true`/`false` いずれでも）に変わっても、出力 `false` が覆ることは絶対にない。
- **`R → R + mP` における確定鎖の不変性と余裕の単調増加**：
  - `code/k50_general.js` 自体は `orbitLen(c)` のみを計算し `preperiod(c) < R0` を明示チェックしていなかったため、独立検証スクリプト `code/gemini2_verify_k50.py` で**全 28 組のすべての確定鎖について `preperiod(c) < R` および閉路 `≠ {1}` を明示検証**した。
  - その結果、全 28 組のすべての確定鎖が **`preperiod(c) = 0`**（1 歩目から純周期的）かつ閉路 `≠ {1}` であった。
  - 閉路 `≠ {1}` の任意の要素 `b > 1`（`< 3r`）は `t = v2(b + 3r) ≤ ρ - 1` を満たすため、`R → R + mP` で右辺 `v + ρ(R - 1) + 1` が `ρ·mP` 増えるのに対し、`Kodd` は 1 段あたり高々 `ρ - 1` しか増えず、条件 `(a)/(d)` の余裕は全段で少なくとも `+mP` だけ単調増加する。また `2ℓ | P` より `s(R + mP) - s(R)` は常に偶数、`b_{R + mP} = b_R` となる。
- **`leM(x)` と `a_min` の明示確認**：`code/k50_general.js` の `leM` は漸近判定（`co < 0 ⇒ true`）のみであったが、独立検証で `R ≥ 3v` に対応する最小 `a_min` に対して全節点で `co · a_min ≤ rhs`（`co < 0`）・`co · a_min > rhs`（`co > 0`）・`d > 0`・`max_k = 17 ≪ N_min` を明示検証し、例外なく成立することを確認した。
