  - 多いものは次のとおり。
    - 「10」（交互型）369 個
    - 「110」93 個
    - 「100」54 個
    - 「1110」22 個
    - 「11010」16 個

  - k = 1 なら「110」、k = 2 なら「11010」、k = 3 なら「1101010」、k = 4 なら「110101010」。

**前提**：`notes/2026-11-23-claude-1-proof-structure.md` の系 1.1、主張 H(j)、定理 K3（`[非形式証明]`、未査読）。

## 結果

### 記号と型

- 「m が **110 型**」とは、すべての i ≥ 0 で次が成り立つこととする。
  - g_{3i} = g_{3i+1} = m+2
  - g_{3i+2} = m+1
- このとき A 行は a_{3i} = i(3m+5)、a_{3i+1} = i(3m+5) + m + 2、a_{3i+2} = i(3m+5) + 2m + 4（i についての帰納法）。
- 系 1.1 より、110 型 ⇔ すべての n ≥ 1 で「(n, 0) が P ⇔ n mod (3m+5) ∈ {0, m+2, 2m+4}」。
  （0 < m+2 < 2m+4 < 3m+5 なので、剰余で正しく表せている。）

### 定理 K12 `[非形式証明]`

m ≥ 5 で v2(m+1) = 1（h = (m+1)/2 は奇数）、v2(3h+1) = 2 とする。Q := (11h + 5)/8 とおく。このとき次が成り立つ。
- (a) Q は整数。Q が奇数なら、m は 110 型。
- (b) g₀ = g₁ = m+2。g₂ = m+2 ⇔ v2(Q) が奇数。特に v2(Q) が奇数なら、m は 110 型でない。

#### 準備

- v2(3h+1) = 2 なので、3h + 1 = 4w（w は奇数）と書ける。
  e* := (3h+1)/2 = 2w。m + 2 = 2h + 1、m + 2 + h = 3h + 1。
- **Q が整数であること**：3h + 1 ≡ 4 (mod 8) なので 3h ≡ 3 (mod 8)、h ≡ 1 (mod 8)。よって 11h + 5 ≡ 16 ≡ 0 (mod 8)。
- **Q の意味**：(m + 2 + w)/2 = (2h + 1 + (3h+1)/4)/2 = (11h + 5)/8 = Q。
- **値の範囲**：
  - e* ≤ m ⇔ 3h + 1 ≤ 4h − 2 ⇔ h ≥ 3。
  - Q ≤ m ⇔ 11h + 5 ≤ 16h − 8 ⇔ 5h ≥ 13 ⇔ h ≥ 3。
  - m ≥ 5 なので h ≥ 3。
- **(iii) の対象**：h − 1 は偶数。下で追う距離のうち偶数は e* = 2w だけで、e* = h − 1 ⇔ 3h + 1 = 2h − 2 となり不可能。
  奇数の距離（h, w）には (iii) は効かない。

#### ブロックの種類と規則

1 つ前の間隔で、規則（H(j)(d)）は次のようになる。
- **1 つ前の間隔が m+1（偶数）（「E 型」）**：奇数 d はすべて入る（(i)(ii)(iii) のどれも成り立たない）。
- **1 つ前の間隔が m+2（奇数）（「O 型」）**：
  - 奇数 d（≠ h − 1）：(i)(iii) は成り立たない。e = (m+2+d)/2 ≤ m なら、d ∈ S_j ⇔ e ∉ S_{j−1}。
  - 偶数 d（≠ h − 1）：(ii) は m + 2 + d が奇数なので成り立たない。よって d ∈ S_j ⇔ d/2 ∉ S_j。

#### 証明 (b)

- **g₀**：定理 K3 より h ∈ S₀（h は奇数）。H(0)(c) より g₀ = m+2。
- **g₁**：ブロック 1 は O 型。h ∈ S₁ ⇔ e* ∉ S₀。v2(e*) = 1 なので、K3 より e* ∉ S₀。よって h ∈ S₁、g₁ = m+2。
- **g₂**：ブロック 2 も O 型（g₁ = m+2）。
  - h ∈ S₂ ⇔ e* ∉ S₁。
  - e* = 2w（偶数、O 型）について、e* ∈ S₁ ⇔ w ∉ S₁。
  - w（奇数、O 型）について、w ∈ S₁ ⇔ Q ∉ S₀ ⇔ v2(Q) が奇数（K3）。
  - よって h ∈ S₂ ⇔ e* ∉ S₁ ⇔ w ∈ S₁ ⇔ v2(Q) が奇数。
  - H(2)(c) より主張が成り立つ。∎

#### 証明 (a)

Q が奇数とする。主張 Θ(j) を次のように定める。
- **j ≡ 0 (mod 3)**：
  - (E1) すべての奇数 d が S_j に入る
  - (E2) e* ∉ S_j
  - g_j = m+2
- **j ≡ 1 (mod 3)**：
  - (P1) w ∉ S_j
  - (P2) e* ∈ S_j
  - (P3) h ∈ S_j
  - g_j = m+2
- **j ≡ 2 (mod 3)**：
  - (R1) h ∉ S_j
  - g_j = m+1

Θ(j) を j についての強い帰納法で示す。帰納法の仮定は「Θ(0), …, Θ(j−1) が成り立つ」こと。

- **j ≡ 0 (mod 3)**：
  - j = 0：K3 より奇数はすべて入り、v2(e*) = 1 なので e* ∉ S₀。h ∈ S₀ より g₀ = m+2。
  - j ≥ 3：仮定より g_{j−1} = m+1 なので E 型。奇数 d はすべて入る。
    e* = 2w で w は奇数なので w ∈ S_j、(i) により e* ∉ S_j。h（奇数）∈ S_j より g_j = m+2。
- **j ≡ 1 (mod 3)**：仮定より g_{j−1} = m+2 なので O 型。S_{j−1} は (E1)(E2) を満たす。
  - (P1)：w は奇数で、e = Q ≤ m。Q は奇数なので Q ∈ S_{j−1}（(E1)）。よって w ∉ S_j。
  - (P2)：e* は偶数で、e* ∈ S_j ⇔ w ∉ S_j。(P1) より成り立つ。
  - (P3)：h は奇数で、e = e* ∉ S_{j−1}（(E2)）。よって h ∈ S_j。
  - H(j)(c) より g_j = m+2。
- **j ≡ 2 (mod 3)**：仮定より g_{j−1} = m+2 なので O 型。S_{j−1} は (P2) を満たす。
  - (R1)：h は奇数で、e = e* ∈ S_{j−1}（(P2)）。よって h ∉ S_j。
  - H(j)(c) より g_j = m+1。

帰納法により、すべての j で Θ(j) が成り立つ。よって m は 110 型。∎
