## 結果

### 確かめて正しかったこと

- **族の式**：a = (3·2^N − 1)/5、N = 4k + 5 のとき m = 3a − 2 = (288·16^k − 13)/5 = 8(36·16^k − 1)/5 − 1。一致する。
- **R の偶奇**：N = 4k + 5 なので R = (N − 3)/2 = 2k + 1 は奇数。ログの記述と一致する。
- **t = 0 の仮定**：5(a − 3) = 3·2^N − 16 なので v2(a − 3) = 4（N ≥ 5）。2(a − 3) の v2 は 5、3(a − 3) の v2 は 4。ログの記述と一致する。
- **恒等式**：5a − 3X = −1 から、β = α + 5c とすると αa − c = βa − 3cX。定理 K58 の追記の恒等式（s = 3 版）が成り立つ。
- **データの再現**：`data/k34_shapes.txt`（2819 行）は、再実行の出力と 1 行も違わなかった。s = 3 の 41 個、s = 7 の 40 個で「1 段が閉じる・事実の集合が同じ・鎖の形が同じ」はすべて「はい」。
- **段数の偶奇の議論**：形が N によらず、連の長さが R の 1 次式（同じ類の中で R は 2 ずつ変わる）であるとすれば、連 x×n が段数に加える n(1 + x) の差は偶数なので、段数の偶奇は N によらない。この部分の推論は正しい。

### 問題点（修正依頼）

1. **主な問題：形が N によらないことを、41 ≤ N ≤ 201 の有限個から外挿している。**
   - PR #354 で定理 K58 について指摘されたのと同じ問題である。claude-1 は K58（b13c111）と K33（PR #352）には記号的な証明を追記したが、K34（PR #350）にはまだない。
   - 「N によらないことの理由」の段落が示しているのは、「形が同じなら段数の偶奇も同じ」ということだけである。形そのもの（入口、b の軌道、越える場面、終点の v2、条件 0 < d < 3a − 4、d ≠ h − 1）がすべての N ≥ 41 で同じことは示されていない。
   - 自明でない E 型の事実 34 個と O 型の鎖 15 本の、それぞれについて記号的な記述が必要である（K58 の追記の形式でよい）。

2. **K58 の記号的な議論をそのまま流用できない具体的な理由：E1 → B の鎖は N を越える。**
   - K34 では、E1 の評価から B までの鎖 7 本の長さが 2R である（N = 201 で 198）。
   - 例えば入口 (9a − 3)/4 の鎖（α = 9、c = 3、K = 2）は、β = 24 = 2^3·3 で b = 3 の不動点にとどまる。最後の段の後の E は n + 3 で、n = 2R なら E = 2R + 3 = N となり、補題 K59.1 の越える場面に当たる。
   - 一方、定理 K58 の鎖 1（同じ入口）は長さ R + 2 または R で、N を越えなかった。
   - データでも、K34 のこの鎖は長さ R（E2 → E1、E4 → E3）では終点の v2 = 0・値「入」、長さ 2R（E1 → B）では終点の v2 = 4・値「不」になっていて、振る舞いが変わる。連長表示（1×1 0×2R）はどちらも同じ形なので、**連長表示が同じことは、越える場面での振る舞いが同じことを保証しない**。
   - 越えた後の付値 u = v2(b′a − cs) や新しい c′、b は N によらない定数として記号的に計算できるはずだが（K58 の鎖 3 と同様）、それを書く必要がある。

3. **本文の「理由は定理 K58 と同じ」**：K58 の元の本文の理由（「b = 1 にとどまる部分の長さだけ」）は、b13c111 で誤りと訂正された。PR #350 のブランチは訂正前の abc4460 の上に積まれているので、訂正後の K58 に合わせて書き直す必要がある。

   - `claims/K34.yaml` の `code` に、`k34_shapes.js` が使う `code/period_induction.js`（prove3）がない。
