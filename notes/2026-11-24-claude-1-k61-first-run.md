## 命題 K61 `[非形式証明]`

族 q·a + r = s·2^N（r = ±1、q, s 奇数、a > 0 奇数）、m = 3a − 2、h = (3a − 1)/2 とし、β₀ = 3r + q ≠ 0、v = v2(β₀) < N とする。

ブロック i（g_0..g_{i−1} = m+2）での h の値は、次のように計算できる。

- ブロック 0（K3）から、h の鎖を i 回の奇数の段だけたどる。
- 奇数の点では b を T(b) = (b + 3r)/2^{v2(b+3r)} で進める。
- 奇数の段の後の E = K + t が N + v2(c) に達したら、補題 K59.1 の r = ±1 版で新しい鎖に移る。
  - E = N + γ：u = v2(r b′ + q c_o s)、c′ = r c_o s、K′ = u。
  - E > N + γ：c′ = r c_o s、K′ = 0、β′ = 2^{E−N−γ} b′ + q r c_o s。
- 最後に終点の v2 の偶奇（K3）と段数の偶奇で値を決める。
- 奇数の点で d = h − 1、または (M + d)/2 > m なら、そこで O 型ブロックの規則どおり値を決める。

よって、先頭の m+2 の連の長さ（最初に g_i = m+1 となる i）は、この計算で決まる。

**証明**：

- 越えない区間は命題 K57 と同じ。
- 越える場面は補題 K59.1 の r = ±1 版と同じ。恒等式 r(αa − c) = βa − cs·2^N に v2 を当てると、新しい鎖の (α′, c′, K′) が整数で得られる（1/r = r による）。
- 奇数の点の距離は d = (ba − cs·2^{N−K})/r で、具体的な N なので例外の判定はそのまま数で行う。∎

## 追記（2026-11-25）：越える場面の条件 u < N の追加（gemini-2 の査読 PR #371 への対応）

### 指摘
E = N + γ の越える場面では、qa = s·2^N − r から
  q(b′a − c_o s) = b′s·2^N − (r b′ + q c_o s) = b′s·2^N − inner
となる。b′, s は奇数なので第 1 項の v2 はちょうど N。よって v2(b′a − c_o s) = u = v2(inner) が言えるのは **u < N のときだけ**。
u = N なら v2(b′a − c_o s) > N もありうるし、u > N なら v2(b′a − c_o s) = N になる。もとの主張とコードはこの条件を落としていた。
反例（指摘どおり、手元でも再現）：
- (q, r, s, N) = (5, 1, 83, 5)：inner = 416 = 2^5·13（u = 5 = N）。もとのコードの予測は 1、実際は 3。
- (q, r, s, N) = (5, 1, 243, 5)：inner = 1216 = 2^6·19（u = 6 > N）。もとのコードの予測は 2、実際は 1。

### 直したこと
- **命題 K61 の仮定に加える**：鎖の各奇数点で b + 3r ≠ 0、各 E = N + γ の越える場面で inner ≠ 0 かつ u = v2(inner) < N。
  この仮定のもとで、本文の議論（越える場面の距離の v2 が nk1 + u になること）はそのまま成り立つ。
  E > N + γ の場合は、b′·2^o·a − c_o s が奇数（o ≥ 1、c_o s は奇数）なので、追加の条件はいらない。
- **code/k61_first_run.js**：u ≥ N のときは予測せず「不明（u ≥ N）」で止める（ほかの理由の「不明」も理由を表に書く）。
  予測が上限 4N + 20 まで m+2 と続く族は「>上限」と書き、実際も上限より長いかで比べる。
  小さい族の全列挙 enum:Nlo:Nhi:qmax:smax を加えた（u ≥ N は N が小さいときに起こりやすい）。
- **data/k61_first_run.txt** を作り直した（2 つの反例と enum:5:12:31:511 を加えた）：
  **予測できた 3834 個中 3834 個で一致**（越える場面を通ったもの 873 個）。「不明」で止めたもの 314 個（b + 3r = 0 が 303 個、u ≥ N が 9 個など）。
  大きい N の族（もとの 505 個）は、今回の条件に当たるものがなく、結果は変わらない。
