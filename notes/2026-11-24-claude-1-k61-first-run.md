## 命題 K61 `[非形式証明]`

族 q·a + r = s·2^N（r = ±1、q, s 奇数、a > 0 奇数）、m = 3a − 2、h = (3a − 1)/2 とし、β₀ = 3r + q ≠ 0、v = v2(β₀) < N とする。

ブロック i（g_0..g_{i−1} = m+2）での h の値は、次のように計算できる。

- ブロック 0（K3）から、h の鎖を i 回の奇数の段だけたどる。
- 奇数の点では b を T(b) = (b + 3r)/2^{v2(b+3r)} で進める。
- 奇数の段の後の E = K + t が N + v2(c) に達したら、補題 K59.1 の r = ±1 版で新しい鎖に移る。
  - E = N + γ：u = v2(r b′ + q c_o s)、c′ = r c_o s、K′ = u。
  - E > N + γ：c′ = r c_o s、K′ = 0、β′ = 2^{E−N−γ} b′ + q r c_o s。
- 最後に終点の v2 の偶奇（K3）と段数の偶奇で値を決める。
- 奇数の点で d = h − 1、または (M + d)/2 > m なら、そこで O 型ブロックの規則どおり値を決める。

よって、先頭の m+2 の連の長さ（最初に g_i = m+1 となる i）は、この計算で決まる。

**証明**：

- 越えない区間は命題 K57 と同じ。
- 越える場面は補題 K59.1 の r = ±1 版と同じ。恒等式 r(αa − c) = βa − cs·2^N に v2 を当てると、新しい鎖の (α′, c′, K′) が整数で得られる（1/r = r による）。
- 奇数の点の距離は d = (ba − cs·2^{N−K})/r で、具体的な N なので例外の判定はそのまま数で行う。∎

## 結果（`data/k61_first_run.txt`）

505 族のすべてで、予測した先頭の連の長さが実際と一致した。

- r = ±1 の族：362 個、すべて一致。そのうち 162 個は、鎖が N を越える場面を通った。
  - 例：K34（5:1:3:41）で 38 = 2R、K58（5:1:7:43）で 22 = R + 2、K60 の N ≡ 1 類（29:1:15:85）で 42、K33（1:−1:3:21, 23）で 20, 22。
- **観察**：r ≠ ±1 の族（定理 K47 の形で r = 5, 21, 85, …）でも、143 個がすべて一致した（ほぼすべてが越える場面を通る）。
  - ただし、越える場面の新しい鎖の式は 1/r = r を前提にしていて、一般の r では導いていない。一般の r で一致する理由は分かっていないので、命題は r = ±1 に限る。
