### 主張ごとの査読結果

#### 1. 定理 K14（25〜31、48〜115 行）：**正しい（最後まで確認した）**
- **準備（50〜75 行）**：
  - `w ≠ 1`：`w = 1` なら `Q_k = h + 1 = (4^k + 2)/3` で `4^k + 2 ≡ 2 (mod 4)` より `v2(Q_k) = 1`（奇数）となり `q` 偶数に矛盾。よって `w ≥ 3`、`3h+1 = 4^k w ≥ 48` より `h ≥ 16`。
  - `(iii)` の対象：`h − 1 = 2^i w N`（`N` 奇数、`i ≥ 1`）なら `3·2^i w N = 4^k w − 4 ⇒ w | 4 ⇒ w = 1` で矛盾。調べる偶数 `e_i` と `2^i w_t`（`w_t = w(2^{2k−t}+1)`、`2k−t ≥ 2` より `2^{2k−t}+1` 奇数）はすべてこの形ゆえ `(iii)` 非該当。
  - 記号と範囲（`1 ≤ t ≤ 2k−2`, `h ≥ 16`）：`f_t = h + e_t ≤ h + (3h+1)/4 ≤ m`（`h ≥ 5`）、`c_t = e* + e_{t−1} = 2^{t−1} w_t ≤ 5(3h+1)/8 ≤ m`（`h ≥ 13`）、`Y_t = (m+2+w_t)/2 = Q_k + 2^{2k−t−1} w ≤ m ⇔ w_t ≤ 2h−3`（`w_t ≤ 9(3h+1)/16 ≤ 2h−3 ⇔ h ≥ 12`）。すべて `1..m` に収まる。
  - `(ii)` の `e` 値：O 型で `f_t → c_t`、`w_t → Y_t`；E 型で `e_i (2 ≤ i ≤ 2k−1) → f_{i−1}`（`1 ≤ i−1 ≤ 2k−2` に収まる）。正確。
- **ブロック 0〜4（72〜115 行）**：
  - `w ≥ 3 ⇒ m ≠ 9` より定理 K12″ (b) で `g₀ = g₁ = m+2, g₂ = m+1`、E 型より `h ∈ S₃ ⇒ g₃ = m+2`、O 型より `g₄ = m+2 ⇔ h ∈ S₄ ⇔ e* ∉ S₃`。
  - `f_t ∈ S₂`（`1 ≤ t ≤ 2k−2`）：ブロック 1 で `w_t ∈ S₁ ⇔ v2(Y_t)` 奇数、`t−1` 回 2 倍で `c_t ∈ S₁ ⇔ v2(Y_t) + t` 偶数、ブロック 2 で `f_t ∈ S₂ ⇔ c_t ∉ S₁ ⇔ v2(Y_t) + t` 奇数。`q = 0` なら `v2(Y_t) = 0` より `f_t ∈ S₂ ⇔ t` 奇数；`q ≥ 2` で `t = 2k−2` なら `Y_{2k−2} = Q_k + 2w` は `v2 = 1` で `1 + (2k−2)` 奇数より `f_{2k−2} ∈ S₂`。
  - ブロック 3（E 型）：`q ≥ 2` は `f_{2k−2} ∈ S₂` より `e* = e_{2k−1} ∉ S₃ ⇒ g₄ = m+2`。`q = 0` は基底 `i = 2`（`f₁ ∈ S₂ ⇒ e₂ ∉ S₃`）から帰納法で `2 ≤ i ≤ 2k−1` にわたり `e_i ∈ S₃ ⇔ i` 奇数、よって `2k−1 ≥ 3`（奇数）で `e* ∈ S₃ ⇒ g₄ = m+1`。誤り・穴なし。
