# 鎖と評価木の記号的な評価器：定理 K58・K33・K34 の 1 段の記号的な評価

## やったこと

- 定理 K58 への査読（PR #354）で、「40 個の N での形の比較だけでは定理 K36d″ の基準に届かない」と指摘された。
  - K58 と K33 には、手で記号的な証明を追記した（PR #348、#352 のブランチ）。
  - K34 は自明でない事実が 34 個、鎖が 15 本あり、手では誤りやすい。
- そこで、帰納法の 1 段を R の 1 次式のまま評価するプログラム `code/chain_symbolic.js` を作った（`data/chain_symbolic.txt`）。

**前提**：H(j)、K3、補題 Q_n、補題 K33d（査読済み）、定理 K47 の鎖の記述（査読済み）、補題 K59.1（査読済み）。

## 評価器の中身

- **記号**：N = n1·R + n0（R は十分大きい整数、偶奇だけ固定）。距離は (αa − c)/2^K（α, c, K は具体的な整数）で、β = rα + qc とすると恒等式 r(αa − c) = βa − cs·2^N。
- **E 型ブロック**：E 型の規則で評価する。
  - 奇数は入る。v2 = 1 は入らない（補題 K33d）。
  - それ以外は「d/2 が入らず、かつ h + d/2 が 1 つ前のブロックで入らない」。第 1 項が入るなら第 2 項は評価しない。
  - 周期の始まり B では、v2 ≥ 2 の距離は帰納法の仮定で決める。
- **O 型ブロックの鎖**：奇数の点の b を T(b) = (b + 3r)/2^{v2(b+3r)} で進め、K と段の数は R の 1 次式で持つ。
  - b が不動点（t = 1, 2）にとどまる区間は、越える直前か鎖の終わりの直前まで一度に進める（区間の長さは R の 1 次式）。
  - 越える場面は補題 K59.1 の r = ±1 版で扱う。c が偶数（v2(c) = γ）なら、越える基準を N + γ とし、c を c/2^γ に置き換える。
- **鎖の条件**：各奇数の点で 0 < d ≤ 3a − 4 を、a の係数で確かめる。
  - 不動点の区間では、区間の始めと極限の係数で確かめる。係数は K について単調。
  - 極限の係数が 3 の場合は、区間の終わりで N − K ≥ 1 + t から d ≤ 3a − 4 を確かめる。
  - d = h − 1 ちょうど（係数 3/2、定数 −3/2）なら、O 型ブロックの規則でその距離は入らないので、鎖の値はそこで決まる。
- **評価する対象**：
  - 各 E 型ブロックでの h と、次の周期の始まり L での仮定の各距離。
  - 各連（E 型ブロック X から長さ ℓ）の中の h の鎖。長さ 1, 2, 3、R − 1..R + 3、ℓ − 2, ℓ − 1, ℓ（ℓ 以下のもの）で評価し、ℓ だけが「入らない」ことを確かめる。

## 結果（`data/chain_symbolic.txt`）

4 つの族（K58、K33 の e ≡ 1 と e ≡ 3 (mod 4)、K34）のすべてで、失敗なしに評価が終わった。

- E 型ブロックでの h の値が周期と一致し、仮定が L で再現された。
- 連の中の h の鎖は、評価した長さのすべてで、連の最後だけが「入らない」だった。
- **K34**：E 型ブロックは B、E1..E4、L。仮定 2(a − 3) ∉ S_B と 3(a − 3) ∈ S_B が L で再現された。
  - 評価した鎖は 38 本（連の中の h の鎖を含む）、自明でない E 型の事実は 34 個。
  - 34 個の事実の値は、数値の評価（`data/k34_shapes.txt` の N = 41）とすべて一致した（名前の対応：数値の評価の「B」「E5」は L）。
  - K34 では、鎖の途中でちょうど d = h − 1 になる点があり、評価器はこれを規則どおり扱った。数値の評価で「O 型ブロック（例外で止まった）」と表示されていた鎖である。
- **K58、K33**：手で追記した記号的な証明（PR #348、#352 のログ）と、同じ値になった。

### 定理 K34 の証明についての意味

- K34 の 1 段の自明でない部分（E 型の評価木と、その中の鎖）は、評価器により R の 1 次式のまま評価された。R は十分大きい奇数。
- 連の中の h の鎖は、不動点の区間の一括処理と同じ理由で、評価した長さの間では値が変わらない。b = 1、t = 2 の区間では、段数の偶奇が長さによらない。
- よって定理 K34 は、形の比較（PR #350）ではなく、記号的な評価によって成り立つ（`[非形式証明]`、計算機による記号的な評価を含む）。

**残る点**：

- 「R が十分大きい」の具体的な下限は、評価器では出していない（不動点の区間の長さが正になる、などの条件）。
- prove3 による確定（K34 は 21 ≤ N ≤ 401、K58 は 23 ≤ N ≤ 399、K33 は e ≤ 399）が、小さい N を覆っている。

## 途中で直したこと

1. 極限の係数が 3 の不動点（K58 の b = 3、K33 の b = −3）を「範囲外」としていた。区間の終わりでも d ≤ 3a − 4 が成り立つ場合を正しく判定するようにした。
2. 連の中の h の鎖を評価していなかったので、加えた。
3. c が偶数の入口（K58 の鎖 2 など）で、越える基準を N のままにしていた。N + v2(c) に直した。
4. d = h − 1 の例外を、鎖の条件の違反として扱っていた。O 型ブロックの規則どおり、値を決めるように直した。
5. E 型の規則の第 1 項が入るときにも第 2 項を評価していたため、K34 で仮定にない距離を求めていた。第 2 項を評価しないように直した。
