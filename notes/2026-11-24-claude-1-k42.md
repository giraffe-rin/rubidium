# 定理 K42：v2(m+1) が偶数（≥ 2）の m の状態のくりこみ

## やったこと

- `data/state_period_even.txt`（`notes/2026-11-24-claude-1-state-period-even.md`）で、v2(m+1) が 2 以上の偶数の奇数 m の状態の周期を見た。周期は u = (m+1)/2^v だけで決まり、偶数 m' = u − 1 の状態の周期と同じに見えた。
- `code/k42_renorm.js` で、v = 2, 4, 6、奇数 u ≤ 101 の 50 個について、λ(2^v u − 1) と λ(u − 1) を比べた（`data/k42_renorm.txt`）。すべて一致し、前周期はどれも 0 だった。
- これを手で証明した。証明の 2 つの段階を、`code/check_k42.js`（`data/k42_check.txt`）で照合した。

**前提**：主張 H(j)（規則 R、間隔の規則）と定理 K3（gemini-2 が PR #111 で `[査読済み]`）。定理 K41（`notes/2026-11-24-claude-1-k41-proof.md`、未査読）は (3) でだけ使う。

## 結果

### 定理 K42 `[非形式証明]`

m を奇数とし、v := v2(m+1) は 2 以上の偶数、u := (m+1)/2^v（奇数）、m' := u − 1（偶数）とする。すべての j ≥ 0 について次が成り立つ。
- (1) g_j = m + 1。
- (2) v2(d) ≤ v − 1 の 1 ≤ d ≤ m について、d ∈ S_j(m) ⇔ v2(d) が偶数。
- (3) 1 ≤ d' ≤ m' について、2^v d' ∈ S_j(m) ⇔ d' ∈ S_j(m')。

1 ≤ d ≤ m で v2(d) ≥ v の d は、ちょうど 2^v d'（1 ≤ d' ≤ m'）の形である（2^v d' ≤ 2^v u − 1 ⇔ d' ≤ u − 1）。よって、m の状態は m' の状態から決まる。

### 系 K42b

- m の R の状態は、m' = u − 1 の状態とブロックごとに 1 対 1 に対応する。
- 定理 K41 により、ブロック 1 から純周期的で、周期は λ(m) = λ(u − 1)。
- (1) から、開始局面の型は「間隔がいつも m+1」。これは定理 K4 の、v2(m+1) ≥ 2 の場合の別証明になる。

### 証明

j についての帰納法で、(1)(2)(3) を同時に示す。

**記号**：
- h = (m+1)/2 = 2^{v−1}u。v2(h) = v − 1 は奇数。
- n' := m' + 1 = u（奇数）。

**j = 0**：K3 により、d ∈ S_0(m) ⇔ v2(d) が偶数。
- (2) はそのまま成り立つ。
- (1)：v2(h) は奇数なので h ∉ S_0、g_0 = m+1。
- (3)：v2(2^v d') = v + v2(d') の偶奇は v2(d') の偶奇と同じなので、K3 による m' のブロック 0 と一致する。

**j ≥ 1**（j − 1 で成り立つとする）：(1) より g_{j−1} = m+1 なので、R の (iii) は起きない。(ii) は次のようになる。
- 奇数の d では、s = (m+1) + d は奇数なので起きない。
- 偶数の d では、e = (m+1+d)/2 = h + d/2 について、e ≤ m かつ e ∈ S_{j−1} のとき起きる。

- **(2)**：b = v2(d) についての帰納法で示す。
  - b = 0：(i)(ii) は起きないので入る。
  - 1 ≤ b ≤ v − 1：
    - d/2 の付値は b − 1。b についての帰納法により、[d/2 ∈ S_j] = [b − 1 が偶数]。
    - b − 1 < v − 1 = v2(h) なので、v2(h + d/2) = b − 1 ≤ v − 1。j − 1 での (2) により、h + d/2 ≤ m なら [h + d/2 ∈ S_{j−1}] = [b − 1 が偶数]。
    - よって [d ∈ S_j] = ¬[b − 1 が偶数] ∧ ¬[b − 1 が偶数] = [b が偶数]。h + d/2 > m のときも同じ。
- **(1)**：(2) を d = h（v2 = v − 1 は奇数）に使うと h ∉ S_j。H(j)(c) により g_j = m+1。
- **(3)**：d = 2^v d'（1 ≤ d' ≤ m'）とする。m' は偶数なので、m' の R は定理 K41 の証明の形になる。
  - 奇数の d' では [d' ∈ S_j(m')] = ¬[(u + d')/2 ∈ S_{j−1}(m')]。
  - 偶数の d' では [d' ∈ S_j(m')] = ¬[d'/2 ∈ S_j(m')]。
  - d' が奇数：
    - (i)：d/2 = 2^{v−1}d' の付値は v − 1（奇数）。(2) より d/2 ∉ S_j(m) なので、(i) は起きない。
    - (ii)：h + d/2 = 2^{v−1}(u + d') = 2^v·(u + d')/2。u + d' は偶数。
      - h + d/2 ≤ m ⇔ u + d' < 2u ⇔ d' < u は成り立つ。
      - j − 1 での (3) により、[h + d/2 ∈ S_{j−1}(m)] = [(u + d')/2 ∈ S_{j−1}(m')]。
      - (u + d')/2 ≤ u − 1 = m'（d' ≤ u − 2）。
    - よって [d ∈ S_j(m)] = ¬[(u+d')/2 ∈ S_{j−1}(m')] = [d' ∈ S_j(m')]。
  - d' が偶数：
    - (ii)：h + d/2 = 2^{v−1}(u + d')。u + d' は奇数なので付値は v − 1（奇数）。(2) より h + d/2 ∉ S_{j−1}(m) なので、(ii) は起きない。
    - (i)：d/2 = 2^v (d'/2)。ブロック j の中で d' についての帰納法（小さい d' から）により、[d/2 ∈ S_j(m)] = [d'/2 ∈ S_j(m')]。
    - よって [d ∈ S_j(m)] = ¬[d'/2 ∈ S_j(m')] = [d' ∈ S_j(m')]。
- これで j で成り立つ。∎

### 補足

- 「くりこみ」：v2(m+1) が 2 以上の偶数の m の全局面の表の周期は、偶数 m' = u − 1 の表の周期で決まる。m' の周期は、定理 K41 により、u を法として 2 を掛ける写像の軌道で決まる。
- 例：m = 2^v·51 − 1（v = 2, 4, 6）の状態の周期は、すべて λ(50) = 60。
- `notes/2026-11-24-claude-1-renormalize.md` で探して見つからなかった「くりこみ」（v2(m+1) = 1 の場合）とは違い、v2(m+1) が偶数の場合には、状態そのものの完全なくりこみがある。
