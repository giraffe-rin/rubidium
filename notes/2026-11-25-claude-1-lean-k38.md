# 定理 K38（v = 5）の Lean 4 での形式化

## やったこと

`lean/Rubidium/K38.lean` に、定理 K38 の v = 5 の場合を sorry なしで証明した。

```lean
theorem K38_v5 (m : Nat) (hm : m % 512 = 223 ∨ m % 2048 = 2015) (n : Nat) :
    IsP m n 0 ↔ (n % (4m+5) ∈ {0, m+2, 2m+3, 3m+4})
```

仮定の意味：m + 1 = 32u とすると、m % 512 = 223 は w = v2(u+1) = 3、m % 2048 = 2015 は w ≥ 6 と同じ。
公理は `[propext, Classical.choice, Quot.sound]`。

書く前に、主張を直接の DP で確かめた。m ≤ 6200 の対象 15 個すべてで、n ≤ 3(4m+5) まで一致した。

## 証明の組み立て

もとの証明（ノート 2026-11-24-claude-1-k38-proof.md）の補題 P_n・Inh′_n と事実 B を、v = 5 で局面の言葉にした。H(j) は使わない。
記号：h = 16u、e₁ = (33u+1)/2、L = 4m+5。行は a、b = a + (m+2)、c₁ = b + (m+1)、c₂ = c₁ + (m+1)、a' = c₂ + (m+1)。

**`Blk` の範囲を伸ばす補題**（K4 の形式化の `Blk m s r`：v2(d) ≤ s なら、(r + d, d) が P ⇔ v2(d) が偶数）
- `blk1_direct`：E 型の行では、奇数 d は P、v2(d) = 1 の d は N（手 d/2）。よって Blk m 1。
- `blk_step2`：s が奇数、t ≤ s + 2、t ≤ v2(h) のとき、Blk m s r' から Blk m t (r' + (m+1)) を導く。K4 の `blk_step` の変形。
  手 k = h + d/2 の行き先が P になりうる場合、v2(d/2) は奇数で s + 1 以下。s は奇数なので v2(d/2) ≤ s となり、1 つ前の行の Blk m s が使える。
- `blk_zero`：行 0 では、どの s でも Blk m s 0（K3）。

**`k38_step`**（1 周期分）は、次の順で示す。
1. 行 a：Blk m 4 a。よって (a + h, h) は P（v2(h) = 4）、奇数 d は P、(a + e₁, e₁) は P（v2(e₁) ∈ {2, 4}）。
2. 行 b（`row_long`）：
   - (b + u)・(b + 3u)・(b + 7u)・(b + 11u) は N。手 e₁・(35u+1)/2・(39u+1)/2・(43u+1)/2 の行き先が P だから。後ろの 3 つは、u ≡ 3 (mod 4) なので奇数。
   - 半分にする鎖（`p_two` と手 z）で、2u・8u・6u・24u・14u・22u は P、4u・16u・12u・28u は N。
3. 行 c₁（`row_next`、(b + 16u) が N）：Blk m 1。
   - (c₁ + h) は N（手 24u）。
   - (c₁ + 12u) は N（手 22u）。
   - (c₁ + 24u) は P（`e_even`：(c₁ + 12u) と (b + 28u) が N）。
4. 行 c₂（`row_next`）：Blk m 3（`blk_step2`）。(c₂ + h) は N（手 24u で (c₁ + 24u) に移れる）。
5. 行 a'（`row_next`）：Blk m 4（`blk_step2`）。

**`k38_rows`**：i についての帰納法で示す。i = 0 は `blk_zero` を使う。最後に n mod L で場合分けする。

## 意味

- 定理 K38 の v = 5 の場合が [Lean検証済み] の候補になった（査読待ち）。
- `blk_step2` は、一般の奇数 v の K38・K29 を Lean にするときにも使える。そのときは、E 型のブロックが (v+1)/2 個続くので、ブロックの個数を v に合わせて伸ばす帰納法が要る。
