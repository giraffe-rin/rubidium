## 記号

- N ≡ 6 (mod 8)、N ≥ 30、X = 2^N、a = (3X − 5)/17 とする。a は奇数で、17a + 5 = 3X。
- m = 3a − 2、M = m + 2 = 3a、h = (m+1)/2 = (3a−1)/2、n = (N−2)/4（奇数）とする。
- z = 3（N ≡ 6 (mod 24)）、z = 2（それ以外）、w = 1^n 0^z、L = n + z とする。
- a ≡ −5/17 (mod 2^N) なので、m + 1 = 3a − 1 の下位の桁は N によらない。v2(m+1) = 5、u = (m+1)/32 について v2(u+1) = 4。
- a ≡ 1 (mod 5)：17 ≡ 2、2^N ≡ 4 (mod 5) から。

## 定理 K44 `[非形式証明]`（計算機による部分を含む）

N ≡ 6 (mod 8)、N ≥ 30 なら、m の型は前周期なし・周期 1^n 0^z である。

系：v2(m+1) = 5、w = 4 の類の型は無限に多い。m+2 の間隔の極大な連の長さ n = (N−2)/4 が、N ごとに違うからである。

### 証明の枠組み

周期についての帰納法を使う。主張 P(t) は次のとおり。

- ブロック B = tL で、(G) が成り立つ：奇数の距離は入り、v2(d) ≤ min(2z−1, 4) の距離は「v2 が偶数 ⇔ 入る」。
- そのうえで h ∈ S_B（g_B = m+2）。

**t = 0**：K3 による。v2(h) = 4 は偶数なので、h ∈ S_0 である。

**P(t) ⇒ P(t+1)**：次の 3 つを示す。

1. h ∈ S_{B+i}（1 ≤ i ≤ n−1）、h ∉ S_{B+n}（補題 K44.1）。これで g_B, …, g_{B+n−1} = m+2、g_{B+n} = m+1 となる。したがって、ブロック B+1..B+n は O 型で、B+n+1 は E 型。
2. h ∉ S_{B+n+j}（1 ≤ j ≤ z−1）、h ∈ S_{B+L}（評価木、下記）。これで B+n+1..B+L は連続する z 個の E 型ブロックになる。
3. ブロック B+L は z 個目の連続する E 型ブロックなので、補題 Q_z により (G) が成り立つ。2 と合わせて P(t+1) が成り立つ。

### O 型ブロックの一本道

直前の間隔が m+2 のとき、R は次の一本道になる。

- 偶数 d が入る ⇔ d/2 が同じブロックで入らない。
- 奇数 d が入る ⇔ (M+d)/2 が 1 つ前のブロックで入らない。ただし (M+d)/2 > m なら入る。また、d = h − 1 なら入らない。

h − 1 は奇数（v2(h) = 4）なので、例外は奇数 d でだけ起こる。

### 補題 K44.2（鎖の記述）

奇数 c と整数 α、K について、d = (αa − c)/2^K と書き、β = 5α + 17c とおく。

- 17a + 5 = 3X から、次の恒等式が成り立つ。
  - 17·2^K d = 3αX − β
  - d = (βa − 3cX)/(5·2^K)
- よって v2(β) < N なら v2(d) = v2(β) − K。
- 一本道の 1 段の効果：
  - 偶数の段では K が 1 増える。
  - 奇数の段 d → (M+d)/2 では α → α + 3·2^K、β → β + 15·2^K、K → K + 1。

**入口**：d₀ = c(3a−1)/2^k（c 奇数、k ≤ 5）のとき、α = 3c、β = 32c で、v2(β) = 5。

- まず 5 − k 回半分にする（偶数）。
- K = 5 で奇数の点に着く。そこでは β = 2^K b、b = c。

**奇数の点から次の奇数の点まで**：

- 1 段目（奇数の段）で β = 2^K(b + 15)、K + 1 になる。
- 続いて r(b) − 1 回半分にする（r(b) = v2(b+15)）。
- 次の奇数の点では b' = T(b) = (b + 15)/2^{r(b)}。

**鎖の結果**：ブロック B+j から入ると、奇数の段は j 回で、ブロック B に着く。

- 着いたときの v2 は r(b_j) − 1。
- 段数は s = (5 − k) + j + Σ_{i<j}(r(b_i) − 1)。
- 結果は「終点の値（(G) による）」を s 回反転したもの。

**条件**（各奇数の点で確かめる）：

- (a) v2(β) < N。
- (b) (M+d)/2 ≤ m。奇数の点で d = (ab − 3c·2^{N−K})/5 < ab/5 なので、b ≤ 13 なら成り立つ（(3a + 13a/5)/2 < 3a − 2）。
- (c) d ≠ h − 1。d = h − 1 とすると (2b − 15)a + 15 = 3c·2^{N−K+1}。a ≡ −5/17 (mod 2^N) を代入して 17 倍すると 330 − 10b ≡ 0 (mod 2^{N−K+1})、つまり 165 − 5b ≡ 0 (mod 2^{N−K})。ところが 0 < 165 − 5b < 2^8 なので、N − K ≥ 8 なら起こらない。b ≤ 7 なら大きさからも起こらない（d < 7a/5 < h − 1）。

T の軌道：{1}（r = 4）、{5}（r = 2）、{3, 9}（r = 1, 3）、{7, 11, 13}（r = 1, 1, 2）。どれも純周期的で、b ≤ 13。

### 補題 K44.1（ブロック B+i での h）

h = 1·(3a−1)/2^1 なので、c = 1、k = 1、b ≡ 1、r = 4。

- 奇数の点の K は 5, 9, …、v2(β) は最大で 5 + 4i。
- 1 ≤ i ≤ n − 1 の場合：
  - 5 + 4i ≤ N − 1 < N で、条件 (a) を満たす。b = 1 なので (b)(c) も満たす。
  - 終点の v2 は 3 で、3 ≤ min(2z−1, 4) なので (G) で決まり、入らない。
  - s = 4 + i + 3(i − 1) = 4i + 1 は奇数なので、h ∈ S_{B+i}。
- i = n の場合：
  - ブロック B+1 での奇数の点は K = 4n + 1 = N − 1 で、まだ v2(β) = K < N。
  - 最後の奇数の段で β = 2^{N+3}、K = N となり、恒等式から終点 d = (8a − 3)/5 を得る。これは整数（a ≡ 1 (mod 5)）で奇数なので、(G) により入る。
  - s = 4n + 1 は奇数なので、h ∉ S_{B+n}。∎

### E 型ブロックの評価木（`code/k44_symbolic.js`）

ブロック B+n+j（j = 1..z）での h を、E 型の規則で評価する。E 型の規則：

- 奇数 d は入る。
- 偶数 d は、「d/2 が入らず、かつ e = h + d/2（≤ m のとき）が 1 つ前のブロックで入らない」とき入る。

**記号的に扱えること**：

- 現れる距離は (Pa + Q)/2^K で、P, Q, K は N によらない（K ≤ 5）。
- 偶奇は a mod 2^30 で決まる（N ≥ 30）。
- e ≤ m の判定は、a ≥ (3·2^30 − 5)/17 のすべてで同じ答えになる（スクリプトが確かめる）。

**O 型ブロックへ入るところ**（j = 1 で 1 つ前がブロック B+n）：

- 入口は、すべて c(3a−1)/2^k の形。c は 9, 5, 3, 11, 7（z = 2 で N ≡ 14 (mod 24) のときは 9, 5, 3, 11）。
- 鎖の結果は補題 K44.2 で決まる。
- c ≥ 3 の軌道では r の平均が 2 以下なので、v2(β) ≤ 5 + 2n + 2 < N で条件 (a) を満たす。
- 奇数の点の K ≤ 2n + 7 なので N − K ≥ 2n − 5 ≥ 9 で、条件 (c) も満たす（n ≥ 7）。
- 終点の v2 は r(b) − 1 ≤ 2 なので、(G) で決まる。

**鎖の結果が n mod 6 だけで決まること**：

- b_j は j mod ℓ で決まる（ℓ は軌道の長さで、1, 2, 3 のどれか）。
- s(j+6) − s(j) = 6 + (6/ℓ)·S_ℓ（S_ℓ は軌道 1 周での r − 1 の和）は偶数になる。ℓ = 1, 2, 3 のそれぞれで 6S、3·2、2S だからである。
- n mod 6 は N mod 24 で決まる：N ≡ 6, 14, 22 なら n ≡ 1, 3, 5 (mod 6)。

**結果**（3 つの類のそれぞれ）：

- E 型ブロックでの h の列は 001（z = 3）、01（z = 2）で、w[n+1..L] と一致する。
- 評価木の事実の数は 29、16、16。
- 照合：N = 30, 38, …, 1006 の 123 個のそれぞれで、評価木の全事実が実際の a での数値評価と一致した。

以上で P(t) ⇒ P(t+1) が示され、定理 K44 が従う。∎
