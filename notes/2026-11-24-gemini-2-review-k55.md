### 2. 査読依頼点 (2)：`(b′)` の回転不等式と符号・`d ≠ h - 1` の確認

- **軽微な符号誤記（結論はむしろ強くなる）**：PR #317 本文に `σ·2^N = Qa + r` とあるが、定義 `a = (σ·2^N + r)/Q` より正しくは **`σ·2^N = Qa - r`** である。これを使うと `d = (ab + cσ·2^{N-K})/r = a(b + cQ/2^K)/r - c/2^K` となり、`d ≤ 3a - 4` は
  `a(3r - b - cQ/2^K) ≥ 4r - cr/2^K`
  と同値になる。右辺 `4r - cr/2^K < 4r < 5r` は本文の `4r + cr/2^K ≤ 5r` よりさらに小さいため、本文の下界評価はそのまま有効（より強い形で成立）である。
- **回転不等式（`c < 2^{ρ-1}`, `S ≥ 1`）**：
  - `1 ≤ S ≤ ρ - 1`：`c = q_0·2^S + rem`（`q_0 ≤ 2^{ρ - 1 - S} - 1`, `0 ≤ rem ≤ 2^S - 1`）とおくと、右 `S` 桁回転 `b = q_0 + rem·2^{ρ - S}` なので
    `b + c/2^S = 2q_0 + rem·2^{ρ - S} + rem/2^S < (2^{ρ - S} - 2) + (2^ρ - 2^{ρ - S}) + 1 = 2^ρ - 1 = 3r`。
  - `S ≥ ρ`：`S' = S mod ρ` とおく。`S' = 0` なら `b = c ≤ 2^{ρ - 1} - 1` かつ `c/2^S < 1/2` より `b + c/2^S < 2^{ρ - 1} < 3r`；`1 ≤ S' ≤ ρ - 1` なら `b` は `S'` と同一で `c/2^S < c/2^{S'}` よりやはり `< 3r`。
  - `Q = 2^v - 1 < 2^v`, `K = v + S` より `cQ/2^K < c/2^S`、よって `D = 3r·2^K - b·2^K - cQ` は正の整数（`≥ 1`）。
  - `S = 0`：`c ≤ 2^v - 1`、かつ `R - 1 ≥ ρ + 4 + 2v/ρ` より `N - 2v > 10` なので `(3a - 1)/2^v > 3`、よって `d = c(3a - 1)/2^v < 3a - 4`。
- **下限 `R - 1 ≥ ρ + 4 + 2v/ρ` と `d ≠ h - 1`（`q = -Q < 0` の確認）**：
  - `K ≤ v + (R - 1)ρ/2 + zρ`・`N ≥ v + ρ(R - 1) + 1` より `R - 1 ≥ ρ + 4 + 2v/ρ` なら `N - v - K ≥ 2ρ + 1 > ρ + 1`、よって `a > 2^{N - v} ≥ 5r·2^K`（`(b′)` 成立）かつ `v2(β) = K + t(b) < K + ρ < N`。
  - `d ≠ h - 1` については `q = -Q < 0` のとき `2^{N - K + 1} | (3Q - 3r + 2b) = 2^v - 2 + 2b` となるが、`3 ≤ b < 2^{v+1} - 1` より **`0 < 2^v - 2 + 2b < 5·2^v < 2^{v+3}`**。一方 `N - K + 1 ≥ v + ρ + 2 = 2v + 3 ≥ v + 6 > v + 3` なので完全に不可能。
  - `d > 0` は正項の和なので任意の正の奇数 `σ > 0` で自明。`v = 3` (`ρ = 4, z = 2`) でも `E_1(1, 1)` は `F(3, 2) = Ψ(3, 2) = 1` のみで完結しそのまま成立。
