## 確立した結果
（`[査読済み]` または `[Lean検証済み]` のものだけをここに書く）

- **定理 K47（偶数 `w ≤ v - 1` のすべての類で間隔列・前周期を含む型は無限に多い）** `[査読済み]`（査読者：gemini-2、PR #283、根拠：`notes/2026-11-24-claude-1-first-run.md`、`notes/2026-11-24-gemini-2-review-k47.md`、`data/gemini2_verify_k47.txt`）：奇数 `v ≥ 3`、偶数 `2 ≤ ρ ≤ v - 1`、`q = 2^v - 2^ρ + 1`、`r = (2^ρ - 1)/3`、偶数 `N ≥ v + ρ + 1`、正の奇数 `s`（`q | s·2^N - r`）に対し `a = (s·2^N - r)/q, m = 3a - 2` は `v2(m+1) = v, w = v2(u+1) = ρ` かつ間隔列先頭 `m + 2` 連長 `R = ⌈(N - v)/ρ⌉`。独立 K8 遅延評価で 1,323 例＋非最小 `s` 60 例および `PROBLEM.md` 全探索照合でエラー 0（※ 周期部分のみの無限性は別問題）。
- **定理 K47b（`w = v` の類で間隔列・前周期を含む型は無限に多い）** `[査読済み]`（査読者：gemini-2、PR #285、根拠：`notes/2026-11-24-claude-1-w-equals-v.md`、`notes/2026-11-24-gemini-2-review-k47.md`、`data/gemini2_verify_k47.txt`）：奇数 `v ≥ 3`、`Q = 2^v - 1`、`r = (2^{v+1} - 1)/3`、偶数 `N ≥ 2v + 2`、正の奇数 `σ`（`Q | σ·2^N + r`）に対し `a = (σ·2^N + r)/Q, m = 3a - 2` は `v2(m+1) = v, w = v2(u+1) = v` かつ先頭 `m + 2` 連長 `R = ⌈(N - v)/(v + 1)⌉`。独立 K8 遅延評価で全 1,080 例＋非最小 `σ` 20 例および `PROBLEM.md` 全探索照合でエラー 0。これにより定理 K29・K38 と合わせて `v ≥ 5` の全 `w` 類の有限/無限（前周期を含む型）の二分が完成。
