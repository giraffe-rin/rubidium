## 予想・未査読の結果
（`[予想]` には確かめた範囲を、`[非形式証明]` には証明の場所を書く）

記号：v2(x) は x を割り切る 2 の最大べきの指数、h = (m+1)/2（m が奇数のとき）。「A 行」はすべての p で (r, p) が P になる行。

- `[予想]` K4：m ≥ 2 のとき、「(n, 0) が後手必勝 ⇔ (m+1) | n」⇔ v2(m+1) が偶数。
  範囲：2 ≤ m ≤ 100, n ≤ 10000（全探索）。m ≤ 200 の全 n は漸化式 R 経由（R も予想）。根拠：`notes/2026-11-23-claude-1-conjectures.md`
- `[予想]` K1：m ≥ 2 で、どの行でも P になる p は「全部」「1 つ」「なし」のどれか。
  範囲：2 ≤ m ≤ 100, r ≤ 10000。根拠：同上
- `[予想]` K2：A 行の間隔は m+1 か m+2。A 行 a からの距離 d の行の P 局面は (a+d, d)（d ≤ m）か (a+m+1, h) だけ。
  範囲：2 ≤ m ≤ 100, r ≤ 10000。根拠：同上
- `[予想]` K3：1 ≤ r ≤ m で、(r, p) が P ⇔ p = r かつ v2(r) が偶数。範囲：r ≤ m ≤ 1000。根拠：同上
- `[予想]` K5：v2(m+1) が奇数（m ≥ 2）なら、最初の後手必勝の開始局面は n = m+2。範囲：m ≤ 100。根拠：同上
- `[予想]` K6：m ≡ 5 (mod 8) なら、(n, 0) が後手必勝 ⇔ n ≡ 0 または m+2 (mod 2m+3)。
  範囲：m ≤ 100, n ≤ 10000（全探索）、m ≤ 200（R 経由）。根拠：同上
- `[予想]` K7：開始局面列は周期的。2 ≤ m ≤ 200 では m = 55, 95 を除いて純周期的（m = 55, 95 には前周期あり）。根拠：同上、`data/block_periods_m2-200.txt`
- `[予想]` K8（ブロック漸化式 R）：表全体が、直前のブロックだけから決まる漸化式で書ける。
  範囲：2 ≤ m ≤ 100, r ≤ 10000 の全局面で全探索と一致。式と根拠：同上
- `[予想]` C1〜C7（m ≤ 30 での周期・間隔・小さい m の全局面）：根拠 `notes/2026-11-23-claude-1-solver.md`。
